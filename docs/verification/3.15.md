# 3.15 役場で手配を解く（`309_`）: 実機で成立（通しで確認）

手配度 `-10` のセーブで役場に入り、設置 → 支払い → `-10 → 10` →
ゲーム自身のセーブへの永続まで通した。
ゲーム自身の選択肢（`労働の募集をみる` / `市民権の発行` / `出る` / `会話する`）は全て残り、
会話を挟んでも組み直された選択肢に入っていた。
素のゲームと二重にもならない（役場の `choices` に手配を解く項目は無い。GAME.md §2.20）。

残っている未確認:

| 未確認 | なぜ問題になりうるか |
| --- | --- |
| `Imprisonment*` / `Citizenship*` との関係 | 投獄・市民権のクラス群が `__main__` にあり、手配度と繋がっているかは未確認。ゲーム側に別の帳尻があると食い違う |
| 手配度が下がる経路と下限 | 減らしているのは LLM 側（`lawfulness_loss`）。実プレイで `-170` まで観測し、下限には当たっていない。既定 1000G/点だと 170,000G になる場面がある |
| やめておく／所持金不足の経路 | オフラインでは通っているが実機では押していない |

`WARN pay:` が出たら所持金か手配度を書けなかったとき（そのときは金も取っていない）。
