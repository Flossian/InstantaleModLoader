# 2.53 ゲーム自身の衛兵とぶつかった（`316_`）

同じ夜の `BattleStartManager` 11回のうち2回がゲーム自身の衛兵（呼び出し元が
`on_button_press`）。ゲーム側も同じ操作から衛兵を出すので、追手が先に動くと潰れる。

直したのは3点。効いたのは3つ目で、それまで**時間で**差し替えを開けていたため、
その窓の中でゲームが出した衛兵まで強くして改名していた。

| 手 | 何をするか |
| --- | --- |
| 一拍待つ | 出すと決めてから間を置き、何か始まっていたら降りる |
| 出た後は控える | ゲームが衛兵を出したらしばらく追手を出さない |
| 取り違えない | 差し替えと改名を**自分が組んだマネージャの `start_battle` の中だけ**に閉じる |

同じ記録で、**逃げて終わった回の手配度の戻しを取りこぼしていた**ことも分かった。
下がる時機は一定ではない（終わりの5秒後の回と、それより後の回がある）。
