# 2.30 シーン記述エンジンは普通の施設でも走る（成立）

使い捨ての実験 mod で宿屋に 16 ステップを通した。
エンジンは `facility_type` を見ておらず、`program_id` を渡せばどの施設でも走る
（§2.29 で制約として数えていた「`free` 施設は3つしか無い」は制約ではなかった）。
MOD からマネージャを起こすのは `ui.Screen.start_phase` → `process_choice` にそのまま乗る。
`lint_program` の戻り値は指摘の `list` で、空なら合格。

いちばん大きい収穫は**セーブを汚さずに済むこと**。
`_lookup_program` を包んで自前のプログラムを返せばよく、
プログラム自体は世界に書かない。
ただし `flag_set` を1つ使っただけで宿屋の `config` に `free_flags` が生え、
これはセーブに残って MOD を外しても消えない。
包む方式なら分岐の前提をプログラムに焼き込めるので `flag_set` 自体が要らない。
詳細は GAME.md §2.21.3。
