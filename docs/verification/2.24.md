# 2.24 `111_` プロンプトの置換（移植後、全プロバイダで決着）

## 移植で効いた差: プロキシは JSON にした後のボディを見ていた

| プロキシが見ていたもの | プロセス内で見えるもの | 対応 |
|---|---|---|
| `\n`（2文字）／`\uXXXX` | 本物の改行／生の文字 | 置換後は必ず復号。置換前は素の形と復号形の両方を登録 |
| .NET の `$1` / `${名}` / `$&` / `$$` | Python の後方参照 | 読み替える。存在しない番号は警告して文字列扱い |
| 1秒の正規表現タイムアウト | Python の `re` に無い | 1秒以上かかったルールを以後捨てる |

## 実データでの照合

`output_data/` の 13,461 ファイル・51,897 メッセージ。
読み込み時の警告 0 件、26/27 グループが発火、置換が起きたメッセージ 16,636 件、
置換後も `105_` のスキーマ圧縮は素の状態と同数（8,859/8,859）。
残る1グループは `\n` 入りルールの素の形で、復号形の双子が当たっている
＝**復号が無ければ死んでいたルール**。

## 仕掛け先が5版で変わった（クラウド対応）

落とし穴は毎回同じ。
送信の入口を名指しで包むと、プロバイダが変わった瞬間に素通りする
（ローカルとクラウドはどちらか片方しか import されない。GAME.md §2.12）。

v1 はローカル3点 → v2 `any_server` → v3 gemini → **v4 `llm_manager:send_request*`**
（使われる送信モジュールからの from-import 別名）→
v5 で「無かった別名を5秒ごとに見張り、生えたら包む」を追加。
v4 が今の形で、`alias_scan` が同じ関数を持つ全モジュールを張り替えるので、
モジュール名を知らないまま全プロバイダに届く。

実機で4経路とも発火。
Gemini / OpenAI / Claude はそれぞれのプロバイダ名で `[REPLACE]` が出て、
**名指ししていないモジュールにも自動で届いた**。
ローカルは `chat` のみ ＝ 二重抽選の歯止めが実機で機能。
同じ回で v5 の見張りも発火し（注入の25秒後に late-armed）、
**別名の後生えはローカルでも起こる**ことが確定した。
未実測は Alibaba と任意 OpenAI 互換だけで、設計上は同じ別名を通る。

運用で2度踏んでいる。
**プロバイダを切り替えたら再注入**、
**注入の版は armed 行の形でしか見分けられない**。

残る限界は、境界で見えるのが呼び出し側の渡した `message` だけで、
`send_request` の中で足される部分（Gemini の `_schema_instruction`）には当たらないこと。

## ルールの見直し（コードは無変更）

全 59,447 メッセージに当て直して1行ずつ検分。
**既存29行は全ルールが存命**。
句点の直後に `- 項目:` や `【見出し】` が改行なしで続く形が20種類・延べ2,800件超残っていたので、
**列挙を正規表現3本に畳んだ**（箇条書き・見出し13名の whitelist・番号付きリスト）。

等価性は全メッセージで突き合わせて証明した。
改行以外の差 0、列挙が当てて正規表現が逃した箇所 0。
差の出た128メッセージは全て正規表現側だけが拾った正しい改行漏れ。
重さも 1.27s → 0.75s（グループ 54 → 30）と半減した。

手元のファイルには順序の罠が1つある。
`発言者名は不要です。【現在の状況】` の控えのリテラルは、
個人ルールより前に置かないと見出しの正規表現が当たらなくなる（`#memo:` に残した）。

## 効果で3種に分けて、効かない1種を無効化した

| 種類 | 効果の見立て | 扱い |
|---|---|---|
| ① 指示の書き換え（NPC改善・生成文言・要約） | モデルに依らず効く | 残す |
| ② JSON安定化（`True=>true` ほか4行） | **効かない**。ローカルは grammar が構造を強制し、クラウドは構造化出力をプロバイダが保証する | `#offtab:` で無効化 |
| ③ 誤字・改行漏れ | 保険。維持費3行・数十µs | 残す |

②は消さず `#offtab:`（実行時の費用 0）へ倒した。
構造化出力を保証しない任意の OpenAI 互換サーバーでは意味が戻るので、
`#tab:` に書き換えれば復活できる。
無効化後は同梱 26 グループ・手元 29 グループ。

未測定は③の実効果だけ（測るなら同じプロンプトを同じモデルへ A/B）。
