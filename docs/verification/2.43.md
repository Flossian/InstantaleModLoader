# 2.43 `output_data/` は `111_` 適用後が記録される（原因確定）

記録済みの実プロンプトと照合する検査が、途中の件数から落ちた。
食い違いは行末の1箇所だけで、原文の誤植が直っていた ＝ `111_` の同梱ルールそのもの。

`output_data/` に何が記録されるかが途中で変わっていた:

| 時期 | `111_` の仕掛け先 | 記録される姿 |
|---|---|---|
| 移す前 | `LlamaCppClient.chat`（ゲームのダンプより下流） | ゲームが組んだ素のプロンプト |
| 移した後 | `llm_manager` の `send_request*` 別名（上流。[§2.24](2.24.md) の v4） | `111_` が書き換えた後 |

`output_data/` を根拠に使う検査は、今後この前提で読むこと。
ゲーム内の動作は壊れていない（プロンプトを組む時点で当たる MOD が見るのは今も素の文）。
壊れていたのは照合に使っている資料の性格だけ。

対処は目印を行末に依存しない形へ変えたこと
（行頭だけで当てて行ごと差し替える）。
同梱ルール30本を各 MOD の目印と突き合わせて、当たるのはこの1本だけだと確認した。
