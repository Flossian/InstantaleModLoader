## 分かっていて直していないもの

- ローダの `state.other_playthroughs` は、主人公の名前に `.` が入ると（`Al` と `Al.Bob`）、同じ世界の別の主人公の控えを自分の周回の副ファイル（`<鍵>.cast.json` など）と見誤り、世界名だけの控えを移してしまう。わざとそういう名前を付けないと起きない
- `239_probe_game_flags` の見張り（クラスに置くデータデスクリプタ）は、MOD を外してもクラスに残る。値は素通しで遊びは変わらず、読み書きに関数呼び出し1段ぶんの費用が残るだけ
