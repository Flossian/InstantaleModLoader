# 3.110 主人公が逃げると仲間も一緒に戦闘から逃げる（`147_fix_party_flee`）: 依頼の戦闘・衛兵戦・闘技場（仲間2人）で実機成立・会話からの戦闘は仲間が加わらず出番が無い・逃げる手での勝ちは未

## 見つけたこと

2026-10-21、[§3.109](3.109.md) の実機の途中で本人が見つけた。
仲間2人を連れた衛兵との戦闘で「逃げる」が通ると、主人公だけが一覧（`app.party`）から外れて預かり（`app.escaped_member_in_battle`）に入り、仲間は戦い続けた。
画面には主人公の手番のボタン（攻撃・スキル・防御・発言する・逃げる）が並んだままだった（押した先は測っていない）。
GAME.md §2.10 の記録（10-06、追手3体と仲間2人。仲間が倒し切って勝ちで終わった）と同じ形。
MOD を全部切った素のゲームでは試していない。

ゲームは、一覧が空になったときに逃走で終える（`check_battle_end` が敵の一覧を空にして `BattleEndManager(app, 'escaped')`）。
その終わり方の中で預かりを全員一覧へ戻す。
主人公1人の闘技場では、外した時点で一覧が空になって終わる（GAME.md §2.10「逃げたときと倒れたとき」）。
預かりに入れた仲間もゲームが戻すことは、`334_colosseum_custom` が倒れた仲間を預けた回で見えていた（`fallen: escaped: … is back in the party`）。

## 決めた仕様

本人が決めた（2026-10-21）。

- 新しい修正の MOD（`147_fix_party_flee`）にする
- 主人公が逃げた手（`resolve_battle_effect` で主人公が新しく預かりに入った手）の直後に、一覧に残った仲間も預かりへ移す。終わらせるのも全員を戻すのもゲーム自身
- 審判の文は主人公の逃走しか書かないので、その手の地の文の後に「〈仲間〉も後に続いて戦いを離れた。」を1行出す（`handle_battle_situation` の後。通らない経路では `check_battle_end` の前）
- 逃げる手で敵も倒し切ったときは、ゲームが勝ちで終えて預かりを戻さない。`107_fix_battle_flag_stuck` が戻すが、入っていなくても仲間が消えないよう、戦闘の終わり方の後で、移した仲間が一覧に居なければ手で戻す
- 設定は無い

## 確かめたこと（オフライン）

`tools\tests\test_party_flee.py`（新しく15件）。仲間が預かりへ移って一覧が空になる・地の文の後に1行出る・逃走の終わり方でゲームが戻したら触らない・逃げるのに失敗した手と主人公が前から抜けている手と仲間のいない逃走では何もしない・3人なら「、」でつなぐ・戻さない終わり方では移した仲間を戻して預かりから外す・控えは使い切り。

## 確かめたこと（実機）

2026-10-21、テストワールド（仲間1人を連れた依頼のダンジョンの戦闘）。試した後は控えへ戻した。

| 場面 | 結果 |
| --- | --- |
| 依頼の戦闘で「逃げる」 | ✓ 1回目で通った。`the player fled; 95 (…) followed into escaped_member_in_battle` の後、ゲームが逃走で終え（`BattleEndManager.end_phase: the party is back`）、一覧は主人公と仲間に戻った。本文は審判の地の文 →「〈仲間〉も後に続いて戦いを離れた。」→ ゲームの「パーティは戦闘から離脱した。」→「パーティは合流した。」の順。旗 `in_battle` は下り、敵の一覧は空。画面はダンジョンの選択肢に戻り、右の欄に2人が並んだ（写真） |

2026-10-22、テストワールド（仲間2人。リュウ・ジーン）。試した後は控えへ戻した。

| 場面 | 結果 |
| --- | --- |
| 衛兵との戦闘（ミストル、手配度 -50 で見つかって「抵抗する！」）で「逃げる」 | ✓ 1回目で通った。`95 (リュウ), 104 (ジーン) followed` → `the party is back (['95', '104'])`。手配度は -50 → -60（ゲームが衛兵との戦闘で勝っても逃げても下げる 10。GAME.md の実測と同じ。この MOD は手配度に触れない） |
| 会話から入った戦闘（ギルドの冒険者に会話で斬りかかった） | ✓ この MOD の出番は無かった。戦闘は主人公と相手の1対1で、仲間は加わらない（`319_` の記録の手番が2人だけ）。1回目は審判が逃げ損ねと裁いて戦闘が続き、2回目で逃げて会話に戻った。パーティは3人のまま（`app.party` と `original_party`）、`escaped_member_in_battle` は空 |
| 闘技場（オーラムの円環、`331_` の施設）で「逃げる」 | ✓ 1回目で通った。2人とも預かりへ移って戻った。手配度はこの環境の `334_` の設定（逃げても手配されない ON）どおり 20 のまま。`334_` の撤退の扱いと重ならなかった |

本文の「パーティは合流した。」は仲間2人のとき2行出る（衛兵戦・闘技場とも）。ゲームの文で、この MOD は出していない。仲間の数だけ出るのかは確かめていない。

## まだ確かめていないこと

- 闘技場で `334_` の「逃げても手配されない」を切った形（素の手配度の下がり方と重ならないか）
