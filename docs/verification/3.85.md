# 3.85 選択肢の窓口（`choices`）と乗せ替え: 21 本を乗せ替え、押下まで実機で確認・残りは `check_mods` の決まり

ボタンの不具合が MOD を問わず続いたので、選択肢のボタンの扱いをローダの窓口に集めた（2026-10-06）。
決まりと作りは TECH.md §3.3.14、ゲーム側の事実は GAME.md §2.3。
きっかけは `336_` の5件（突き返された後のロード・裏の事務所のロード・死刑の判決の画面のロード・裁判のロード・盗品買取商の後始末）で、
どれも「ロードの途中は人物が 0 人」「MOD のボタンを押してもゲームは保存しない」のどちらかの抜けだった（§2.88）。

| 見たこと | 結果 |
|---|---|
| 包み | 起動の当て直しのたびに `choices: installed (generation …)`。1つの世代で1度 |
| 印の持ち越し | 裏の事務所で保存したセーブを読むと `restored the marks of 2 button(s) after the load`（裏の依頼掲示板・盗品を売る）。押すと掲示板の一覧が開いた |
| ロードの後の組み直し | 人物が揃った後に `after load: refreshed …` が1度。ローダの古い口（`ui.refresh_choices_after_load`）を止めても、336 の人物を見るボタンが毎回出た（§2.88） |
| 押下の振り分け | 衛兵の買収・裁判の介入・掲示板の押下が窓口を通って動いた。突き返された後にロードすると、窓口が「大人しく捕まる」の印を付け直し、裁判に贈賄の5年が付いた（懲役30年 → 35年） |

## 実機で見たこと（乗せ替えの後）

| 場面 | 結果 |
|---|---|
| ギルド | 冒険者の一覧に「冒険者を募集する」（`320_`）。会話の中に「この話から依頼を作る」「依頼を受ける（話を切り上げる）」（`301_`）。押すとその冒険者の依頼に絞った掲示板が開いた |
| 役場 | 「家を借りる・買う」（`330_`）・「施設の建設（出資）」（`331_`）。押すとそれぞれの窓口が開いた。戻ると2つの並びが入れ替わるのは、乗せ替える前のコードでも同じだった |
| 宿 | 「宿泊する(1週間)」が「出る」の前（`135_` / `315_`）。部屋の選択肢に名前と値段（`315_`） |
| 土地の移動 | 「新たな道を探す」（`325_`）。手段の画面に「徒歩(30日)」「馬車(1000G・7日)」（`314_`）と「危険な道を行く」（`307_`） |
| 戦闘 | 「スキル・防御」への改名、スキル一覧の「防御」、押すと `guard button pressed`（`319_`） |
| 裏の事務所・衛兵の買収・裁判 | §3.85 の上の表（`336_`） |
| 手配・所持金・同行者が要る押下 | `309_` の罰金、`314_` / `315_` / `332_` の断り、`302_` の別れ、`404_` のパーティー会話、`327_` の2回目の活動、`316_` / `334_` の組み直しの後の合図（VERIFICATION_LOG.md §2.90）。このとき直したのが2件: `309_` は店を出ても下りない `in_shopping` でボタンが出なかった（v1.14.0 から）、`314_` はロードした手段の画面に保存した時の運賃が出た。`404_` はスクリプトで名簿へ入れた仲間（会話を経ていないので別の機械のパスのまま）の立ち絵が白い板になったが、素の遊び方では起きず、発生が限られるので手当てしていない |

## 分かっていて直していないもの

- MOD のボタンだけでできた確認の画面（`309_` の「納める／やめる」、`302_` の「やめておく」、`330_` / `331_` の「やめる」）は、戻る先の画面をメモリにしか控えていない。その画面を出したままのセーブを読むと、窓口が印を付け直すので押下は届くが、戻る先が無く同じ画面のまま動けない。ただしゲームは MOD のボタンでは保存せず（GAME.md §2.3）、4本とも保存は元の画面に戻った後なので、その画面の上のセーブはできない。素の遊び方では届かず、実機で確かめられない（2026-10-06 のコードレビュー）
