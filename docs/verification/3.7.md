# 3.7 名前の消毒（`110_`）: 以後の見張り方

§2.15 で決着済み。
以後は `out/character_name.log` を時々見るだけでよい。

- `-- not touching` … 予約デバイス名か、消毒すると空になる名前（未観測の種類）。
  直すには名前を発明することになるので、その名前を控えて設計を決めること
- `(same string also in: ...)` … 名前と同じ文字列を持つ別の属性が居る。
  そこが表示や突き合わせに使われていないかを見る
- 世界名は対象外（入口が未調査）。起きれば `001_` が `WinError 123` として捕まえる
