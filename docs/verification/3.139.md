# 3.139 街ごとの依頼の難易度の範囲（開発中の `922_town_quest_difficulty`）を `318_area_difficulty_growth` に取り込む: ゲーム抜きの検査は通過・設定画面は一時フォルダ相手に組んで保存まで通過・実機は未

922 と 318 はどちらも「その街で引かれる依頼の難易度」を決める（922 は範囲、318 は育ち）。共有フックは `generate_random_quest`。
922 は未公開なので、移行の仕組み（`MERGED_MODS`）を通さず、318 の中へ移して 922 のフォルダを外した。
318 の題は「街ごとの依頼の難易度と上昇」に改めた。

| どこ | 変えたこと |
| --- | --- |
| `318_area_difficulty_growth` 版8→9 | 922 の本体を `town_bands.py`、範囲の表と式を `bands.py`（そのまま）、設定画面を `tool.py` として持つ。入口は育ちのフックの後に `town_bands.install` を呼ぶ（922 の頃と同じく、ゲームの関数を包む層が外側）。設定に `TOWN_BANDS_ENABLED`（既定は入）を足した。上限は 318 の `DIFFICULTY_LIMIT` 1つで、922 の同じ名前の設定は外した。窓口 `quest_bands` の持ち主は `318_area_difficulty_growth`。記録 `out\town_quest_difficulty.log` と控え `state\town_quest_difficulty\<世界名>.json` は 922 の名前のまま |
| `318_` の設定画面（新規） | `"tool"` を持つ MOD は宣言の設定も画面が引き受ける約束（`tools/gui.py` の `_edit_settings`）なので、タブを2つにした。「設定」は宣言の全項目（`modtool.Form`）、「街ごとの範囲」は 922 の画面。下の「保存」が両方を書く（`SettingsFooter` の `before_save` / `extra_dirty`）。範囲の上限は「設定」のタブの入力をその場で使う |
| 開発機の手元 | `load_order.local.json` から 922 を外した。`settings\mod_settings.json` の 922 の項（上限 100。318 と同じ値）を外し、`settings\gui.json` の窓の記憶を 318 の名前へ付け替えた |
| 検査 | `test_wip_town_quest_difficulty.py` を `test_town_quest_bands.py` に向け直して CI に入れた。`test_area_difficulty_growth.py` の偽の ctx は、同じ対象への2つ目のフックを外側に重ねる形にした（辞書の上書きで育ちのフックが消えていた） |

## 決めた仕様（再検討しない）

- 922 の設定画面には上限の欄が無く、GUI から 922 の上限を変える道が無かった（`"tool"` を持つと宣言の設定のダイアログが開かないため）。318 に入れたことで「設定」のタブから変えられる
- 控えの置き場は `town_quest_difficulty` のまま。設定画面は `modtool.world_store_path`（フォルダ名から番号を落とした名前を使う）を使わず、置き場を名指しする。318 のフォルダ名からは `area_difficulty_growth` になり、922 の頃の控えを見失うため
- 設定画面の未保存の判定は、範囲の入力を文字のまま比べる。上限で収めた値で比べると、上限を変えただけで範囲が変わったことになり、保存のたびに控えの範囲が上限で収め直される
- 範囲に変更が無いときは、保存しても控えを書かない（設定だけを変えた回に、空の控えを作らない）
