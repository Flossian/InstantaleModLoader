# 2.17 `109_` アイテム説明の自動リサイズ（実機で発火）

`max_lines=0` なので行数で切られているのではなく、
`text_size` の高さ 150 に入らない行が描かれていないだけ。
300px 幅・`font_size=27` で 72 文字が、実際に見えていた文字数と一致する。

修正後、`box_h` は 550 / 630 / 670 / 1300 と伸び、
短い説明の回は同じログに `box_h=500 (design 500)` で並ぶ ＝
「長い文だけ伸びる・普通のアイテムは 1px も変わらない」が実データで成立。
