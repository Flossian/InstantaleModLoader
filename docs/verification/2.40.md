# 2.40 空 `Literal[]` の原因確定（スキル0件の敵）

`203_` のトリップワイヤが `live_crashes.log` へ locals ごと残した。

| 分かったこと | 根拠 |
|---|---|
| 原因は**スキルを1つも持たない敵が敵ターンを迎えたこと** | `skills_literal_list` が len=0 のまま `Literal` へ渡っている |
| 第一容疑だった「敵候補0件」は否定 | `current_enemy_dict` は len=1 で埋まっている |
| 落ちるのは敵ターンの側だけ | `enemy_turn_separate` → `referee_npc`。プレイヤー側は別経路 |
| 相手は「戦うために作られていない NPC」 | HP 100 の街の住人。会話から戦闘に入ったときに出てくる型 |

再現手順は「スキルを持たない一般 NPC に会話から喧嘩を売り、相手のターンまで進める」。
[§2.18](2.18.md) で見た「`Literal` が消費に応じて減る」とは別筋（あちらは尽きたモデルを作らない話）。

修正は未着手。
要るのは「空なら `Literal` を組ませない」の1点だが、
空でない何かに差し替えるとその値を LLM が選んで返してくる。
ゲームがそれをスキル名としてどう扱うかを確かめてからでないと、
「落ちない代わりに存在しない技を使う敵」になる。
