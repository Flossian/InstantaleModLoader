# 3.115 依頼人の一覧と街の噂（`301_quest_from_conversation`・`336_crime_overhaul`）・窓口 `quest_clients`: ゲーム抜きで成立・実機は未

2026-10-25 に作った。
きっかけは2つ。会話の「依頼を受ける（話を切り上げる）」が、相手の依頼が無くても出ていた。片付けた依頼を NPC が知っている割合が低かった。

## 測ったこと（10-25。テストワールドとヴェスティアのセーブ、`out\quest_offer.log`）

- 依頼のデータには依頼人の id が無い。持っているのは `client_name` の文字列だけ（欄は `quest_title` から `quest_area_id` までの14個、両世界とも同じ）
- `client_name` は「役職・名前」「役職 名前」「役職名前」「名前」が混ざる（宿屋の店主・バルガス、鉱山監督官 ガリウス、商人エドワード、冒険者ギルド長）
- 名前の末尾で実在の人物と照らすと、テストワールドは 35 件中 20 件、ヴェスティアは 73 件中 27 件が誰かに当たった。
  ただし同名の別人が多い。テストワールドでは依頼人がエドワードの依頼が3件あり（考古学者の老人・司祭・漁師の老人）、拠点は 0・3・7 とばらばら。実在のエドワード（id 106）は拠点 7 にいる。
  ゼノは依頼2件に実在の3人が当たり、ヴェスティアのエレナは依頼5件（拠点 5〜7・0）が実在の1人に当たった。
  名前の一部で照らすと、片付けていない人物に「片付いた」と伝えることになる
- 名前の完全な一致で当たったのは、ヴェスティアの片付いた依頼 56 件のうち 8 件。6 件は `301_` で作った依頼（控えにも在る）、2 件は `336_` の裏の仕事（依頼人の欄に事務所の主の名前を入れている）
- 会話への差し込みは、`no completed quest for` が 635 回、`+N chars into profile` が 21 回だった。差し込んだ 21 回の相手は、どれも本当の依頼人（`301_` の控えに在るか、名前が完全に一致）。
  伝わらない理由は、片付いた依頼の大半に依頼人として実在の人物がいないことで、差し込んだ文をモデルが無視したことではない。差し込んだ後の返答で依頼に触れたかは数えていない

## 決めた仕様

| 項目 | 決めたこと |
| --- | --- |
| 依頼人の持ち方 | 依頼 id → 依頼人の人物 id の一覧で持つ。`301_` の控え（`state\quest_clients.json`）と、ほかの MOD が置く行（ローダの窓口 `quest_clients`。TECH.md §3.3.23）。依頼の状況（未了・済み）は写さず、毎回セーブから読む（写すとゲームとずれる） |
| 名前で照らす範囲 | 完全な一致だけを残す。名前の一部では照らさない（上の同名の別人） |
| 依頼を受けるボタン | その町の掲示板に、相手が出した未完了の依頼があるときだけ出す。判定は掲示板の絞り込みと同じ `quest_belongs_to`。掲示板に出さない依頼（窓口 `board`）は数えない。「この話から依頼を作る」は今までどおり出す。絞り込みを切っている（`FILTER_BY_NPC` が偽）ときは今までどおり出す |
| 依頼人のいない依頼 | 依頼の街（`neighboring_settlement_id`）にいる人物に「主人公がこの街で片付けたと噂になっている依頼」として伝える。依頼人としては伝えない |
| 裏の仕事 | 依頼人（事務所の主・脱出の手引き役）は一覧に入れ、依頼人として知っている。街の住人には、誰の仕業かを伏せた「この街で最近あったらしい出来事」として伝え、主人公の仕業だとは思わせない |
| 噂から外す依頼 | その相手が依頼人の依頼（依頼人の節で伝える）・主人公以外が片付けた依頼（窓口 `quest_claims` の片付けた行）・ほかの街の依頼 |
| 噂を足さない相手 | 同行している仲間（その場にいたことがある） |
| 件数 | 依頼人の節は今までどおり3件。噂は表の依頼と裏の仕事を別々に、新しいものから3件（設定 `MAX_TOWN_TOLD`）。題に要約の頭の1行（80字まで。MOD が足した【…】の注記は落とす）を添える |

## 作り

- ローダ: `instantale_modloader/quest_clients.py`（`declare` / `clients` / `client_of`）。形は `board`・`quest_claims` と同じ
- `336_`: 裏の仕事の控えに事務所の主の id（`client`）、脱出の控えに手引き役の id を足した。
  進行中の控えは片付くと消すので、片付いた分は `kept_past`（題・依頼人の id・名前）に残す。
  作り直した周回で id が使い回されても取り違えないよう、題が今のセーブと同じものだけを数える。
  `kept_past` の依頼も窓口 `board` の「掲示板に出さない依頼」に数える（`301_` が誰の仕業かを伏せるのに使う）
- `301_`: `quest_belongs_to` は自分の控え → 窓口 `quest_clients` → 名前の完全な一致の順に見る。
  会話の差し込みは、依頼人の節の後ろに噂の節（表の依頼・伏せる依頼）を足す。噂の街は主人公の今いる街
