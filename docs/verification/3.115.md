# 3.115 依頼人の一覧と街の噂（`301_quest_from_conversation`・`336_crime_overhaul`）・窓口 `quest_clients`: ボタンの出し分けと噂の差し込みは実機で成立（Haiku 5.5）・裏の仕事も正規の経路で成立・処刑場からの脱出は未

2026-10-25 に作った。
きっかけは2つ。会話の「依頼を受ける（話を切り上げる）」が、相手の依頼が無くても出ていた。片付けた依頼を NPC が知っている割合が低かった。

## 測ったこと（10-25。テストワールドとヴェスティアのセーブ、`out\quest_offer.log`）

- 依頼のデータには依頼人の id が無い。持っているのは `client_name` の文字列だけ（欄は `quest_title` から `quest_area_id` までの14個、両世界とも同じ）
- `client_name` は「役職・名前」「役職 名前」「役職名前」「名前」が混ざる（宿屋の店主・バルガス、鉱山監督官 ガリウス、商人エドワード、冒険者ギルド長）
- 名前の末尾で実在の人物と照らすと、テストワールドは 35 件中 20 件、ヴェスティアは 73 件中 27 件が誰かに当たった。
  ただし同名の別人が多い。テストワールドでは依頼人がエドワードの依頼が3件あり（考古学者の老人・司祭・漁師の老人）、拠点は 0・3・7 とばらばら。実在のエドワード（id 106）は拠点 7 にいる。
  ゼノは依頼2件に実在の3人が当たり、ヴェスティアのエレナは依頼5件（拠点 5〜7・0）が実在の1人に当たった。
  名前の一部で照らすと、片付けていない人物に「片付いた」と伝えることになる
- 名前の完全な一致で当たったのは、ヴェスティアの片付いた依頼 56 件のうち 8 件。6 件は `301_` で作った依頼（控えにも在る）、2 件は `336_` の裏の仕事（依頼人の欄に事務所の主の名前を入れている）
- 会話への差し込みは、`no completed quest for` が 635 回、`+N chars into profile` が 21 回だった。差し込んだ 21 回の相手は、どれも本当の依頼人（`301_` の控えに在るか、名前が完全に一致）。
  伝わらない理由は、片付いた依頼の大半に依頼人として実在の人物がいないことで、差し込んだ文をモデルが無視したことではない。差し込んだ後の返答で依頼に触れたかは数えていない

## 決めた仕様

| 項目 | 決めたこと |
| --- | --- |
| 依頼人の持ち方 | 依頼 id → 依頼人の人物 id の一覧で持つ。`301_` の控え（`state\quest_clients.json`）と、ほかの MOD が置く行（ローダの窓口 `quest_clients`。TECH.md §3.3.23）。依頼の状況（未了・済み）は写さず、毎回セーブから読む（写すとゲームとずれる） |
| 名前で照らす範囲 | 完全な一致だけを残す。名前の一部では照らさない（上の同名の別人） |
| 依頼を受けるボタン | その町の掲示板に、相手が出した未完了の依頼があるときだけ出す。判定は掲示板の絞り込みと同じ `quest_belongs_to`。掲示板に出さない依頼（窓口 `board`）は数えない。「この話から依頼を作る」は今までどおり出す。絞り込みを切っている（`FILTER_BY_NPC` が偽）ときは今までどおり出す |
| 依頼人のいない依頼 | 依頼の街（`neighboring_settlement_id`）にいる人物に「主人公がこの街で片付けたと噂になっている依頼」として伝える。依頼人としては伝えない |
| 裏の仕事 | 依頼人（事務所の主・脱出の手引き役）は一覧に入れ、依頼人として知っている。街の住人には、誰の仕業かを伏せた「この街で最近あったらしい出来事」として伝え、主人公の仕業だとは思わせない |
| 噂から外す依頼 | その相手が依頼人の依頼（依頼人の節で伝える）・主人公以外が片付けた依頼（窓口 `quest_claims` の片付けた行）・ほかの街の依頼 |
| 噂を足さない相手 | 同行している仲間（その場にいたことがある） |
| 件数 | 依頼人の節は今までどおり3件。噂は表の依頼と裏の仕事を別々に、新しいものから3件（設定 `MAX_TOWN_TOLD`）。題に要約の頭の1行（80字まで。MOD が足した【…】の注記は落とす）を添える |

## 作り

- ローダ: `instantale_modloader/quest_clients.py`（`declare` / `clients` / `client_of`）。形は `board`・`quest_claims` と同じ
- `336_`: 裏の仕事の控えに事務所の主の id（`client`）、脱出の控えに手引き役の id を足した。
  進行中の控えは片付くと消すので、片付いた分は `kept_past`（題・依頼人の id・名前）に残す。
  作り直した周回で id が使い回されても取り違えないよう、題が今のセーブと同じものだけを数える。
  `kept_past` の依頼も窓口 `board` の「掲示板に出さない依頼」に数える（`301_` が誰の仕業かを伏せるのに使う）
- `301_`: `quest_belongs_to` は自分の控え → 窓口 `quest_clients` → 名前の完全な一致の順に見る。
  会話の差し込みは、依頼人の節の後ろに噂の節（表の依頼・伏せる依頼）を足す。噂の街は主人公の今いる街

## 確かめたこと（実機。10-25、テストワールド。クラウドの Claude を `136_` で Haiku 5.5 に差し替え）

アビス（拠点 8）。片付いた依頼は2件（嵐の夜の徴収人・深海の呼び声）、未完了は1件（嵐の夜の隠れ家）で、どれも依頼人は実在の人物でない。試した後は控えへ戻した。

| 確かめたこと | 結果 |
| --- | --- |
| 依頼の無い相手に「依頼を受ける」を出さない | 成立。宿の主アンガス・住人ドリス・ギルドのマトヴェイの3人とも `no offer: … has no quest on the board here` で、選択肢は「この話から依頼を作る」と「会話を終了する」（宿は「売買する」も） |
| 依頼を作った後は出す | 成立。アンガスとの会話で「この話から依頼を作る」を押すと依頼 37 ができ、同じ会話の選択肢に「依頼を受ける（話を切り上げる）」が並んだ |
| 押した先の一覧 | 成立。1回目は疲労でゲームが受注を断った（ゲーム自身の判定。疲労を戻して押し直した）。2回目は一覧が依頼 37 と「やめる」だけ（`restricted to 'アンガス' -> 1 quest(s), dropped ['嵐の夜の隠れ家']`。写真で確認） |
| 住人に噂の節が届く | 成立。アンガスに +181 字（表の噂2件）。第一声では触れず、噂を尋ねると「港の略奪船がいつの間にか消えたとか、沈没船の跡で妙な光が見えたとか」と、2件を依頼人としてではなく噂として話した。誰が片付けたかは言わなかった |
| 仲間には噂を足さない | 成立。仲間との話し合いで `no completed quest for 'リュウ'`（何も足さない） |

裏の仕事は、正規に片付けるには事務所で受けて戦闘まで要るので、片付いた依頼「深海の呼び声」を、ゲームの中から 336 の `kept_past` に書き足して作った（依頼人はギルドのマトヴェイにした）。
書き足した直後に、窓口 `board` の掲示板に出さない依頼に `33` が、窓口 `quest_clients` に `{'quest': '33', 'npc_id': '100'}` が出た。

| 確かめたこと | 結果 |
| --- | --- |
| 住人には誰の仕業かを伏せる | 成立。ドリスに +300 字で、表の噂（嵐の夜の徴収人）と伏せた噂（深海の呼び声）の2節に分かれた。誰が遺物を持ち帰ったかを尋ねると「誰が持ち帰ったのかは、わたし、知りません」 |
| 依頼人には依頼人の節で伝え、伏せた噂には回さない | 差し込みは成立。マトヴェイに +294 字で、深海の呼び声は依頼人の節に入り、伏せた噂の節は無かった |
| 依頼人が片付いたことを受けて話す | 不成立（試し方による）。「片付けておいた」と言うと「その件を誰かに頼んだ覚えはありません」と否定した。マトヴェイは記録を書き足して依頼人にしただけで、依頼を出した経緯が人生の記録に無い |

ドリスは表の噂（略奪船）についても「誰がやったかまでは知りません」と答えた。怯えて会話を切り上げたがる人物で、性格のせいか、噂の節の「主人公が片付けた」が伝わっていないのかは、この1回では分けられない。

マトヴェイの否定を受けて、同じ日に正規の経路を通し直した（Haiku 5.5。試した後は控えへ戻した）。

| 確かめたこと | 結果 |
| --- | --- |
| 会話から作った依頼を正規にクリアし、依頼人に報告する | 成立。アンガスに厄介事を尋ね、「この話から依頼を作る」で依頼 37（荷揚げ場の影に潜む残党）を作り、「依頼を受ける」から受けて（疲労だけ戻した）、`autoplay.py` で13手でクリアした。宿に戻ると依頼人の節に依頼 37 が入り（+338 字）、「片付けてきたぞ」に「へえ、荷揚げ場の残党を片付けてきたのか。…報酬の話はその後だ」と受けて話した。片付いた後は「依頼を受ける」を出さない |
| 住人が表の噂を主人公の手柄として話す | 成立。依頼を作る前の会話で、アンガスが「略奪船はあんたらが片付けたらしいが、その後始末で荷揚げ場はまだ揉めてる」と話した |

過去の記録（ゲームの `output_data`。モデルは記録に残らない）にも、正規の経路で依頼人が受けて話した回がある。
`301_` で作った依頼では、ヴェスティアのエレン（10-20）が「熱源周辺区域の調査は、既に完了の記録があるわ。報酬も支払い済みよ」と話した。
`336_` の裏の仕事を事務所で正規に受けて片付けた回では、ヴェスティアのライル（10-23。暗殺の仕事）が「ドレクの件ですか。あの金貸しが夜に死んだという噂は…ずいぶんと手際が良いことで」と話した。
マトヴェイの否定は、依頼を出した経緯の無い人物を依頼人に当てた試し方によるもので、正規の経路では起きていない。

### 裏の仕事を正規の経路で（10-25、ペルディション。Haiku 5.5。試した後は控えへ戻した）

テストワールドには裏の事務所が無いので、事務所が4つあるペルディション（主人公 Lv80）で試した。

| 確かめたこと | 結果 |
| --- | --- |
| 作った仕事に事務所の主が依頼人として付く | 成立。イシュメルドの黒鉤の伝達所で「裏の仕事を探す」から盗掘の仕事 35 を作ると、窓口 `quest_clients` に `{'quest': '35', 'npc_id': '54'}`（事務所の主マーズ・イオロス）が出た |
| 片付けると `kept_past` に残る | 成立。`autoplay.py` でクリアし（報酬は5倍、手配度 10 → 0）、周回のファイルの `kept_past` に `{'35': {'title': …, 'client': '54'}}` が書かれた。窓口の行も片付いた後に残った |
| 事務所の主が依頼人として受けて話す | 成立。依頼人の節に仕事 35 が入り（+466 字）、第一声は「また来やがったか、灰の盗掘者」。「運び出してきたぞ」に「依頼は完了だ、報酬はいつもの通り受付で受け取れ」 |
| 同じ街の住人には誰の仕業かを伏せる | 成立。宿の主サール・ロークの伏せた噂の節に仕事 35 が入った。墓所の件を誰がやったか尋ねると「誰がやったかまでは知らないね。…まさか、あんたじゃないだろうな？」 |

事務所へ戻る途中、手配度が 0 になったので衛兵に呼び止められ、抵抗して戦闘で抜けた（ゲームと 336 の普段の流れ）。

見つかった不具合: 同じ住人の表の噂の節に、10-05 に片付けた古い裏の仕事2件（黄昏の墓所に眠る『不滅の遺産』・澱んだ関所の夜通し）が主人公の名前付きで入った。
版3までは裏の仕事を片付けると控えから消していたので、`kept_past` にも窓口 `board` にも残っていなかった。
2件とも要約に 336 の注記が無い（注記を足す前の版で作った）ので、注記では見分けられない。
裏の仕事の依頼人の欄は最初の版（913、10-04）から事務所の主の名前にさせているので、336 に「控えに無い片付いた依頼のうち、依頼人の欄が世界の裏の事務所の主の名前のもの」を古い裏の仕事として数える `older_jobs` を足した（窓口 `board` と `quest_clients` の両方。依頼人は事務所の主）。
起動し直して同じ住人と話すと、2件は伏せた噂の節へ移り（表の噂の節は表の依頼2件だけ）、「関所の夜通しの荷運びがあったって話は耳にしたが、誰が請けたかなんて知らないさ。墓所の件も同じだ」と答えた。

この見分け方の限り:
- 処刑場からの脱出は、依頼人の欄が手引き役（好感度の高い人物なら誰でもなる）なので、版3までに片付けた分は見分けられず、表の噂になりうる
- 事務所の主が会話から出した表の依頼（`301_` で作った依頼）も、片付くと裏の仕事として伏せる側に入る
