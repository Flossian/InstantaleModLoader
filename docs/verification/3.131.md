# 3.131 健康状態の欄に怪我を部位ごとに出す（`121_ui_character_sheet` 版8）・読み込みの後も怪我を能力値に効かせる（`149_fix_injury_after_load`）: 段階の境目と倍率を実機で測り、どちらも実機で成立

2026-11-16。
素のゲームの健康状態の欄は、怪我のある部位を `arms: hurt, ` と英語のまま並べるだけで、何が下がったかはどこにも出ない。
欄を `胴体: 軽傷` の行に書き直し、下がっている能力値を欄にマウスを乗せたときの説明のウィンドウに出した。
遊び方は MOD の DOC.md、ゲームの側の作りは GAME.md §2.19.1。

## 分かったこと

- 怪我はゲームが能力値へ倍率を掛けている。胴体の `hurt` で耐久 24 → 23（`244_probe_ability_reads` の記録）
- 段階の境目は `injury` が 10・30・60・100。exe の定数に在るのは 10・30・100 で、60 は実機で測った
- `lost` は倍率がいちばん重いだけの段階で、部位が無くなる処理も死亡の処理も無い。
  表示は「使用不能・危篤・錯乱」にした
- 同じ能力値を複数の部位が下げるときは `body_parts` の並びの順に掛け、1つごとに丸める
- 段階ごとの 0.97・0.95・0.9・0.85 は体力の上限に掛かる。最大 HP に段階の倍率は無い
- 読み込み直すと、怪我は残るのに能力値は元の値に戻る（`149_` で直した。下の節）。
  腕を `damaged`・胴体を `hurt` にして保存し、題の画面から読み直すと、筋力 28・器用 26・耐久 28 が 30・30・30 になった。
  体力の上限は 47 のまま

## 測り方

世界Fで、主人公の `body_parts` を書き換えて `check_body_damage` を呼び、段階・能力値・最大 HP・体力の上限を読んでから元の値へ戻した。

| 測ったこと | 結果 |
| --- | --- |
| 6部位それぞれで `injury` を 0〜100000 の 24 通り | 段階は6部位とも同じ。9 は `intact`、10 は `hurt`、30 は `damaged`、100 以上は `lost` |
| 腕の `injury` を 28〜102 まで1つずつ | 段階が変わるのは 30・60・100 |
| 段階が付いた後に `injury` を下げる | 段階も戻る（`lost` で 0 にすると `intact`） |
| 6部位 × 5段階の能力値 | GAME.md §2.19.1 の表のとおり。30 ×0.95 は 28、30 ×0.85 は 26（.5 は偶数へ） |
| 腕 `damaged`・脚 `hurt` | 器用 25（腕が先。脚が先なら 24） |
| 腕 `hurt`・脚 `damaged` | 器用 24 |
| 胴体 `damaged`・腕 `disabled` | 筋力 24（胴体が先。腕が先なら 25） |
| 胴体 `disabled`・腕 `damaged` | 筋力 25 |
| 胴体 `hurt`・脚 `disabled`・内臓 `damaged` | 耐久 20 |
| 体力の上限（元は 51） | `hurt` 49・`damaged` 48・`disabled` 46・`lost` 43 |
| 怪我を消して組み直す | 上限は 51 に戻り、今の体力は 43 のまま |

`update_max_physical_integrity` は呼ぶたびに今の上限へ重ねて掛かるので、段階を直に書いて続けて呼ぶ測り方では上限が下がり続けた。
上限と今の体力を元の値へ書き戻してから1段階ずつ測り直した。

## 表示の決め方

- 部位ごとの行は、ゲームと同じ順で倍率を掛けた結果が今の能力値と合うときだけ `耐久 30 → 28（×0.95）` と書く
- 今の能力値が元の値のままなら、倍率だけを灰色で書く（読み込み直した後の状態）
- どちらでもなければ、倍率だけを書く
- 比べる能力値は補正を足す前の値（`abilities.raw`）。装備や特質の補正は連携 API が後から足す

## 読み込みの後も怪我を効かせる（`149_fix_injury_after_load`）

読み込みの後に、怪我のある主人公の `update_ability_scores` を1回呼ぶ。
`check_body_damage` を呼ぶ形にはしなかった。
体力の上限の組み直しも一緒に走り、セーブに残っている下がった後の上限へ倍率がもう一度掛かる。

世界Fで、胴体を `hurt`・腕を `damaged` にして保存した。

| 読み込み方 | 筋力 / 器用 / 耐久（元は 30 / 30 / 30） | 体力の上限 |
| --- | --- | --- |
| MOD なし、題の画面から読み直す | 30 / 30 / 30 | 47 |
| `149_`、題の画面から読み直す | 28 / 26 / 28 | 47 |
| `149_`、ゲームを起動し直す | 28 / 26 / 28 | 47 |

`out\injury_after_load.log` には読み込みのたびに `怪我 body hurt, arms damaged の倍率を掛け直した（strength 30 -> 28, …）` が1行出た。
