# 2.61 残りの分岐が実機で発火した（`316_`）

| 分岐 | 記録 |
| --- | --- |
| ゲーム自身の衛兵 | 決まっていた控えが落ち、衛兵は `衛兵1〜3`・レベル21のまま（改名も強化もされない）。2回 |
| 捨てる側 | 連泊中に決まった追手が合図20回ぶんで捨てられ、次の契機で決まり直した（宿泊1泊で合図およそ2回） |
| 逃げて終わった回 | `画面が整った` の側で手配度を戻せた（§2.53 の取りこぼしは解けている） |

クールダウンが 0 日だと衛兵を数えても日数の抑えは働かない。
それでも衝突しないのは**決まっていた控えをその場で落としている**から（抑えは2段）。
