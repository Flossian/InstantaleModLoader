# 3.96 入力した世界の概要をそのまま使う（`145_`）: 実機で成立

ゲームの経路は GAME.md §2.27。記録は `out\world_overview.log`。

もとは `130_fix_world_overview`。実機で世界を1つも生成しないまま v1.7.2 を迎えたので 2026-08-21 に `905_` へ移し、08-30 に `discontinued\` へ移した（手元では `local\` の写しを読み込んでいた）。
2026-10-11 に `145_` として正式化した。元にしたのは `discontinued\` の 09-11 の版（照合の仕掛け口を移した後）。
`local\` の写し（08-30 の版）は `out\backup\local_905_fix_world_overview_20261011\` へ退避した。

## 決めた仕様（再検討しない）

- 新しい 1xx として独立させる（2026-10-11）。`144_` への相乗りと並べて選んだ（144 は固定の文を外す、こちらは世界を作るときの1回だけ効く）
- 戻すのは `World.overview` の1項目だけ。地理の説明文と3層9エリアの構造は LLM が書いたもの。生成を止めて自前で組むと、入力に無いものを大量に足すことになる
- 照合（二段目）は記録だけで、書き換えない。照合は生成の直後の1回だけ

## 確かめたこと

2026-09-11 の外部の実機1回（ローダ v1.10.0 / game main_025・014。世界を1つ生成したところまで）:

| 決着したこと | 根拠 |
| --- | --- |
| `create_world_overview_from_plot` を通る（概要を入れた場合の分岐の推定が当たっていた） | `overview replaced: generated 166 chars -> yours 395 chars` |
| 応答 `World` の `overview` に代入が通る | 代入後の読み直しが一致（`WARN could not replace` が出ていない） |
| 差し替えが**この後の生成すべてに届く** | 本番の `output_data\` で、書き手の文の印（`【概要】`）が `create_story` / `create_settlement_detail` / `settlement_quest_generator` / `area_quest_difficulty` に在り、本体が書いた文の印は `create_world_overview` の応答にしか無い |

このとき二段目（照合）は出なかった。
当時の仕掛け口 `save_world_json:generate_new_world` は画面に関数のまま控えられていて、包みが2秒差で間に合わなかった（`defer wrap` 09:58:46 → 画面が在る 09:58:52 → `wrapped` 09:58:54）。
同日、二段目を `save_world_json:write_obfuscated_json_file` へ移し、概要を空のまま生成した経路の記録を `create_world_overview`（引数なし）の包みへ移した。復号器（`scripts.save_codec`）が引けないときは、書き出す直前の `data` で照合して `OK what was handed to the writer` を出す。検査は 24件 → 33件で、増やしたうちの2件は載せ先そのものを縛る。

手元の3回（移す前の 08-30 の版。`out\world_overview.log`）:

- 09-14 テストワールド（入力 5 字）、10-11 積層都市ヴァルカ（入力 155 字・書き直し 245 字）、10-11 わたぐも諸島（入力 168 字・書き直し 240 字）
- 3回とも `generating` → `overview replaced` → `OK the saved world_data['overview'] is what you wrote` まで出た。手元の起動では `generate_new_world` の包みが間に合っていた
- 10-11 の2世界は、`143_` の実機（[§3.93](3.93.md)）でさいころに渡した世界の概要が入力した文章そのものだった

## 推定のまま残っているもの

- 概要が空のときに `create_world_overview`（引数なし）へ落ちる分岐の条件。定数からは分岐が在ることしか読めない（HUD 側の `内容ある` / `内容ない` の分岐から採った）
- `world_data["name"]` が入力した名前と `World.world_name` のどちらから来ているか（この MOD は触らない）

今の形（09-11 の版）の実機（2026-10-11 11:18〜11:46、Claude。[§3.95](3.95.md) と同じ回）:

- 概要を入れた生成4回で4回とも `overview replaced`（書き直し 207〜261 字 → 入力 146 字）。生成が最後まで通った2回は、書き出しの関数の包みで `OK the saved world_data['overview'] is what you wrote (146 chars)` が出た（残る2回は町の生成で止まり、書き出しに届いていない。[§3.95](3.95.md)）
- 入力が抜けて概要を空のまま生成した1回で `nothing was replaced for this world; no world overview was typed in, so the game is writing its own` が出た（仕掛け口を移した後の空の経路）

## 確かめていないもの

- ローカル LLM で世界を作った回に `OK` の行が出なかった理由（保存された概要は書いた文のままだった）。クラウドの回は、世界を作った後に1回行動しても `OK` の行は増えなかった（[§3.93](3.93.md)）

記録の行の読み方:

| 出た行 | 意味 |
| --- | --- |
| `OK the saved world_data['overview']` | 決着 |
| `WARN the saved ... is not what was put in` | 差し替えの後に本体が別の文章を入れている |
| `OK what was handed to the writer` | 照合は通ったが読み返せていない。`scripts.save_codec` が引けていない |
| `WARN could not read ... back` | 書き出しの実体は通ったのに中身が読めない。`data` の形から見直す |
| `overview replaced:` の後が何も出ない | `write_obfuscated_json_file` を通っていない。世界の保存が別の経路に変わった（町の生成などで生成が途中で止まった回も出ない） |
