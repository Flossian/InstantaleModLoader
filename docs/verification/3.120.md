# 3.120 武器にたまにスキルが付く（`410_weapon_skill_chance`。提供の `801_` を正式化）: クラフト・主人公・店の主・仲間・敵の経路と仲間の技・説明欄は実機で成立

2026-11-01 に作った。
提供を受けた `801_weapon_skill_chance`（わさの 様）を 410 として取り込んだ。
INT・DEX の 60 の段（必ず付く）は、意図が分からないので手を付けていない（決めたこと）。

## 801 から変えたこと

| 変えたこと | 理由 |
|---|---|
| 店の入口とクラフトの外で作られた武器は、受け取る人（`generate_item_from_item_data` の `obtainer`）で分ける。世界の人物（店の主・仲間など）なら店の確率、主人公と敵なら「テキスト・イベント」の確率 | 801 はどれも「テキスト・イベント」（主人公の腕前の倍率つき）にしていた。店の品揃えを入れ替える `312_` / `340_`（店の主へ作る）と、仲間の初期装備の `407_`（仲間へ作る）の武器にも、主人公の腕前でスキルが付いていた |
| 店の武器には INT・DEX の倍率を掛けない | 801 は既定の「クラフトとそれ以外」で店の武器（上乗せ）にも倍率を掛けていた。設定の説明（「店の武器には掛けない」）と食い違っていた |
| INT・DEX は窓口 `abilities` から、装備などの補正を足した値で読む | `313_` と同じ読み方（[§3.119](3.119.md)） |
| 保存の包みに `safe=True` | 包みの中の不具合で保存を止めない |
| DOC の「窓」を「ウィンドウ」に | 遊ぶ側の言葉 |
| 版を 2、author の末尾に R01/Flossian | 取り込みの決まり |

## 実機（11-01、テストワールド Lv72。生成はスクリプトからゲームの入口を呼んだ）

| 確かめたこと | 結果 |
|---|---|
| 主人公に作る（確率を 100% に上げた） | ゲームのスキル生成でスキルが付いた。INT 22・DEX 34 は装備の補正込み |
| 店の主（行政官ガレス）に作る | 店の確率（既定 0%）で抽選され、付かなかった。801 なら「テキスト・イベント」の確率で抽選されていた |
| 仲間（リュウ）に作る（店の確率を 100% に上げた） | 店の扱いでスキルが付いた |
| 戦闘で仲間が武器のスキルを使える状態になる | 依頼2件・戦闘9回すべてで、始めに技へ加わり、終わりに外れた（仲間の短剣にスキルをスクリプトで写した） |
| 宿の休養 | 仲間のスキルの回数が 0 → 3 に戻った |
| 敵に作られた品 | 戦闘の前に敵（世界の人物に居ない）へ作られる品は「テキスト・イベント」に入った（素材・防具。武器は出なかった）。最初の版は世界の人物かを見ず、敵の武器 1本を店の扱いにしていたので直した |
| 例外 | 無し |

### クラフト（同じ日、画面の操作で）

持ち物の剣2本（epic・legendary）を材料の枠へ移し、入力欄に「二本の剣を鍛え直して、一振りの片手剣を作る」と書いて「作成」を押した。
クラフトの確率は 100% に上げた。

| 確かめたこと | 結果 |
|---|---|
| 経路 | `source=craft`。INT 22・DEX 34（装備の補正込み）で「そのまま」の段、100% |
| スキル | 出来た片手剣（legendary、価値 100、攻撃力 591）に `蒼鋼の絶閃` が付いた。作成を押してから品が出るまで約3秒長くなった |
| `411_` | 同じ品に器用 +3・知力 +3 が付いた（legendary の既定の量） |
| 説明欄 | スキル名の下に効果（長い文も「効果：」の直後から折り返す）と `使用回数: 3/3`、その後に 411 の補正の行。109 の箱に収まった |
| 副産物 | 素材が1つ出た（410 は抽選しない） |

試しの後は控えへ戻した。

## 残っていること

- 敵が持って現れた武器を「漁る」で手に入れたときに、スキルが付いたまま手元に来るか
- `equipment.equip` で仲間の手に武器を入れられなかった（「not placed」。右手は埋まっていて左手は空いていた）。410 ではなく装備欄の窓口の側の挙動で、まだ調べていない
