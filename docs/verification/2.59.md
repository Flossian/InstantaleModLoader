# 2.59 戦闘の選択肢と敵の表示の重なり（`220_`）

`right_button_layout`（溢れた選択肢を出す右の欄）と `top_info_layout_battle`
（戦闘の情報欄）が**同じ矩形**で、両方 opacity 1 になる回がある。

割れているのは**戦闘に入る直前の選択肢の数**で、5つ以上だと開いたまま残る（実測5回）。
MOD が起こしたかゲームが起こしたかでは割れない。

> 記録の `started_by` は当てにならない。ゲームのクエスト戦闘も `on_button_press` を
> 経由せず `execute_battle_process` から来る。見分けるなら呼び出し元の文字列を読むこと。
