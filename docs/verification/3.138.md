# 3.138 仲間が離れるときの3本（`302_` / `303_` / `304_`）を `348_party_departure` に書き直して1本にする: ゲーム抜きの検査は通過・設定の引き継ぎも検査で通過・実機は未

会話から別れる（`302_leave_party_in_conversation`）、依頼の解散の置き先を変える（`303_quest_end_party_to_guild`）、依頼の解散を止める（`304_quest_end_keep_party`）は、
どれも `remove_party_member` → `move_npc_to_facility` の同じ経路（GAME.md §2.8）にそれぞれフックし、勝ち負けを番号の並びに頼っていた。
3本を新しい `348_party_departure` に書き直し、フックを1組にして場面で振り分けるようにした。
3本は `"superseded": "348_party_departure"` で伏せた（フォルダは残す）。

| `348_party_departure`（新規） | 入口 `party_departure.py` が3つのフックと離脱の文の差し替え（窓口 `text_filters`）を持ち、会話の別れは `farewell.py`、置き先の小さな部品は `places.py`。設定は `KEEP_PARTY` / `FAREWELL_ENABLED` / `STAY_NEARBY` / `ALSO_ON_QUEST_RETIRE` / `ANNOUNCE_DESTINATION` / `KEEP_TEXT`（既定は3本の既定と同じ）。印 `mod_party_action` と残骸の掃除の文言、記録 `out\party_leave.log` は 302 のまま |

## 決めた仕様（再検討しない）

- 置き先の決まりは会話の別れと依頼の解散で1つにした。雇った土地なら雇った場所、土地を跨いでいたらいまの町のギルド、ギルドの無い土地ではゲームの置き先。依頼の解散では、雇った土地ならゲームの置き先（＝雇った場所）をそのまま使う。303 は依頼の解散でいつもいまの町のギルドに置いていた
- 303 の3段目（8秒待って誰も置かなければ自分で置いて保存する）は外した。ゲームは外した直後に必ず置き直すので（GAME.md §2.8）、出番は MOD が無くても NPC が消える場面だけだった。代わりに、置き先の控えも引き留めの控えと同じく `HOLD_SECONDS`（30秒）で切れる
- 302 の調べもののコード（名簿の在り処の総ざらい・画面の顔ぶれの記録・`method_1` の対応表・記録だけの3つのフック）は外した。答えは GAME.md §2.8 にある
- 304 の「離脱の文を差し替えない」切り替え（コード側の定数）は外した。「解散を止めたときに出す文」を空にすれば差し替えない
- 放棄の扱いの既定は切のまま。放棄の解散の経路はゲームでは観測済み（GAME.md §2.8）だが、MOD を通した経路は確かめていない
