# 3.125 現在地の下に日付を表示する（`345_date_display`）: 表示・はみ出しの対策・日数の更新・ロード・設定の反映は実機で成立

2026-11-07 に作った。
能力値の欄の `status_texts` に日付の行を足して塗らせる。

## 分かったこと

欄の組み方は GAME.md §2.29。

- 窓 1920×1080 では、ラベルの上端からアイコンの上端まで 272.7px で、8行（34px × 8 = 272px）でちょうど埋まる
- 箱の高さを超えた行は描かれない。別の `CoreLabel` に同じ条件で10行を組むと、行間 1.2 では8行で切れ、最後の行は Location の途中だった。日付の行が消える形
- ラベルの `_cached_lines` は切れた後の行だけを持つので、行数の判断に使えない
- 字とアイコンは起動時の窓の大きさで決まり、起動後に窓を変えても変わらない。実寸 1280×720 の余裕は、起動時なら 182.5px（字 13）、1920×1080 で起動して窓を変えたときは 168.5px（字 20）だった
- 8行が行間 1.2 のまま入るのは、試した中では高さ 1080 のときだけだった。ほかのサイズは8行でも行間が 1.13〜1.18 に詰まる（字の大きさが整数に丸められるため。字が読めないほどの差ではない）
- 4:3 は欄の幅が狭いので、同じ名前でも折り返しが1行多い（16:9 で 10 行のものが 11 行）
- 当て直し（`boot #N`）はワールドの読み込みの後にも起きる。`130_` が新しい世代を包んだ時点で古い層がまとめて剥がれ、`345_` が包み直すまで欄の塗りに日付が付かない。ローダの既知の穴で、この MOD では直さない

## 決めた仕様

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 足す場所 | `Location:` の行の直後に1行足す。別のウィジェットにしない | 折り返しの行数によらず Location の下に来る |
| `status_texts` | 書き換えない。見張りに渡す値だけを差し替える | ゲームの値のまま残し、直に呼び直すときに二重に足さない |
| 収め方 | 高さの制限を外した別の組版で数え、入らなければ行間を詰め、下限 0.8 でも入らなければ字を 90%・80%・70% と小さくする | 行間は折り返しを変えないので先に試す。字を小さくすると折り返しが変わるので測り直す |
| 暦の持ち方 | `MONTHS` の1行（`31,28,霜月:31`）だけを持ち、1年の日数と月数は合計と個数で出す | 別々に持つと食い違う |
| 設定画面の動き | 1年の日数か月数を変えると均等に割り振り直し、月の日数を変えると1年の日数が合計に追従する | どちらから入れても暦が1つに決まる |
| 打ちかけの値 | 月数より少ない1年の日数などは表へ移さず、欄を離れると表の値へ戻す | 入力の途中で表が崩れない |
| 再描画 | 日数の後（`durations.on_days`）とロードの後（`loads.on`）に見張りを直に呼ぶ | `status_texts` は中身が変わったときしか見張りを呼ばない |
| 個別設定の読み直し | 世界が変わったときに加えて、ロードのたびに読む | 同じ世界を開き直しても設定画面の変更を反映する。最初の版は世界の名前が変わったときだけで、効かなかった |
| 当て直しの後 | `apply` の終わりに見張りを直に呼ぶ | 当て直しの最中に塗られると、日付の無い文字列が次に欄が変わるまで残る。最初の版は既定の 4:3 の試しで3行目がこの窓に当たり、日付が消えた |

## 実機（テストワールド）

| 確かめたこと | 結果 |
|---|---|
| 562日 | `Date:2年7月17日`。行間 1.2 のまま 8行 272px に収まる |
| 戦闘中 | 599日で `Date:2年8月23日` が欄の文字列に入る |
| Location が2行 | 9行。行間 1.06、1行 30px、計 270px。字は 20 のまま |
| Location が3行 | 10行。行間 0.96、1行 27px、計 270px。字は 20 のまま |
| Location が11行 | 17行。字 14、行間 0.8、1行 16px、計 272px |
| 短い場所へ戻す | 字 20、行間 1.2 に戻る |
| 40日進める（他の欄は同じ） | `Date:2年8月26日` にその場で変わる |
| 起動後に窓を 1280×720 へ変え、1920×1080 へ戻す | 字 16、行間 0.9 に詰まり、戻すと字 20、行間 1.2 に戻る |
| 当て直しの最中に欄を塗らせる | 塗った直後は日付が無く、当て直しの後は日付が戻る |
| 個別設定（起動して読む） | 1000年・3か月（霜月100日ほか）で 602日が `Date:1002年霜月3日` |
| 個別設定（同じ世界を読み直す） | 1200年と形の変更で `霜月3日 1202年` |
| 一括設定 | 500年・`霜月:300,5` で 562日が `Date:501年霜月258日` |

Location の長さは、場所の名前をメモリの中だけ差し替えてゲームの `update_ui` で塗らせた。
写真で、日付が Location の下にあり、アイコンに重ならず、行間 0.96 と字 14 で読めることを確かめた。

### 起動時のサイズごと

`config.json` の `ui_setting.window_size` を変えて、サイズごとに起動し直した。
当て直しが終わってから、場所の名前を差し替えて読んだ。
どのサイズも、実際のラベルの最後の行が日付で、行の高さの合計はアイコンの上に収まり、字は小さくならなかった。
