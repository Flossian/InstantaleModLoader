# 3.137 裏の事務所には衛兵と追手が来ない（`336_crime_overhaul` の `sanctuary`・窓口 `arrivals` の `enter` / `leave`）: ゲーム抜きの検査は通過・実機は未

手配された土地では、裏の事務所に入るときにもゲームの衛兵が出ていた（GAME.md §2.20「衛兵の抽選」）。
追手（もと `316_`）も施設の種類を見ずに抽選していた。
どちらも裏の事務所の中では出さないようにした。[§3.136](3.136.md) の取り込みと同じ版8 に入れた。

| どこ | 変えたこと |
| --- | --- |
| `336_` の `sanctuary.py`（新規） | 移動先が裏の事務所で、その土地の手配度が平常（10）未満なら、移動の処理の間だけ手配度を 10 に置き換え、終わったら戻す（移動の間に動いた分は足す）。移動の途中の保存は本当の値で書く（窓口 `saving`。錠は保存の間ずっと持つ）。設定 `SANCTUARY_ENABLED`（既定 ON） |
| `336_` の `hunter.py` | 追手を起こす直前に、今いる施設が裏の事務所なら控えたまま待つ（記録に `出るまで待つ` を1行）。出て画面が整ったところで出る |
| ローダの `gates` / `arrivals` | 前後の処理に `enter` / `leave` を足した（`orig` のすぐ前と後。`leave` はどの `after` より先で、`orig` が投げても来る）。後方互換の追加 |

`leave` を足したのは、到着の後の処理（`after`）が登録の古い順に走るため。
`after` で戻す形にすると、先に適用された `317_` の到着の後の処理が、置き換えた手配度（平常）を読む。
すると、評判の控えを外したり、悪名の累計を数え直したりしうる。
