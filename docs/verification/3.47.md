# 3.47 NPC の外見・性格・経歴の偏り（`132_`）: 実機で決着

記録の検分・本測定・MOD の形での再測定は VERIFICATION_LOG.md §2.82、仕組みは `132_` の DOC.md。
「ほぼ同じ見た目」の正体は、頼み文に人を見分ける材料（髪・目・肌・体格）が無く、役職の型で埋まること。
画像のタグは look_description と同じ応答で出るので、当て所は生成時の look_description の本文だけ。
測って決まったこと: 要素名だけ足すのは値が同じ（宿屋の主人の瞳は 10回とも「鋭い灰色」。`111_` のルール1行では足りない）。
値を引いて渡すと指定が 94〜99% で本文に載り、役職の型の語は 59% → 15%、「鋭い」は 17% → 3%。
`132_` の形でも役職の型の語 10%・「鋭い」5%、書式の写り 0、短髪と編み髪の同居 0、老人と子どもも戻る（§2.82 の mod 版2）。
既存 NPC の語を「使うな」と並べる形は取らない（頼み文の語が出力へ漏れる。§2.63）。
版3で表を世界を選ばない句に書き直した後の測り直しと、町の look_description が英語になった件の手当ては §3.93。
オフラインは `tools/tests/test_npc_variety.py` 82件と `tools/tests/test_npc_variety_probe.py` 40件。

実機は2回で決着（§2.82 の実機の表2つ）。既存の世界で隣の村へ移動（町生成）、新しい世界を作って物語 NPC が出るまで。書式の写りは 0。
衛兵は最初の1回で**種が付いた**（見分けの前提が古かった。§2.82）。見分けを直し、別の土地の衛兵で `[SEED]` が出ないことを見た。
6手順は全部済んでいる。手順は残す:

1. 新しい世界を作る → 開始地点の町の NPC（新しいプロセスの最初の LLM リクエストで `wrap_outgoing` の保留が解けたか。`out\npc_variety.log` の `[SEED] … town`）
2. 隣の町へ移動して新しい町の NPC（`[SEED] … town`）
3. 物語 NPC（`master_ai_npc_generater`）が1人出るまで進める（`[SEED] … single`）
4. セーブの look_description に「髪=」のような書式や「決まっていること」の見出しが写っていないこと。`[SEED]` の文と突き合わせて髪・瞳・体格が載っていること
5. 立ち絵が種のとおりに出ること（`image_generation_prompt` は同じ応答で出る）
6. 衛兵（`guard_npc_generator`）と闘技場の敵に `[SEED]` が出ないこと

ワールド生成の町も旅の途中の町も `create_settlement_detail` 1本で、system と指示部分はローカル経路の9件で同一（§2.82）。probe はその写しを投げているので、頼み文としては測り済み。
