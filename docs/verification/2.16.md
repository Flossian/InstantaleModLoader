# 2.16 `108_` 売買画面の `IndexError`（原因確定・救済は未発火）

> ゲーム本体 main_024 で直ったので `superseded` で降ろした（§3.8.1）。この節は原因の記録として残す。

`place_existing_item` が `is_valid_placement()` を通さずに `occupy_slots` を呼ぶ。
縦2マス以上のアイテムが最下段に置かれて1マスはみ出し、
`slot_index=25` が `self.slots`（24マス）の範囲外になる。

正常時の寸法（`inventory.log` の192件から確定）:
`cols=4 rows=6 len(slots)=24 size=[259,389] spacing=[1,1]`、1マス 64px、
2x2 のアイテムは 129px。
`grid_x` / `grid_y` / `slot_size` はアイテム側の属性としては存在せず、`current_slots` の添字で持つ。
