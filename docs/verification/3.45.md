# 3.45 戦闘の戦術（`319_`）: 圧縮・構え・状態異常は実機で成立・残るは2点

§1 の行に書いていた経過をここへ移した。実測の記録は [§2.69](2.69.md) / [§2.70](2.70.md) / [§2.71](2.71.md)。

## 済んでいること

- 圧縮は実機で成立（戦闘4つ・51発すべて照合、`unmatched` 0件。[§2.69](2.69.md)）。
  賞金稼ぎ3体と4巡の削り合いになり、素で 1 だった格下の被弾も 41〜83 になった
- 上限 0.650 の発動と仲間同行（`base=-` で代用の比に落ちる。
  仲間が武器を参照しないのは公式回答により仕様と判明、版2の底上げで対応）も確認
- レベル差の段（差14の強敵戦が式どおり）と状態異常の復元（継続ダメージが毎巡29点。[§2.70](2.70.md)）も実機で成立
- 防御ボタンは経路成立・1手消費まで確認したが、版2は構えが自分の手で即消える欠陥があり
  版3で二段化（`guard armed:` の行が付いた）
- 構えの二段・自由入力の防御・倍率の合成（構え0.5×耐久低下1.1）・`AttributeEffect` の復元は
  同じセッションの実機で決着（同じ一斉攻撃で構えあり102に対し無し224、ちょうど半分。[§2.71](2.71.md)）
- 出どころ表示（`308_` 版2）も実機で確認
- 版5でボタンをスキル一覧の中へ移した（戦闘画面の5つ目は右の UI と重なるため。
  スキルの名前が「スキル・防御」になり、並びは スキル・（スキル2）・防御・やめる）

## 残っていること（実機は2点）

1. スキル一覧内の防御の表示と位置。`guard into the skill list at N:` の行。
   [§2.71](2.71.md) の押下は版5の注入前
2. 一撃の解禁域（レベル差20以上）。版7からは一撃時のダメージが同じ式の上限なしの値になる。
   普段の帯と地続きの過剰殺傷（英雄→スライムで374前後）が出るかも同時に見る。
   素の計算値を借りた版6は物差しが途切れるので差し替えた

読むのは `out\battle_tactics.log`。
