# 3.127 攻撃やスキルで仲間を斬る（`319_battle_tactics` 版22）: 原因は審判が選ぶ対象・味方側の手の効果を向きに合う側へ揃える・オフラインで通過・実機は未

通常攻撃の対象が仲間になる、と言われて調べた。
主人公の通常攻撃で、地の文は敵を斬っているのに仲間の HP が 38% 減った手があった（`308_` のログで `ally <仲間> hp 1882 -> 1161`、319 のログで `hit: <主人公> -> <仲間> weakx1 ... final=721`）。
送り先は `claude`。
通常攻撃を直した後、仲間が倒れてからでは遅いとして、スキルにも広げた。

## 分かったこと

数と審判の形は GAME.md §2.10.1。

- 通常攻撃やスキルの相手はプレイヤーが選ばない。審判の `skill_effects[].targets` に書かれた名前にそのまま当たる。対象の Literal には手番の側の名前も入っている
- ゲームのプロンプトには「これは敵単体への物理攻撃」とすでに書かれていて、それでも外れる。プロンプトの文を足すだけでは止まらないと見た
- 味方側の手で敵が1人も居ない戻りは、主人公の通常攻撃で 1250 手のうち 12、仲間の通常攻撃で 184 手のうち 8。どれも地の文は敵への攻撃
- スキルは効果ごとの `target_type` と照らすと、主人公のスキル 106 手で1件（全体攻撃が仲間1人だけに）、仲間のスキル 498 手で2件（自分や味方への強化が敵に）外れていた
- 敵の通常攻撃でも 937 手のうち 29 が敵側を対象にしていた。地の文が「味方が敵を斬った」になっている戻りが混ざる
- ゲームが返す pydantic の答えへの `setattr` は、`342_` が `vfx` で同じことをしていて実機で通っている（[§3.111](3.111.md)）

## 決めた仕様

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 直す時点 | 審判の戻りを、ゲームが変換する前に書き換える | モデルによらず効く。送るスキーマの選択肢を絞る形は、プロバイダごとの送り方と json_schema を守らないモデルの分だけ漏れる |
| 直す手 | 主人公の通常攻撃とスキル、仲間の手（通常攻撃とスキル） | 仲間が倒れてからでは遅い |
| 向きの決め方 | 効果ごとの `target_type`。主人公のスキルは審判の引数（名前か表の1件）、仲間の手は戻りの `skill` で本人の `skills` を引く。通常攻撃はどの効果も `single_enemy` | 回復や自分の強化のように、正しく味方を狙う効果に触らない。表に無いスキルと知らない `target_type` は触らない |
| 敵向けの寄せ先 | 1体向けは地の文に鍵か表示名が出た敵（先に出た者、同じ位置なら長い語）、無ければ生きている先頭の敵。全体は敵全員。書くのは敵の辞書の鍵 | 審判の対象は鍵で書かれる（GAME.md §2.10.1）。外れた通常攻撃20手はどれも敵が1人の戦闘で、地の文に敵の名前が出ていたのは10手 |
| 味方向けの効果に入った敵 | 落とす。誰も残らなければ、自分向けは手番の者、全体は味方全員。それも読めなければ対象を空にする | 319 は強化を数に効かせるので、敵に掛かると本当に敵が強くなる。効果を外すほうがまし |
| 敵と味方が混ざった敵向けの対象 | 味方の名前だけ落とす | 実記録には無い |
| `additional_effects` | 触らない | 手番の側に当たった7件は、地の文が反撃や武器の反動を語っていて描写と合っている |
| 自由入力の手 | 触らない | プレイヤーが味方へ向ける手を書くことがある |
| 敵の手番 | 触らない | 地の文が敵の被弾を語る戻りがあり、味方へ移すと食い違う。敵が自分を斬る分はプレイヤーの得にしかならない |
| 自分を対象にした通常攻撃 | 敵へ寄せる | 4件のうち2件は地の文が「かわされた」だった。その2件は当たる扱いに変わる |
| 設定 | 足さない | 素のゲームの不具合の手当てで、切りたい場面が無い |
| 画面 | 何も出さない。ログに `target fixed:` を出す | 直した後の数は地の文と合うので、画面に断りを出す理由が無い |

## 確かめたこと

- `tools/tests/test_battle_tactics.py` の「対象」の27項目（純関数と、主人公の通常攻撃とスキル・仲間の通常攻撃・回復・自分の強化・全体の回復・表に無いスキル・敵の手番・キーワード引数のフック越し）が通る
- `output_data` の全記録の戻りに `effect_targets` を通した（敵はプロンプトの敵の欄の鍵と `名前`、効果の向きはプロンプトのスキル詳細）。書き換わったのは、主人公の通常攻撃の12件、主人公のスキルの1件、仲間の手の10件（通常攻撃8・強化2）だけだった。敵向けは敵の鍵に、強化は本人と味方に寄った。ほかの 2322 件は書き換わらなかった
- 最初の版は寄せ先を表示名で書いていた。連番付きの敵では審判の対象の形と合わないので、上の当て直しの前に鍵へ直した
- 実機は未。外れる率が 1% 前後で、狙って起こせない。`out\battle_tactics.log` に `target fixed:` が出た手で、`308_` の行が正しい側の HP の増減になっていれば成立
