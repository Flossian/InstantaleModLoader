# 3.82 衛兵の戦闘と倒れた戦闘の窓口（`guards` / `defeat`）: 3本とも実機で成立

`336_` の脱獄で、衛兵の戦闘の強さの差し替え（`316_` と同じ2か所）と、倒れた戦闘の切り上げ（`334_` と同じ手順）を写して持っていた。
同じ処理を3本で持たないよう、ローダの窓口 `guards`（TECH.md §3.3.10）と `defeat`（§3.3.11）へ移し、3本とも乗せ替えた。
振る舞いは変えていない。`tools\tests\` の検査は通っている（`test_bounty_hunter` / `test_colosseum_custom`。偽の ctx は同じ対象への2つ目の包みを外側に重ねる形に直した）。

| mod | 版 | 変えたこと | 実機で見ること |
| --- | --- | --- | --- |
| `316_bounty_hunter` | 3（§3.80 で上げた版のまま） | 追手の衛兵の戦闘を `guards.build` で組み、強さは `guards.arm` で決める。2か所の包みを外した | 済（2026-10-05）。手配度 -80 で宿泊の後に追手（発生率と間だけメモリ上で 100%・0 日にして、終わってから戻した）。`modloader.log` に `guards: building the enemies with difficulty 75`、改名・倒した分の手配度の戻し（-90 → -80）・336 への知らせ（前金）も従来どおり |
| `334_colosseum_custom` | 6→7 | 倒れたときの切り上げを `defeat` に登録する形にした（体力を戻す・逃走と同じ終わり方・残りの手と敵の欄の 0 除算は窓口が受け持つ）。倒れた仲間を連れて戻すのと、手配度を戻すのはこの MOD のまま | 済（2026-10-05）。闘技場で体力を 0 に保って倒れる。`defeat: ending the battle as an escape for 334_colosseum_custom` → `the player is back in the party` → `hp 0 -> 1`、ゲームオーバーにならず闘技場の選択肢へ。334 の手配度の戻し（`undid the drop from losing the match`、-110 → -100）も従来どおり |
| `336_crime_overhaul` | 1 | 脱獄の決行を `guards` と `defeat` に乗せ替えた。あわせて1本のファイル（約1,950行）を機能ごとに分けた（`loot` / `law` / `theft` / `office` / `prison` と土台の `common`） | 済（2026-10-05）。勝つ（備え 1 で難易度 76 → 65、敵 Lv66）と倒れる（`defeat: … for 336_crime_overhaul`、刑期 4 → 6 年で牢へ戻る）の両方 |
