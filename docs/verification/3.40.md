# 3.40 功績による土地の案内文の書き換え（`321_`）: 実機で成立・残るは言及率だけ

オフラインで確かめたこと（`tools\tests\test_area_chronicle.py`）:
クリアからの編纂・descriptions の差し替え（**新しい dict で。元は書き換えない**）・
取りこぼしからの立ち直り（`done` が進まない限り次の照合で再挑戦）・
読めない返答と膨張の却下・功績の絞り・ロード時の当て直し・
第一声への差し込み（既定 OFF / 複製にだけ足す / 年代記の無い土地では足さない）。

実機1回目（[§2.75](2.75.md)）で決着したこと:

- **実行時の形**: dict。ただし鍵は3枚で、
  world_data には無い `area_description` がある（誰が読むかは未特定。
  差し替えは2鍵だけ上書きするので3枚目は素のまま残る）
- **キャッシュの有無**: 無い。編纂を境に narrator /
  random_quest_generator / vacation の各プロンプトが新文面へ切り替わった
- **街歩きナレーション**: `narrator` で確定。
  プロンプトに overview が載っている（facilities は載っていない）ので
  原文の差し替えが自動で波及する。注入先の追加は不要
- **編纂の質**: 1件目は合格。霧の記述が両方の文から消え、
  土地の正体と未解決の糸は残った。並べ直しにも堕ちていない

実機2回目（[§2.76](2.76.md)。依頼1件の通し）で決着したこと:

- **クリア契機**: `契機 クリア` で予約、ゲーム側の要約が書いた10件目を
  待ちの1巡目で拾って編纂。頼み文には前回の編纂結果が現行文として載り、
  新しい功績は1件だけ（織り込みの連鎖と絞りが設計どおり）
- **ロード時の当て直し**: `load:` の行に加え、当て直し後の
  `quest_summarizer` のプロンプトが編纂済みの文面を載せていた
- **編纂後の会話**: conversation_starter の【土地情報】が新文面
- 読み手の追加発見: `shop_item_generator_ordinary` も overview を読む

## 残っていること（実機は1点だけ）

1. **言及率の前後比較**。介入前の基準値は 0/775（GAME.md §2.24）。
   物差しは、system に載った回を分母、応答の自発的な言及を分子。
   上がらなければ `MENTION_IN_STARTER`（既定 OFF）を入れて再測定
