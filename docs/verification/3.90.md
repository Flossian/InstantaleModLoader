# 3.90 会話の外で送った文を本文に残す（`141_`）: 自由行動・戦闘・会話・値切り・依頼の中の行動・裁判・依頼の中の会話は実機で成立

遊び方は `141_` の DOC.md。記録は `out\free_input_echo.log`。

## 決めた仕様（再検討しない）

- 形は送った文そのままの1行で、名前も印も付けない。会話の発言と同じ「主人公名: 文」にすると、行動が発言に見える（実機で出して見た）。頭に「＞ 」を付ける形も実機で出したが、要らないとした。足す先は本文の待ち行列（`ui.Screen.say`）で、ゲームの処理より先に足す
- 足すのは入力欄の送信（`on_text_input`）の中で `process_choice` が来たときだけ。文は `process_choice` に渡った文字列を使う。ボタンの押下には足さない
- 送り先が `ConversationPhaseManager` / `ShoppingNegotiateManager` / `UtteranceInBattleManager` のときは足さない（ゲームが出す）。値切りと戦闘の「発言する」は版2で足した
- 依頼の中の会話（`ConversationInQuestPhase`）は、ゲームが主人公の発言を出さないので「主人公名: 文」で足す（版2。版1は足さない側に入れていた）。会話の中なので行動と見分ける必要が無く、ふだんの会話でゲームが出す行と同じ形にした

## 分かったこと

- 会話の外の自由行動は、入力文を本文に出さない。122 の記録では、自由行動の前に入力文の行が無く、GM の語りから始まっていた（10-04 の盗みなど）
- 入力欄の送信は `on_text_input` の中で `process_choice` を同期で呼ぶ。自由行動は `FreeInputStart`、戦闘は `BattlePhaseManager` に流れた
- 戦闘の入力文もゲームは本文に出さない（141 が足した1行だけが出た）

## 確かめたこと（2026-10-08、ペルディションの闘技場）

- 自由行動: `FreeInputStart: echoed`。本文に入力文の行（このときは「主人公名: 文」の形）が GM の語りの前に出た（写真でも見えた）。122 の記録にも同じ行が入った。「＞ 文」の形でも、同じ場面で語りの前に出て、写真で見えた。印を外した今の形は実機で出していない
- 会話: `ConversationPhaseManager: the game shows it`。本文の発言の行は1つだけ
- 戦闘（試合）: `BattlePhaseManager: echoed`。入力文の行は1つだけで、続けて審判の語りとダメージの行が出た
- 確かめていないもの: 裁判の釈明（`TrialPhaseManager`）、依頼の中の会話（`ConversationInQuestPhase` がゲーム自身で出すかも測っていない）。どちらも 11-03 に確かめた（下）

## 確かめたこと（2026-11-03、テストワールド。版1）

送り先ごとに1回ずつ送り、本文の行を拾って写真でも見た。

| 送り先 | ゲーム自身が出す行 | 版1の本文 |
| --- | --- | --- |
| 店の値切り（`ShoppingNegotiateManager`） | 「主人公名: 文」 | 2行（141 の行の後にゲームの行） |
| 戦闘の「発言する」（`UtteranceInBattleManager`） | 「主人公名は「文」と発言した！」 | 2行 |
| 戦闘中に入力欄から送った行動（`BattlePhaseManager`） | 無し（審判の語りだけ） | 141 の1行 |
| 依頼の中の行動（`QuestPhaseManager`） | 無し（GM の語りだけ） | 141 の1行 |

値切りと発言は版2で足さないようにした。

版2を同じ場面で実機に出した（2026-11-03）。
値切りは `ShoppingNegotiateManager: the game shows it` で、本文はゲームの「主人公名: 文」の1行だけ。
「発言する」は `UtteranceInBattleManager: the game shows it` で、ゲームの「…と発言した！」の1行だけ。
戦闘中に入力欄から送った行動は、変わらず `BattlePhaseManager: echoed` で 141 の1行の後に審判の語りが出た。
## 裁判と依頼の中の会話（2026-11-03、テストワールド。版2）

| 送り先 | 入り方 | ゲーム自身が出す行 | 版2の本文 |
| --- | --- | --- | --- |
| 裁判の釈明（`TrialPhaseManager`） | 手配度 -40 で施設を2往復しても衛兵が出ず、ギルドの「出る」を `TrialStartManager`（衛兵の「大人しく捕まる」と同じ罪状）に差し替えて押した。裁判から先はゲームと MOD の経路のまま | 無し | `TrialPhaseManager: echoed`。141 の1行（一文ごとに改行されて3行に見える）の後に判事の判決 |
