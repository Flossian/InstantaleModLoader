# 3.24 タイトル画面の版表示（`126_`）: 決着

タイトル画面の隅に `modloader v<版>` のラベルを1枚置く。
ゲームの値は何も読まず、何も書き換えない。
表示・組み直し・窓の追従・タイトルの操作、いずれも実機で確認済みで未確認は残っていない（§2.47）。

設計の要点は足す経路が2つあること。
注入は窓が出てから走るので、`__init__` を包むだけでは注入時のタイトル画面に何も出ない。
`ctx.on_ready` で `Window` から辿る側と `__init__` を包む側の両方が同じ関数を呼び、
足す前に自分の印が付いたラベルを外すのでどちらから来ても1枚になる。

いちばん危なかったのは画面の子を1枚増やすこと（HUD では同じことがアイテムの移動を壊している。§2.33）。
**タイトル画面には「最初の子」を読む側が居ない**というのが足してよい根拠で、
実機の確認はそこを見ていた。
