# 3.41 パーティーメンバー全員と話す（`404_`）: 決着・残るはレビュー後の再確認だけ

オフラインで確かめたこと（`tools\tests\test_party_talk.py` 84件）:
応答の解読（フェンス付き・説明混じり）・アンカーと仲間への分配（参加者以外と重複を落とす）・
仲間の台詞を本体の履歴に積まず自分のプロンプトへ位置どおりに合流させること・
立ち絵の枠が相手枠のすぐ手前に同じ寸法で挿さり終了と戦闘で外れること・
選択肢が「会話する」の一覧と NPC 不在の根のメニューにだけ出ること・
パーティー会話中に `302_` / `402_` の選択肢を落とすこと・要約の例外でも会話を畳むこと。

実機6回（[§2.78](2.78.md)）で決着した。残るのは次の1点。

- レビューで直した9点の実機での再確認。実機で見えるのは
  「要約が失敗した回でも次の会話が普通の1対1に戻る」「3人で 12 ラウンド以上続けても仲間が前の台詞を踏まえる」
  「`prompt trimmed:` は 30,000 字を超えたときだけ出る」の3つで、どれも壊れていないことの確認になる。
  読むのは `out\party_talk.log`

確認手順: 仲間を2人以上連れ、「会話する」→「パーティーメンバーと話す」。
`party_talk.log` に `party talk start` → `portrait added` → `round N anchor=... extras=[...] dropped=[]` →
`hid the party-only choices` → 終了で `portraits removed: frames=[...] anchor_restored=True`。
