# 3.14 戦闘のダメージ表示（`308_`）: 実機で成立

通常攻撃・スキル・とどめの一撃・味方の被弾がいずれも表示された（§2.39）。

1回目は**とどめの一撃だけが1行も出なかった**。
原因は報告のときに「今 `current_enemy_dict` に居る者」だけを見ていたこと。
倒した敵は報告より先にそこから抜けるので、比べる相手が居なくなる。
台帳に HP だけでなく持ち主そのものを控え、
鍵が場から消えた回にその参照から最後の HP を読んで1行出す形に直した
（残量の代わりに `（撃破）`。HP が動かないまま消えた敵＝逃走は出さない）。
「スキルのダメージが出ない」と見えていたのも、その手で敵が倒れた回だった。

**残っているのはコロシアムと、味方が倒れた／逃げた場合の2つだけ**（どちらも0件）。

| 見るもの | 意味 |
| --- | --- |
| `battle start: N combatant(s)` が出ない | `start_battle` を通らない戦闘（コロシアム）。台帳の取り直しを別の入口にも足す |
| `ally … (left the field)` | 味方が名簿から抜けている。味方に `（撃破）` は出したくないので文言を分ける |
| `battle end check:` に HP の変化が並ぶ | `handle_battle_situation` が拾えていない ＝ 報告点が足りない |
