# 2.57 時計をやめた（`316_` 版5）

秒で区切る箇所を、**画面が整った合図の回数**と**ゲーム内の日数**に置き換えた。

| 区切り | 前 | 後 |
| --- | --- | --- |
| ゲーム自身の衛兵の後 | 300秒 | 1回の遭遇として数える（クールダウンの日数に乗せる） |
| 決めたのに出せないまま | 120秒 | 合図20回 |
| 出したのに戦闘が始まらない | 120秒 | 合図20回 |
| 倒したぶんの手配度の見張り | 60秒・7回の予約 | 戦闘の終わりと、その後画面が整うたび（合図10回ぶん） |

秒で区切ると、待っている間にゲームが何をしていたかと無関係に時間だけが過ぎる。
実機で踏んだ2件（§2.54 / 宿泊への割り込み）はどちらも
「秒は経ったが場面は終わっていない」形だった。
