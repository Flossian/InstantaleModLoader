# 3.105 宿屋で食べ物・飲み物・酒を売り買いできる（`340_inn_shop`）と、312 の宿屋の分岐（版7）: #1〜#8 は実機で成立（10-19）・売買のたびに足す品（#9）は呼ばれる場面が未確認・セーブエディタで足した宿屋で落ちたのを直した（実機で成立）

2026-10-19 に作った。宿屋の `Facility.choices` に店と同じ `売買する` を足し、品揃えの生成はゲームに任せる。

## セーブエディタで足した宿屋で落ちた（10-19、実プレイの世界）

実プレイの世界の宿屋で「売買する」を押すと、`shopping_start_method_1` が `KeyError: '228'` でスレッドごと落ちた（`out\live_crashes.log`。`stall guard: Thread-3 (execute) died`）。
その宿屋はセーブエディタで足した施設で、セーブを復号すると `save_data_dict` には在り、`world_dict`（`world_data.json`）には無い（GAME.md §2.28 と同じ形。同じ街の 229 は 08-21 に `906_` の試しで写したもの）。
素のゲームでは宿屋の売買が開かないので、これまで表に出なかった。

| 直し（版1のまま） | 中身 |
| --- | --- |
| 出さない | 選択肢の組み直しの前に、今いる宿屋の施設と主が `world_dict` に在るかを見る。無ければ施設の `choices` と組み直す前のボタンから `売買する` を外す（`withheld at inn` を1度だけ記録） |
| 揃ったら出す | 在れば足し直す。宿屋の画面（`宿泊する` と `出る` が並ぶ）のボタンに欠けていれば先頭に入れる。ロードは保存に焼かれたボタンを戻すだけなので、入口を足す前に保存した宿屋の画面にも効く |
| 写さない | `906_` のように `world_dict` へ写すことはしない。素のゲームでは踏めず、直すのはエディタの側（施設も `world_data.json` へ写す） |
| その後（10-20） | `146_fix_save_only_entities` が売買の間だけ引き先をセーブ側にする（[§3.107](3.107.md)）。`340_` は窓口 `save_lookup` に `146_` が名乗っていれば、この守りを外して入口を出す |

ゲームは保存のたびに `world_data.json` も書く（2つの世界とも `savedata.json` の約0.1秒前に更新されていた）。

実機（テストワールド、メモリ上の `world_dict` から宿屋を抜いて同じ形を作り、控えへ戻した）:

| 見たこと | 結果 |
| --- | --- |
| 素データに無い宿屋に入る | 成立。`宿泊する(1週間) / 出る / 会話する` で `売買する` が出ない。`withheld at inn 222 '銀灰の宿': not in world_dict` |
| その場で素データへ戻し、選択肢を組み直す | 成立。`売買する / 宿泊する(1週間) / 出る / 会話する` に戻り、押すと品揃えを作って開いた（`rewrites=1`） |
| 起動し直した直後 | 読み込みが 340 の当て直しより先に済むと、最初の画面には出ない。何か1つ選ぶと見回りが走って出る（`sweep: 11 inn(s)`） |
