# 3.67 闘技場の試合から逃げると建物から出られない（`modfacility` / `331_`）: 原因は `107_` 版2 で決着・`107_` を切った構成の備えだけ実機未確認

実機で踏んだ（`331_` が建てた闘技場）。
試合に出て戦闘から逃げた後、闘技場の画面に**出口（`出る`）が出ず、建物から出られなかった**。
ゲームは実行時に足した施設に出口を作らないので、出口が出ないとその建物からは出られない。

ログから読める並び（`out\real_estate.log` の `modfacility:` の行。この起動では計測は入っていない）:

```text
23:31:02  where: … inside=mod:331_…:6-2 game_choices=3 → 5    ← 入った直後は足せている
          to_display_buttons ['試合に出る','観戦する','会話する'] -> … 出る まで
23:31:22  [BGMPICK] colosseum … in_battle=1 in_colosseum_battle=1   ← 1試合目
23:31:29〜42  where: … game_choices=3 / 2 / 3 / 2   ← 逃げた後もこの間 to_display_buttons が1行も無い
23:31:42  arena: 4 earlier fighter(s) told to the generator   ← 2試合目を申し込んだ
23:32:10  where: … game_choices=3 → 5、to_display_buttons で 出る が出る   ← 普通に終えた後は足せた
23:32:12  pressed '出る'
```

同じ画面（闘技場の3つの選択肢）で、逃げた後だけ足されていない。
`can_add_here` の門は2つ（`game_is_busy` の旗と `is_top_screen`）で、
どちらで降りたかはログに残っていなかった（この判断は1行も書いていなかった）。
この起動は 68 本の構成で、旗を下ろす側（`106_` / `107_`）も計測（`207_` / `233_`）も入っていない。

原因は旗の残骸で確定した。 撤退すると `in_colosseum_battle` が立ったまま残る
（`233_probe_colosseum` の実機。§1 の `107_` の行と GAME.md §2.10）。
本体は `in_battle` だけを main_024 で直していて、闘技場の撤退はそこから漏れている。
`107_fix_battle_flag_stuck` を版2で現役に戻し、そちらで旗を下ろすようにした（実機で成立）。

下の2つは**旗が下りない構成でも閉じ込められない**ようにするための備え（`107_` を切っていても効く）:

| 何 | どこ |
|---|---|
| 戦闘の旗が立っていても、**敵が居なければ**（`app.current_enemy_dict` が空）その旗は無かったものとして扱う。旗そのものは下ろさない | `modfacility.battle_leftovers` / `can_add_here`（TECH.md §5.8） |
| 建物の中で何も足さずに降りた回に、理由と画面の spec を1行残す（理由が変わるまで黙る） | `modfacility.note_blocked` |

オフラインは `tools\tests\test_modfacility.py` に5件足した
（敵が居る間は足さない／残骸なら出口が出る／旗は下ろさない／会話の旗が混ざっていたら足さない）。

**実機で確かめること**（`107_` 版2 が入っていれば旗は下りるので、下は `107_` を切った構成での確認）:

| # | 何 | どう確かめるか |
|---|---|---|
| 1 | 逃げた後に出口が出る | `107_` を切って、`331_` の闘技場で試合に出て撤退する。闘技場の画面に `出る` が並び、押して街へ戻れる |
| 2 | 本物の戦闘では足さない | 同じ試合の戦闘中、選択肢に `出る` が混ざらない |
| 3 | 理由の行が出る | 足さずに降りた回に `out\real_estate.log` へ `modfacility: nothing added inside …: the game is busy (in_colosseum_battle; enemies are present)` のような行が1本だけ出ること（理由が変わるまで黙る） |

`107_` を入れた構成では、#2 と #3 は `334_` の実機で見えた（戦闘中は `the game is busy (in_battle, in_colosseum_battle; enemies are present)` で足さず、逃走の終わり方の後は `出る` が足された。`334_` の切り上げで敵が残った回だけは出口が出なかったが、それは切り上げ側の不具合で直した。§3.69）。#1（`107_` を切った構成）は試していない。
