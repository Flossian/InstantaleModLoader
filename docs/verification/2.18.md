# 2.18 クエスト1件を頭から終わりまで実測

結論は「討伐でないクエストは**プロンプトの差し替えだけで成立する**」。
判定に使った事実:

| 観測 | 意味 |
|---|---|
| `ReturnAfterCompletion` がボス健在でも毎ターン作られる | 完了はスキーマで塞がれていない |
| 残イベントが尽きた瞬間 `FieldEvent` が union から消えた | 空 `Literal[]` を避ける分岐が実在する |
| `Battle.enemies` の `Literal` が 7→6→5→1 と減る | `Literal` は残りであって `enemies` 全体ではない |
| 完了フェーズは `QuestEndManager(app)`、引数ゼロ | MOD から完了させる手が残る |
| `QuestEventManager(app, event_name, enemies_info, event_turn)` | 戦闘を通さず1回分の出来事を起こせる |

敵とボスのデータは削らずに残す（`Literal` を空にしないため）。
進行ループの詳細は GAME.md §2.9。
