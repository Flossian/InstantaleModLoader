# 3.18 自由入力の能力値補正（`313_`）: 経路も加点も実機で成立

推定は 6/6 とも `dexterity`（行動はすべてスリ）で、追加コストは 0.8〜1.6 秒。
`chance_percent` の書き換えも通り、
`dexterity` を 12 → 25 にした回で `+16%(能力値)` ＝ **表どおりの加点**が乗ることまで確認した
（他の能力値は動かしていないので、読んでいるのが `reference_attribute` に対応する値であることも確かめられた）。

この回で見つかった2点は対処済み。
控えの鍵に `think` / `narration` を混ぜていたため毎回聞き直していた（**鍵は入力文だけ**に）。
能力値が想定よりずっと低く、**基準15では新規キャラの加点がほぼ0になる**
（作成時の才能点が既定だと合計76前後。GAME.md §2.17）。
これを受けて「基準15のまま、底上げは0」と決めた。
素のゲームの確率をそのままに、訓練で15を超えてから効き始める形。
あわせて加点0の回も記録に残す（何も起きない回が普通になるので、
記録まで空だと「MOD が動いていない」のと見分けが付かない）。

残るのは推定の質だけ。
スリ以外（説得・こじ開け・解読・見張り）を通し、選ばれた能力値が噛み合うかを見る。
的外れな回は `output_data\<世界>\<PC>\mod_ability_for_action\` から語句の表を直す材料になる。
