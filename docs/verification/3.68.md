# 3.68 MOD の建てた施設の主人と既存 NPC の名前が重なると立ち絵を共有する（`modnpc` / `330_` / `331_`）: 直しは入れた・実機で未確認

**重なりは実データで確認できた。** `120_fix_npc_name_collision` の記録（`out\npc_name.log`）に、
MOD の主人と素の NPC・MOD どうしの衝突が並んでいる。

```text
id='mod:330_real_estate:keeper-6' '<名前A>' clashes with id='89' '<名前A>'
id='mod:330_real_estate:keeper-4' '<名前B>' clashes with id='mod:331_facility_investment:keeper-0-1' '<名前B>'
id='33' 'カイン' clashes with id='mod:331_facility_investment:keeper-6-2' 'ガイン'
```

`120_` は MOD の人物を改名しない（`left as it is`）ので、重なったまま残る。
控え（`state\modnpc\<世界>.json`）とセーブを突き合わせても同じで、
`mod:330_real_estate:keeper-6` の名がセーブの id `89` と同じだった。

**原因**: `330_` も `331_` も、主人の名前を決めるときに避ける名前（`taken`）を
**自分の帳簿の主人だけ**から集めていた。素の NPC も他の MOD の主人も見ていない。

**直し**: ローダに窓口を1つ置き、両方がそこを見るようにした。

| 何 | どこ |
|---|---|
| その世界で使われている人名（実行時の名簿・セーブの素データ・登録されている MOD の NPC 全部・プレイヤー）を1か所から返す | `modnpc.names_in_use(app, skip=…)`（TECH.md §5.7） |
| 主人の名前を決める前にそれを `taken` へ混ぜる | `330_` / `331_` の `keeper_names` |
| **既に重なっている主人を空いている名前へ寄せる**（控えの `name` と素データ、居れば実体の3か所。表に空きが無ければ WARN を出してそのまま） | `330_` の `settle_keeper_name`（据える前に毎回）／`331_` の `settle_keeper_names`（世界で使われている名前を先に置いてから突き合わせる） |

オフラインは `tools\tests\test_modnpc.py` に6件
（名簿・素データ・他の MOD・プレイヤーから拾う／重複を畳む／`skip` は数えない）、
`test_real_estate.py` に5件・`test_facility_investment.py` に3件
（同名の人物が居たら寄せる／素の人物のほうは変えない／実体と控えの素データにも書く／ログに残る）。

**症状**: 同じ名前の人物が2人居ると、**同じ立ち絵で、記憶・経歴・性格だけが違う人物**になる
（最初の報告にあった「記憶も引き継ぐ」は誤りで、
中身は主人自身のもののまま、顔だけが先に居た人物のものになる）。

原因は**立ち絵の置き場が名前**であること。

| 何 | 根拠 |
|---|---|
| 立ち絵は名前のフォルダに置かれる（`worlds\<世界名>\characters\<名前>\`） | GAME.md §2.31。実データでも `characters\<名前A>\` に `face_image.png` / `generated_image.png` / `prompts.json` が揃っていた |
| 絵は**無ければ作り、以後は再利用**する | §3.59 の #7 で実測。だから後から同じ名前で立った人物は、先に居た人物の絵をそのまま着る |

人物そのものが入れ替わるわけではない（こちらのコードとローダは人物を全部 id で引いている。
`ui.character_name` / `311_` の控え / `120_` の書き換えはどれも id が鍵。
`323_npc_carryover` だけは世界をまたぐので名前だが、これは仕様）。
名前を1つに保てば絵も分かれるので、直しは名前の側だけでよい。

`121_ui_character_sheet` の名前での引き当ては**この件とは無関係**。
人物欄に出るのはプレイヤーだけなので、あの引き当ては常にプレイヤーで止まる。

**実機で確かめること**:

| # | 何 | どう確かめるか |
|---|---|---|
| 1 | 名前が重ならなくなる | 名前が重なっている世界で新しい建物を建て、主人の名が既存の誰とも重ならないこと（`out\npc_name.log` に新しい衝突が増えない） |
| 2 | 顔が分かれる | 寄せた後の主人と会話し、`worlds\<世界名>\characters\<新しい名前>\` が新しく作られて、素の NPC と違う顔になること（古い絵は相手のフォルダに残るだけで、害は無い） |
| 3 | 既に重なっている主人が寄る | いまの世界の `mod:330_real_estate:keeper-6`（'<名前A>'）は素の id=89 と同名。ロードして家に入ると `out\real_estate.log` に `keeper: … was renamed '<名前A>' -> …` が1行出て、以後はその名前で通る（変わるのは一度だけ。次のロードではもう重なっていない） |
