# 3.12 訓練の経験値を仲間にも（`306_`）: 写しは成立・レベルアップが未観測

実機1回目で写しは成立した。
宿屋の訓練は `VacationTrainManager` で確定し、経験値は `Character.gain_exp` を通り、
写す量はプレイヤーと同額（`732806 → 1419658` ＝ +686852 が同行者にも入った）。
支給は訓練1回につき1本、誤爆なし。

レベルアップだけが未観測。
その回は仲間もプレイヤーも必要経験値に届いていなかっただけで、経路が壊れているわけではない。
その後の訓練6回も**すべて同行者ゼロ**だった（§2.49）。

この回を受けて2点直した。
`ANNOUNCE_GAIN` を既定 ON に（高レベルでは1回でレベルが上がらず、
ログを見ないと効いているか分からない）。
文言はプレイヤーの獲得経験値の後に出す（`gain_exp` はゲームの2行の間で呼ばれるので、
その場で出すと順番が入れ替わる）。
支給の点数と表示の数字は別物（686852 を写して画面には 156 と出る）ので、文言に数値は入れない。

**残りの確認手順**: 仲間を1人雇ってから宿屋で月日を訓練に充てる。

| ログの形 | 意味 | 次にやること |
| --- | --- | --- |
| `+... exp` の行が出ている | 効いている | ゲーム内のレベル表示と突き合わせる |
| `shared 0 gain(s)` ＋ `WARN ... no Character.gain_exp call was seen` | 経験値が `gain_exp` を通っていない | `player lvl/point` の変化を添えて報告 |
| `VacationTrainManager` の行が1つも出ない | 別のマネージャで走っている | `(not training)` の `from ...` を見て `INN_TRAINING_MANAGERS` に足す |
| `nobody is travelling with them` | 仲間が同行していない | 行の末尾に候補の入れ物が全部出る |

未確認のまま残るもの: 施設での訓練が本当に宿屋とは別画面なのか /
休養（`SHARE_REST`、既定オフ）で経験値が入るのか / 仲間のレベルアップで HP・能力値がどう動くか。
