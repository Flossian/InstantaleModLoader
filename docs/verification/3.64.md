# 3.64 訓練所の代金・修行の量・1段の期間・再訓練（`332_`）: 実機で代金・期間・倍率・表示・文言・頼み文・再訓練が成立（版11 まで）・残るは2件

`231_probe_training` で録れた訓練の暦（GAME.md §2.17）に当てる MOD。
代金と1回の修行の年数は `TrainingStartManager.__init__` の引数を差し替え、
1段の期間（ベース期間 × 倍率）はローダの関所（TECH.md §3.3.3）へ望みを出す。
ゲームが数える年数（残り年数の減り方と、残り年数に収まる修行だけを並べる判定）は
ゲームの内側に在って引数に出てこないので触っていない。

## 実機で成立したこと

| 見たこと | 結果 |
|---|---|
| ベース期間（#3） | **通った**。ベース `1ヵ月` で `label: 'ただ鍛える(1年)' -> 'ただ鍛える(1ヵ月)'`（4つとも）。`新たな技を学ぶ(3ヵ月)` を押して `days: 1095 -> 90 (332_training_custom decided 90)`、暦も 90 日だけ進んだ |
| 画面の文言（#9） | **通った**。`あと3年間。どうする？` → `あと3ヵ月。どうする？`、`一年間、ひたすら鍛錬した。` → `1ヵ月、ひたすら鍛錬した。`、`残り1年間。何をする？` → `残り1ヵ月。何をする？`、`二年間、技を磨くことに費やした。` → `2ヵ月、…`。`基礎を積む` の言い回しだけ1つ漏れた（下の「分かったこと」） |
| AI へ渡る頼み文（#10） | **通った**（版4 以降）。`prompt at chat: the years became the real period` が開始と卒業の両方で出て、卒業の言葉も「この数ヶ月」になった。版4 より前は画面が `あと3ヵ月` でも師範のセリフだけが「三年間」のままだった（頼み文に年数が焼き込まれている） |
| 卒業した施設での再訓練（#11） | **通った**（版9）。押した時点で `retrain: dropped the 'trained' mark of '<道場名>' (config now ['level_of_detail'])`。そのままゲームの訓練が始まり、頼み文の書き換え → `あと3ヵ月。どうする？` → 選択肢4つ、と**卒業していない施設と同じ道**を通った。同じセッションで2周目も通った |
| 印を立たせたままにしない（#11） | **通った**。卒業した段の後にも `dropped`。控え（`state\modfacility\<世界×主人公>.json`）の config は `{"level_of_detail": 0}` で、一度も卒業していない道場（`<別の道場名>`）と同じ姿 |
| `技を磨く` の段（#12） | **通った**（版9）。`二年間、技を磨くことに費やした。` → `2ヵ月、…`、`days: 730 -> 60`。2周とも動いた |
| 段がゲームの流れで走る | **通った**。`基礎を積む(2ヵ月)` で `days: 730 -> 60`、筋力・器用・耐久が上昇、`残り1年間。何をする？` → `残り1ヵ月。何をする？`。続く `ただ鍛える(1ヵ月)` で `days: 365 -> 30` から卒業まで。段の年数の勘定（3 → 1 → 0）もゲームのまま |
| 関所の外（計測） | 同じ回に `231_probe_training` が `elapse_days(1095)` と**素の数**を録っていて、「計測は関所より外」の性質も保たれている |

オフラインは `tools\tests\test_training_custom.py`（129項目。偽の訓練所で
代金・拒否・年数・期間・倍率・未知の種類・再訓練・文言・頼み文・表示・ワールド個別・窓口）で通っている。
訓練所は `331_facility_investment` の道場で開ける。

## まだ確かめていないこと

済んでいるのは #1〜#7 と #9〜#13 の12件。
#9 は `基礎を積む` の言い回しで一度漏れたが、版10 の直しまで実機で通した。
残るのは #8 と #14 の2件。

## 分かったこと

**1段の結果の言い回しは修行内容で違う。**
4種とも実機で見た。

| 修行内容 | 画面に出る文（実測） |
|---|---|
| ただ鍛える | `一年間、ひたすら鍛錬した。0の経験値を得た。` |
| 基礎を積む | `二年を基礎能力の向上に費やした。筋力が上昇した。…`（**「間」が無い**） |
| 技を磨く | `二年間、技を磨くことに費やした。` |
| 新たな技を学ぶ | `新たな技の習得を模索した...` → `スキル「<技名>」を習得した。`（**年を言わない**。2回とも） |

錨が `年間` だけだったので `基礎を積む` に当たらなかった（暦は `days: 730 -> 60` で正しく、文言だけが年で残った）。
版10 で助詞まで見る形にした（`N年` の後ろが `、` `を` `で` のときだけ当てる）ので、
`三年後` のような別の意味の年には当たらない。

**「1年で進む日数」を設定にすると画面の年数と意味がずれる。**
版1 はそれで、暦は縮むが**1年が30日になる**。
版2 で「1段のベース期間 × 修行内容ごとの倍率」に作り直し、
ボタンにも実際に進む期間（`ただ鍛える(1ヵ月)`）を出す形にした。

**ゲームが年で言うのは画面だけではない。**
版3 で画面の文言（`あと3年間` `一年間、ひたすら鍛錬した。`）を実際の期間に直したが、
実機では師範のセリフだけが「三年間」と言い続けた。
頼み文にも年数が焼き込まれていたためで、版4 で頼み文の側も直した。
錨は訓練の頼み文にしか無い言い回しに打つ。
素の `N年` に当てると、同じ頼み文に載っている人生ログ（`3年間の過酷な基礎訓練`）や
土地との縁（`この土地に合計2年暮らしている`）まで書き換えてしまい、
どちらも**過去の記録**なので後から期間を書き換えるのは嘘になる。

**卒業済みを断っている根は施設の印で、キーごと落とすしかない。**
卒業した道場の控え（`state\modfacility\<世界×主人公>.json`）に
`snapshot.config.trained = True` が立っていた（`savedata.json` の側には同じ名前の項目が無い）。
版8 は `False` を入れていたが実機で断られ続け、版9 でキーごと落とす形にした。
一度も卒業していない道場の config には**キー自体が無い**ので、
ゲームが見ているのは値ではなくキーの有無と読める。

**断られた回を引き取る形は、ゲームの支度ごと失う。**
版5〜7 は修行の選択肢を自分で組んでいた。
引数の形が実測どおりでも支度（主の絵と背景）が飛ぶので背景の出ない画面になり（実機）、
断りの文言を伏せる・払い戻すといった後始末も要った。
実機2回目に `技を磨く` が 0.0 秒で断られた（`<道場名>は今日はここまでのようだ。`）のも
ゲーム側の条件ではなくこの作りが原因で、版9 では2周とも通っている。
印を落とす側に寄せて、引き取る・伏せる・払い戻すを全部やめた。
