# 2.78 仲間全員と話す。実機6回で決着（`404_`）

提供元（MoririnJP 氏の `404_party_talk` v6）の同梱ログ1回分に続き、こちらで6回。
すべてローカル llama-server、仲間2〜3人。読んだのは `out\party_talk.log` / `events.log` /
`npc_profile.log` / `npc_social_memory.log` / `output_data\...\mod_party_talk\N.json` と目視。

| 回 | 見たこと | 結果 |
| --- | --- | --- |
| 1 | 横取りと分配。仲間の台詞を本体の履歴に積まない | facilitator を2回とも横取りし、本体の1対1は走らない（`llm_overlap.log`）。`output_data` の【直近の対話ログ】に仲間の台詞がラウンド1の位置で並び、同じラウンドの `311_` の抽出は `transcript 174 chars` で仲間の台詞（約60字）を含まない。`403_` は `changed: false`（更新材料が無い。設計どおり） |
| 2 | 立ち絵を並べる初版 | 並んだが仲間が本文の枠の手前に相手枠より大きく出た。`overlay_host` の FloatLayout は本文より手前に描かれ、`type(base)()` の複製に kv の canvas が付いてこないため。置き場所を相手枠の隣に、寸法と切り抜きを canvas の Rectangle から写す形へ |
| 3 | 2版の並び | 相手枠と同じ大きさで本文の奥に並んだ。終了後に仲間の絵だけ約2秒残った（`finish_conversation` の要約の後に片付けていた）。宿屋の根のメニューで選択肢が出ず、部屋選びには出ていた（spec 名の除外リストの取り違え） |
| 4 | 一覧方式と片付けの前倒し | `portraits removed` が `party talk end` より 2.2 秒先に来て、要約より先に消えた。「会話する」の一覧（相手 0 人でも）に出て、NPC 不在の画面には自前の「会話する」が出て2択の一覧になった（`to_display_buttons [...] -> ['パーティーメンバーと話す', 'やめる']`）。ギルドの一覧（「やめる」だけ）に出なかった件と、店に寄った後に出なかった件（`in_shopping` が店を出ても残る）はここで直した |
| 5 | 仲間3人 | 並びと寸法は揃ったが左端が x≈480 で縦に切れた。切り抜きの矩形を毎ターン相手枠から読み直し、動かした後の矩形（canvas はウィジェットに追従する）を写していたため。動かす前に1度だけ控える形へ。横位置も 1/(n+1) 刻みから 0.32〜0.68 の等間隔へ（両端が左の選択肢と右の仲間欄に被った） |
| 6 | 3人の並び、`302_` / `402_` の選択肢 | 仲間A（アンカー）0.32 / 仲間B 0.50 / 仲間C 0.68。左端は切れず両端は UI に掛からない。「ここで別れる」「＜アイテムの受け渡し＞」は毎回落ちて `1 left`。4ラウンド `dropped=[]`。タイトルへ戻って抜けても `portraits removed: frames=['18', '19'] anchor_restored=True` |

相手枠の実測（3回とも同じ。窓 1920 幅）:
`base size=(1920, 825) pos=(0, 29.11) drawn=(0, 29.11, 1920, 825) clip=(0, 29.11, 1920, 825) host=FloatLayout index=11`。
絵の矩形も切り抜きもウィジェットの矩形と一致し、複製が大きく出たのは矩形の差ではなく親で解決される寸法の差だった。

立ち絵が黒い板になる件（提供元の v6 で毎回ではなく発生）は、Clock 経由に変えてから6回とも出ていない。
原因がスレッドである点は仮説のままだが、区別のつく状態を作る手（ワーカースレッドから直接呼ぶ版で再現させる）は取っていない。

6回とも注入後の `modloader.log` に `party talk:` の例外なし。
