## 決めた仕様（再検討しない）

- 新しい 1xx の MOD に置く（2026-10-11）。`132_` への相乗りと並べて選んだ
- 種も渡す（2026-10-11）。世界観を渡すのは `143_`、表の種は `132_` が自分の表から足す（MOD どうしで表を貸し借りしない）
- 足すのは世界の名前・概要・情勢の3つ。地図の構造（`structure_description`）は渡さない。情勢は設定で外せる
- 足す先はさいころ（`create_character`）と、続けて送られる立ち絵の要素（`create_look`）の2つ。スキル・特質の生成（`create_skill` / `create_trait`）は触らない

- `132_` の種の添え書きは「世界に無いもの（生き物・職業・場所・道具）は世界にある近いものに置き換えて書く。置き換えられない句は使わない」と言い切る（主人公・単体・町とも。2026-10-11）。「置き換えてよい」と許すだけでは、魔法も剣も無い世界で「元は羊飼い」の種から出自が牧場の羊になり、特質が「羊追いの勘」になった（下の記録）
- `132_` の同梱の表の句には、舞台の物（生き物・地形・天候・建物や施設の種類・職名・身分や制度・技術）を書かない（2026-10-11）。人と人の関係・出来事・身分の上下だけを残し、固有の名詞は生成 AI に世界から選ばせる（「領主に一族を潰された」→「土地を治める者に一族を潰された」、「元は写字生」→「元は記録を書き写す仕事」）。添え書きでは止めきれなかったため（下の記録）。最初に出した書き直し（「家畜の世話をして育った」「元は書き写しの仕事」の程度）は、ファンタジー・中世・近代・現代には合っても、SF とポストアポカリプスでは元の句に引っ張られて外れる、という判断で退けた。冒険者・ギルド・傭兵は残す（どの世界にもある前提。`144_` の【共通世界観】）。書き換えたのは 85句（来歴が中心。外見と性格はそのまま）。添え書きは取りこぼしの受け皿として残す
- 才能点・年齢・能力値のばらつきも同じ MOD に入れ、名前を `143_fix_random_character`・題を「さいころで作るキャラを世界観に合わせ、作りもばらつかせる」に改めた（2026-10-11。リリース前なので `state\` と設定の移し替えは無い）
