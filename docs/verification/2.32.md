# 2.32 `112_` が効かなくなっていた（原因確定）

ゲームの更新ではなく、他の MOD との相互作用だった。
`112_` はラベルを「`display_text` と同じ文字列を持つウィジェット」として探していたが、
`117_` が長い本文を載せ替えるようになり、探索が空振りしていた（`117_` のほうが内側）。

直し方は名前で引くこと（`hud.text_display`。§2.25 の実測で分かっていた）。
文字列の探索は予備に降ろした。

> **表示中の文字列を手がかりに描画先を探す作りは、
> その文字列を触る MOD が増えた時点で壊れる。**
> 一度実測で名前が分かったら、名前で引くほうへ移す。
