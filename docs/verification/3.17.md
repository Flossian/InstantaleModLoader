# 3.17 ミニイベントの判定（`215_`）: 負の差の正体だけが残っている

> `313_` は両系統とも決着している（フィールドイベント側23件・[§2.49](2.49.md)、自由入力側・[§3.18](3.18.md)）。
> `215_` の計測も4イベント録れていて、
> 問い「判定の窓で `calculate_attribute` が呼ばれるか」は **YES**
> （[§2.37](2.37.md) の「能力値は判定経路に一切入っていない」は否定された）。

残っているのは負の差（-2 〜 -40）の正体だけ。
差が出たのは4件中1件（`credibility 8` ＝ 上限 100% に対し `percent 89`、差 -11）で、
そのとき `before` と `now` は完全に同一・無傷・状態も空・HP も 95% 残り ＝
**HP・負傷・状態では説明が付かない**。
残る候補は「判定の瞬間にしか存在しない値」。

しかも4件とも `313_` を有効のまま測っており、**素の分布が無い**。
必要なのは「フィールドイベントを踏むこと」ではなく、
**手順1 を守って `313_` を切り、差が 0 でない回を数件集めること**。

| 手順 | すること |
| --- | --- |
| 1 | デバッグモードで `215_` を有効・**`313_` を無効**にする |
| 2 | 依頼を1件受け、道中のフィールドイベントを5回以上引く。途中でHPを減らす／回復する／負傷する、と状態を動かすこと（差が動く材料はここにしか無い） |
| 3 | `out\event_roll.jsonl` を見る（1行1判定。`credibility` / `percent` / `gap` / `player_before` / `player_now` / `calculate_attribute_calls`） |
| 4 | `gap` が 0 でない行を集め、`player_before` のどれが `gap` と一緒に動くかを見る |

| `event_roll.jsonl` の中身 | 意味 |
| --- | --- |
| `gap: 0` ばかり | そのキャラでは差が出ない状態。HPや負傷を作ってから引き直す |
| `calculate_attribute_calls` の `caller` がゲーム側 | 引数と戻り値、そのときの `gap` を並べれば式が出る |
| `caller` が `313_` だけ | ゲームは読んでいない |

**まだ手を出していないこと**: `credibility` の付き方そのもの
（プロンプトが「手心を加えないこと」と念を押し、10 が一度も出ていない）と、
`certain_success` が 132 回中 10 回しか出ないこと。
どちらも緩めると判定の甘さが二重になるので、`313_` の効き方を実機で見てから決める。
