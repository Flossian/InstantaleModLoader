# 3.112 依頼の難易度の上限を 100 まで上げられるようにする（`318_area_difficulty_growth` 版6）: 76 を超えた依頼のクリア・訓練・店の品揃えまで実機で成立

`318_` の「難易度の上限」は、前はゲームの定数 `scripts.functions.QUEST_DIFFICULTY_VALUE_MAX`（76）で天井を切っていて、設定でも 76 より上にできなかった。
本人の問い（2026-10-22。「クエストのレベル上限は外せないか。100 までいってもいい」）で、76 を超えた依頼をゲームがどう扱うかを測ってから広げた。

## 決めた仕様（本人）

- 既定は 76 のまま。設定で 100 まで上げられる（本人が選んだ案。既定を 100 にする案は採らなかった）
- 天井は `DIFFICULTY_CEILING`（100）。難易度 100 で敵のレベルがゲームの上限（Lv101）に届く。ゲームの定数 76 は天井にしない

## 分かったこと

ゲームの関数に難易度を直に渡した（2026-10-22。読むだけ）。

| 関数 | 76 を超えると |
|---|---|
| `get_enemy_exp_lvl(段, 難易度)` | 難易度 + 1 で伸びる。100 で Lv101、それより上も 101 |
| `get_enemy_attributes_base_point` | わずかに伸びる（ボスで 76 → 18.38、100 → 18.83） |
| `get_quest_reward` / `get_talent_point_quest_clear` / `get_labor_reward` | 76 の値で止まる（報酬 24,216・才能点 12・働いた報酬 449） |
| `get_equipment_price` / `get_heal_item_price` / `get_other_item_price` / `get_npc_employ_price` | 76 の値で止まる |
| `get_weapon_spec` | 76 の値の帯（300〜340）で止まる |
| `clamp_quest_difficulty_value` / `clamp_npc_difficulty_value` | 76 で切る（ゲーム自身の切り） |
| `clamp_quest_scaling_value` | 100 で切る（`QUEST_SCALING_VALUE_MAX = 100`。何に使うかは調べていない） |
| `get_training_experience_point` | 76 の値で止まる |
| `get_talent_point_by_quest_level` / `get_training_price_quest_clear` | 75 以上で KeyError。今の上限 76 でも届く値。ゲームの exe に名前が1回しか出ず（定義だけ）、下の実機でも呼ばれなかった |

## 実機（2026-10-22、テストワールド）

主人公の周回の `318_` の控えでアビスの依頼は素の難易度 70〜73・上昇量 +13 で、76 で切られていた。
試しの間だけ `318_` から見たゲームの定数を 100 にし（ゲームの定数そのものは 76 のまま）、掲示板を開いた。
主人公の武器はテストソードだが、見たのは 76 を超えて動くかで、釣り合いではない。試した後は控えへ戻した。

| 場面 | 結果 |
|---|---|
| 掲示板を開く | `board: 土地 8 依頼 34 難易度 76 -> 83（素 70 + 13）`。ゲームは書き戻さない |
| 依頼の中の戦闘 | 敵は Lv84（`lv=72->84`）。能力値の基準は難易度 83 で作られた（`get_enemy_attributes_base_point(…, 83)`） |
| クリア | `QuestEndManager` まで通り、依頼は完了。`out\modloader.log` に ERROR・KeyError・stall guard は無い |
| 報酬と才能点 | 「24216円の報酬を受け取った。」「12の才能を得た。」（所持金の増え方も 24,216）。難易度 76 と同じ額 |
| クリアの後 | `clear: 土地 8 は 3 回目（… いま +18）`、依頼の難易度は 88〜91 |

76 を超えた分は敵だけが強くなり、報酬・才能点・品の値段と強さは増えない。

続けて同じ周回で、店と訓練場を通した。
ゲームの関数の呼び出しは試しの間だけ包んで記録した（引数・戻り値・例外。値は変えない）。

| 場面 | 結果 |
|---|---|
| アビスの雑貨屋の棚を空にして売買を開く | ゲームが雛形から7品を作り直した。品の `value` は 70〜73（世界を作ったときの値）で、段の難易度 92〜95（`get_area_quest_difficulty_for_tier`。投げない）は品に届かない |
| 移動先の一覧 | アビスは「適正Lv 93〜96」と出る。上げた難易度がそのまま表示に使われる |
| カスティアの訓練場（`331_` の施設。訓練の処理はゲームのもの）で訓練を受ける（3か月） | ゲームが呼んだのは `clamp_quest_difficulty_value(83) -> 76` と `get_training_experience_point(83)`（76 の値）だけ。KeyError の2つは呼ばれず、訓練は最後まで進んだ。ERROR は無い |

`312_` の新しい品揃え（LLM で作る経路）は、雛形の `value` を頼み文に渡す作りで、依頼の難易度を読まない（コードを読んだだけ。実機では通していない）。

## 確かめたこと（オフライン）

`tools\tests\test_area_difficulty_growth.py` に3件（上限を 100 にすれば 76 を超える・100 で止まる・設定を 100 より上にしても 100 で止まる）。
