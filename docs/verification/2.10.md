# 2.10 依頼受注の絞り込み（オフラインでライブ世界と照合）

mod の絞り込み（エリア7）は `[39, 43, 45]`、
ゲーム自身の `get_quest_difficulties(area, world)` は `[45, 43, 39]` で一致。
mod は実行時にもこの照合をし、食い違えば `WARN difficulty mismatch` を残す。

`client_name` は実在 NPC と結び付いていない（ライブ5世界・全114依頼で一致0件）。
したがって既定（`FILTER_BY_NPC = True`）では、
初対面の NPC の一覧は「この話から依頼を作る」だけになる。GAME.md §2.7。
