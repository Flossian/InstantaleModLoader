# 2.31 残骸の掃除が他の MOD のボタンを消していた（コードで確定）

`302_` の `prune_stale`（セーブから復元された印無しの自前ボタンを落とす）が、
`309_` の確認画面のキャンセルを消していた。
`CANCEL_LABEL = "やめておく"` が2つの MOD で完全に同じ文字列だったのが直接の原因。
画面から見えるのは「役場で罰金の確認画面を出すと、最初からキャンセルが無い」だけ。

直し方は2段。片方だけでは塞がらない。

1. 「どの MOD の印も無い」を条件に足す。
   セーブに焼かれるのは text と spec だけなので、復元された残骸は印を1つも持たない
2. 掃除に使う文言をその MOD にしか無いものだけにする（`OUR_LABELS` から汎用語を外す）

1 だけでは、ゲーム自身が `やめておく` を出していた場合に消してしまう。
2 だけでは、文言が偶然揃った次の MOD で再発する。

同じ点検で `307_` / `309_` にも `prune_stale` を入れた。
3つの修正はそれぞれ、戻すと対応する検査が落ちることを確認済み。
