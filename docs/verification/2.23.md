# 2.23 待機表示を共通部品へ移した

点のアニメーションは `301_` がゲーム自身の「クエストを探す」を実測して真似たもの
（`.` → `..` → `...` を 0.3秒周期、ボタン全枠、`is_button_enabled=False`、送信ボタン無効）。
「ゲームがどう動いているか」なので `ui.Screen` へ移した（TECH.md §5.1）。

呼ぶ側の判断だけ MOD に残してある:
生成に入る直前へ出し例外で抜けるときも必ず解く（出したまま抜けると操作不能）、
掲示板を開き直す経路は `busy_off(restore=False)`（塗り直すと一瞬だけ古い画面が見える）。

> 2026-09-25、見た目だけ真似た結果の穴が出た。点を送っているのはゲーム自身
> （`is_button_enabled` が False のあいだ `display_button_load` が自分を予約し直す）で、
> ローダの自前のコマ送りと二重に回っていた。しかもコマごとの `paint` が
> `display_button_load(0)` を呼び、そのたびにゲームの点送りを1本ずつ増やしていた
> （`234_probe_busy_display` の実機。1.2秒で4本。点が飛び、解いた後にも点が一瞬戻った）。
> 自前のコマ送りをやめ、旗を下ろして回っていなければ1回だけ回し始める形にした（GAME.md §2.4）。
