# 3.129 新しい主人公を始めたら、前の周回の控えを退避する（v1.21.0）: 実機で成立

`407_` の報告から始まった。
同じ世界で主人公を作り直して、初期装備を持たせた仲間をもう一度加えると、装備欄が空のまま作り直されない。

## 原因

- `407_` の「渡した」印も `333_` の装備欄の控えも、周回の鍵（世界×主人公）で持っている。同じ名前で作り直すと鍵が同じになり、前の周回の印が残る
- ゲームは新しい主人公のセーブを骨格から組み直すので、前の周回の装備欄（`333_` の控え）は新しいセーブに無い。印だけが「渡した」と言うので、`407_` は作り直さない
- 同じ形の持ち越しは、周回の鍵を使うほかの MOD にもある。世界名だけの鍵で、中身はセーブと同じ寿命の控えを持つ MOD（`122_` / `300_` / `311_` / `316_` / `403_`）は、名前を変えて作り直しても持ち越す

## 直し方

ローダが `start_game` の中で、登録された前の処理より先に、その世界の控えを `state\_retired\<世界>\<日時>\` へ移す（TECH.md §5.4「新しい主人公を始めたときの退避」）。
世界名だけの控えのうち、移すのは `mod.json` の `"state_lifetime"` で `"save"` と名乗ったフォルダのものだけ（TECH.md §3.11）。
1つのファイルに全周回ぶんを持つ `301_` / `307_` と、控えをメモリにも持つ `122_` / `316_` / ローダの値切りの固定は、`loads.NEW_GAME` の前の処理で自分の分を捨てる。
`323_` は、その世界で置いた予約を「終了」にする。

## 実機（テストワールド。控えを取ってから試し、最後に控えへ戻した）

| 段 | 見たもの | 結果 |
|---|---|---|
| 起動し直して続きから | ローダのログ・`state\_retired` | `start_game` の関所はローダが立てた（`start_game <- (loader), …`）。続きからでは何も移らず、`_retired` も作られなかった |
| 題の画面でセーブを外し、同じ名前の主人公をランダム作成で始めた（ゲームを閉じずに） | ローダのログ | 「前の周回の控え 30 件を退避した」。`301_` の依頼の出所も同じフォルダへ書き残した。世界名の食い違いの WARN は無い |
| 同じ | 退避の後に書かれたファイル | `317_` の評判は空の新しい控え、`122_` のログは新しい主人公の本文1件だけ（前の本文を書き戻していない） |
| 前の周回で初期装備を渡した仲間を加えた | `407_` のログ・`333_` の控え | 印が無いので作り直し、装備欄に入れた（`handed … -> equipped`）。印は新しい周回のファイルに書いた |

## 1回目の実機で見つけたこと

- **新規開始の `World.__init__` では、周回の鍵が世界名だけになっていた。** 骨格から組んだセーブにまだ主人公の名前が無いため。`318_` はこの時点で世界名だけの鍵の控え（周回の鍵へ切り替える前の古いファイル）を読み、新しい主人公の依頼の難易度に前の周回の補正を足した。退避の前からある経路で、退避では直らない（世界名だけの古いファイルは、宣言の無いフォルダに残る）
- `start_game` は `World.__init__` より前に作成画面の `scripts.create_world:CharacterVM.to_dict` を呼び、戻り値に新しい主人公の `name` がある（`214_` の記録）
- **MOD が仲間に持たせた品は、骨格の `world_data.json` の NPC の持ち物に焼き付いている。** 新しい周回でも、その NPC の持ち物に装備されないまま残っていた。`407_` が作り直すと、古い2品を持ち物に、新しい2品を装備欄に持った

直し方:

- ローダが `CharacterVM.to_dict` の戻り値から名前を控え、`start_game` の間は周回の鍵をその名前で作る（`state.new_game_player`。TECH.md §5.4）。世界名だけの控えを移す `adopt` は、鍵の世界と同じ世界の控えだけを移す
- `407_` は、まだ渡していない種類の品が持ち物にあれば、作らずにそれを装備させる（`407_` の DOC.md「持ち物にある品」）

## 3回目の実機（退避の後の振る舞い）

新しい主人公を始める前に、前の周回の側へ `307_` の道中1件と `323_` の置いた予約（保存の前）1件を書き、施設を出て `316_` に通算日数を読ませた。
そのうえで同じ手順で作り直し、仲間を1人加えて宿屋へ入り、宿主と会話して1週間泊まった。

| MOD | 新しい主人公を始めたとき | その後 |
|---|---|---|
| `307_` | 道中を外し、中身を退避のフォルダへ書き残した | `road_travel.json` は空のまま |
| `323_` | 置いた予約を「終了」にした | ロードの後も「待機」に戻らず、置き直さなかった |
| `316_` | メモリの通算日数を読み直す印を立てた | 宿屋に着いて通算 0 日から読み、1週間の宿泊で 7 日と書いた（前の周回の日数に足していない） |
| `300_` | 応答の数の控えを退避した | 宿屋に着いて宿主が声をかけた。控えは新しく作られていない（返事をしたので数えない） |
| `311_` | 人物像の控えを退避した | 宿主の人物像を 0 字から書き、控えには宿主1人だけ |
| `403_` | 関係の控えを退避した | 宿主と仲間の関係を 0 字から書き、控えにはその2人だけ |

## 確かめていないもの

- 主人公が死んでからの作り直し。ゲームの入口は同じ `start_game` なので確かめない（本人の判断）
- 名前を変えて作り直したとき。周回の鍵が別になるので確かめない（本人の判断）
- `300_` で前の周回に声をかけなくなっていた人物が、新しい主人公には声をかけること（宿主は前の周回で1回だけの相手だった）
