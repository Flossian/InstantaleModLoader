## 実機で直したこと

- **知らせの点が古い位置に残る**（ローダ `hudicons`）。点はボタンの動き（`pos`）に結んだ手で描き直すが、その知らせの中では Kivy の `top` / `right` がまだ動く前の値を返す。読み込みでボタンが y=0 から 48 へ動いたとき、`y=48 top=40` で描き直して、点が y=0 のときの位置に残った（描く呼び出しを記録して見つけた）。`y + height` / `x + width` から描くようにした。
- **点と列の幅に結んだ手が前の世代のまま**（ローダ `hudicons`）。`_follow` と `_watch` はボタン・列ごとに1回しか結ばず、注入し直しても前の世代のモジュールの手が残っていた（上の直しも、ゲームを起動し直すまで効かない形だった）。前の世代の手なら外して結び直す。
- **`relaunch.sh restore` の照合が狭すぎた**。直した照合（`<世界>.json` と `<世界>×*`）では、`テストワールド.jsonl`（会話の記録）や `.cast.json` を戻さない。`<世界>.*` と `<世界>×*` にした。

338 の窓で、段の概要の文の句点が1字だけ次の行へ送られていた（「…沈んでいる」の次の行に「。」）。行の折り返しの禁則の話で、この直しとは別。直していない。
