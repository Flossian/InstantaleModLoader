# 2.46 `121_` プレイヤーの人物欄（実機で1度直した）

載せる値の在り処は `212_probe_character_sheet` の計測で確定した。
実機で1度外している。
「ゲームが決めた寸法の 1.4 倍」で広げると、ウィンドウを小さくしたときに下の情報欄へ食い込む。
四辺をウィンドウに対する割合で持つ形に直した。

その後の版で外して直したもの:

- 二つ名を別の箱に置いた2つの版は、名前と並べると浮き、レベル行と並べると折り返しが手配度の枠に食い込んだ（実機の2周目・3周目）。レベル行の text に続けて書く形にした
- 引き直しボタンを箱の割合（幅0.05×高0.06）で置いた最初の版は、ウィンドウに合わせて横長に潰れた。正方形の固定値にした
- 引き直しボタンは版3まで右端の固定位置で、短い二つ名だと文字から大きく離れて見えた。文字の直後に置く形にした
- 引き直しボタンの絵柄は版3まで円弧＋矢尻で、`408_` の立ち絵の描き直しボタンと見分けが付かなかった。サイコロの面にし、版6で `317_` も同じ形を使うのでローダへ移した
- 説明のウィンドウの幅は最初 0.26 で、1920px では1行が全角約18字になり、長い特質の説明が18行まで伸びた。0.36 にした
- 効いていない効果の色は、説明の灰色と並ぶと見分けにくかった。効果の色を暗くした
- 注入し直すと、マウスが動くまで新しい世代の見張りが呼ばれず、前の世代の説明のウィンドウが残った。消すときに前の世代のものも片付ける
