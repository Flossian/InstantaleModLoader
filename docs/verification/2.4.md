## ログの量と初見の控え（版3）

曲の内訳（`[BALANCE] pool under ...` と size ごとの4行）は apply のたびに出ていて、遅れて当て直す boot を含めて約40日で1,120回ずつ・約700KB になった。
版3から、前に書いた中身と同じなら書かない。
ワールドごとの「最初に見たときに在ったエリア」の控え（`_seen`）は版2までモジュール変数で、boot のたびに空に戻り、今あるエリアを全部「前からある」として覚え直していた（`first sight` が約40日で447行）。
作られた瞬間の包みを通らずに増えたエリアが、次の保存より前に覚え直しに当たると、新しいエリアなのに二度と選び直されなかった。
版3から控えを `sys` に置いて1プロセスで持つ。
