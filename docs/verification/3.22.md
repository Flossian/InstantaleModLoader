# 3.22 クラフト画面の枠の重なり（`124_`）: 座標では成立・残るのは目視

グリッドの矩形もボタンの幅も窓の大きさで決まるので、**寸法は実測でしか得られない**。
MOD は固定値を持たず、画面を開いた時点で測って動かす。

1回目でボタン側は成立したが、**矢印が生成先グリッドの裏に埋もれたまま**だった
（矢印の定位置がもともとグリッドの中なので、ボタンを動かしても解消しない）。
版2で矢印も動かすようにし、あわせて**ラベルは文字の箱で測る**ようにした。
Kivy の `Label` は `text_size` が無ければ文字を矩形の中心に描くので、
矩形で測ると「どこにも置けない」に化ける。
押せるもの（`on_press`）だけ矩形で測り、それ以外は `texture_size` で測る。

2回目で矢印側も実機で動いた（`slid dx=-37`）。
移動後の右端 1494 がグリッド左端 1500 に届いていない ＝ **座標の上では重なりが解けている**。
残るのは目視だけで、`ItemCraftManager.arrow_label_animation` が後から位置を戻すかは
この記録の範囲外（動かした時点しか残らない）。

**確かめる手順**: クラフト画面を開いて `out\craft_window.log` の1行を見る。

| 見るところ | 期待 |
| --- | --- |
| `grids` の件数 | 画面のグリッド数と一致（0件なら見分け方が外れている） |
| `->` の後の矩形 | どのグリッドとも重なっていない |
| `arrow` の矩形 | 同じく重なっていない。**グリッドと同じくらい大きい値なら `texture_size` が読めていない** |
| 画面 | 枠が交差せず、矢印が読め、どちらも遠くへ飛んでいない |

そのあとアイテムを置く・生成する・開き直す → 位置が元へ戻らないこと。

外れうるところ: `grids 0件`（`GRID_MARKS` を実機の属性名に合わせ直す）/
ボタンが右へ回り込む / 詰めすぎて文字が切れる（`MIN_WIDTH_RATIO` を上げる）/
**矢印が動いた直後に元へ戻る**（`arrow_label_animation` が位置を触っている。
設定「矢印も動かす」を OFF にして枠の交差だけ直す）/ 矢印が遠くへ飛ぶ。
