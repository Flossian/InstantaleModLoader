# 3.36 評判と二つ名（`317_`）: 残るは編纂の質と据え置き

素材はゲーム自身が既に書いているもの（`area_history` の成した事・手配度・
完了した依頼と、完了クエスト）。この MOD は記録を新しく始めない。
オフラインの検査（`tools\tests\test_reputation.py`）で、素材の読み・印・注入の
5経路・素通し・控えの形・安全側の倒し方まで通してある。

## 済んでいること

| 何 | どこまで |
| --- | --- |
| 二つ名の出方の偏り | LLM で 240回（heretic 版・it-qat 版で 120回ずつ）。空 0・写し 0・地名 0（[§2.63](2.63.md)） |
| 人物欄の表示 | 実機3周で決着。名前の右→浮く、レベル行の右の別箱→折り返しが枠に食い込む、**レベル行への続け書き**で落ち着いた |
| 引き直しボタン | 押下 → 頼みのファイル → 次の照合で編み直し、まで実機で通った |
| 素材の実行時の形 | `area_history` は `309_` / `316_` が実機で読み書きしている経路と同じ |

## 残っていること

| # | 確かめること | やること | 見るところ |

| 1 | 編纂の質 | 遊び込んだセーブで各地の評判を編ませる | `output_data\…\mod_reputation_compile\`。出来事の並べ直しになっていないか、好悪を書いていないか |
| 2 | 据え置き | 質的な変化を何度か起こす | `out\reputation.log` の `据え置き` / `改名` の行。変化のたびに名が揺れないか |
| 3 | `achievements` が増える契機 | 新しい世界と遊び込んだセーブで件数を見る | **未特定**。素材の増え方が分かると `MIN_DEEDS` の既定を判断できる |

## 分かっていて直していないもの

- 会話からの自由行動（`master_ai_facilitator_from_conversation`）には届かない。
  会話5関数を通らないため（GAME.md §2.25。`311_` も同じ制約）
- **二つ名の上限を下げると、今より長い名は次の編纂まで注入から外れる**
  （人物欄には残る）。引き直しボタンで即座に付け替えられる
- `LOG_MATERIAL` は開発中の確認用。配る既定を OFF にするか設定ごと落とすかは未決
