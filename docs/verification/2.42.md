# 2.42 新種: 立ち絵の無い人物で `image_portrait` に None

ゲーム本体のバグで MOD 側は未対処。
`update_character_image` が `image_src=None` をそのまま `StringProperty` へ代入している。
起点は2つあり、どちらも `Clock` 経由の遅延呼び出し。
立ち絵がまだ生成されていない／生成に失敗した人物を映そうとしたときに起きると読める
（`110_` で潰した `WinError 123` と地続きの可能性）。

塞ぐなら `image_src` が None のとき何もせず戻す1行で足りるが、
そうすると立ち絵が前の人物のまま残る。
先に「None のときゲームが本来どうしたかったのか」を決める必要がある
（`character_sheet.log` に `source='placeholder.png'` の実例があるので、そちらが本命）。
