# 3.21 会話ログの窓が空（`122_`）: Label 1枚に入れすぎていた

控えと読み出しは成立していた（`opened the window with 500 entr(y/ies)`）。
足りなかったのは描く側で、500件ぶんの本文を Label 1枚の `text` に入れていた。
Kivy の Label は中身を1枚のテクスチャに焼くので、
GPU の上限（多くの環境で 16384px）を超えると生成に失敗し、**例外も出さずに何も描かれない**。
窓 2560x1440・書体27px で見積もると 50,000字 ≒ 33,000px ＝ 上限の2倍。

直した点: 本文を `VIEW_CHUNK_CHARS`（1200字）ごとの Label に割って縦に並べる /
組む量に上限（20万字。あふれるのは古いほう）/ 開いたまま来た本文は最後の塊に継ぎ足す。

検査は120件（各400字超）で窓を開き、複数枚に割れていること・
1枚も上限を超えないこと・**古い順に並ぶこと**を見る。

> 教訓は「**テクスチャに焼かれるものは、量が増えると黙って消える**」。
> 例外も警告も出ないので実機で見るまで気付けない。
> 長い文字列を1つのウィジェットに載せる MOD は、件数が増えた状態を一度作って確かめること。
