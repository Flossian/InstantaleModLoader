# 3.128 MOD が LLM に渡す材料の字数切りを外す（v1.21.0）: オフラインで通過・実機は未

[§3.95](3.95.md)「概要を全文足しても窓に収まるか」で、同梱の llama-server の窓（16,384 トークン）には世界の概要を全文足しても収まると分かった。
そのとき全文にしたのは `144_` と `143_` の概要だけで、ほかの MOD には材料を字数で切る箇所が残っていた。
全 MOD を grep で洗い（`runtime\mods\` の git 管理下。`local\` は見ていない）、材料の切りを外した。

## 外す・残すの決め方（2026-11-10）

字数の上限は外すが、無条件に際限なく長くしてよいわけではない。
外したのは、上限を外しても長さが別のところで抑えられる項目だけ。

- ゲームの欄（世界の概要・エリアと施設の説明・人物の profile / personality / speech_style など）。ゲーム自身の頼みも全文を載せている
- 人生の記録。ゲームの `life_log_summarizer` が古い範囲をまとめ直すので際限なくは伸びない（GAME.md §2.25 の「`life_log` は際限なくは伸びない」）。ゲーム自身の頼みも毎回全文を載せている
- MOD が長さの目安を付けて書かせた記録（`311_` の人物像、`403_` の関係）
- 件数で抑えているものの1件ぶん（会話の書き起こしは発言数、事実は件数、功績は件数や土地ごと、住人は1回 20 人）

残したのは次のもの。

- 遊ぶほど伸び続け、件数でも抑えていないもの: `339_` の功績（全部の街の功績をつないだもの。3000字、途中導入の調整は勢力ごとに 1500字）。ゲームは土地ごとの功績しか載せず、全部の街をつないだ形はこの MOD だけが作る
- プロンプト全体の安全弁: `404_` の全体の上限（超えたときだけ人物の塊から削る）。30000字は約 15,800 トークンで窓とほぼ同じ大きさになり、ローカルでは安全弁として働かないので、20000字（約 10,500 トークン）に下げた
- 返答の長さの上限（頼み文の「N字以内」と、返答を控えるときの切り）。窓ではなく文の長さを決める上限なので [§3.95](3.95.md) の根拠は当たらない
- 名前・種別の切り（壊れた値への用心）と、画像生成のタグの上限（`335_` / `408_`）
- `401_` の同行者の欄（項目ごと・全員で 6000字）。審判の頼みに毎ターン載る肥大への対策として置いた上限で、[§3.95](3.95.md) の数えに `401_` が足した分が入っているかを見ていない。足した後の大きさを測ってから決める

## 確かめたこと

- compileall・vermin（3.10）・pyflakes・`check_mods.py --strict` が通った（`check_mods` の1件は手元だけにある `load_order.local.json` の指摘）
- 素の venv で `tools\tests\test_*.py` が全部通った。`test_npc_profile_memory` の「事実の差し戻しを文字数で頭打ちにする」は、長い事実も件数に収まれば落とさない形に書き換えた

## 確かめていないもの

- 実機。外した後の頼みの長さは、ゲーム抜きの見積もり（[§3.95](3.95.md) の数え）に頼っている
- `401_` の同行者の欄を外してよいか（上の「残したもの」）
- 材料が伸びた分の、ローカル LLM の読み込みの時間
