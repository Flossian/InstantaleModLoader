# 2.44 `116_` パーティ欄の拡張（実機で5回外して直した）

実機では表示・押下とも成立している（6人まで）。
5回外していて、その5回がそのまま
**「他人の画面に物を足すときの規則」**になっている:

| # | 外したこと | 何が違ったか |
|---|---|---|
| 1 | 足した枠に枠線が付かない | canvas は複製されない。ゲームの `add_border` を借りる |
| 2 | 元の枠が数 px ずれる | `size_hint_y=0.33` は 1/3 ではない。実測座標に釘付けにする |
| 3 | ゲームの選択肢が押せなくなる | **他人が管理する状態は控えて書き戻さない**（`disabled`） |
| 4 | 覆った先の選択肢が透けて押せる | 足した枠は背景を持たない。黒い板を1枚敷く |
| 5 | 雇い直しで `IndexError` | **他人の入れ物に、他人が数えている物と違う物を混ぜない**（帯に置いた黒い板が枠として塗られた） |

仲間の増減は `add_party_member` / `remove_party_member` からその場で追う。

版3で、上限より多い仲間をページで送れるようにした（実機で3ページまで成立）。
枠は全員ぶん作り、今のページに入らない枠は窓の外へ置く。
中身を差し替えずに置き場所だけ入れ替えるので、塗るのも押下の行き先もゲームのまま。
実機で1回外している。
最後のページを後ろへ詰めて空の行を作らない形にしたら、2ページ目に1ページ目の仲間が6人混ざった。
下3行に元の3人を据え置いて上へ積む並びだったため、重なった仲間がページごとに別の行へ動き、見分けにくかった。
ページは重ねず、どのページも上から並べ、最後のページは帯を縮める形に直した。
