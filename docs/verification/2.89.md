# 2.89 ゲームの旗 7 つを誰が立てて誰が下ろすか（`239_`）

`InstantaleApp` のクラスに旗ごとの見張り（データデスクリプタ）を置き、書き込みを呼び出し元つきで、読み取りを読んだ関数ごとに録った（2026-10-06、版1、ペルディション）。
手順は「出口の手段の画面 → 入口 → 魔道具市場 → 雑貨屋に入る（話しかけの会話が始まる）→ 会話の中で売買の窓を開けて閉じる → 会話を終える → 会話の外で売買の窓を開けて閉じる → 店を出る → 自由入力「辺りを見回す」→ 露店商と会話して終える → 起動し直してロード」。
試す前にセーブ・世界の骨格・state\ を控えた（`out\backup\perdition_before_flagprobe_20261006_101454`。state\models は除いた）。

| 旗 | 立てた | 下ろした | ゲームが読んだ |

- 見張りを通らない書き換え（`__dict__` の直書き）は、保存の前の突き合わせで1件も出なかった
- 手元の7世界のセーブのうち、売買したことのある4世界は `in_shopping` が True のまま焼かれていた。ほかの旗で、焼かれた選択肢の場面と食い違うものは無かった
- 控えの過去のセーブで `in_shopping` が False だったのは、10-04 16:19 と 17:42 の2つ（どちらも同じ主人公・Lv80・依頼の記録19件）。`227_` の記録でペルディションの店の売買の窓が最初に開いたのは 10-04 17:56 で、2つはそれより前。まだ一度も窓を開いていなかったので False だったと読める
- 旗が True のままの測り方では「下ろさない」と「書き込みが見えない」を分けられないので、旗を False にしてから測り直した（2026-10-06 10:39）。店に入る: 書き込み無し。「売買する」: `shopping_start_method_1`（`instantale.py:3069`）が False → True。窓の外側を本物の入力で押して閉じる: 窓は閉じて選択肢が戻ったが、書き込み無し（`close_shopping_window_process` は `in_conversation` を読むだけ）。店を出る: 書き込み無し。窓に閉じるボタンは無い（写真）
