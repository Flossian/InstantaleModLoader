# 3.126 v1.20.0 のリリース前の動作確認: 見つけた不具合6件を直し、実機で成立

2026-11-07 に作った。
v1.19.0 からの未確認の項目を、テストワールドと新しく作った世界で確かめた。
途中で不具合を6件見つけ、直して同じ場面で確かめ直した。

## 直した不具合

| # | 症状 | 原因 | 公開済みの版にあるか | 直し方 |
|---|---|---|---|---|
| 1 | `331_` で建てた闘技場の戦績（`current_phase` と `enemy_data`）が、読み込みの後の最初の保存で消える | 読み込みの中で `331_` の `apply_holdings` が先に建て、その後でローダの `restore_world` が控えを読む。`spawn` は建っている実体をそのまま返すので、既定の `config` のまま次の `snapshot_all` が控えを上書きする | ある（10-20 のログも `forgot → built → restored` の順） | `modfacility._bring_back_config`。`restore_world` が、建っている実体の `config` へ控えを戻す。辞書は入れ替えない（`install_plain` の写しが同じ辞書を指す） |
| 2 | 闘技場で勝っても名声が増えない | `317_` の `material.arenas` は段の鍵を文字列で引くが、読み込みの後に戦った段の鍵は数（`0`）。相手の格が読めない（`ranks: []`） | 無い（名声は v1.20.0 の新機能） | 文字列と数の両方で引く |
| 3 | 闘技場の相手が主人公と同じ名前になり、自分の攻撃が自分にも当たる | `colosseum_enemy_generator` は街の概要を読み、概要に主人公の名前が載っていると、それを相手に付けることがある。審判の攻撃先は名前で引くので、同じ名前だと両方に当たる | ある（ゲームの経路） | `334_` が生成のプロンプトに一行の名前を伝え、それでも重なれば `generate_enemy_data` の戻りで `<名前>の名を騙る闘士` に改名する |
| 4 | 闘技場で負けた後、主人公が一覧の末尾に並ぶ（読み直すと戻る） | ゲームは預かりから戻すときも一覧の末尾へ足す。窓口 `defeat` の `_ensure_player_back` は、居れば並びを見なかった | ある | `ui.player_to_front` を足し、`defeat` と `put_back_party` が使う |
| 5 | 負けた後の本文に「3211 回復した（残り HP 1/2039）」と出る | `defeat` が HP を -3210 から 1 へ戻した差を、`308_` が回復として数える | ある | HP が 0 以下から 1 以上へ戻った差は画面に出さず、記録に `stood up` の行を残す |
| 6 | 旅の記録の文の日数が実際と違う（徒歩は「3ヵ月」、馬車は「14日間」のまま） | 文はゲームの定数で、`elapse_days` の差し替えに合わない。`day_start` / `day_end` は実際の値 | ある（`307_` / `314_` / `325_` が日数を変えたとき） | `durations.correct_travel_records`。街を移った後に、主人公と仲間の新しい記録の文を範囲に合わせる（30日の倍数は「Nヵ月」、ほかは「N日間」） |

3番を素のゲームで踏むとどうなるかは測っていない（`334_` が倒れずに済ませるので、死亡するかを見ていない）。
依頼の敵が主人公と同じ名前になる形は見ていないので、手当てしていない。

## 確かめたこと（11-07、テストワールド）

| # | 確かめたこと | 結果 |
|---|---|---|
| 1 | 勝つ → 起動し直す → 移動して保存 | `brought back the saved config of …:5-1 (level_of_detail, current_phase, enemy_data)`。読み込みの後も控えの後も phase 2。次の試合は `match 2`、`variety: 1 earlier fighter(s)` で前の相手を伝えた。勝って phase 4、段の鍵は `"0"` と `2` の混在でそのまま動いた |
| 2 | 勝って1日送る | `arenas` の `ranks` が `[77]`。その土地の名声が 75 → 312（77²÷25＝237） |
| 3 | LLM の答えの名前を主人公の名前に差し替えて申し込む | `same name as the party: 'ヴェイン・カスティロ' -> 'ヴェイン・カスティロの名を騙る闘士'`。戦闘の敵もその名前で、主人公の攻撃は敵だけに当たった。プロンプトの記録に「闘士の名前に 「ヴェイン・カスティロ」「リュウ」「ジーン」 を使ってはならない」が載った（差し替えた回は結果だけを変えた） |
| 4 | 主人公の HP を 5、相手の HP を 999999 にして負ける | `the player is back in the party (moved to the front)`。一覧は `['player', '95', '104']` |
| 5 | 同じ負け | `stood up: hp -96 -> 1 (not shown)`。本文に「回復した」の行が出ない |
| 6 | 馬車（`314_` で 15 日・7 日）で移動 | 範囲 562-577 の記録が「15日間」、前の 465-472 の記録が「7日間」。3人とも直った |

`325_` の道中の依頼で14日の到着は、同じ後処理を通る `AreaMoveManager.execute` の経路（直す前の回で確かめた経路）で、文の形はゲーム抜きの検査で確かめた。

ゲーム抜きの検査は `test_modfacility`（順・戻す・辞書を入れ替えない・次の保存）、`test_reputation`（数の鍵）、`test_colosseum_custom`（改名・空白と中黒・頼みの一文・施設に残らない・並べ直し）、`test_battle_flag_stuck`（`player_to_front`）、`test_battle_damage_display`（起こした差・その後の回復）、`test_durations`（徒歩・馬車・ヵ月・合っていれば触らない・0日）。
