# 3.103 v1.16.2 から v1.17.0 までの変更のコードレビューの指摘を直したもの: オフラインで通過・333 の自由枠と 128 の設定の窓と候補の下限は実機で成立（10-18）

2026-10-18 に、v1.16.2 のタグから HEAD（`6135331`）までの差分を3つに分けて読み、指摘をコードで確かめてから直した。
3つは、`128_` と設定の窓、配布の3分割と GUI の更新ボタン、`301_`・窓口 `choices`・`333_`・`312_`。
どれも `tools\tests\` の検査は通っている（更新ボタンの直しの検査は、直す前のコードでは落ちることも確かめた）。
10-18 にテストワールド（ローカル LLM）で、下の表の「実機で見ること」のうち `333_` と `128_` の分を確かめた（[§3.70](3.70.md) / [§3.26](3.26.md)）。GUI の更新の直しは公開した後でないと通らない。
`128_` 版9 は v1.17.0 で初めて配るので版を上げていない。

| 対象 | 変えたこと | 実機で見ること |
| --- | --- | --- |
| GUI の更新（`tools\gui.py`） | 展開でアセットの指紋（`runtime\assets.json`）を最後に書く。前は zip の並びのまま途中で書いていた。展開が途中で落ちると、絵と辞書が古いまま指紋だけ新しくなり、次の更新から lite が選ばれて直らなかった | - |
| GUI の更新（`tools\gui.py`） | Release にアセットの zip の指紋が2種類あれば full を落とす（前の版の zip の消し忘れで、古い指紋と手元が合って lite を選ぶことがあった） | - |
| `333_` 版26 | 自由枠の品を能力値に数えない（作者の決め）。本体に渡す1品・合算・窓口 `combat` のどれにも入らない。審判への文（`401_`）と見た目（`408_`）には載る | 自由枠に一番防御の高い品を置いても、Def と `wearable -> ` の行が変わらない（10-18 成立。[§3.70](3.70.md)） |
| MOD の設定画面の窓（`tools\modtool.py`） | 前回の位置が今の画面（仮想デスクトップ）の外なら、位置を捨てて大きさだけ当てる（`load_window`。GUI 本体の `_on_screen` と同じ判定）。リリース文の画像を撮っていて、`128_` と `332_` の窓が外したモニタの負の座標で開き、何も見えないのに気づいた（10-18）。`128_` の `build_window` も他の世界ごとの設定の道具と同じく `mod_dir` を受けるようにした | 直した後、`128_` の設定画面が画面の中に開いた（10-18 成立） |
| 検査（`test_update`） | `ci.yml` の `$assetDirs` と `make_dist.bat` の `ASSETDIRS` が同じかを見る（ずれると CI は赤くなるが、文言から原因を辿りにくい） | - |
| `128_` の設定の窓（`tool.py`） | 「画像一覧」「ジャンル内の重み」のタブが組めないとき（ローダが見つからない・`genres.json` が壊れた）、窓ごと開かなかったのを、そのタブに理由を出して残りのタブは開くようにした。本体を読むときのローダの探し先を `modtool.add_loader_path` にした | 設定画面が4つのタブで開く（10-18 成立） |
| `128_` の設定の窓（`tool.py`） | ジャンル内の重みを別のファイルに書いてから差し替える（本体は品を選ぶたびに読み直すので、書きかけを読ませない）。書けなかったら画面に出す | ゲームを開いたまま重みを保存し、次の品から効く（10-18 成立） |
| `128_` 版9 | 候補の下限（`SIM_FLOOR`）の幅を足す前の値で決める（作者の決め。前は比を足した後の値に掛け、全部の絵に同じだけ足す世界で幅が広がった。[§3.26](3.26.md)）。10の世界・306品で選ばれた絵が変わったのは3品、世界に合う絵の数は同じ。`TOP_K` の説明の「1 で素と同じ」を、重みを置いた世界の場合に合わせて直した | - |
| `128_` 版9 | ジャンルの加算をキャッシュから引き直さずに返す（間に別のスレッドが重みのファイルを読み直すと KeyError で素の選び方に落ちた） | - |
| README §1.2・`make_dist.bat` | 手で更新するときの書き方を、zip の中の `InstantaleModLoader-<版>` フォルダの中身を写す形に直した（zip を展開すると隣に新しいフォルダができるだけで、上書きにならない）。§5 の表の `runtime\assets.json` の行が制御文字に化けて重なっていたのを消した | - |

直していないもの:

| 件 | 理由 |
| --- | --- |
| ワールド個別の値は型が一括設定と違うと捨てる（小数の設定に整数を手で書くと使われない）・範囲を見ない（`TOP_K` を手で 0 にすると、その世界では品ごとに素の選び方に落ちる） | `314_` / `332_` と同じ作り。道具の画面から書けば起きない |
| 更新ボタンが手元の絵と辞書を見ない（絵のフォルダを消しても lite を選び、絵は戻らない） | 作者の決め（10-18）。変わっていないのに full を落とす誤検知を避ける。`128_` は要らない分類の絵を消してよいことにしていて、数やハッシュで手元を見ると、消した人が更新のたびに full を落とし、消した絵も戻る。戻したいときは `runtime\assets.json` を消して更新する（README §3.6） |
| `128_` の選び方を動かす検査が無い（別扱いの側・下限 0.4・加算の式・読み直し） | 偽の torch を作る大きさの仕事 |
