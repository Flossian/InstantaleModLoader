# 3.108 店主の人柄と主人公との関係で売買の値段が変わる（`341_shopkeeper_attitude`）と、窓口 `wanted` の店の値の圧: 手配中の判定は 336 に置いていた形で実機1回・平時と 341 としての動きはオフラインだけ

2026-10-20 に作った。
はじめは `336_crime_overhaul` の「店が委縮して値を下げる」の中で、手配中の店主の応じ方（怯える・動じない・足元を見る）を LLM に決めさせた（336 版3 の途中の形）。
実機で出来が良かったので、手配に限らず働かせるために新しい MOD へ移した。
手配中の率（手配の重さ × 1点あたり、上限あり）は 336 が持ち、ローダの窓口 `wanted` に「店の値の圧」として置く。
341 はそれを引き受けて向きを決める。引き受けた MOD が居る間、336 は自分では値段も1行も出さない。
窓口の決まりは TECH.md §3.3.9、遊び方は `341_` の DOC.md。

## 確認項目

| # | 確かめること | 合格 |
|---|---|---|
| 1 | 平時に着いたら裏で頼む | 店に着くと `out\shopkeeper_attitude.log` に `mod_shopkeeper_attitude: …s` と `judged 〈名前〉 (id) [usual] -> discount / usual / overcharge (理由)` |
| 2 | 宿屋でも着いたときに頼む | `340_inn_shop` の宿屋に着いて、1 と同じ行（売買を押す前に出る） |
| 3 | 平時の値段と1行 | 負けるなら初めての回に店主の1文と「（買値 -10%・売値 +10%）」、ふっかけるなら逆。普段どおりは何も出ず素の値。`shop [usual] … [stored]` |
| 4 | 手配中は 336 の率で | 336 を入れて手配中の土地の店。`[wanted]` の判定で、率は 336 の設定（手配の重さ × 0.5%）。336 の怯える1行は出ず、336 のログは `rate N% handed to 341_shopkeeper_attitude` |
| 5 | 待ち | 着いてすぐ売買を押すと待機表示のあと開く（`[waited]`） |
| 6 | 使い回しと決め直し | 同じ店にもう一度入ると頼まない（`[stored]`）。会話で好感度が動いた後（`337_`）や 30 日後は頼み直す |
| 7 | 341 を切る | 336 だけの素の委縮（好感度 40 以上は委縮しない）に戻る |
| 8 | 値段がセーブに焼き付かない | 負ける・ふっかけるの店で保存して読み直し、店を出ると素の値 |

## まだ確かめていないこと

1〜8 のすべて（341 としての実機）。平時の頼みの文面をローカルの LLM に通して、3通りに分かれるかも未確認。

## 決めた仕様（再検討しない）

- 応じ方は場面ごとに3通り。平時は負ける・普段どおり・ふっかける、手配中は怯える・動じない・足元を見る（10-20）
- 根拠が無ければ、平時は普段どおり、手配中は怯える（手配中は 336 の素の動きと同じ）
- 好感度は判定の材料にする。判定が無いときだけ、手配中は好感度の線（既定 40）で決める
- 置き場は新しい MOD。手配中の率は 336 が持ち、窓口 `wanted` で仲介する（336 を切っても平時は働き、341 を切れば 336 の素の委縮に戻る）
- 頼むのは店に着いたとき（裏で1回）。売買を押した時に済んでいなければ待つ
- 平時の普段どおりは何も出さない（店に入るたびに1文が出ると煩い）
