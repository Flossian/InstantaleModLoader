# 3.108 店主の人柄と主人公との関係で売買の値段が変わる（`341_shopkeeper_attitude`）と、窓口 `wanted` の店の値の圧: 平時の判定・値段・知らせ・待ちは実機で成立（宿屋の中から始めた回）・手配中は 336 に置いていた形で2回・336 からの受け渡しは実機で成立（10-22）・着いた時の宿屋は未

2026-10-20 に作った。
はじめは `336_crime_overhaul` の「店が委縮して値を下げる」の中で、手配中の店主の応じ方（怯える・動じない・足元を見る）を LLM に決めさせた（336 版3 の途中の形）。
実機で出来が良かったので、手配に限らず働かせるために新しい MOD へ移した。
手配中の率（手配の重さ × 1点あたり、上限あり）は 336 が持ち、ローダの窓口 `wanted` に「店の値の圧」として置く。
341 はそれを引き受けて向きを決める。引き受けた MOD が居る間、336 は自分では値段も1行も出さない。
窓口の決まりは TECH.md §3.3.9、遊び方は `341_` の DOC.md。

## 決めた仕様（再検討しない）

- 応じ方は場面ごとに3通り。平時は負ける・普段どおり・ふっかける、手配中は怯える・動じない・足元を見る（10-20）
- 根拠が無ければ、平時は普段どおり、手配中は怯える（手配中は 336 の素の動きと同じ）
- 好感度は判定の材料にする。判定が無いときだけ、手配中は好感度の線（既定 20。336 の委縮しない好感度を 20 にしたのに揃えた。10-22）で決める
- 置き場は新しい MOD。手配中の率は 336 が持ち、窓口 `wanted` で仲介する（336 を切っても平時は働き、341 を切れば 336 の素の委縮に戻る）
- 頼むのは店に着いたとき（裏で1回）。売買を押した時に済んでいなければ待つ
- 平時の普段どおりは何も出さない（店に入るたびに1文が出ると煩い）
