# 3.124 依頼から帰還すると日付が進む（`344_quest_return_days`）: 攻略・放棄・道中の依頼で実機成立

2026-11-07 に作った。既定は切（設定 `ENABLED`）。

きっかけは、依頼を片付けて戻っても「さっきの件は」と前の会話の続きで話される不具合。
`301_` は文で伝えて直したが（[§3.115](3.115.md)）、効きはモデルで差が出た。
依頼の間は暦が進まないので、出発前の会話は `current_log` に残ったままになる。
日付が変われば `current_log` は `life_log` へ移る（GAME.md §2.25）ので、暦を進めれば原因そのものが消える。

## 決めた仕様

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 進む日数 | 宿の宿泊1回（`durations.inn_stay_days`）。上限は設定 `MAX_DAYS`（既定 30、1〜30） | 暦の進みの基準を宿に揃える。素のゲームの宿泊は3ヵ月以上なので、宿泊期間を変えていなければ毎回30日 |
| 乱数 | 使わない | 宿の日数を基準にしたので、振れ幅を持たせる理由が無い |
| 既定 | 切。`load_order.json` の `disabled` でなく設定で持つ | `gui.py` の `carry_order` は配る側の `disabled` を優先するので、`disabled` で配ると更新のたびに切れ戻る |
| 対象 | `QuestEndManager.execute` と `QuestRetireManager.execute` | 依頼の戦闘から逃げても依頼は続く（[§3.110](3.110.md)）ので、終わりの経路はこの2つ |
| 進める時機 | 元の処理が返った後、文 → `elapse_days` → `save_game` の順 | 報酬の文より先に、日数で動く MOD の文を出さない。帰還の保存は元の処理の中で済んでいるので保存し直す |
| 道中の依頼 | 片付けたときは足さない。放棄は足す | 片付けると移動し、到着で日数が進む。放棄は元の土地へ戻るだけ |
| 見分け方 | ローダの窓口 `durations.quest_travels`。`307_` / `325_` が `declare_quest_travel` で答える | MOD どうしは import しない（TECH.md §3.2.3、§3.3.3）。依頼が片付くと控えの段階が進むので、元の処理の前に聞く |

## 実機（テストワールド、クラウド LLM、11-07）

手元の設定は `315_` の宿泊期間が1週間。切り替えは `setmod.py` で `デフォルト` へ変えた。

| 確かめたこと | 結果 |
|---|---|
| 既定で何もしない | ✓ 設定が無い起動は `quest return days: off` |
| 攻略 | ✓ 562 → 569。`cleared: quest '6', day 562 -> 569 (7 day(s), the limit is 30)`。セーブにも 569 |
| 本文の順 | ✓「クエストを攻略した。」→ 報酬 → 才能 → 仲間の文 →「帰還してから7日が過ぎた。」→ `318_` の文 → `321_` の文 |
| 出発前の会話の行き先 | ✓ 出発前に話した相手の `current_log` は空になり、会話は `life_log` の day 562 の行へ移った |
| 戻った後の第一声 | ✓「掲示板の依頼はもう片付いたのか？」。返事も「もう終わらせてきたか」で、今日の続きとして話していない。1回だけ |
| 放棄 | ✓ 自由入力で引き返すと審判が retire を選び、569 → 599 |
| 上限 | ✓ 宿泊期間を `デフォルト` にすると 30 日で止まる（同じ回） |
| 道中の依頼（`307_`） | ✓ 片付けると `moves on to another area`。599 → 613 で道の14日だけ。到着の文と `arrived: … the road took 14 day(s)` も素のまま |
| 日数で動く MOD | ✓ 依頼の掲示板に `911_` の残り日数が減って出た。到着で家賃の文が出た |

放棄の後は選択肢に「会話する」が無かった。
放棄ではゲームが仲間を解散する（「パーティは撤退した...」→「〈仲間〉はパーティから離脱した。」）ので、話せる相手がいないだけで、日付とは関係しない。

`325_road_opening` の道中の依頼は 11-07 に実機で成立した。`moves on to another area` で、786 → 800 日と道の14日だけ進んだ（[§3.126](3.126.md)）。
