# 2.51 衛兵の戦闘の道（`220_`）

手配された土地でゲーム自身の衛兵を出し、全段を録った。経路は GAME.md §2.20。

```text
BattleStartManager(app, 'guard', None) -> execute -> start_battle -> sb_1
  -> create_guard_enemies -> guard_npc_generator(area, world, 20) -> EnemyData 1件
     generate_enemy_instance_from_quest_dict({'type':'normal',…}, …, 20) ×3 -> None
  -> current_enemy_dict = {'衛兵1': …}（レベル21、HP 228〜248）
```

- `enemy_type='guard'` / `enemy_content=None`。難易度の数1つでレベルも能力値も決まる
- 敵は `create_guard_enemies` が名付ける（`EnemyData` に名前の項目は無い）
- **衛兵と戦うとその土地の手配度が 10 下がる**（`-10` → `-20`）
- 難易度 20 の出どころは未特定（プレイヤーはレベル60、手配度 -10。どちらとも一致しない）
