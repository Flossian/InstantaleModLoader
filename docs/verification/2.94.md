# 2.94 装備の見た目を立ち絵に足す（`408_`）の取り込みと、`138_` / `335_` の切り出し

提供を直した版3を v1.14.0 で同梱した。
提供の版2は主人公の日本語の外見文を SD1.5 へ渡していた。
2026-09-29 の実機の経緯。
VERIFICATION.md §1 の 400番台の表からここへ移した。

## 主人公ボタン（後の `335_`）

- 実機1回で生成まで通った。`create_look` が英語6要素を返し、装備から1要素（テストソード）を足した配列を本体が「, 」で繋いで前置き・後置きの間に置いた（`prompts.json` の全文 267字）
- 顔の検出は外れて 32x64 の代わりになったが、既存の立ち絵 393枚中 17枚でも同じ外れ方をしている
- 人物欄の絵はゲーム中に変わらず、ロードし直すと変わった。同じパスへ上書きするので Kivy のキャッシュが古い絵を出す（主人公のセーブに `id` が無く `update_character_image` は呼ばれていなかった見込み）
- 最初に開いたときボタンが出なかったのは、開閉が注入の途中だったため。人物欄を閉じると本体が子を全部外し、開くと `121_` が引き直しボタンを作り直す
- 剣の絵柄では何のボタンか分からず、`121_` の引き直しと見分けも付かないという指摘で、408 を人の胸像＋やり直しの矢印に、`121_` をサイコロ（`121_` 版4）にした。サイコロが二つ名の直後に来ることは実機で確かめた
- 408 のボタンは人物欄の中から HUD の `overlay_host` へ移し、立ち絵の矩形の左上に追従させた

## 読み直しが効かなかった件

読み直しを入れた版でも立ち絵は変わらず、ボタンも出なかった。
`protagonist portrait reloaded` が一度も出ておらず、同じプロセスへ注入し直していた（`already done in this process`）。
`jobs.Worker.rebind` が `on_done` を付け替えないため、終わった後の処理が最初に注入した版のまま動いていた。
ローダの `rebind` が `on_drop` / `on_done` を受けるようにし、同じ形の `311_` / `317_` / `321_` も `jobs.rebind` で直した（[§3.77](3.77.md)）。
直した後、主人公の立ち絵はゲーム中に変わった。

## 顔の読み直し（後の `138_`）

顔画像（パーティー欄）は主人公も NPC も変わらなかった。
NPC は本体の再生成の経路でも同じで、素のゲームの取りこぼし。
読み直しを画像生成関数の包みへ移し、再生成が終わったらその人物の画像フォルダを `source` に持つ HUD の画像を木ごと探して `reload()` する形にした（`images reloaded for <名前> (N widget(s))`）。
主人公・仲間とも立ち絵と顔の2枚がゲーム中に変わった（15:11）。
素のゲームの取りこぼしを直すものなので `138_fix_character_image_refresh` として切り出した。
切り出した後も、仲間と主人公の再生成で2枚を読み直した（15:41〜15:50）。
オフラインは `tools\tests\test_fix_character_image_refresh.py` 21件。

## 装備の語

- 装備を持たせた仲間の再生成で、LLM が1語（`rusty dagger`）を返して控えに入り、本体の外見の語の直後・後置きの前に足された（全文 ASCII）。2回目は控えから足し、LLM を呼ばなかった（15:33〜15:34）
- NPC の経路で本体の `prompt` の型は `list`。装備が空の仲間には足さない（仕様どおり）

## `335_` への切り出し

主人公の描き直しを `335_player_portrait_regenerate` に切り出した（当時は 409。コードの 8 割以上をこちらで書いたので 3xx に置き、MoririnJP 氏の提案として扱う）。
408 は装備の語を足すだけになり、主人公は再生成の経路を問わず足す対象にした（335 からの呼び出しは本体の再生成の経路を通らない）。
包む関数は `config.json` で選ばれている方式から引く（前は `sdcppcuda` 固定。方式を切り替えるとゲームが再起動するので、注入時に1回読めば足りる）。
切り出した後、335 の描き直し（押下から `create_look`・装備の語・生成・`138_` の2枚の読み直しまで。16:03〜16:04）と、仲間の再生成（16:07）で装備の語が足された。
人物欄の開閉で立ち絵とボタンが一緒に出入りすることも目で確かめた。
オフラインは `tools\tests\test_player_portrait_regenerate.py` 45件、408 は 35件。
