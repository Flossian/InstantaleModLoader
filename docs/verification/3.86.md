# 3.86 ゲームの旗 7 つの立ち・下り（`239_`）と `107_` 版6: 店・会話・自由入力・闘技場・ロードは実機で確定・ボス戦と逮捕は記録待ち

`in_shopping` の立ちっぱなしで MOD の機能が出なくなる不具合が5本続いたので、
ローダの `ui.BUSY_FLAGS` から外し、MOD が読むと `check_mods.py` が落とすようにした（TECH.md §2.3）。
そのうえで、ほかの6つの旗にも同じ形の残り方が無いかを `239_` で測った（2026-10-06。結果は [§2.89](2.89.md)、旗ごとの事実は GAME.md §2.6）。

| 旗 | 結論 | 対策 |
|---|---|---|
| `in_shopping` | 立てるのは「売買する」、下ろす書き込みは無い（旗を False にしてから測り直して確定）。ゲームの下ろし忘れ。ゲームが読むのは保存だけ | MOD は読まない（済み）。`107_` 版6が窓を閉じた後・ロードの後・注入の時点で下ろす（3か所とも実機で成立） |
| `in_conversation` / `in_action_in_conversation` | 会話の終わりで両方下りる。会話から戦闘に入ると、戦闘の後にゲームが自分で会話を終えて下ろす。「雇う」の後は会話が続き、旗も立ったまま（画面と合っている）。MOD が会話を終える経路（`301_` / `302_`）も同じ終わりのボタンを押す形（コードで確認。実機では測っていない） | 要らない |
| `in_free_input` | 同じ処理の中で立てて下ろす。自由行動から戦闘に入ると、戦闘の間は立ったままで、戦闘の後に自由行動の続きが終わるときに下りる（会話の中なら `end_process_in_conversation`） | 要らない |
| `in_battle` | 戦闘の開始で立ち、闘技場の勝ち・撤退・自由行動の戦闘のどれでもゲームが下ろす | 要らない（`107_` は素通り） |
| `in_colosseum_battle` | 試合の開始で立つ。勝つとゲームが下ろし、**撤退すると残る**（今の版でも [§2.10](2.10.md) のまま） | 既存（`107_` が撤退の後に下ろした。実機） |
| `in_boss_battle` | 測っていない | 既存（`107_` は立っていたら記録だけ） |
