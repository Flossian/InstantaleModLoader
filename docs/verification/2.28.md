# 2.28 `115_` アイテム一覧が画面の上へはみ出す

一覧は `scripts.hud.new_hud:ToolListPopup`（`GridLayout` 派生）。
`GridLayout` だと分かった時点で直し方は1つに決まる。**`cols` を増やす**。
位置も行の大きさも変えずに高さが 1/N になる。

実機で3回外している。

| 回 | 外したこと |
|---|---|
| 1 | 吹き出し `ItemDetailBox` を一覧と誤認し、まだ組み上がる前の `(0,0)` を「触る前の位置」として控えた |
| 2 | 「入れ物の高さが中身と噛み合う」をレイアウト完了の判定に足したら、その条件が永久に成立しなかった |
| 3 | `cols=2` は当たったのに1列のまま |

決定打は `rows_prop=20` ＝ **ゲームが `rows`（件数）を入れていた**。
`cols x rows` の枠が足りないと Kivy はレイアウトを行わない。
`cols` を入れて `rows` を外し、箱の高さを中身ぶんにして初めて通った
（20件が2列で画面内に収まることを実機で確認）。
最後に `VERIFY_DELAY` 秒後、行が実際に何列に並んだかを数えて、
1列のままなら行の位置を自分で入れる。

相手は「列を持てる入れ物」（`cols` と `minimum_height` を持つ）に限る。
ボタンの中に居る入れ物は触らない（吹き出しはアイテムのボタンにぶら下がっている）。
掴まなかった相手と理由もログへ残す。
1回目・2回目とも、なぜ掴めた／掴めなかったのかがログから読めなかった。
