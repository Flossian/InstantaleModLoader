# 2.87 インベントリの装備欄。主人公・仲間・合算・審判への部位（`333_`）

開発中は `912_equipment_slots` の名前で動かした。今の状態と未確認は VERIFICATION.md [§3.70](3.70.md)。
ログは `out\equipment_slots.log`（仲間は行頭が `npc:<id>:`）。

## 主人公の装備欄（版1〜版10、2560x1440）

| 操作 | 結果 |
|---|---|
| 窓を開く | 装備欄が窓の左に出て、控えの位置に品が並ぶ。所持品側からは消える |
| 所持品の剣（1×4）を右手へドラッグ | `drop 'item_0' at (4, 2) 1x4 -> ok`。weapon が剣に替わり Atk +580 |
| 装備欄の短剣を所持品へドラッグ | `unequipped 'item_1'`。「左手」の表示が戻る |
| 兜を頭から胴へドラッグ | `wrong region body for head` → 頭へ戻る |
| 薬草を胴へドラッグ | `not equipment` → 所持品へ戻る（黄枠も残らない） |
| 指輪を装飾1から装飾2へドラッグ | `ok`。控えが `[4, 6]` に更新 |
| 所持品の短剣を右クリック→「装備」（両手が埋まっている） | 右手の剣が所持品へ出て短剣が右手へ。weapon は左手の剣 480（最高値） |
| 装備欄の短剣を右クリック→「外す」 | 所持品の空きへ戻る |
| MOD を入れる前から本体が装備していた品 | 開いたとき空いている部位へ拾われる（`adopted 'item_0' into right_hand`） |
| 本体の popup で装備した品（MOD の包みが無かった世代） | 次に開いたとき拾われる |
| 防具の最高値 | 兜 439 と装飾 500 → Def +500。兜を外しても +500 のまま |
| 並びの変更（版4→版5） | 一度「装飾・頭・装飾／手 2×6」に変えたとき、旧配置の装飾が右手の矩形に入り右手として数えられた（剣が無視され Atk +480）。部位と種類の検査で落とし、装飾1へ拾い直された。版5で当初案へ戻し、上の両隅のマスと外枠を消した |
| ドラッグ中の描画 | 所持品から装備欄の上へ引いた短剣が装備欄の上に描かれる（装備欄を窓の直後に差した後） |
| 売買のあとの Atk 表示 | 開いたとき `refresh weapon` で塗り直され +580 に戻る |
| 辞書から抜く（版6） | 開いたとき所持品に装備欄の品が並ばない。装備欄の品は MOD が作って並べる（`built 4 of 4 items`） |
| 置換 | 剣が居る右手へ短剣を落とす → `replace: 'item_0' leaves right_hand for 'item_1'`。剣は所持品の空きへ、短剣が右手に入り Atk +451 |
| 拡大表示 | 1×1 の短剣・兜・装飾が 2×2 で描かれ、部位の左上に寄る。所持品へ戻すと 1×1 に戻る |
| 注入を剥がして戻したとき | 装備欄の品が持ち物にも装備欄にも無くなった（版6の最初の形。辞書を MOD のモジュールに持っていた）。プロセスに残っていた 4 品を `gc` から拾い直し、辞書は `sys` へ移した |
| 戦闘後の「漁る」で落ちた | `toggle_twin_inventory_visibility` が持ち物の辞書を回している最中に本体が `save_game` を呼び、`save_game` の包みが辞書へ4品を足して `dictionary changed size during iteration`。合流を書き出す JSON の側（`write_obfuscated_json_file`）へ移した |
| セーブ→起動し直し→ロード | 落ちる前のセーブに装備欄の4品が `inventory` に入っていた（`equipments` は `item_0` / `item_2`）。起動し直して開いた窓に4品が控えどおり並んだ（`built 4 of 4 items`） |
| 開いている間の右側の選択肢（版7） | 「会話する」と空の枠 3 つが消え、閉じると戻る |
| 世界を切り替える（版8） | 3つの世界を続けてロード。切り替えのたびに前の世界の品を辞書から落とし（`world changed (A -> B): dropping N item(s)`）、新しい世界の装備欄はその世界の品だけで組まれた |
| 合算の表示（版9〜10） | 両手に武器・防具を複数で、画面上部の括弧が合算の値になった。最高値の品が変わらないドラッグでは HP や所持金が動くまで描き変わらなかったので、見張りを直に呼ぶようにし、版10 でその場で描き変わった |
| 合算の戦闘（版10） | 被弾で `combine wearable: 268 -> 307.8`（指輪 268 ＋ 残り × 10%）、攻撃で `combine weapon: 600 -> 761.5`（左手 323 × 50%）。`319_` の `anchor` が 1,330 から 1,499 ＝ 2×√(737 × 761.5) に上がり、式どおり |

## 仲間の装備（段1〜段4、版11〜版17、1920x1080）

仲間の装備を数にも効かせる計画を 4 段に分けて進めた。段1 はローダの窓口 `combat` と `319_` の受け口と
`402_` の「装備」ボタン、段2 は仲間の装備欄、段3 は `equipments` を書く役の一本化、段4 は審判への部位。

| 操作 | 結果 |
|---|---|
| 段1: 402_ の窓で仲間に杖 323・指輪 268 を装備して戦闘 | 仲間の手の `hit:` に `weapon=260x323` が付いた（能力の側 ＝ `get_npc_defense` 260）。「大きいほう」では錨 992 のまま（素の max_hp が武器の式 580 より大きい）。率で足す形に変更（`319_` 版15）し、錨が 992 → 1281（992 ＋ 580 × 0.5） |
| 段1: 仲間の被弾 | `armor=268` が付き、防御 260 ＋ 134 ＝ 394（軽減 33%）で `final=155`（錨 344 × 65% × 0.67 の帯に一致） |
| 段1: 主人公の防御 0 | 本体の popup で所持品の別の指輪を「外す」と、装備欄の胸当ての枠まで消えて防御 0 で被弾していた。戦闘の1手ごとに装備欄から確かめ直すようにした（版12） |
| 段2: 仲間の装備欄（版13） | 受け渡しの窓の右に出て、右クリックの「装備」で杖が右手・指輪が装飾1に入り、`npc:<id>: weapon -> 杖` `wearable -> 指輪` と辞書に書かれた。閉じて開き直しても同じ並び |
| 1920x1080（版14） | 65px のマスでは 10 行が窓より高く、仲間の装備欄が右下の仲間の欄に被った。マスを 51.5px に縮めると、本体は品を固定の単位（65px）で置くので絵が枠からはみ出した（`fit` の記録で pos ＝ grid.x ＋ 4×65）。マスは 65px のまま、余白を無くして画面の右上に寄せる形にし、窓の下の印にも右下の仲間の欄にも掛からなくなった。主人公の装備欄も同じ寄せ方で被らない |
| 仲間の装備を含むセーブ→ロード | 主人公の 3 品と仲間の 2 品で `save: added 5 equipped item(s)`。ロード後に受け渡しの窓を開くと、仲間の装備欄に 2 品が元の部位で戻った（`built 2 of 2 items`）。仲間の持ち物の窓に二重には並ばなかった |
| 段3: 装備欄から主人公側へ直接引く（版16） | `npc:<id>: 'item_212' handed to '<主人公>'` のあと `weapon -> None`。402_ は `equipment of ... is left to the equipment slots` を 1 行残して解除も掃除もしなかった。杖は主人公に 1 つだけ渡り、仲間側には残らなかった。次に窓を開くと装備欄の品は 1 つ（`panel built: items=1`） |
| 段3: 窓口 `equipped` の答え | 402_ が聞いた時点の答えは 2 回とも `equipped=False`（`id` は装備欄の鍵と同じ、402_ が内側の順も読みどおり）。計測の行で、引いた辞書は画面の装備欄と同じ物（`same_as_panel=True`）なのに、ドラッグ中の品はどの装備欄の辞書にも居なかった（`held_by=[]`）。本体がドラッグで装備欄のグリッドの辞書から品を抜くため |
| 段3: 主人公の品を仲間の装備欄へ直接落とす | `not this owner's item` で断ったが 402_ の `transfer synced: <主人公> -> <仲間>` が走り、品は仲間の持ち物の窓へ戻った。もう一度落とすと `equipped` |
| 段4: 審判への部位（版17・`401_` 版8） | 闘技場の戦闘で、審判への記録（`referee_npc_rewrite`）に主人公の枠（`right_hand` `body` `accessory1`）と仲間の `right_hand` `accessory1` が名前(説明)と属性の行で載った。`item_id=` の行は消えた。追記は 407 字から 1101 字 |
| 売買・クラフト・強化の窓、捨てる | 実機で確認した。窓を組む前に抜く処理は記録を書かず、捨てる処理も断ったときしか書かないので、ログには跡が残らない |
