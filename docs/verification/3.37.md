# 3.37 通貨の呼び名と所持金の表示（`130_`）: 実機で成立・残るは古いセーブの文

通貨の表記がどう書かれているかは、実機ではなくビルド内の文字列から拾った。
`instantale.exe` を UTF-8 で走査し、`ゴールド` 37件・数の直後の `G`・`所持金` の
周りを読み出したもの（GAME.md §2.29）。
`scripts.languages` の `translate_dict` / `pattern_dict` に
`ja` / `en` / `zh-Hant` の3つ組で並んでいることも、そこから読んだ。

画面上部の `Gold:` は別経路で、こちらは**3つ組を持たない素の英語の定数**だった
（`Atk` `Def` `Exp` `Gold:` `Age:` `Sta` `Location`）。
そのうえで**実機で通した**（§2.64）。
欄の実物は `Gold:13184` で、桁区切りの無い整数だった。

## 踏んだ食い違い（実機の画面で発覚）

通貨を `シルバー` / `Slv` にしても、画面上部だけ `Gold:13184` のまま残っていた。
`out\modloader.log` に `hud="game's own"` と出ており、
**書式の設定が既定だったので画面上部には何も仕掛けていなかった**。

初版は「設定が素のゲームの値と同じなら触らない」をそのまま当てはめていた。
だが画面上部の `Gold` は設定の対象である前に**通貨の呼び名そのもの**で、
文中の `ゴールド`・英語表示の ` gold` と綴りが違うだけだった。
呼び名を変えたらここも変わるのが筋で、
直した後は書式を触らなくても付け替わる（`effective_template`）。
「素のままなら触らない」は残っている。
呼び名も書式も動かしていないときは、今も何も仕掛けない。

## 分かっていて直していないもの

- 既にセーブに書かれた文は直さない。
  行動ログ・人生ログ・世界観に残った `ゴールド` はそのまま
  （LLM へ送るときだけ直す）。画面に出る古いアイテムの説明文などは素の表記のまま出る
- 文中の短い形は数の後ろに置く形しか無い（`$1000` と書けるのは画面上部の欄だけ）
- 画面上部の**他の**見出し（`Atk` / `Def` / `Exp` / `Age` / `Sta` / `Location`）と、
  キャラクタ作成画面の `所持金` には触っていない。通貨の話ではないため
