# 3.118 難易度と品の価値の 76 超えを報酬と品の強さに効かせる（`923_beyond_76`・窓口 `value_limits`）: 報酬は実機で成立・品の側は検査まで

2026-10-31 に作った。
[§3.112](3.112.md) で、76 を超えた難易度では敵だけが強くなり、報酬・才能点・品の値段と強さは 76 の値で止まると分かった。
品の価値は 76 を超えても認め、武器・防具の性能も伸ばすと決めた（10-31）。
伸ばし方は `243_probe_value_curves` で 0〜100 の曲線を測ってから決めた。

## 測ったこと（10-31、テストワールド。`243_` 版1、2回の起動）

| 関数 | 70 | 76 | 77〜100 |
|---|---|---|---|
| `get_quest_reward` | 21,223 | 24,216 | 止まる |
| `get_talent_point_quest_clear` | 12 | 12 | 止まる（67 から 12） |
| `get_labor_reward` | 421 | 449 | 止まる |
| `get_training_experience_point` | 5,766万 | 2億9,262万 | 止まる（1段で約1.15倍） |
| `get_equipment_price` / `get_heal_item_price` / `get_other_item_price` | 3,719 / 707 / 707 | 4,646 / 929 / 929 | 止まる |
| `get_weapon_spec` / `get_heal_spec`（5回の中央の値） | 291 / 332 | 332 / 406 | 300〜350 / 370〜430 の揺れの中で横ばい |
| 逆引き `get_*_level_from_price` | | | 76 の値段より上は 76 を返す（KeyError は出ない） |
| `get_talent_point_by_quest_level` / `get_training_price_quest_clear` | 71 から KeyError | | |

56〜76 の傾き: 報酬 約 +600、日雇い +5、装備の値段 約 +113〜129、回復と道具の値段 約 +23〜26、武器 約 4.1〜4.5、回復 約 4.7〜5.0（最小二乗と最後の10段）。

## 決めた仕様

- 76 を超えた分は、76 までの曲線の傾きのまま 100 まで直線で延ばす。`f(v) = f(76) + 傾き × (min(v, 100) − 76)`
- 乱数を引かない関数（報酬・日雇い・値段の3本）の傾きは `(f(76) − f(66)) / 10`。初めて 76 を超えた呼び出しのときに計る
- 乱数を引く武器と回復は、測った傾きを定数で持つ（4.3 / 4.8）。素の関数は引数を 76 に替えて1回だけ呼ぶので、乱数の進みは変わらない
- 才能点は 10 段ごとに +1（設定）。訓練の経験は延ばさない（指数なので 100 で数十億になる）
- 逆引きは値段の延ばし方の逆（76 の値段より高い分を傾きで割って段に足す。100 で止める）
- 品を作る MOD（`312_` / `340_` / `921_`）の価値の切りは、窓口 `value_limits`（TECH.md §3.3.26）から引く。923 が品を延ばしている間は 100、無ければ 76。
  LLM に見せる目盛り（「最高が76」）は 76 のまま
- 測りの probe が数を流している間（`_instantale_probe_dry_run_thread`）は、923 の記録に書かない。
  初回の起動で、243 の値段の測りが 77〜100 の行で記録を埋め、遊んだ回の行が残らない形になっていた

## 実機（10-31、テストワールド。控えを取って試し、後で戻した）

アビスの依頼（素 70、318 で 83）を受けてクリアした。

```text
get_quest_reward: 傾き 603.80（66 の値 18178 → 76 の値 24216）        （out\beyond_76.log）
get_quest_reward(83) -> 28443（76 の値 24216）
get_talent_point_quest_clear(83) -> 12（76 の値 12）
28443円の報酬を受け取った。                                          （画面）
12の才能を得た。
```

ゲームは報酬の関数に 83 をそのまま渡していた（呼ぶ前に 76 へ切っていない）。
