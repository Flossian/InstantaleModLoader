# 3.130 主人公の特質を能力値と店の値段に効かせる（`346_player_trait_effects`）: 置き換え・条件・値段・LLM への添え書き・人物欄は実機で成立

2026-11-13 に `924_player_trait_effects` として作り、同じ日に正式化した。
主人公の特質（`player_data.traits` の name / description / severity）を、LLM に1回頼んで決まった効果の一覧に置き換え、能力値の窓口（`abilities`。TECH.md §3.3.27）と値段の窓口（`prices`）に効かせる。
遊び方と量の決め方は MOD の DOC.md。

## 分かったこと

- 素のゲームの severity は、作成画面で才能点を数えるのに使われるだけで、作った後はどこにも使われない
- 説明の文は会話・戦闘・依頼の頼みに載るが、数値には何も効かない
- 実行時の `Area` は規模を持たない。ダンジョンは依頼の中にしか無いので、「ダンジョンで」は「依頼中」と見分けられない。条件は「常に・依頼中・戦闘中・ボス戦・体力半分以下」の5つにし、場面の見分けはローダの `abilities.situations` に置いた（人物欄の灰色と同じ見分けを使うため）
- `output_data` には書き換える前の頼みが残る。LLM への添え書きは `out\trait_effects.log` の `LLM: 効果の一覧を足した` の行で確かめる
- 特質の見本は、作ったモデルで偏りが大きい。Gemma4 の 46 件は約半分が「致命傷で倒れない」で、Haiku 5.5 の 88 件は環境への耐性・察知・交渉が中心だった

## 量の物差し

最初の物差し（条件の割引が大きく、目安の重さが severity と同じ）では、テストワールドの severity 3 の特質が「戦闘中判断+4」になった。
装備の能力値補正（`411_`。1品で epic +1〜2・legendary +2〜3・mythic +3〜4）に揃えて、次のように直した。

- 条件の割引: 依頼中・戦闘中 0.8、体力半分以下 0.6、ボス戦 0.4
- 重さの目安: severity ÷ 2
- 1つの効果の量: ±3 まで
- 1つの特質の中で、同じ能力値の利点・代償は1つずつ（「依頼中判断+3・戦闘中判断+2」が依頼の中の戦闘で +5 になっていた。頼み文に決まりを足しても 159 件中 14 件残ったので、検算でも量の大きい方だけを残す）
- 決まりの版（`RULES_VERSION`）を控えに書き、古い版で置き換えた特質は次の照合で置き換え直す

ゲームと同じ Haiku 5.5・effort high で、主人公4人と見本 45 件の特質 53 個を3回ずつ（159 回）置き換えて比べた。

| | 前 | 後 |
| --- | --- | --- |
| 能力値の量の分布 | +2: 96、+3: 66、+4: 26、+5: 1 | +1: 69、+2: 127、+3: 3、+4 以上: 0 |
| severity 3 の正の補正の合計（平均） | 3.3 | 2.1 |
| severity 8 の正の補正の合計（平均） | 6.3 | 4.0 |
| severity と向きが合う | ほぼ同じ | 121/145 |

主人公4人の結果は3回ともほぼ同じだった。
文と severity が食い違う特質（利点だけの文に severity -3）は、文の側に沿った正の効果になった。設定「寄せる」は向きが逆のときは触らないので、結果は変わらない。

## 実機（テストワールド。クラウドの Haiku 5.5。控えを取ってから試し、最後に控えへ戻した）

| 確かめたこと | 結果 |
| --- | --- |
| ゲームの LLM の経路で置き換えが通るか | 通った。約1.7秒 |
| 照合の契機 | 注入・人物欄の開け閉め・読み込みの3つとも通った |
| 条件 | 依頼の中の戦闘で依頼中・戦闘中が立ち、町へ戻ると外れた |
| 店の値段 | 売値 1600 → 1760（+10%） |
| LLM への添え書き | 依頼の審判などの頼みに足した（`LLM: 効果の一覧を足した（claude、143字）`） |
| 人物欄のマウスオーバー | 特性とスキルの箱に乗せると、名前・効果・説明の窓が出た。いまの場面で効いていない効果は灰色で出た |
| 決まりの版の上げ直し | 注入し直すと古い版の控えを置き換え直した（`戦場での直感 severity=3（目安の重さ 1.5） 重さ=2.4 -> [戦闘中判断+2・戦闘中器用+1]`） |

ほかに直したこと:

- 条件の行と添え書きの行が交互に毎回ログに出ていたので、同じ行は1回だけ書く形にした
- 注入し直した後に、前の世代の説明の窓が残った（マウスが同じ位置にあると処理が呼ばれない）。窓は印で探して、どの世代のものも外す形にした
- スキルの属性が英語（`physical`）のまま出ていたので、よく出るものを日本語にした
- 説明の窓は、最初の幅（窓の 26%）では長い特質の説明が18行まで伸びた。36% に広げた（広げた後の実機は未）

実プレイの世界のログ（読むだけ）では、ボス戦の条件も立っていた。
