# 3.107 セーブにしか無い施設や人物で落ちる3か所を直す（`146_fix_save_only_entities`・ローダの窓口 `save_lookup`）: 既定は切・入れた状態で売買・宿屋の売買・闘技場・人物の詳細は実機で成立・ふだんの経路は変わらない

2026-10-20 に作った。[§3.106](3.106.md) で洗い出した3か所（売買・人物の詳細の生成・闘技場の試合）を直す。

## 決めた仕様

| 対象 | 世界側にあるとき | 世界側に無いとき（セーブエディタで足したもの） |
| --- | --- | --- |
| 店の品揃えの雛形 | ゲームのまま世界側にも書く（店の性格として残す） | その処理の間だけ引き先をセーブ側にし、雛形はセーブ側にだけ入る |
| 人物の詳細（性格・話し方・立ち絵・能力値など） | ゲームのまま世界側にも書く | 同上。詳細はセーブ側にだけ入り、骨格には足さない |
| 闘技場の相手 | ゲームのまま | 同上 |

遊んだ記録（ライフログ・関係・持ち物・成長）は、いまも世界側に入っていない（[§3.106](3.106.md) のヴェスティアの比べ）。

**既定は切**（設定 `ENABLED`。明確なゲームの不具合と判断できない以上、全員に無条件で当てない）。
切っているときは何も包まず窓口にも名乗らないので、`340_` の宿屋の守り（セーブにしか無い宿屋には入口を出さない）がそのまま働く。
下の実機は設定を足す前の版で行った（入れた状態と同じ動き）。

## 作り

- ローダの窓口 `save_lookup`（TECH.md §3.3.20）。`redirected(app)` の間だけ `app.world_dict` をセーブ側の辞書に差し替える。数えて入れ子にし、最後の1つが抜けたときに戻す。戻すときに辞書が入れ替わっていたら戻さない。保存の書き手（`save_world_json:write_obfuscated_json_file`）を包み、差し替えの間に `world_data*` へセーブ側の辞書が渡されたら本来の世界の辞書に取り替える
- `146_` は4つの入口を包む。`ShoppingStartManagerRemake.shopping_start_method_1`・`InstantaleApp.generate_npc_detail`・`ColosseumMatchStart.method`・`ColosseumMatchStart.generate_enemy_data`。いる施設（と主）か、詳細を作る人物が世界側に無いときだけ差し替える
- `ColosseumMatchStart.method` も包むのは、外す試しで、相手が作られている段でも生成が呼ばれたため（`config` の `enemy_data` を世界側で見て「無い」と読む）
- `340_shop_lineup` は、窓口に売買を直す MOD が名乗っていれば、世界側に無い宿屋でも「売買する」を出す
- 名乗りには場面ごとの包みの対象を添え、窓口は問われるたびに台帳を見て、全部（と保存の守り）が当たっているときだけ「直っている」と答える。`146_` も差し替える前に同じ判断を見る（10-20 のコードレビューで足した。実機は未）
- `340_` の「施設と主が世界側にあるか」は窓口の `in_world` でたどる（`146_` と同じ判断。差し替えの間も本来の世界を見る）

検査は `tools\tests\test_save_only_entities.py`（窓口と 146。47項目）と `test_shop_lineup.py` の2項目。

## 実機（10-20）

施設と人物を `world_dict` からだけ外して（[§3.106](3.106.md) と同じ形）試した。試した世界は控えへ戻した。

| 世界・場面 | 結果 |
| --- | --- |
| ペルディション・イシュメルドの宿屋（`340_`）で「売買する」 | 入口が出て開いた。`redirect on (shopping: facility 151 … is not in world_dict)` → `redirect off`。棚は酒・飲み物・食べ物（と `405_` の特産品） |
| 同・品揃えの雛形の行き先 | セーブ側の施設 151 に8品。世界側には施設 151 が無いまま。ディスク上の `world_data.json` に `player_data` は入っていない |
| 同・闘技場の「試合に出る」→「申し込む」（2試合） | 試合が始まり、勝って戻った。仕込みと相手の生成の両方で差し替え → 戻し。2試合目も相手を作ったのは段が上がったため（外さない状態でも同じ） |
| テストワールド・エテルナの奴隷市場の主テスター（詳細度 1）に話しかける | 会話が始まった。`redirect on (npc_detail: npc 120 (テスター) …)`。セーブ側は詳細度 2・話し方「控えめで丁寧語」・スキル2つ。世界側には足していない |
| 計測ワールド・世界側にいるペトラ（詳細度 1）に話しかける（外さない） | 差し替えは入らない（`146_` の記録が増えない）。詳細は世界側とセーブ側の両方に入った（今までどおり） |

この間、`out\modloader.log` に `KeyError` もスレッドの落ちた知らせも無かった。

## まだのこと

- 訓練場の教官（人物の詳細の生成の別の入口）は、外す試しを入れていない。入口の関数は会話と同じ `generate_npc_detail`
- この MOD より前に落ちて欠けた人物は直さない。話し方が空のまま詳細度 2 の人物は前の版のゲームで作られた人物にも多く（ヴェスティア45人・テストワールド23人・ペルディション66人）、見分けが付かない
