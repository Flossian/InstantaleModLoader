# 3.111 攻撃の演出を武器と属性に合わせる（`342_attack_animations`）: 型が届く・銃撃・1体と全体の差し替え・音・自由入力の審判は実機で成立・ローカル LLM で足した値を選ぶのは実機で成立（10-25）・10-20 夕方に足した6種の残りと控えめの絵は未

開発中は `920_attack_animations` の名前で動かした。遊び方と設定は `342_` の DOC.md、ゲーム側の事実は GAME.md §2.10.5。

## 決めた仕様

2026-10-20 に始めた。

- 攻撃の演出の種類を増やす。`128_item_image_variety` で足した銃器などの武器にも合うものにする
- 審判の型の `vfx` に選択肢を足し、足した値はゲームの分岐に在る値（運び手。1体の物理は slash、1体の魔法は fire、全体は fire_aoe）に乗せてゲームへ渡す。
  置き方と大きさはゲームのまま、絵のフォルダと属性の効果音だけをその手の間だけ差し替える
- 武器と体の絵はゲームの slash1 / blow に揃えて描く（64x64、全体は 128x128）。属性はゲームに在って使われていない絵を使う
- 描き足した絵が派手だったので、控えめ（既定）とはっきりの2組にし、設定で選ぶ
- 足りない演出として、光の刃・鞭・連射・衝撃波・毒・毒の全体を足した（128 の分類と、属性のデータに多い poison／毒 から選んだ）。足す値は30

## 確かめたこと（オフライン）

`tools\tests\test_attack_animations.py`。pydantic のある環境で153件、無い環境では型の節を飛ばして128件。
型の広げ方（欄の並び・検証・説明の手引き）・送り口の差し替え・絵と音の差し替えと時間切れ・敵の手・画風の切り替え・絵の在庫（画風ごとのコマの数と大きさ）・自由入力の審判の置き換えと戻し・最後のコマに絵がある9つの写し。

## ローカル LLM の実機（10-25、テストワールド。衛兵との戦闘。試した後は控えへ戻した）

llama.cpp（CUDA）の Fenrir-X-26B-A4B。送り口は `chat`。
起動の後に `widened vfx for referee_npc` が出て、審判は足した値（`heavy_slash`・`light`・`thrust`）を選んだ。
`heavy_slash` は運び手 `slash` で返り、絵と音（打撃）が差し替わった。
`light` は運び手 `fire` で返ったが、6 秒以内に `fire` の演出の呼び出しが来ず（`NOTE light: no fire effect call came within 6.0s`）、絵は差し替わらなかった。
同じ NOTE は前から `thrust`・`arcane`・`wind`・`dark` などでも出ている（ゲームが演出を描かない手の回）。
クラウド（Haiku 5.5）でも同じ日に `thrust`・`earth_aoe` が選ばれ、差し替わった。

## 設定画面の見本（10-25）

`tool.py` を足し、GUI の「設定…」で開く画面にした（一括設定だけ。この MOD は世界ごとの設定を読まない）。
上に「描き足した絵の見え方」、下に描き足した17種を控えめ・はっきりの2升ずつ、1行に2種並べる。
コマは `effects\<見え方>\<演出>\frame_*.png`（戦闘で出すのと同じ物）を読み、1コマ 70 ミリ秒で流す。
升は 128 角（64 角の絵は2倍、全体の毒は等倍）。全体の毒だけ 256 角にした版は、その列が広がって右の組が画面の外に切れた。
はじめは全部の見本を揃えて流し、いちばん長い全体の毒（16 コマ）が終わるまで短い見本を最後のコマで待たせたが、最後のコマは空なので、ほとんどの升が黒いままだった。見本ごとに「1回流す → 止め絵で 0.5 秒止める」を繰り返す形にし、止め絵はコマの中ほど（頭のコマはほぼ空）にした。同じ演出の控えめとはっきりはコマの数が同じなので、左右は揃って動く。
画面は開いて写真で確かめ、自分で閉じた（控えめ・はっきりの両方、下までスクロールした形）。検査は `tools\tests\test_attack_animations_tool.py`（窓抜き）。
同じ日に、見本をスクロールせずに1画面に収まる大きさへ変えた。升は絵の等倍の 64 角（全体の毒は半分に縮める）、1行に3種で6行。スクロールの部品はやめ、画面の最小の高さを 740 にした（6行が切れない高さ）。既定の大きさ（900x820）で、17種がスクロール無しに収まるのを写真で確かめた。
