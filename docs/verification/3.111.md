# 3.111 攻撃の演出を武器と属性に合わせる（`342_attack_animations`）: 型が届く・銃撃・1体と全体の差し替え・音・自由入力の審判は実機で成立・ローカル LLM と10-20 夕方に足した6種と控えめの絵は未

開発中は `920_attack_animations` の名前で動かした。遊び方と設定は `342_` の DOC.md、ゲーム側の事実は GAME.md §2.10.5。

## 決めた仕様

本人の依頼（2026-10-20）。

- 攻撃の演出の種類を増やす。`128_item_image_variety` で足した銃器などの武器にも合うものにする
- 審判の型の `vfx` に選択肢を足し、足した値はゲームの分岐に在る値（運び手。1体の物理は slash、1体の魔法は fire、全体は fire_aoe）に乗せてゲームへ渡す。
  置き方と大きさはゲームのまま、絵のフォルダと属性の効果音だけをその手の間だけ差し替える
- 武器と体の絵はゲームの slash1 / blow に揃えて描く（64x64、全体は 128x128）。属性はゲームに在って使われていない絵を使う
- 描き足した絵が派手だったので（本人）、控えめ（既定）とはっきりの2組にし、設定で選ぶ
- 足りない演出として、光の刃・鞭・連射・衝撃波・毒・毒の全体を足した（128 の分類と、属性のデータに多い poison／毒 から選んだ）。足す値は30

## 確かめたこと（オフライン）

`tools\tests\test_attack_animations.py`。pydantic のある環境で153件、無い環境では型の節を飛ばして128件。
型の広げ方（欄の並び・検証・説明の手引き）・送り口の差し替え・絵と音の差し替えと時間切れ・敵の手・画風の切り替え・絵の在庫（画風ごとのコマの数と大きさ）・自由入力の審判の置き換えと戻し・最後のコマに絵がある9つの写し。

## 確かめたこと（実機）

2026-10-20、テストワールドで依頼3件（Claude、136 で Haiku 5.5）。主人公の剣は試しの間だけ名前と説明を拳銃にし、終わってから控えへ戻した。

| 確かめたこと | 結果 |
|---|---|
| 審判（`referee_player_attack_new_new` / `referee_npc`）に広げた型が届く | 成立（このときは32択）。戻りに足した値が入る |
| 拳銃を持った主人公の通常攻撃で gun_shot を選ぶ | 成立。主人公の手は全部 gun_shot |
| 仲間の手で足した値を選ぶ | thrown_weapon・earth_aoe・light_aoe が出た |
| 1体の差し替え（slash の運び手） | 成立。銃撃・投擲の絵（はっきり）が敵の位置に 240x240 で出た（写真で確認） |
| 全体の差し替え（fire_aoe の運び手） | 成立。earth_aoe が window_effect で1回差し替わった |
| 効果音の差し替え | 成立。斬撃 → 雷（小）。最初は `play_sound` の名前を1つ目の引数と読んで当たらず、2つ目に直した |
| ダメージの無い手・敵の手 | ゲームが絵を出さない。敵の手では「絵が来ない」の NOTE を出さないようにした |

版2（2026-10-21、[§3.109](3.109.md) の実機の途中で見つけた2件）:

- 自由入力の審判（`NARROWED_MANAGERS`）の答えだけ、送り口から返る所で足した値を運び手（ゲームが描ける `blow` / `water` は slash / ice）に置き換えて控え、
  `resolve_battle_effect` の入口で控えから元の値に戻すようにした（控えは使い切り、`PENDING_SECONDS` で捨てる）。
  直す前は `319_` の防御の手番で `arcane` が元の型に落ち、敵の手番に進まなかった。
  直した後は防御の答えの `blow` が `slash` に置き換わって返り、演出を決める所で `blow` に戻ってゲームが描き、手番が進んで戦闘が終わった。`stall guard` の行は出ていない
- 入力欄に直に書いた魔法の行動で、自由入力の審判が `arcane_aoe` を返した。
  `fire_aoe` に置き換えて返り、演出を決める所で戻して、絵（`battle/neutral_energy_aoe1`）と音（炎（大）→ 雷（大））を差し替えた。
  その絵の最後のコマが次の全体の演出まで画面に残った（本人の指摘。GAME.md §2.10.5）。
  空のコマを足した写しを `out\attack_animations\art\` に作って渡すようにした後は、全体の部品が `image_end.png` で止まり、写真にも残っていない
- 仲間の手で `blow` を選んだ回は、`blow: the game draws it` の後にゲームの `InstantaleApp.effect` が `Assets/effects/blow` で呼ばれた（記録だけ。写真は撮っていない）
