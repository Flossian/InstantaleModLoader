## 決めた仕様（再検討しない）

- 盗みは売買画面の右クリックから（10-04）。施設の選択肢の「盗みを働く」は外した。回数の制限は無く、続けるほど下がる
- 判定の物差しは能力値そのもの（基準 15 は `313_` と同じ）。`get_quest_appropriate_stat` はゲーム自身が呼ばないので使わない（[§2.84](2.84.md)）
- 「裏の依頼掲示板」は公式の未実装の枠だが、同じ役割なので公式が未実装のあいだだけ乗っ取る（未実装の枠は埋めない決まりの例外。10-05）。一覧はギルドの掲示板と同じ形
- 裁判の介入の効き目は判事の頼みへの一文と判決のボタンの直しの2か所で確かにする。上限は「求刑 × 割合」で、判事の年数からは減らさない（二重に減るため）
- 司法取引の締め出しは牢を出てから数える
- 脱獄は年をかけて備える形で、行動は「脱獄を試みる」の下にまとめる。決行で倒れたらゲームオーバー
- 盗んだ店には売れず、断りは主人公の気づき。よその店で半分、盗品買取商（裏の事務所）で7割
- 買収が突き返されたら、大人しく捕まるか抵抗するかを選ぶ（10-06）。贈賄の罰を裁判へ持ち越すのは捕まるときだけ
- 処刑場からの脱出はダンジョンで、好感度の高い人物がいるときだけ。撤退は処刑
- 同房の囚人は新しく作る。服役の始まりに確率で入り、会話と年ごとに親しくなり、加勢し、出所後は雇える
- 店の主の好感度が線（既定 40）以上なら委縮しない（10-20。版3）。率はローダの窓口 `wanted` に店の値の圧として置き、店主の人柄から向きを決める `341_shopkeeper_attitude` が引き受けていれば任せる。はじめは 336 の中で LLM に応じ方を決めさせたが、手配に限らず働かせるため 341 へ移した（[§3.108](3.108.md)）
- 捕まったら（裁判の前に）仲間を解散させる。牢を出ても戻らない（10-21）。素のゲームは捕まっても仲間を外さず、裁判・牢・処刑場からの脱出に仲間が付いてきた。脱出に同行するのは手引きした人物だけで、押したときにパーティに入れる
- 牢に入っている間（服役の始まり〜牢を出るまで、処刑場からの脱出の最中）は、窓口 `confinement` に閉じ込めていると返す（10-21）。`330_` はこの間、借りている家の契約を打ち切る（服役の年ごとに家賃が引かれていた）

## 分かったこと

- 処刑場からの脱出の難易度は、依頼の生成に渡しても記録に届かない（GAME.md の依頼の生成の項）。作った直後と始める直前に記録へ書く（2026-10-21）
- 仲間欄の塗り直し（`ui.Screen.paint_party`）をワーカースレッドから呼ぶと、新しく入った仲間の顔の絵が読み込まれず枠が空になった（起動し直すと出た）。脱出を作る段も裁判の段もワーカースレッドなので、塗り直しはメインスレッドへ回す（2026-10-21）
- 人物の `current_area` は土地の実体のことがある。id として使う前に `ui.area_id_of` を通す（2026-10-21）
- 盗みの判定は行動の締めの要約（`master_ai_process_summarizer*`）に `loot_scale` / `loot_reason` を相乗りさせ、抜いて元の型で返す。包みは `119_` より外側
- 「売買も 0」と添えただけでは売った代金を盗みと判定した（10-10 の報告。10,000G の売却が 12G に削られた）。理由（誰からどう受け取ったか）を規模より先に書かせ、1〜4 は金銭を相手の意に反して取ったときだけと先に言い、売った代金は出どころを問わず 0 とした（[§2.88](2.88.md) の 65）
- 「LLM が渡した額」は、行動の最初の facilitator の前と要約の後の所持金の差。目安は `get_quest_reward(get_area_average_difficulty(土地))`（1→7G、10→326G、30→4,234G）
- 時効の日数は `elapse_days` の前後の暦の差。`residency.last_stay_end` は使わない
- 盗んだ品の持ち主の切り替えは `Item.buy` に任せ、払った額を両方へ戻す。置き場所は `place_new_item`
- 盗む確認はゲーム自身の売買の確認の窓を借りて文言を差し替える。自前の窓は見えなかった（GAME.md §2.13.1）
- 裏の仕事は `random_quest_generator` の `area_description` に種類の指示を足して作る（`307_` と同じ）。`328_` より内側。依頼の辞書に鍵を足さず、id は控えに持つ（GAME.md §2.9）
- 一覧は `apply_buttons` で塗るまでやる（`app.buttons` を差し替えて合図を出すだけでは変わらない）
- 掲示板に出さない依頼はローダの窓口 `board`（TECH.md §3.3.12）に置く。無いと掲示板の依頼を片付けていく MOD に狙われた
- 報酬の倍率は `QuestEndManager.execute` の間だけ帰還の文の額を書き換え、差を足す（`334_` と同じ）
- 判事は贈賄の露見で求刑の2倍を言い渡し、5年と二重になった。頼みに「贈賄の分の刑は別に加えるので、求刑を大きく超えて重くしないこと」を足した
- 決行はローダの窓口 `guards`（TECH.md §3.3.10）で組み、難易度を差し替える
- 盗品買取商の窓は店でない施設でも開く（GAME.md §2.13.1）。実機で4つ直した: 売った後に右の欄が窓の上に出た（選択肢を絞り合図を出す）、閉じても選択肢が戻らない（`set_buttons_to_normal`）、売った品が主に積もる（閉じたら外す）、話しかけの会話の上で開いた（施設の最初の画面にだけ出す）
- 同房の囚人は `npcs.make_npc` で作り、すぐ `generate_npc_detail` で HP・スキルを埋める（埋めないと戦闘で落ちる）。`make_npc` は骨格にも書くので、試すときは骨格も控える
- 関係の印を「初対面」で作ると出所後に名乗り直した。「同房の囚人」で作る
- 牢の中の会話で `301_` の依頼を受ければ牢から出られた。ローダの窓口 `confinement`（TECH.md §3.3.13）で止める
- 囚人の側への知らせは自分の本文を予約した後（先だと「牢獄の外へ出た」より先に出た）
- ロードの途中の組み直しでは `world.characters` が 0 人。人物を見て出すボタンは、人物が揃ってから 336 自身が1度組み直す。条件にはなるべく人物を入れない
- 出し分けや効き目に効く状態（突き返された印・裁判の効き目・持ち越す罰）は控えに持ち、払った後はゲーム自身の保存を呼ぶ（この押下ではゲームは保存しない）

コードの分け方は `crime_overhaul.py` の先頭の表、検査が何を通すかは `tools/tests/test_crime_*.py` の docstring。

## 分かっていて直していないもの

いずれも 10-06 のコードレビューで見つけたもので、素の遊び方では通らず実機で確かめられない。

- 決行でゲームの `process_choice` が例外を投げて戦闘を起こせないと、先に加勢させた囚人がパーティに残る。取り消すには冒険者の一覧から外すローダの部品が要る
- 決行の戦闘の終わりで `end_type` を見ていない。`107_` を切り、闘技場から撤退した後の `in_colosseum_battle` が残っていると、倒れた戦闘を `334_` が逃走として受け止め、牢の外へ出られる（`107_` は既定 ON）
- 時効の「まだ戻しに使っていない日数」は保存より前に確定する。その間に落ちると最大1回ぶんを失う

## 気づいたこと

- 自由行動の盗み1回で手配度が 20 下がった（要約の `lawfulness_loss` は 5）。336 は手配度を書かないので、ゲームが 5 をどう反映しているかは別に測る
- 物語の盗んだ額（「500ゴールド」）と、336 が足す目安（1,211G）が食い違う。目安を物語に寄せる手立てが要るかもしれない
- 服役と決行を挟んだ後、攻撃 510 → 490、HP の上限 1564 → 1501（49 → 54 歳）。年齢か戦闘かは分けていない
- 平常より手配度が高い街では片付けても手配にならないことがある（25 → 15）。概要の「片付ければ手配される」は言い過ぎになる
