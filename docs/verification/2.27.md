# 2.27 `114_` 自由入力の欄からフォーカスが外れる

外れること自体は Kivy の作りどおりで、ゲームの不具合ではない
（送信ボタンを押す＝入力欄の外を触るので `focus = False` になる）。

送信の経路は捕まえず、**焦点が外れたことを見て戻す**。
経路はビルドで変わりうるが「入力欄が焦点を持っているか」はどのビルドでも同じ場所に出ている。
入力欄は `focus` と `insert_text` の両方を持つウィジェットとして探す
（選択肢のボタンも `text` は持つが `insert_text` は持たない）。
待機明けの合図は送信ボタンの `disabled` が False へ戻ること。
取り合いになったら手を引く（2秒に12回で5秒休む）。
最悪でも「今までどおり毎回クリックする」に戻るだけ。

実機は §2.39 で3系統とも発火。
