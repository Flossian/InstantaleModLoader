# 2.63 二つ名の偏りを LLM で 120回ずつ測った（`317_`）

`tools\epithet_probe.py`。ゲーム抜きで llama-server を起こし
（`llm_ctx_probe.py` と同じ形）、MOD の頼み文と読み取りをそのまま使って
6場面×20回ずつ二つ名を引いた。生の返答は `out\epithet_probe_*.json` に全件残る。

- モデル: gemma-4-26B-A4B-it-qat-uncensored-heretic-UDmerge-Q4_K_XXL
- サンプリングは config.json の `llama-cpp-completion-cuda` と同じ
  （temp 1.0 / top-p 0.95 / top-k 64。seed 無し）
- 思考を吐くモデルは `--reasoning-budget 0` で切る。
  切らないと返答上限を全部思考に使い切り、本文が HTTP 200 のまま空になる

| 120回中 | 対策前 | 対策後 |
| --- | --- | --- |
| 読めない返答 | 0 | 0 |
| 二つ名が空 | **88** | **0** |
| 素材の写し（名前・題名） | 11 | 0 |
| 地名をそのまま含む | 0 | 0 |
| 場面ごとの異なり（範囲） | 1〜4種 | 3〜12種 |

事前の予想は「同じ形の名前ばかり出る」だったが、実際の偏りは逆で
**そもそも出ない**が支配的だった（空 73%）。
「記録に無いことを足さない」の縛りが二つ名にまで効き、
「ふさわしいものが無ければ空文字」へ逃げる。
対策は頼み文に2行足すこと（「二つ名だけは連想して新しく作ってよい」と
「本人の名前や依頼の題名をそのまま使わない」）＋コード側の番人。

副次的に分かったこと2つ。

- 頼み文に載る名前が二つ名の語彙へ漏れる。
  プレイヤー名が「旅人」で始まる形だと末尾「旅人」が 32/120。
  名前から「旅人」を外したら 4/119 に落ち、異なりも広がった
- 素の it-qat 版でも向きは同じ（異なり 5〜13種、最頻の寄りは緩い）。
  「旅人」を外した条件では異なり 11〜17種まで広がり、
  「暴走の＜名前＞」のような**名前に語を足した形**が3件出た
  （頼み文で禁じたのは「そのまま」なので、番人はこの形を通す線に合わせた）

場面**内**の収束は残る（医療 20回中15回が同じ二つ名）。
実際の遊びでは1つの素材から1回しか編纂しないので、これは問題にしていない。
