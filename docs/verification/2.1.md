# 2.1 Kivy 終了時クラッシュ（決着）

`100_` のガードが終了操作で2回発火（`wm_pen` / `wm_touch`）。
そのうえで `crash_log.txt` は 173,055 bytes のまま・`ctypes.ArgumentError` は 47 件のまま・
`out/live_crashes.log` は未作成。
「バグは起きたが、クラッシュにはならなかった」が4指標とも揃って効果が確定。

ガードは毎回発火するわけではない（記録の47件も日を跨いでばらける）ので、
版2までの `100_` は呼ばれるたびログを出し「効いた」と「今回は踏まなかった」を区別できるようにしてあった。

版3（2026-11-02）で、失敗したときの呼び直し（ハンドラを整数のアドレスにして `SetWindowLongPtrW`）と毎回の記録を外した。
10-16〜11-01 の失敗72回は全部 `hWnd=None` で、呼び直しは一度も走っていなかった（戻す相手のウィンドウが先に消えている）。
いまは失敗の行（`SetWindowLong_WndProc_wrapper failed`）だけを書く。

真の原因と、`alias_scan` が無ければ素通りしていた件は TECH.md §4.1。
