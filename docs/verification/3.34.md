# 3.34 賞金首狩りの前提（`220_`）: 道は全部繋がった

手配された土地でゲーム自身の衛兵を出し、全段を録った
（経路は GAME.md §2.20、記録は VERIFICATION_LOG.md §2.51）。
MOD からゲームの戦闘を起こすのに要る値は揃った。

| 録れたもの | 値 |
| --- | --- |
| 戦闘の起こし方 | `BattleStartManager(app, 'guard', None)` → `execute` |
| 敵の作られ方 | `create_guard_enemies` が `guard_npc_generator` で `EnemyData` を1件作り、`generate_enemy_instance_from_quest_dict` で3体に組む |
| 強さの決まり方 | 難易度の数値1つ。`get_enemy_exp_lvl('normal', 20) -> 21` / `get_enemy_attributes_base_point('normal', 20) -> 11.37` |
| 割り込む場所 | 4箇所とも発火。施設到着は7回とも手が空いていた。**自由行動は4回とも `is_button_enabled=False`** |
| 手配度の振れ | 29土地のうち手配は1土地（`-10`）。衛兵と戦った後は `-20` |

残っているのは3点。どれも追手を出すこと自体は止めない。

| 未実測 | 効いてくる場面 |
| --- | --- |
| 難易度 `20` の出どころ | ゲーム自身の衛兵が何を基準に強さを決めているか。追手側は自分で難易度を渡すので、比較の目安が無いだけ |
| 敵の数の決まり方 | `create_guard_enemies` の中。3体固定なのか難易度で動くのか |
| 敵の名前の付き方 | `衛兵` はマネージャ側が付けている。追手を別名にするならここを触ることになる |
