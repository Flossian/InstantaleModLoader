# 2.84 街の依頼の難易度は初訪問で決まる。決め方も5回で決着（`225_`）

`133_ui_area_difficulty` が未訪問の街に帯を出すための計測。移動5回（`225_` 版1〜4）で決め方まで写った。
`out\area_quest_difficulty.log`（1回目は 539行、`.jsonl` 284件）。

| 回 | 世界 / 移動 | 版 | 難易度 |
|---|---|---|---|
| 1 | 世界B（Lv 60・物語の段階 0・140日目）。未生成の id 2 へ馬車 | 1 | `[26, 21, 25]` |
| 2 | 同 id 2 → id 3 へ馬車 | 2 | `[52, 47, 51]` |
| 3 | 世界C（Lv 1・段階 0・60日目）。id 7 へ徒歩 | 3 | `[38, 42, 37]` |
| 4 | 同 id 7 → id 8 へ徒歩 | 4 | `[74, 69, 76]`。決め方が写った |
| 5 | 同 id 2・id 3 へ徒歩 | 4 | `[25, 26, 24]` / `[53, 55, 48]` |

経路:

- 街は `AreaMoveManager.execute` → `method_1` → `save_area_json:write_area_data_to_world_dict(world_dict, area_id)` の中で作られる。
  `create_settlement_detail` が :80、`settlement_quest_generator` が :335、`generate_quest_area` が :373 から。
  移動の前後で `level_of_detail` 0 → 1、`nodes` 0 → 1、依頼 `[]` → `['30', '31', '32']`
- 頼み文には `- 想定段階: ゲーム序盤` と `- quest_1:難易度は26/70` の形でゲームが決めた数が書かれる（`output_data\unknown\unknown\settlement_quest_generator\N.json`。世界名が `unknown` に落ちているのは別件）
- 依頼3件の難易度は `World.generate_character` が `choice([26, 21, 25])` で冒険者 NPC のレベルにも使う（:11047）
- `uniform(0.9, 1.1)` ×2 と `uniform(0.9, 1.2)` ×1 が依頼1件ごとに :355 / :359 から呼ばれるのは難易度が決まった後（報酬か規模の揺らぎと読める）
- ロード時にも `Area.update` / `generate_nodes` が全43エリアで走る（`World.generate_areas` から。0.0s で中身は作らない）
- Nuitka のフレームは `f_locals` が空で、ローカル変数の写しは取れない

決め方（4回目の写し）:

```text
乱数: sample("range(67, 77, 1)", k=3) -> [74, 69, 76] caller=write_area_data_to_world_dict (save_area_json.py:329)
頼み文: settlement_quest_generator difficulties=[[74, 69, 76]]                        (save_area_json.py:335)
```

街の初期依頼3件の難易度は `random.sample(range(lo, hi), k=3)` の1回（重複なし）。
`lo` / `hi` は :329 より前に乱数も `scripts.functions` も使わずに決まる。
:80〜:335 の間の乱数は BGM の `choice` 1件とこの `sample` だけで、`randint` / `uniform` / `random` / `randrange` / `gauss` と
`get_quest_difficulty_from_stat` / `get_quest_appropriate_stat` は 0 回。`scripts.functions` の全47関数は2〜4回目とも 0 本
（窓の中で呼ばれたのは `get_quest_difficulties` だけで、移動の直前に `method_1` から1回と :373 から数回。戻りは `[]`）。
Lv 1・物語の段階 0・id 8 に物語の依頼が無い世界でも枠どおりなので、プレイヤーにも物語にも依らず街の枠（id）で決まっている。
物語の依頼（`story_quests`）は物語の順に 14・28・42・56・70 で、街の帯とは別（同じ街でも一致しない）。

probe の側は、`132_` の種の抽選が乱数の上限 300 件を2秒で食う（2回目）、
「MOD 自身の抽選を数えない」判定が probe 自身のラッパを MOD と見なして全件を捨てる（3回目）を版4で直し、上限を 1000 にした。

枠の窓。5世界の world_data の初期依頼（各街3件）の観測と実測を合わせたもの。序盤 0・1・4 → 中盤 2・5・7 → 終盤 3・6・8 の順に隣り合う
（前の枠の `hi` が次の枠の `lo`。上限 77 は `QUEST_DIFFICULTY_VALUE_MAX` 76 + 1）:

| 順 | id 0 | id 1 | id 4 | id 2 | id 5 | id 7 | id 3 | id 6 | id 8 |
|---|---|---|---|---|---|---|---|---|---|
| 観測の最小〜最大 | 1〜5 | 3〜11 | 11〜22 | 19〜31 | 28〜37 | 37〜47 | 47〜56 | 57〜66 | 67〜76 |
| `range(lo, hi)` | (1, 6) | (3, 11) | (11, 19) | (19, 28) | (28, 37) | (37, 47) | (47, 57) | (57, 67) | (67, 77) |
| 出所 | 15件の観測 | 観測 | 観測 | 実測 | 観測 | 観測 | 実測 | 観測 | 実測 |

観測の側は 5世界 × 3件がすべて窓に収まる（id 0 は 15件が全部 5 以下）。
例外は最も古い世界D（id 1 に 11、id 4 に 19〜22、id 5 に 37、id 7 に 47 と、窓を1つ上に外れた値がある）。
作られた時期のゲームの版で境界が違っていたと読み、いまの版の表には入れない。
エディタで足した街（枠なし）は全域 `range(1, 77)` から引かれる（id 33 で `sample("range(1, 77, 1)", k=3) -> [6, 34, 3]`。世界B の id 21 の `[13, 30, 40]` も同じ）。
`133_ui_area_difficulty` 版2はこの表（`SLOT_RANGES`）で未訪問の街を「推定 lo+1〜hi」と出し、枠の無い街は推定しても 2〜77 にしかならないので「不明」のまま。
