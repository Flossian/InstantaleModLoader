# InstantaleModLoader

Instantale（Epic版）に**ゲームのファイルを一切書き換えずに** MOD を効かせる仕組み。
バグの修正と、ゲームに無かった遊びの追加が入っている。

- **ゲームフォルダには何も書き込まない。** Epic のアップデートや修復（repair）をしても
  壊れないし、MOD 側を消すだけで完全に元通りになる
- **管理者権限は不要。** 追加のインストールも不要（Python だけ）
- **セーブは壊さない。** MOD が書き換えるのはゲームが自分で保存する値だけ

技術的な中身は [TECH.md](TECH.md)、検証の状況は [VERIFICATION.md](VERIFICATION.md)。

---

## 何ができるか

### 直るもの

| | 内容 |
|---|---|
| **終了時のクラッシュ** | ゲームを閉じるときに落ちる件（記録されていたクラッシュの最多ケース）を抑える |
| **NPC 雇用時のクラッシュ** | 特定の NPC を雇おうとすると落ちる `KeyError: 80` を修正 |
| **戦闘後もBGMが戻らない** | 会話から戦闘に入ると戦闘BGMが鳴り続ける件を修正。溜まった「迷子の曲」も注入時に掃除する |
| **ロードすると戦闘BGMで始まる** | 会話からの戦闘で「戦闘中」の印が下ろされずセーブに焼かれるのを修正。**一度戦闘すると施設でNPCから話しかけられなくなる**のも同じ原因だった |
| **売買画面を開くと落ちる** | 店で売り買いしようとした瞬間に落ちる件を修正。持ち物の置き場所がはみ出したときは、ゲーム自身の「空いている場所に置く」処理に流す |
| **アイテムの説明が途中で切れる** | 説明欄が固定サイズで、長い説明・長い名前が読めなかったのを修正。**入り切らないときだけ枠が広がる**（普通の長さのアイテムは今までと同じ見た目） |
| **特定のNPCの画像が生成されない** | 名前に `"` などファイル名に使えない文字が混じると、立ち絵などが無言で作られないままだった件を修正。名前を全角に置き換えて通す（表示はほぼ変わらない）。既に世界に居るNPCも直す |
| **AIの応答が遅くなる/おかしくなる** | ゲームがAIへ送る文章の重複・肥大を削る（実測で約73%削減）。長時間プレイでの劣化が軽くなる |
| **エリアBGMの偏り** | 新しく生成されるエリアの曲が一部に偏るのを均す。使われていなかった曲が出るようになる |

### 増えるもの

| | 内容 |
|---|---|
| **施設でNPCから話しかけてくる** | 宿屋や店に入ると、そこに居るNPCの方から会話が始まることがある。ゲーム本来の会話なので立ち絵も履歴も普通に付く |
| **会話から依頼を受けられる** | 会話中に「依頼を受ける」が出る。**いま話した内容から依頼を1件作らせる**こともできる |
| **仲間と別れられる** | 本来は死別とクエスト解散でしか外れない仲間を、会話から「ここで別れる」で外せる。別れた相手は雇われた場所（土地を跨いだ場合はいまの町のギルド）に残る |
| **クエスト解散でいなくならない** | ゲーム本来のクエストクリアは同行者を雇った町へ帰してしまうので、**いま居る町のギルドに残す**ように変える。また組みたくなったら会いに行ける |
| **クエストクリアで解散しない** | そもそもパーティを解散しない。クエストが終わっても仲間はそのまま同行し続ける（雇い直しが要らなくなるので、**ゲームバランスは意図的に変わる**）。外したくなったら会話から「ここで別れる」 |
| **戦闘なしのミニクエスト** | 掲示板に「軽い頼まれごとを探す」が出る。**採集・救助・偵察**の依頼を作り、道中も戦闘ではなく自由入力と選択肢で進む。受注も報酬もゲーム本来のクエストと同じ |

## 導入

### 必要なもの

- Instantale（Epic版）
- **64bit の Python 3.13**（`C:\Users\<ユーザー名>\AppData\Local\Programs\Python\Python313\`）
  — 32bit 版では動かない

このフォルダをどこに置いても構わない（既定は `Desktop\InstantaleMods\InstantaleModLoader`）。
ゲームフォルダの中に入れる必要はない。

### 使い方

**`watch.bat` をダブルクリックして立てておくだけ。** あとはいつも通りゲームを起動すれば、
準備が整った時点で自動的に MOD が入る。

```powershell
.\watch.bat          # 起動を監視して自動注入。閉じるときは Ctrl-C
.\watch.bat --once   # すでに起動しているゲームに1回だけ入れて終了
```

> ## ⚠ ゲームを起動するたびに入れ直しが必要
>
> MOD はゲームのプロセスと一緒に消える。**ゲームを再起動したら必ず注入し直すこと。**
> 忘れると素のゲームが動き、修正も追加要素も何も効かないまま遊ぶことになる。
>
> `watch.bat` を立てっぱなしにしておけば自動で入るので、**基本はそれを開いたままに
> しておくのが確実**。

### 効いているかの確認

`out\modloader.log` の末尾に、こう出ていれば入っている:

```
boot complete: 28/28 mod(s) applied
```

数が足りない場合でも、**AI関連の MOD は最初の会話まで待ってから入る**（ゲームがその
部分を後から読み込むため）。会話を1回してからもう一度ログを見ると揃う。

ゲーム内で分かりやすいのは:

- 宿屋や店に入ったときに NPC から話しかけてくることがある
- NPC と会話すると「会話を終了する」の上に**「依頼を受ける（話を切り上げる）」**がある
- ギルドの「クエスト掲示板」に**「軽い頼まれごとを探す」**がある

## 設定を変える

MOD は `runtime\mods\` の中の `.py` ファイル。**それぞれの先頭に設定がまとまっている**ので、
メモ帳などで開いて値を書き換え、次に注入するときから反映される（ゲーム再起動＋再注入）。

よく触るもの:

| ファイル | 設定 | 意味 |
|---|---|---|
| `300_event_facility_arrival.py` | `CHANCE_BY_TYPE` | 施設ごとのイベント発生率（宿 0.50 / ギルド 0.30 / 店 0.25 …） |
| | `CHANCE_OVERRIDE` | 数値を入れると全施設をその確率に固定。`1.0` にすると必ず発生（動作確認用） |
| | `COOLDOWN_MOVES` | 同じ施設で連続して出さない移動回数（既定 3） |
| | `EVENT_MODE` | `"conversation"`＝会話が始まる（既定） / `"narration"`＝情景描写に一言足すだけ |
| `301_quest_from_conversation.py` | `FILTER_BY_NPC` | `True`＝会話から開いた依頼一覧をその NPC の依頼だけに絞る（既定）。**初対面だと一覧が「この話から依頼を作る」だけになる**ので、全部見たいときは `False` |
| | `ENABLE_GENERATION` | 「この話から依頼を作る」を出すか |
| `302_leave_party_in_conversation.py` | `RETURN_TO_INITIAL_LOCATION` | `True`＝雇った場所に戻す（既定）。`False` でゲーム任せ |
| `303_quest_end_party_to_guild.py` | `ANNOUNCE_DESTINATION` | 解散した仲間の行き先を画面に出すか（既定 ON） |
| | `ALSO_ON_QUEST_RETIRE` | クエスト**放棄**のときも同じ扱いにするか（既定 OFF・未検証） |
| `304_quest_end_keep_party.py` | `KEEP_TEXT` | 解散を止めたときに出す文（既定「…はパーティに残り、引き続き行動を共にすることになった。」） |
| | `ALSO_ON_QUEST_RETIRE` | クエスト**放棄**のときも解散を止めるか（既定 OFF・未検証） |
| `104_balance_area_bgm.py` | `FILL_MISSING` | BGM が空のエリアにも曲を割り当てるか（既定 ON） |
| `305_mini_quest.py` | `COMBAT_MODE` | `"none"`＝戦闘を起こさせない（既定） / `"mobs"`＝雑魚との戦闘は道中の障害として許す（ボス戦はどちらでも出ない） |
| | `KINDS` | お題の種類。既定は採集・救助・偵察の3つで、押すたびに順に選ばれる。文面を書き換えればお題を足せる |
| | `EVENT_COUNT` | 生成させる出来事の数（既定「4から6」）。**戦闘の代わりにこれが依頼の中身になる**ので、道中が薄いと感じたら増やす |
| | `TURN_BUDGET` | 何ターンくらいで決着させるか（既定 10）。長引くようなら減らす |
| `109_fix_item_detail_autosize.py` | `WIDEST` | アイテム説明の枠を横に広げてよい上限（元の幅の何倍まで。既定 3.0） |

**MOD を1つ止めたいときは、ファイル名の先頭に `_` を付ける**（`_301_quest...py`）。
読み込まれなくなる。

### ログの世代管理

`out\*.log` は**注入のたび（＝ゲームを起動するたび）に新しくなる**。前回の内容は
`modloader.log.1` のように `.1` を付けて1世代だけ残り、それより古いものは消える。
放っておくとログが数MBまで育って読めなくなるため、既定で ON。

複数回のプレイをまたいで追いたいときは OFF にできる:

```
.\watch.bat --no-log-rotate       # この実行だけ追記のまま
```

常時 OFF にしたい場合は `logrotate.py` の先頭:

| 設定 | 意味 |
|---|---|
| `ROTATE_LOGS` | `False` にすると常に追記（従来の挙動） |
| `KEEP_GENERATIONS` | 残す古い世代の数（既定 1）。`0` にすると退避せず消す |

環境変数 `INSTANTALE_LOG_ROTATE=0` でも OFF にできる（優先順位は
コマンドライン → 環境変数 → `logrotate.py` の既定値）。

`out\` の中でも `quest_clients.json` などログ以外のファイルと、
`out\test\` `out\recon\` の中身は対象外。

## うまく動かないとき

### まずこれを試す

**`watch.bat --once` を実行する**（ゲームは起動したままでよい）。MOD の入れ直しで、
音の不具合や「イベントが出なくなった」はその場で直ることが多い。

それでも変わらなければ、**`watch.bat` を立てた状態でゲームを起動し直す。**

### 症状別

| 症状 | やること |
|---|---|
| イベントも追加ボタンも出ない | 入れ直す（上）。`out\modloader.log` に `boot complete:` が無ければ入っていない |
| 音が重なる・戦闘後も戦闘BGMが鳴り続ける・タイトルに戻っても曲が止まらない | 入れ直す。溜まっていた分ごと直る。MOD を入れていない場合はゲームの再起動しかない |
| ロードすると戦闘BGMで始まる | 入れ直す。読み込んだ時点で直る |
| 一度戦闘したらNPCから話しかけられなくなった | 同上（上と同じ原因） |
| NPC の立ち絵が消えず、移動しても付いてくる | その NPC ともう一度会話して、普通に「会話を終了する」を押す |
| 仲間と別れるボタンが出ない | 仲間が居ないと出ない。まず NPC を雇う |
| 「ここで別れる」を選んでも別れられない | 人の居る場所（町など）へ戻ってから。ダンジョンでは別れられない |
| 依頼一覧に「この話から依頼を作る」しか出ない | その NPC の依頼がまだ無い状態。すべて見たいなら `301_quest_from_conversation.py` の `FILTER_BY_NPC = False` |
| 選択肢を押しても何も起きない | 画面が「…」の間は処理中。終わるまで待つ |
| 店で売り買いしようとすると落ちる | 入れ直す。落ちなくなる代わりに、はみ出した持ち物が別のマスに置かれることがある |
| アイテムの説明が途中で切れる | 入れ直す。枠が伸びるようになる。それでも入り切らないほど長い説明は画面の高さで頭打ち |
| 特定のNPCだけ立ち絵や画像が出ない | 入れ直す。名前が原因なら直り、次に画像を作る場面（会話・戦闘）で生成される |
| ゲームが落ちる・様子がおかしい | `watch.bat` を止めてゲームを起動すれば**完全に素のゲーム**として動く。記録は `out\live_crashes.log` |

### 不具合ではないもの

| | |
|---|---|
| **「依頼を受ける」を押すと会話が終わる** | 依頼の話をするために会話を切り上げている（ボタンにもそう書いてある） |
| **クエストをクリアしても仲間が離れない** | `304_quest_end_keep_party.py` の効果。**解散するように戻したい**ならこのファイルの頭に `_` を付けて入れ直す（`303_` の「いま居る町のギルドに残る」だけになる）。`303_` にも `_` を付ければゲーム本来（雇った町へ帰る）に戻る。1人だけ外したいなら会話から「ここで別れる」 |
| **追加されたボタンが MOD 無しだと何も起きない** | セーブに残ったボタンの残骸。押しても害は無い |

## セーブとゲームファイルへの影響

- **ゲームフォルダは読むだけ。** 一切書き込まない
- **セーブに書くのは、ゲーム自身が持っている値だけ**（パーティの名簿・依頼・エリアのBGM）。
  MOD 独自の項目をセーブに足すことはしない
- ファイル名に使えない文字を含む**NPC の名前だけは書き換える**（`"` → `”` のように全角へ）。
  そうしないとそのNPCの画像が永久に作られないため。書き換えた名前は
  `out\character_name.log` に残る
- MOD が追加した選択肢ボタンは、押した瞬間に無害な既存の動作へ差し替わる作りなので、
  **MOD を入れずに次回起動しても壊れない**
- 既存セーブの BGM を一括で均す道具（`tools\rebalance_saved_bgm.py`）だけはセーブを
  書き換えるが、**既定は dry-run（変更しない）**で、実行時は自動でバックアップを作る

---

## 制限

- MOD はゲーム起動**後**に入るので、起動時に一度だけ走る処理には手が届かない
- AIが推論している最中に注入すると入るのが遅れることがある（30秒でタイムアウト表示が
  出るが、その後ちゃんと入る）
- 追加した選択肢ボタンがセーブに残骸として残ることがある。無害だが、MOD 無しで押すと
  何も起きない

## ファイルの置き場所

| | |
|---|---|
| `watch.bat` | これを立てておく（ダブルクリック可） |
| `runtime\mods\` | MOD 本体。設定はここを開いて書き換える |
| `out\` | ログ各種。何が起きたかは全部ここに残る（`.1` は前回のプレイ） |
| `logrotate.py` | ログの世代管理（ON/OFF と残す世代数） |
| `tools\` | 検証用スクリプト（ゲーム不要）とセーブのBGM再配分ツール |
| `TECH.md` | MOD を作る人向けのリファレンス |
| `VERIFICATION.md` | 何がどこまで確認済みか・次に何を確かめるか |
