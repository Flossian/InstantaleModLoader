# InstantaleModLoader

Instantale（Epic版）に**ゲームのファイルを一切書き換えずに** MOD を効かせる仕組み。
バグの修正と、ゲームに無かった遊びの追加が入っている。

- **ゲームフォルダには何も書き込まない。** Epic のアップデートや修復（repair）をしても
  壊れないし、MOD 側を消すだけで完全に元通りになる
- **管理者権限は不要。** 追加のインストールも不要（Python だけ）
- **セーブは壊さない。** MOD が書き換えるのはゲームが自分で保存する値だけ

技術的な中身は [TECH.md](TECH.md)（ローダの仕組みと MOD の書き方）と
[GAME.md](GAME.md)（実測でわかったゲーム自身の構造）、検証の状況は
[VERIFICATION.md](VERIFICATION.md)。

---

## 何ができるか

### 直るもの

| | 内容 |
|---|---|
| **終了時のクラッシュ** | ゲームを閉じるときに落ちる件（記録されていたクラッシュの最多ケース）を抑える |
| **NPC 雇用時のクラッシュ** | 特定の NPC を雇おうとすると落ちる `KeyError: 80` を修正 |
| **戦闘後もBGMが戻らない** | 会話から戦闘に入ると戦闘BGMが鳴り続ける件を修正。溜まった「迷子の曲」も注入時に掃除する |
| **ロードすると戦闘BGMで始まる** | 会話からの戦闘で「戦闘中」の印が下ろされずセーブに焼かれるのを修正。**一度戦闘すると施設でNPCから話しかけられなくなる**のも同じ原因だった |
| **売買画面を開くと落ちる** | 店で売り買いしようとした瞬間に落ちる件を修正。持ち物の置き場所がはみ出したときは、ゲーム自身の「空いている場所に置く」処理に流す |
| **アイテムの説明が途中で切れる** | 説明欄が固定サイズで、長い説明・長い名前が読めなかったのを修正。**入り切らないときだけ枠が広がる**（普通の長さのアイテムは見た目が変わらない） |
| **特定のNPCの画像が生成されない** | 名前に `"` などファイル名に使えない文字が混じると、立ち絵などが無言で作られないままだった件を修正。名前を全角に置き換えて通す（表示はほぼ変わらない）。既に世界に居るNPCも直す |
| **AIの応答が遅くなる/おかしくなる** | ゲームがAIへ送る文章の重複・肥大を削る（実測で約73%削減）。長時間プレイでの劣化が軽くなる |
| **エリアBGMの偏り** | 新しく生成されるエリアの曲が一部に偏るのを均す。使われていなかった曲が出るようになる |

### 増えるもの

| | 内容 |
|---|---|
| **施設でNPCから話しかけてくる** | 宿屋や店に入ると、そこに居るNPCの方から会話が始まることがある。ゲーム本来の会話なので立ち絵も履歴も普通に付く |
| **会話から依頼を受けられる** | 会話中に「依頼を受ける」が出る。**いま話した内容から依頼を1件作らせる**こともできる |
| **仲間と別れられる** | 本来は死別とクエスト解散でしか外れない仲間を、会話から「ここで別れる」で外せる。別れた相手は雇われた場所（土地を跨いだ場合はいまの町のギルド）に残る |
| **クエスト解散でいなくならない** | ゲーム本来のクエストクリアは同行者を雇った町へ帰してしまうので、**いま居る町のギルドに残す**ように変える。また組みたくなったら会いに行ける |
| **クエストクリアで解散しない** | そもそもパーティを解散しない。クエストが終わっても仲間はそのまま同行し続ける（雇い直しが要らなくなるので、**ゲームバランスは意図的に変わる**）。外したくなったら会話から「ここで別れる」 |
| **戦闘なしのミニクエスト** | 掲示板に「軽い頼まれごとを探す」が出る。**採集・救助・偵察**の依頼を作り、道中も戦闘ではなく自由入力と選択肢で進む。受注も報酬もゲーム本来のクエストと同じ |

## 導入

### 必要なもの

- Instantale（Epic版）
- **64bit の Python 3.13**（`C:\Users\<ユーザー名>\AppData\Local\Programs\Python\Python313\`）
  — 32bit 版では動かない

このフォルダをどこに置いても構わない（既定は `Desktop\InstantaleMods\InstantaleModLoader`）。
ゲームフォルダの中に入れる必要はない。

### 使い方

**`InstantaleModLoader.bat` をダブルクリックする。** MOD の一覧が出るので、
**「Mod を注入してゲームを起動」**を押せばゲームが立ち上がり、準備が整った時点で
MOD が入る。

一覧でできること:

| | |
|---|---|
| **並べ替え** | 行をドラッグ（または `▲上へ / ▼下へ`）。**上にあるものから順に適用される** |
| **有効/無効** | 左端のチェックを押す。無効にした MOD は読み込まれない（フォルダは消さない） |
| **設定** | `設定` 列の `○` を押す（変更済みなら `●`）。MOD ごとの設定を変えられる |
| **保存** | `保存` を押すと `runtime\mods\load_order.json` に書かれる。次の注入から効く |
| **MOD を追加** | zip でもフォルダでも選べる。`runtime\mods\` に入って一覧の末尾に付く |
| **この MOD を開く** | 選んでいる MOD のフォルダをエクスプローラで開く。一覧に出ない設定を直に書き換えるときに使う |
| **前回** | 前回の注入でその MOD が入ったか。失敗したものは赤くなる |

ウィンドウの大きさと位置は閉じたときのものが残り、次に開くと同じ場所に出る
（`settings\gui.json`）。

`前回` の列と、その下に出る警告が「本当に入ったか」の答え。ゲームを起動して注入すると、
何本入ったか・何が失敗したかがそのまま一覧に出る（ログを開かなくてよい）。

ウィンドウを使わず、コンソールで済ませることもできる。`tools\watch.bat` を立てておくと、
ゲームの起動を見張って自動で注入する:

```powershell
.\tools\watch.bat          # 起動を監視して自動注入。閉じるときは Ctrl-C
.\tools\watch.bat --once   # すでに起動しているゲームに1回だけ入れて終了
```

> ## ⚠ ゲームを起動するたびに入れ直しが必要
>
> MOD はゲームのプロセスと一緒に消える。**ゲームを再起動したら必ず注入し直すこと。**
> 忘れると素のゲームが動き、修正も追加要素も何も効かないまま遊ぶことになる。
>
> `InstantaleModLoader.bat` の起動ボタンから立ち上げれば必ず入る。ゲームを別の
> 場所から起動する癖があるなら、`tools\watch.bat` を立てっぱなしにしておくと確実。

### 効いているかの確認

`out\modloader.log` の末尾に、こう出ていれば入っている:

```
boot complete: 28/28 mod(s) applied
```

数が足りない場合でも、**AI関連の MOD は最初の会話まで待ってから入る**（ゲームがその
部分を後から読み込むため）。会話を1回してからもう一度ログを見ると揃う。

ゲーム内で分かりやすいのは:

- 宿屋や店に入ったときに NPC から話しかけてくることがある
- NPC と会話すると「会話を終了する」の上に**「依頼を受ける（話を切り上げる）」**がある
- ギルドの「クエスト掲示板」に**「軽い頼まれごとを探す」**がある

## 設定を変える

**一覧の `設定` 列を押す。** よく触る設定はウィンドウから変えられる。変えた値は
`settings\mod_settings.json` に入り、**MOD を新しい版に差し替えても残る**。
次に注入するときから反映される（ゲーム再起動＋再注入）。

ウィンドウから変えられるもの:

| フォルダ | 設定 | 意味 |
|---|---|---|
| `300_event_facility_arrival/` | イベントの出方 | 会話が始まる（既定） / 情景描写に一言足すだけ |
| | 発生率を固定 | 空欄なら施設ごとの既定値。`1.0` にすると必ず発生（動作確認用） |
| | 連続して出さない移動回数 | 同じ施設で続けて出さない回数（既定 3） |
| `301_quest_from_conversation/` | その NPC の依頼だけを見せる | 既定 ON。**初対面だと一覧が「この話から依頼を作る」だけになる**ので、全部見たいときは OFF |
| | 「この話から依頼を作る」を出す | 既定 ON |
| `302_leave_party_in_conversation/` | 雇った場所に戻す | 既定 ON。OFF にするとゲーム任せ |
| `303_quest_end_party_to_guild/` | 行き先を画面に出す | 既定 ON |
| | クエスト放棄でも同じ扱い | 既定 OFF・未検証 |
| `304_quest_end_keep_party/` | 解散を止めたときに出す文 | 既定「…はパーティに残り、引き続き行動を共にすることになった。」 |
| | クエスト放棄でも解散を止める | 既定 OFF・未検証 |
| `104_balance_area_bgm/` | 曲が無いエリアにも割り当てる | 既定 ON |
| `305_mini_quest/` | 道中の戦闘 | 起こさせない（既定） / 雑魚のみ許す（ボス戦はどちらでも出ない） |
| | 出来事の数 | 既定「4から6」。**戦闘の代わりにこれが依頼の中身になる**ので、道中が薄いと感じたら増やす |
| | 決着までの目安ターン数 | 既定 10。長引くようなら減らす |
| `109_fix_item_detail_autosize/` | 説明欄を広げてよい上限 | 元の幅の何倍まで（既定 3.0） |

**それ以外の設定はコードに入っている。** MOD のフォルダの中の `.py` を開くと、先頭に
設定がまとまっている（どのファイルが本体かは同じフォルダの `mod.json` に書いてある）。
一覧に無いもので触ることがあるのはこの2つ:

| フォルダ | 設定 | 意味 |
|---|---|---|
| `305_mini_quest/` | `KINDS` | お題の種類。既定は採集・救助・偵察の3つで、押すたびに順に選ばれる。文面を書き換えればお題を足せる |

施設ごとのイベント発生率（宿 0.50 / ギルド 0.30 / 店 0.25 …）は**一覧から変えられる**。
`0` にするとその種類の施設では出なくなる。

> コードを書き換えた場合、その値は **MOD を新しい版に差し替えると消える**。
> ウィンドウから変えた設定（`settings\mod_settings.json`）は残る。

**MOD を1つ止めたいときは、`InstantaleModLoader.bat` の一覧でチェックを外して保存する**。
無効にしたものは `load_order.json` の `"disabled"` に記録され、読み込まれなくなる
（フォルダはそのまま残るので、戻すのはチェックを入れ直すだけ）。
ウィンドウを開かずに止めたいなら、フォルダ名の先頭に `_` を付けてもよい（同じく
読み込まれなくなる）。

**遊んでいる途中で MOD を外したい**ときは `MOD を外す` を押す。ゲームは終了しない。
ただし完全に元通りにはならない（起動時に一度だけ走った処理や、MOD がセーブに書いた値は
戻らない）。素のゲームで確かめたいなら、**注入せずに起動し直すのが確実**。

### ログの世代管理

`out\*.log` は**注入のたび（＝ゲームを起動するたび）に新しくなる**。前回の内容は
`modloader.log.1` のように `.1` を付けて1世代だけ残り、それより古いものは消える。
放っておくとログが数MBまで育って読めなくなるため、既定で ON。

複数回のプレイをまたいで追いたいときは OFF にできる:

```
.\tools\watch.bat --no-log-rotate       # この実行だけ追記のまま
```

常時 OFF にしたい場合は `tools\logrotate.py` の先頭:

| 設定 | 意味 |
|---|---|
| `ROTATE_LOGS` | `False` にすると入れ替えず、常に追記していく |
| `KEEP_GENERATIONS` | 残す古い世代の数（既定 1）。`0` にすると退避せず消す |

環境変数 `INSTANTALE_LOG_ROTATE=0` でも OFF にできる（優先順位は
コマンドライン → 環境変数 → `tools\logrotate.py` の既定値）。

`out\` の中でも `quest_clients.json` などログ以外のファイルと、
`out\test\` `out\recon\` の中身は対象外。

## うまく動かないとき

### まずこれを試す

**`InstantaleModLoader.bat` の「Mod を注入してゲームを起動」をもう一度押す**
（ゲームは起動したままでよい。動いているゲームを見つけたら起動は飛ばして注入だけする）。MOD の入れ直しで、
音の不具合や「イベントが出なくなった」はその場で直ることが多い。

それでも変わらなければ、**ゲームを終了してから、もう一度起動ボタンで立ち上げ直す。**

### 症状別

| 症状 | やること |
|---|---|
| イベントも追加ボタンも出ない | 入れ直す（上）。`out\modloader.log` に `boot complete:` が無ければ入っていない |
| 音が重なる・戦闘後も戦闘BGMが鳴り続ける・タイトルに戻っても曲が止まらない | 入れ直す。溜まっていた分ごと直る。MOD を入れていない場合はゲームの再起動しかない |
| ロードすると戦闘BGMで始まる | 入れ直す。読み込んだ時点で直る |
| 一度戦闘したらNPCから話しかけられなくなった | 同上（上と同じ原因） |
| NPC の立ち絵が消えず、移動しても付いてくる | その NPC ともう一度会話して、普通に「会話を終了する」を押す |
| 仲間と別れるボタンが出ない | 仲間が居ないと出ない。まず NPC を雇う |
| 「ここで別れる」を選んでも別れられない | 人の居る場所（町など）へ戻ってから。ダンジョンでは別れられない |
| 依頼一覧に「この話から依頼を作る」しか出ない | その NPC の依頼がまだ無い状態。すべて見たいなら、一覧で `301_` の `設定` を開いて「その NPC の依頼だけを見せる」を切る |
| 選択肢を押しても何も起きない | 画面が「…」の間は処理中。終わるまで待つ |
| 店で売り買いしようとすると落ちる | 入れ直す。落ちなくなる代わりに、はみ出した持ち物が別のマスに置かれることがある |
| アイテムの説明が途中で切れる | 入れ直す。枠が伸びるようになる。それでも入り切らないほど長い説明は画面の高さで頭打ち |
| 特定のNPCだけ立ち絵や画像が出ない | 入れ直す。名前が原因なら直り、次に画像を作る場面（会話・戦闘）で生成される |
| ゲームが落ちる・様子がおかしい | 注入せずにゲームを起動すれば**完全に素のゲーム**として動く。記録は `out\live_crashes.log` |

### 不具合ではないもの

| | |
|---|---|
| **「依頼を受ける」を押すと会話が終わる** | 依頼の話をするために会話を切り上げている（ボタンにもそう書いてある） |
| **クエストをクリアしても仲間が離れない** | `304_quest_end_keep_party/` の効果。**解散するように戻したい**なら一覧でこれのチェックを外して保存し、入れ直す（`303_` の「いま居る町のギルドに残る」だけになる）。`303_` のチェックも外せばゲーム本来（雇った町へ帰る）に戻る。1人だけ外したいなら会話から「ここで別れる」 |
| **追加されたボタンが MOD 無しだと何も起きない** | セーブに残ったボタンの残骸。押しても害は無い |

## セーブとゲームファイルへの影響

- **ゲームフォルダは読むだけ。** 一切書き込まない
- **セーブに書くのは、ゲーム自身が持っている値だけ**（パーティの名簿・依頼・エリアのBGM）。
  MOD 独自の項目をセーブに足すことはしない
- ファイル名に使えない文字を含む**NPC の名前だけは書き換える**（`"` → `”` のように全角へ）。
  そうしないとそのNPCの画像が永久に作られないため。書き換えた名前は
  `out\character_name.log` に残る
- MOD が追加した選択肢ボタンは、押した瞬間に無害な既存の動作へ差し替わる作りなので、
  **MOD を入れずに次回起動しても壊れない**
- 既存セーブの BGM を一括で均す道具（`tools\rebalance_saved_bgm.py`）だけはセーブを
  書き換えるが、**既定は dry-run（変更しない）**で、実行時は自動でバックアップを作る

---

## 制限

- MOD はゲーム起動**後**に入るので、起動時に一度だけ走る処理には手が届かない
- AIが推論している最中に注入すると入るのが遅れることがある（30秒でタイムアウト表示が
  出るが、その後ちゃんと入る）
- 追加した選択肢ボタンがセーブに残骸として残ることがある。無害だが、MOD 無しで押すと
  何も起きない

## ファイルの置き場所

| | |
|---|---|
| `InstantaleModLoader.bat` | **これをダブルクリックする。** MOD の一覧と起動ボタン |
| `runtime\mods\` | MOD 本体。一覧に無い設定はここを開いて書き換える |
| `runtime\mods\load_order.json` | 適用順と無効一覧。一覧の `保存` が書き込む先 |
| `settings\` | 変えたものの置き場所。`mod_settings.json`（MOD の設定）と `gui.json`（ゲームの場所・ウィンドウの大きさと位置）。**MOD を差し替えても残る**（無くてよい） |
| `out\` | ログ各種。何が起きたかは全部ここに残る（`.1` は前回のプレイ） |
| `out\status.json` | 前回の注入の結果。一覧の `前回` の列はこれを読んでいる |
| `tools\` | 中身。GUI・注入・監視のスクリプトと、検証用の道具 |
| `tools\watch.bat` | GUI を使わない自動注入（コンソール） |
| `tools\logrotate.py` | ログの世代管理（ON/OFF と残す世代数） |
| `docs\TECH.md` | MOD を作る人向けのリファレンス（ローダの仕組みと書き方） |
| `docs\GAME.md` | Instantale 自身の内部リファレンス（実測でわかったゲームの構造） |
| `docs\VERIFICATION.md` | 何がどこまで確認済みか・次に何を確かめるか |
