## ここに在るものの扱い

| | |
|---|---|
| Git | ○ 追跡する（`.gitignore` に当たらない） |
| ローダ | × 読み込まない（`discover()` は `runtime/mods` しか見ない） |
| 配布物 | × 入らない（`make_dist.bat` は `runtime\mods` を写す） |
