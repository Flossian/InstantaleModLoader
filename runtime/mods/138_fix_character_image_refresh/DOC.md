# `138_fix_character_image_refresh`: 再生成した立ち絵と顔がその場で表示に反映される

ゲームは人物の絵を `characters\<名前>\` の決まったファイル（立ち絵の `reduced_color_image.png`、顔の `face_image.png` など）へ上書きする。
画面の画像は同じファイルを指したままなので、キャッシュの古い絵が出続ける。
NPC を再生成すると立ち絵はゲームが出し直すが、パーティー欄の顔はゲームを読み込み直すまで古いまま残る。

この MOD を入れると:

- 人物の絵を描き終えたら、その人物のフォルダを指している画面上の画像をすべて読み直す。
  人物欄の立ち絵、会話の立ち絵、パーティー欄の顔（`116_ui_party_expand` が足した枠も含む）が対象になる
- 読み直すのは描いたその人物の画像だけ。他の人物の画像には触らない
- 画像生成の方式（`sdcpp_cuda` / `sdcpp_vulkan` / `sdcpp_cpu` / `diffusers_openvino`）を選ばない。
  ゲームの `config.json` で選ばれている方式だけを包む（4つは排他で、ゲームは選ばれた1つしか読み込まない）
- `408_visual_changes_based_on_equipment` の主人公の再生成ボタンで描いた絵も、同じ関数を通るので読み直される

ファイルもセーブも書き換えない。画面の表示を読み直すだけ。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 再生成しても顔が古いまま | `out\character_image_refresh.log` に `reloaded N image(s) of <名前>` が出ているか。出ていなければ、その画像がその人物のフォルダを指していない |
