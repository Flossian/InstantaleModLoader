## 1. 遊び方（`docs\MODS.md` 相当）

世界の設定に書かれた勢力（国・教団・組織など）ごとに、主人公がどう見られているかを持つ。
その勢力の街の NPC は、見られ方に応じた態度で接する。
同じ主人公でも、ある勢力の街では歓迎され、別の勢力の街では警戒される。

### 決まり

- 世界ごとに有効にする（設定の「世界ごと」のタブ）。有効にしていない世界では何もしない
- 有効にした世界を読み込むと、世界の設定と街の案内文から勢力を読み取る。初回だけ少し時間がかかる（裏で LLM に2回聞く）
- 設定に勢力が2つ以上書かれていない世界（一つの国が治める世界・勢力の話が無い世界）では、勢力を作らない
- 設定に書かれていない勢力・関係は作らない
- 見られ方は勢力ごとに -100〜100 で、段階は 敵視（-60 以下）・警戒（-20 以下）・中立・好意（20 以上）・信頼（60 以上）
- 最初の見られ方は、読み取った後に1回だけ決める。遊んでいる途中の世界では、主人公の経歴・手配されている街・功績・これまでの出来事から決める。新しく始めた主人公は経歴だけから決める
- 勢力の街の NPC は、見られ方の段階に応じた態度で話す。中立なら何も変わらない。段階によっては、その勢力の者たちのあいだでの主人公の呼び名も知っている
- 仲間にしている NPC は、主人公を個人として知っているので態度は変わらない
- 会話を閉じるたびに、その会話での主人公の言動が相手の勢力にどう映ったかを判定し、見られ方が動く。上がるのは同じ勢力から1日1回、下がる方は毎回
- ある勢力に好かれると、その勢力と対立している勢力からは少し疎まれる
- 宿泊や移動で日数が進むと、勢力どうしの仲もときどき動く。起きたことは噂として NPC が知っている
- 世界の設定にもともと書かれている勢力どうしの関係は、簡単には動かない
- 穏やかな世界観では、勢力どうしが敵対まで悪くなることはない

## 2. 設計の根拠

### 2.1 勢力は設定に書かれたものだけ

ゲームには勢力・派閥に当たるデータが無い。
素直に LLM に作らせると、どの世界も王国・商人ギルド・盗賊団のような似た顔ぶれに寄る（`132_` `104_` `128_` が対処してきたのと同じ種類の偏り）。
加えて、手元の6世界のうち勢力をはっきり書いていたのは1つだけで、残りは滅びかけた世界・政治の語彙が無い世界だった。
設定に無い対立を足すと世界観そのものが変わり、統一された世界とは矛盾する。
だから版1は「設定に2つ以上書かれている世界だけ」で動き、書かれていない世界で事実から導く機能は持たない。

LLM には根拠の原文を一字一句抜き出させ、コードが材料の中に本当にあるかを照合する（空白と括弧は無視、4字未満は認めない）。
見つからない勢力・街・関係は捨てる。
論理は渡さない（`902_city_case` と同じ考え）。LLM が決めるのは「何が書いてあるか」と文章だけで、点数・段階・幅・下限はコードが決める。

### 2.2 元の案内文を読む

`321_area_chronicle` は依頼のクリアごとに `Area.descriptions` を実行中だけ書き換え、元の文を残さない。
勢力はセーブの辞書（`save_data_dict["areas"][id]["descriptions"]`）の元の文から読む。
`area_description`（周辺の土地の文）にも勢力や土地柄が書かれていることがあるので材料に入れる。

### 2.3 最初の見られ方（ライフログはこの1回だけ）

遊んでいる途中の世界に入れたとき、それまでの経過を数に起こすため、経歴・手配度・功績・ライフログを1回だけ読ませる。
以後はライフログを読まない（会話の判定にも渡さない）。その後の動きは台帳の数が持つ。
ライフログは `context_manager.get_life_log_text` の文で取る（ゲームの判事の頼みでは人物の実体の表記が入る不具合がある。GAME.md §2.20）。
長い世界では新しい方から 4000 字に切る。
経歴に「NPC が知る情報ではない」と前書きする書き方があるので、頼み文で「その勢力が知りえたことだけで判断する」と縛る。

### 2.4 見られ方は会話の構えに出す

ゲームの会話の記録 213 件で、足された文が応答に使われたかを数えた（2026-10-09）。

| 足された文 | 応答が使った回 |
|---|---|
| 功績の欄（プレイヤーの情報として事実を並べる） | 0 / 63 |
| 317 の評判の文のうち出来事 | 0 / 63 |
| 317 の二つ名（「あなたも耳にしている」） | 5 / 63（プレイヤーが先に言った回は 0） |
| 321 が書き直した土地の文 | 0 / 17 |
| 911 のライバルの構え（「あなたは〜を見下していて、口を開けば嫌味や挑発が出る」） | 読んだ6件とも嫌味と挑発の口ぶり |

出来事の事実は NPC の側から話題にならないが、「あなたはこの人をこう見ている、だからこう振る舞う」という構えは口ぶりを変え、短い呼び名は第一声で使われる。
勢力の態度に欲しいのは口ぶりなので、911 の書き方に揃えた（構えの文と、段階を判定したときの呼び名）。
構えの文には舞台の物（地形・制度・技術など）を書かず、人と人の関係と振る舞いだけを書く（どの世界観でも成り立つように）。
足す口はローダの `modnpc` の `notes`（会話の5関数）。

相手の勢力は、相手が住人・冒険者として名簿に載っている街で決める。載っていなければ主人公がいま居る街。

### 2.5 会話の判定は要約に相乗りする

`337_` と同じく、会話を閉じるときのゲームの要約に項目を足す（ローダの窓口 `talk_summary`。TECH.md §3.3.16）。
別に呼ぶと会話を閉じる待ちが延びる。337 と同じ要約に2本乗っても送信は1回。
判定は「相手個人の好き嫌い」ではなく「その勢力の者として見た印象」。

### 2.6 勢力どうしの情勢（向きは LLM、幅は規則）

一個人で世界の勢力に抗うのは無理で、個人の知らない所で情勢が動くのは自然なので、勢力どうしの仲は日数の経過でも動く。
LLM に決めさせるのは「何が起きたか・どの2つの勢力か・近づいたか離れたか」と噂の文。
1回で動くのは1組の1段階まで。設定に書かれた関係は同じ向きに2回押されて初めて1段動く（逆向きに押されたら数え直す）。
穏やかな世界観では緊張より下げない。
一度に何日進んでも1回だけ（徒歩の移動は1回で 90 日進むので、LLM を続けて呼ばない）。
起きたことは、全部の NPC の会話に「各地の噂」として足す（317 と同じ「あなたも耳にしている」の形）。
ゲームの噂（`world_data.story.current_rumor`）は遊んでいる間に書き換わらず、会話の第一声の頼みに毎回載っているが、そこを書き換えるとセーブに焼かれる。会話に足す口のほうが外したときに何も残らない。

### 2.7 街の出来事（918）との連動

向きは 918 → この MOD の一方向だけ。この MOD が 918 の控え（`state\town_incidents\`）を読み、無ければ何もしない。918 はこの MOD を読まない。
主人公が片付けた出来事は、その街の勢力の見られ方を上げる（出来事ごとに1回）。
前回の情勢から後に起きた・進んだ・終わった出来事は、情勢を決める材料に渡す。

### 2.8 控えの置き場所

| 何 | どこ |
|---|---|
| 台帳（勢力・街・関係・見られ方・情勢の記録） | `state\town_factions_ledger\<世界×主人公>.json` |
| 世界ごとの設定 | `state\town_factions\<世界>.json`（設定画面が書く） |

同じ世界で主人公を作り直したら台帳は引き継がない（見られ方は主人公の行いで決まるため）。
世界ごとの設定と台帳のフォルダを分けたのは、周回の鍵へ移す処理（`WorldStore.playthrough` の `adopt`）が同じフォルダの `<世界>.json` を古い控えとみなして移してしまうため。

## 4. 未確認項目と確認手順

確かめる世界はヴェスティア以外（実プレイのデータなので、実機の動作検証には使わない）。
勢力が2つ以上書かれた世界が手元に無いので、テストワールドの世界の設定に勢力を書き足した写しを作るか、新しく世界を作る。

| 1 | 勢力を読み取る | 世界ごとの設定で有効にして読み込む。`build: … queued` → `build: … ready:`。読み取った勢力と街が設定どおりか | 未 |
