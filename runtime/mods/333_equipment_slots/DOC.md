# `333_equipment_slots`: インベントリに装備枠を追加

素のゲームの装備は武器1つと防具1つだけで、所持品の窓には装備の欄が無い。
兜も鎧も盾も「防具」の1枠を取り合い、今なにを着ているかは装備印の枠線でしか分からない。

この MOD を入れると、所持品の窓を開いたとき、窓の左に装備欄が出る。

```text
        ［  頭  ］
［左手］［  胴  ］［右手］
［    ］［      ］［    ］
［ 腕 ］［  脚  ］［装飾］
                ［装飾］
```

部位は所持品と同じマスで組んであり、頭・腕・脚・装飾は 2×2、左手・右手・胴は 2×4
（武器は最大 1×4）。グリッドは 6列×10行で、部位の外のマスは見せないので空のマスは見えない。
全体は所持品の窓と同じ白い外枠で囲む。縦4マスの武器も元の大きさのまま入る。
1×1 の品を 2×2 の部位に置くと、部位いっぱい（2×2）に広げて表示する（設定 `SCALE_TO_FIT`。既定は入）。
倍率は縦横比を保った整数（1×1 → 2倍、1×4 の剣は等倍）で、広げる品は部位の左上へ寄せ、
所持品へ戻すと元の大きさに戻る。

`402_party_inventory_transfer` を入れていれば、同行する仲間にも同じ装備欄が付く（下の「仲間の装備欄」）。

## 部位と入る品

| 部位 | 入る品（`item_detail`） |
|---|---|
| 右手・左手 | 武器（種類を問わない）と盾（`shield`） |
| 頭 | `headgear` |
| 胴 | `body_armor` / `clothing` |
| 腕 | `gauntlets` |
| 脚 | `legwear` / `leg_armor` |
| 装飾×2 | `accessory`（知らない種類の防具もここ） |

## 装備する・外す

- **ドラッグ**: 所持品から部位へ落とす。落とせるのは「その部位に収まる・種類が合う」ときで、
  それ以外は所持品へ戻る。装備欄の中で別の部位へ落とすのも同じ規則（通らなければ元の部位へ戻る）。
  外すのは所持品へドラッグで戻す
- **置換**: 既に品が居る部位へ同じ種類の品を落とすと、居た品が所持品の空きへ出て、落とした品が入る。
  所持品に空きが無ければ置換せず、落とした品は所持品へ戻る
- **右クリック**: 所持品の品で「装備」を押すと空いている部位へ入る（手と装飾は右・1つ目が先）。
  埋まっていれば右手（1つ目の装飾）の品と入れ替わり、出た品は所持品の空きへ。
  装備欄の品で「外す」を押すと所持品の空きへ戻る

装備欄の品は所持品の窓には出ない（別枠）。売買・クラフト・強化の窓にも出ないので、装備したまま売ることはない。

## 数字の扱い（既定は合算しない）

本体が読む装備は `weapon` と `wearable` の2つで、ダメージ・防御・画面上部の
Atk/Def はこの2つを見る（GAME.md §2.13.3 / §2.29）。
本体に渡す品は1つずつなので、この MOD は装備欄の中から

- 手にある武器のうち**攻撃力が最高の1つ**を `weapon` に
- 全部位の防具（盾を含む）のうち**防御力が最高の1つ**を `wearable` に

渡す。既定では合算しない。
兜 439 と装飾 500 を着ていれば Def は +500 で、兜のぶんは乗らない。
外したときは残りの中の最高値へ繰り下がる（右手の剣 580 を外すと左手の剣 480 へ）。

### 合算（`COMBINE_SLOTS`）

設定で入れると、最高値の品はそのまま、残りの品を圧縮して足した値を戦闘と画面上部の Atk/Def に使う。

    攻撃 ＝ 最高の武器 ＋ もう片方の手の武器 × 攻撃の率（既定 50%）
    防御 ＝ 最高の防具 ＋ 残りの部位の防具の合計 × 防御の率（既定 10%）

- 品が1つなら今と同じ値。合算を入れても切っても、1品の主人公の数字は変わらない
- 空の部位は 0 を足すだけで罰にならない。兜を被らない主人公は兜の分が無いだけ
- 火力は本体の式（2×√(能力 × 武器)）で平方根に入るので、両手に同じ剣でも約 1.2 倍まで。
  防御は `319_battle_tactics` の割り算（素点 × 素点 ÷ (素点 ＋ 防御)）に入る。防御が素点と同じなら半分が通る
- セーブは変えない。本体の `equipments` には今どおり最高の1品を入れ、合算は戦闘の数と表示の
  ときにだけ作る。MOD を外せば最高値だけに戻る

序盤・中盤・終盤の帯での検算は VERIFICATION.md §3.70。

## 仲間の装備欄

`402_party_inventory_transfer` の受け渡しの窓を開くと、仲間側のグリッドの右に、その仲間の装備欄が出る
（主人公のものと同じ 8 部位）。渡した品をドラッグで部位へ入れるか、右クリックの「装備」で入れる。
装備欄の品は仲間の持ち物の辞書に居ない（主人公と同じ扱い。セーブには `npcs[<id>].inventory` へ合流する）。
仲間の `equipments` は装備欄から決め直して id で書く（本体の Manager は主人公固定なので通さない）。

- 渡す前の品（主人公の品）は仲間の装備欄には入らない。直接落とすと装備はされず、仲間の持ち物へ渡る。
  もう一度落とせば装備される
- 装備欄から主人公側のグリッドへ直接引いた品は主人公へ渡り、仲間の持ち物へは戻らない
- 仲間の `equipments` を書くのはこの MOD だけ。402_ の「装備／外す」はローダの窓口（`combat.toggle`）を
  通してこちらへ来る。受け渡しのドラッグでは 402_ が窓口（`combat.equipped`）に聞いて手を引く。
  この MOD を入れていなければ 402_ が `equipments` を直に書く
- 店の売買の窓（場面が違う）には出さない
- 控えは 周回×人物（`npc:<id>`）。主人公と同じ `state\equipment_slots\<世界>×<主人公>.json` の中
- 以前の版が作った世界名だけの控え（`<世界名>.json`）は、主人公の分を名前で見分けて移す。
  仲間の分は持ち主の主人公が分からないので、その控えに別の主人公の分があるときと、
  その世界に別の主人公の周回の控えがあるときは移さない（TECH.md §5.4）

## 戦闘への効き方

ローダの窓口 `combat`（TECH.md §3.3.5）を通して、他の MOD へ装備を答える。

- **戦闘の数**: `319_battle_tactics` を入れていれば、仲間の武器と防具も数に入る（仲間の一撃と防御に、
  装備の値へ率を掛けて足す。率は 319_ の設定）。主人公は本体が装備の値を渡す経路のまま
- **審判への文**: `401_battle_character_context`（版8）を入れていれば、仲間と主人公の身に着けている品を
  部位ごと（`right_hand` / `head` / `accessory1` など）に戦闘の審判へ見せる。本体が渡すのは主人公の
  武器1つと防具1つだけで、残りの部位は審判に見えていなかった

公式が NPC に武器を参照させない理由は「審判の文脈に全員の装備を書くと小規模モデルで壊れる」で、
数の側の理由ではない。審判への文は 401_ が文字数の予算で抑えている。

## 設定

| 設定 | 既定 | 意味 |
|---|---|---|
| `SCALE_TO_FIT` | 入 | 小さい品を部位いっぱいに広げて描く。切ると本来の大きさのまま |
| `COMBINE_SLOTS` | 切 | 装備欄の品を合算して戦闘と Atk/Def に効かせる（上の「合算」）。切ると最高値の1品だけ |
| `COMBINE_ATTACK_PERCENT` | 50 | もう片方の手の武器の攻撃力に掛ける率（%） |
| `COMBINE_DEFENSE_PERCENT` | 10 | 最高値以外の部位の防御力に掛ける率（%） |

## どう動くか

- 装備欄は本体の `InventoryGrid`（6列×10行）をもう1枚作ったもの。
  本体のドラッグの受け渡し（`get_all_inventories` → `try_place_item` → `change_inventory`）がそのまま効く。
  部位はその上の矩形で、`is_valid_placement` を包んで落とせるかを決める
- 装備欄の品は**持ち物の辞書から抜いて**、装備欄の辞書（`sys` に置く。注入し直しても消えない）
  だけに持つ。本体は窓を開くたびに持ち物の辞書から品を並べ直すので、抜いておけば所持品にも売買・
  クラフト・強化の窓にも出ない。装備欄の品のウィジェットは窓を組んだ 0.1 秒後に MOD が作る（`build_items`）。
  セーブには、書き出す直前の JSON（`write_obfuscated_json_file` に渡る `player_data.inventory`）へ
  装備欄の品を `to_dict()` で足す。生きている持ち物の辞書には触らない。
  ロード直後は品が辞書に居るので、窓を組む前に抜き直す
- 装備欄の品を右クリックで「捨てる」ときは、先に所持品へ戻してから本体に捨てさせる
  （本体は持ち物の辞書から消すので、無いと落ちる）。空きが無ければ捨てない
- 置換は本体の下見で行う。本体はドロップの前に `is_valid_placement` で置けるかを確かめ、
  通らなければ `try_place_item` を呼ばずに品を元へ戻す。その下見で「同じ種類の品が居る部位」なら
  居た品を所持品の空きへ出してから下見をやり直す
- どの品がどの位置に居るかは MOD の控え（`state\equipment_slots\<世界>×<主人公>.json`。
  `{持ち主の鍵: {品の鍵: [x, y]}}`。主人公は名前、仲間は `npc:<id>`。y は上から）。
  控えはセーブと同じ寿命なので、同じ世界で主人公を作り直すと装備欄は空から始まる（TECH.md §5.4）。
  版17までの `<世界>.json` に残っている位置は、その世界で初めて窓を開いた主人公へ移る
- 品の実体を持つ辞書はプロセスに1つなので、ロードと新規開始のたびに空にする（`World.__init__` の包み）。
  同じ世界・同じ主人公のロードでも空にする。セーブの後で装備した品はロードしたセーブの持ち物に無く、
  残すと控えの位置から拾い直されて品が増える
- 本体への書き込みは `equipments` の直書き（本体の popup も同じ）と、HUD の更新のための
  `ItemEquipManager.equip_item` / `ItemUnequipManager.unequip_item`。本体の Manager が MOD 以外の経路で
  走ったとき（本体の unequip は品の種類の枠を無条件に落とす）は、次のフレームと戦闘の1手ごとに装備欄から組み直す
- 所持品の窓を開くたびに控えを持ち物と突き合わせる。
  持ち物に無い品（売った・渡した・捨てた）、部位と種類が合わない品、同じ部位の2つ目の品
  （部位の並びを変えた後の古い控え）は落とし、
  本体が装備しているのに控えに無い品（MOD を入れる前のセーブ）は空いている部位（手は右手が先）へ拾う
- 装備欄は本体の窓より**下**に描く（`FloatLayout` の子の並びで窓の直後に差す）。
  品のウィジェットは窓の `FloatLayout` に居たままなので、ドラッグ中も装備中も装備欄の上に見える
- マスは所持品と同じ大きさ（本体は品を固定の単位で置くので縮められない）。画面の高さに収まらないとき
  （1920x1080 など）は余白を詰め、画面の上端と右端を割らないように寄せる
- 窓を開いたときは装備が変わっていなくても本体の `equip_item` を1度通し、Atk/Def の表示を塗り直す
  （本体は装備を変えたときにしか塗り直さないので、売買のあとなどに前の値が残る）
- 右クリックの「装備」「外す」は `ItemPopupMenu` のメソッドを包み、本体の経路を通さず MOD が移す

## 容量

装備欄は所持品とは別枠なので、持てる量は所持品 24 マス＋装備欄ぶん。
装備中の品は持ち物の辞書に居ないので、本体は所持品 24 マスだけを数え、装備欄が埋まっていても
所持品は満杯まで拾える。外す・置換で押し出す・捨てるは所持品に空きが要り、無ければ何もしない。

セーブには所持品と装備欄の品が全部 `inventory` に書かれる。ロード直後は全部が辞書に居るが、
所持品・売買・クラフト・強化のどの窓を組むときも、本体が並べる前に装備欄の品を抜くので
24 マスへ溢れることはない。

## 既知の癖

- 窓を開いている間は右側の選択肢（「会話する」など）を隠して押せなくする。閉じると戻る
- 装備欄の品は強化（鍛冶）の窓に出ない。強化するときは一度外す
- 装備中の品は持ち物の辞書に居ないので、会話の GM に見せる所持品にも出ない
- 所持品に空きが無いとき、断ったドロップの品はその場では戻せない。次に窓を開いたとき所持品へ返す

## 外すとき

本体のセーブは素のままの形（装備欄の品はセーブの瞬間だけ持ち物へ合流する）。
ただし装備欄の品の `grid_pos` は装備欄の座標（6列×10行）で書かれるので、MOD を外して開くと
所持品の中で他の品と重なって置かれることがある。**MOD を外す前に装備欄を空にしてセーブ**しておけば、
所持品の位置で保存される。`state\equipment_slots\` を消せば控えは残らない。
装備中の品は持ち物の辞書に居ないので、セーブせずに MOD を外す（注入を剥がす）と、その品は
次にセーブされるまで持ち物に居ない。窓を開けば同じプロセスに残っている品を拾い直す。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 装備欄が出ない | `out\equipment_slots.log` に `panel built` が無い。`WARN InventoryGrid class not found` か `panel failed`（例外）か、所持品のグリッドを見つけられていない |
| 装備欄が空のまま | `built N of M items` の N が M より小さい。0.1秒（`SETTLE_DELAY`）では本体が並べ終えていない |
| 落としても所持品へ戻る | `drop ... -> ` の行に理由（`outside a region` / `wrong region` / `occupied` / `not equipment` / `not this owner's item`） |
| 装備欄へそもそも落ちない（枠が反応しない） | `drop` の行も `try_place_item` の行も無ければ、本体が装備欄をグリッドとして見ていない |
| 装備したのに Atk/Def が変わらない | 同じ部位の中で最高値でない（合算を切っているとき）。`weapon -> ` / `wearable -> ` の行がその時点の選択 |
| 右クリックの「装備」で何も起きない | `popup equip ...` の行。`ignored` なら装備でない品か窓が閉じている |
| 仲間の装備欄が出ない | `npc:<id>: panel built` の行。受け渡しの窓（402_）でしか出ない。店の窓には出さない |
| MOD を入れ直した後に挙動が変 | 古い世代の包みが残ることがある（VERIFICATION.md §3.70）。`python tools\injector.py --unload` してから注入し直す |
