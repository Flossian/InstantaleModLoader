# `140_fix_busy_dots_speed`: 待機表示の「…」を普段の速さで流す

待機中に選択肢の枠に出る「…」が、ときどき倍以上の速さで流れる。
ゲームは待機の処理を始めるたびに点送りを1本ずつ始めるので、会話の始まりや戦闘のように処理が続く待機では、点送りが何本も同時に動く。
この MOD は点送りを1本に保ち、普段の速さ（約0.3秒に1コマ）で流す。

止めるのは余った点送りだけで、待機の長さや選択肢の中身は変わらない。
記録は `out\busy_dots_speed.log`（余った点送りを止めたときに1行。300行まで）。

## 困ったとき

| 症状 | やること |
|---|---|
| まだ点が速く流れる | `out\busy_dots_speed.log` に `stopped an extra run` の行が出ているか見る。出ていなければ MOD が適用されていない（`modloader.log` を見る） |
| 待機中に点が止まったまま動かない | この MOD を OFF にして同じ場面を試す。OFF で動くなら、`out\busy_dots_speed.log` と `modloader.log` を添えて報告する |
