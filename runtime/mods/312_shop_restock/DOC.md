# `312_shop_restock`: 日数経過で店の在庫を更新

売買画面に並ぶのは、その店の主が持っている品物そのもの。
ゲームにはそれを入れ替える仕組みが無いので、

- 品揃えが初めて開いたときのまま変わらない
- あなたの売った品はそのまま主の持ち物に積まれ、
  24マスが埋まり切るとそれ以上その店へ売れなくなる

この MOD は、ゲーム内で一定の日数が経った店を次に開いたときに、
主の持ち物をまっさらにする。
品物を作るのはゲーム自身なので、値段も品揃えの傾向も普段どおり。

## 買った品がその場で作り直されるのを止める

素のゲームは、店を開くたびに売れた品を1つ作り直して棚へ戻す。
戻るのは食料・飲み物・薬・ポーション・道具で、武器と防具・装身具は戻らない。
そのため回復アイテムだけは在庫が尽きず、`134_balance_item_effects` で回復量を上げていると実質不死身になる。

この MOD は既定でそれを止める。
止めるのは「その来店で増えたぶんを、画面が出る前に外す」だけで、施設の品揃えの雛形には触らず、入れ替えの日の作り直しは今までどおり動く。

| 設定 | 意味 |
| --- | --- |
| 品揃えを入れ替える日数 | 既定 30（ゲーム内の日数）。最後に入れ替えてからこれだけ経った店を、次に開いたときに入れ替える |
| 初回の来店でも入れ替える | 既定 OFF。切っていると、初めて開いた店は日付を控えるだけで素の品揃えのまま |
| 買った品を作り直させない | 既定 ON。切ると素のゲームのまま（同じ回復アイテムを何度でも買える） |

入れ替えのときに**あなたが売った品も一緒に消える**。
売り戻す（買い直す）つもりがあるなら、入れ替えの日を跨ぐ前に買い戻すこと。

最後に入れ替えた日はセーブではなく `state\shop_restock\<世界名>.json` に入る。
消すと、次の来店が「初回」の扱いに戻る（品揃えはそのまま）。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| いつまでも入れ替わらない | `out\shop_restock.log`。`not due:` なら日数がまだ足りない（`day=` が今日、`last=` が最後に入れ替えた日）。`first visit:` しか無ければ、その店はまだ基準を控えただけ |
| 店が空になった | 同じログの `WARN not refilled:`。ゲーム側が空の持ち物を補充しなかった場合で、品物はその場で書き戻され、以後この MOD は空にしない。次に開けば元の品揃えが並ぶ |
| 買い占めた店が空のまま | 「買った品を作り直させない」が効いている（`kept sold out:` の行）。品揃えは入れ替えの日が来ると戻る。すぐ戻したいなら日数を短くするか、この設定を切る |
| 買った品がまだ棚に戻る | 同じログに `kept sold out:` が出ていないか。出ていなければ設定が切れているか、その店が「初めて開いた店」の扱い（`state\shop_restock\<世界名>.json` に控えが無い） |
| 主が引けないと出る | `skip: cannot resolve the shop owner`。主のいない施設（通路・入口）では何もしない。店で出るなら、その施設に `owner` が設定されていない |
| 売った品を買い戻したい | 入れ替えの日を跨ぐと消える。日数を長くするか、売ったその足で買い戻す |
