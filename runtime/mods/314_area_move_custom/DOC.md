# `314_area_move_custom`: エリア移動の日数・料金・文言を変える

土地から土地への移動は `徒歩(3ヵ月)` と `馬車(1000G)` に固定されている。
この MOD はその日数・馬車の料金・移動中の文言を設定から変えられるようにする。

ボタンには実際の日数が出る。
徒歩を 14 日にすれば確認画面のボタンが `徒歩(14日)` になり、実際に 14 日で着く。
表示に使う値と暦を進める値が同じ設定値なので、表示と実態は食い違わない。

**既定値はすべて素のゲームの値**（徒歩90日・馬車14日・1000G）で、
そのままならこの MOD は挙動を何も変えない。
設定を素の値から動かした項目だけが効く。
例外は馬車のボタンの表示だけ: 素のゲームは馬車の所要日数をどこにも出さない（徒歩は
`3ヵ月` と出るのに）ので、**既定でも `馬車(1000G・14日)` と日数を表示する**。
足している 14 は実測の素の値で、実際にかかる日数と同じ。

```
[素のゲーム]         徒歩(3ヵ月)  /  馬車(1000G)
[既定＝入れただけ]   徒歩(3ヵ月)  /  馬車(1000G・14日)  ← 表示だけ。挙動は素のまま
[徒歩を14日に]       徒歩(14日)   /  馬車(1000G・14日)
[全部変えた例]       徒歩(30日)   /  竜車(500G・7日)    ← 呼び名・料金・日数すべて変更
```

呼び名（`{name}`）を変えると、ボタンと移動中の文言の両方に効く。
文言はテンプレートで、
`{name}`（手段の名前）`{target}`（行き先）`{origin}`（出発地）`{days}`（日数）`{price}`（料金）が使える。
空にすればゲームの文言のまま。

徒歩は日数が素の値のままならボタンの表示もゲームのまま（`3ヵ月` 表記が残る。
呼び名だけ差し替わる）。
日数を変えると `徒歩(14日)` の形になる。
馬車は上記のとおり常に `{name}({price}G・{days}日)` の形で出る。

料金の変更は前払い調整方式: ゲームが運賃（素の 1000G）を引き落とす前に、
差額のぶんだけ所持金をずらしておく。
引き落としは1回でちょうど設定額になり、
「1000引いてから払い戻す」ような紛らわしい動きは画面に出ない。
手持ちが「設定した料金以上・素の 1000G 未満」でも、
調整で残高チェックに弾かれず乗れる。

| 設定 | 意味 |
| --- | --- |
| 徒歩の日数 | 既定 90（素の値＝3ヵ月）。90 のままなら触らない |
| 馬車の日数 | 既定 14（素の値）。14 のままなら実際の日数には触らない（ボタンには既定でも日数が出る） |
| 馬車の料金 | 既定 1000（素の値）。1000 のままなら触らない。0 でタダ。手持ちがこの額に満たないと乗れない |
| 徒歩・馬車の呼び名 | 既定「徒歩」「馬車」。ボタンと文言の `{name}` に入る |
| ボタンの表示 | 既定 `{name}({days}日)` / `{name}({price}G・{days}日)`。徒歩は日数を変えたときだけ、馬車は常にこの形になる |
| 出発・到着の文言 | 既定は出発の2つがテンプレート（内容は素のゲームと同じ文）。空でゲームのまま。馬車の文はゲームが金額を焼き込むので、料金を変えると既定テンプレートが文中の金額を実際の引き落としに揃える |

`307_area_move_dungeon`（危険な道を行く）と一緒に使える。
踏破後の移動は徒歩の経路を借りているので、
徒歩の日数を縮めていればそちらにも効く（小さいほうの日数で着く）。

## 困ったとき

| 症状 | やること |
| --- | --- |
| ボタンの表示が変わらない | 徒歩は日数が素の値（90）のままだと表示も元のまま（仕様）。馬車は既定でも `馬車(1000G・14日)` になるはずなので、ならないときは `out\area_move_custom.log` に `label:` の行があるか見る |
| 日数が設定どおりに進まない | 同じログの `days:` の行。1行も無ければ、お使いのビルドの日数送りが `elapse_days` を通っていない |
| 馬車の文言の金額がおかしい | 素のゲームは料金をいくらに変えても「1000ゴールドを支払った」と言う。既定のテンプレートが金額を実際の引き落としに揃えるので、「馬車の出発の文言」を空にしているなら戻す |
| 料金の引かれ方がおかしい | 同じログの `fare:` の行に前払い調整と引き落としの内訳が並ぶ。`WARN fare:` が出ていたらその行を添えて報告してほしい |
| 手持ちが少ないと馬車に乗れない | 設定した料金未満なら仕様（「（馬車代◯Gに足りない…）」と出る）。素の 1000G 未満で乗れないときは、お使いのビルドが確認画面より前に残高を見ている可能性がある。デバッグモードで `217_probe_area_move` を入れて録ってほしい |
