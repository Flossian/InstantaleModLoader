# `242_probe_world_reads`

遊んでいる最中にゲームが世界の素データ（`app.world_dict`。`world_data.json` の骨格）を引いた箇所を、呼び出し元の関数と行・呼び出しの連鎖・初めて見たときの場面とスレッド・その後の回数で録る。暗号化の層でディスクと読み書きしたファイル（`world_data.json.temp` など）も、名前と連鎖ごとに数える。`app` の型を同じ名前の派生クラスに替えて属性の読みを見張るだけで、辞書も値も変えない。属性を引かずに参照を持ち回す経路は拾えない。要る読み（世界と街の生成）とセーブ側で足りる読みを分ける下調べ（VERIFICATION.md §3.106）。出力は `out\world_reads.log` / `out\world_reads.json`
