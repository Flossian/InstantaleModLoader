# `110_fix_character_name_path`: 名前のせいでNPCの画像が作れないのを直す

名前に `"` などファイル名に使えない文字が混じると、
立ち絵などが無言で作られないままだった。
これを修正し、名前を全角に置き換えて通す（表示はほぼ変わらない）。
既に世界に居る NPC も直す。
書き換えた名前は `out\character_name.log` に残る。

> **main_024 で本体が取り込んだため無効化**。
> デバッグモードのときだけ読み込まれます（README「デバッグモード」）。
> ゲームが自分で名前を直すようになりました。
> この MOD は名前そのものを書き換えてセーブに残すので、そのまま入れておくと、
> 直す必要のない名前まで変えてしまいます。

## 困ったとき

| 症状 | やること |
|---|---|
| 特定のNPCだけ立ち絵や画像が出ない | 入れ直す。名前が原因なら直り、次に画像を作る場面（会話・戦闘）で生成される |
