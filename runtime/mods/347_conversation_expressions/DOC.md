# `347_conversation_expressions`: 会話の相手の表情が、台詞に合わせて変わる

会話の返事が出るたびに、相手の立ち絵の表情が台詞に合わせて変わる。
表情は、ふだん・笑う・怒る・悲しむ・驚くの5つ。
AI が返事を書いた後に、その台詞に合う表情を選ぶ。

- 会話の第一声は、いつもふだんの顔
- 表情の立ち絵は `343_stable_diffusion` が描く。343 はこの MOD が入っているときだけ描く
- 前から居る人物には、ワールドの一括生成をかけると、立ち絵はそのままで表情だけ描かれる。設定の画面の「画像の再生成」で描き直しても、表情も描かれる
- 一括生成では、立ち絵に続けて表情も描く。会話の中などで立ち絵を描いたときは、立ち絵を先に出してから裏で表情を描く。描き終わるまではゲームの立ち絵のまま
- 1人につき表情4つ。1つにつき、顔の周りを1回描くぶんの時間がかかる（SDXL で約7秒）
- 表情を変えても、目の色が少しずれることがある
- 返事が自由行動の扱いになって台詞が出ない回も、AI が選んだ表情に変わる
- `404_party_talk` のパーティー会話でも、話した仲間ごとに表情が変わる
- 表情の強さと、表情ごとに描き足すタグは 343 の設定の画面の「高度設定」で変えられる

表情の立ち絵は、ゲームの立ち絵と同じフォルダ（`worlds\<世界>\characters\<名前>\expressions\`）に置かれる。
立ち絵を描き直すと、前の表情は使われなくなる。

## 困ったとき

| 症状 | やること |
|---|---|
| 表情が変わらない | `out\stable_diffusion.log` の `表情差分 [名前]` の行。無ければその人物の表情はまだ描かれていない（前から居る人物は、ワールドの一括生成をかけるか「画像の再生成」で描き直す）。画像生成が sdcpp 系でないと描かれない |
| 表情は描かれたのに変わらない | `out\conversation_expressions.log` の `widened` の行と、返事ごとの `smile (id): …` の行。`WARN` の行があればゲームの更新で返事の形が変わっている |
| 表情がきつい・弱い | 343 の設定の画面の「高度設定」の「表情差分の強さ」。大きいほどはっきりする（既定は SDXL・その他のモデルで 0.35、SD1.5 のモデルで 0.5） |
