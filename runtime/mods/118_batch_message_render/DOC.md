# `118_batch_message_render`: 本文の出し方（逐次／一括）と既読の色を選ぶ

本文の出し方を選べるようにし、読み終わった本文を灰色にする。
会話履歴やセーブ本文は変えない。

| 設定 | 意味 |
| --- | --- |
| 本文の出し方 | `click`（既定）／`always` |
| 古い本文の見分け方 | `seconds`（既定）／`sessions` |
| 白色を維持する秒数 | 既定 10.0。見分け方が `seconds` のとき |
| 白色を維持するセッション数 | 既定 1。見分け方が `sessions` のとき |

`click`（既定） はゲーム本来の1文字ずつの打ち出しをそのまま使い、
打っている最中に画面のどこかをクリックすると、残りを一度に出して打ち終わりにする。
クリックは横取りしないので、そのまま選択肢を押してもよい。
ホイールの回転は打ち切りにならない（本文を読み返しているだけなので）。

`always` は文字単位の再描画を止め、本文を一括でテクスチャへ反映する。
新着部分の先頭へスクロールした後、覆いを1行ずつ外して末尾まで表示する。
新着位置を見失わず、最終行が先に見えることもない。
新着範囲を特定できない場合だけ短いフェードへ戻る。

ゲームは1文字足すたびに本文ラベル全体のテクスチャを作り直しており、
その塗り直しが打ち出しの時間の大半を占める。
v1.3.0 で `112_` / `117_` の二度手間を外し、
1文字あたり 8.1 ミリ秒（打ち出し間隔の21%）まで下がった。
残りはこの作り直しのぶんなので、そこから先を詰めたい場合だけ `always` にする。

読み終わった本文は50%の灰色にする。
どこからが「読み終わった本文」かは2通りで選べる。
`seconds` は追加からの経過時間、`sessions` はその後に本文が何回追加されたか（本文1つ＝1セッション。1なら最新の本文だけが白、
3なら直近3つが白のまま残る）。
どちらでも色が変わるのは本文が追加された瞬間だけで、読んでいる最中に色は動かない。
