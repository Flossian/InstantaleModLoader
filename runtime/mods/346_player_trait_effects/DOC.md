# `924_player_trait_effects`: 主人公の特質を能力値と店の値段に効かせる

主人公の特質を、能力値の補正と店の値段に効かせる。

素のゲームの特質は、名前と説明の文と、強さの数（severity）だけでできている。
severity はキャラを作るときに才能点を数えるのに使われ、作った後はどこにも使われない。
説明の文は会話・戦闘・依頼の AI に渡るが、AI が文に触れることはほとんど無く、数値には何も効かない。

この MOD は、特質ごとに AI へ1回だけ頼んで、文を下の決まった効果に置き換える。
置き換えた効果はゲームの数値に効く。

## 効果の種類

| 効果 | 中身 | 人物欄の書き方 |
| --- | --- | --- |
| 能力値の補正 | 6つの能力値のどれかを -3〜+3。常に効くものと、下の条件のときだけ効くものがある | `判断+2`・`依頼中筋力+2` |
| 店の値段 | 店から買う値段か、店に売る値段を -20〜+20％ | `買値-5%`・`売値+5%` |

能力値の補正が効く条件は5つ。

| 条件 | 効くとき |
| --- | --- |
| 常に | いつでも |
| 依頼中 | 依頼の最中（道中・ダンジョン・戦闘・出来事）。ダンジョンは依頼の中にしか無いので、ダンジョンの中もこれに入る |
| 戦闘中 | 戦闘の間 |
| ボス戦で | ボスとの戦闘の間 |
| 体力半分以下で | 体力が最大の半分以下のとき |

能力値の補正は、ゲームが能力値を読むところに効く。
能力値そのものは書き換えないので、MOD を切っても数字はずれない。

| 場面 | 効く能力値 |
| --- | --- |
| 攻撃の威力 | 筋力（物理）・知力（魔法） |
| 受けるダメージ | 6つとも（ゲームの防御は6つの能力値の平均から出る） |
| 戦闘で動く順番 | 器用 |
| 依頼の出来事（罠・探索・交渉など） | 6つとも |
| 会話や依頼の後の印象 | 魅力 |
| `313_event_ability_check` の判定 | 6つとも（313 を入れているとき） |

- ステータス画面の能力値の後ろに、装備などの補正と合わせて `判断: 14(+2)` の形で出る。条件つきの補正は、その条件のときだけ数に入る
- 最大 HP には効かない
- 効くのは主人公だけ。仲間の特質には効かない

文の中で効果にできない性質（「教会の者に警戒される」「熱に弱い」など）は、短い1文にまとめて控える。
この文と効果の一覧は、主人公の特質が AI に渡るたびに、特質の文の後ろに添える（設定「LLM に効果の一覧を添える」）。
審判や会話の AI が、数値と食い違う描写をしにくくなり、文の性質を判定に入れやすくなる。

## いつ置き換わるか

世界を読み込んだ後と、人物欄を開け閉めした後に、まだ置き換えていない特質があれば AI に頼む。
返事を待つ間（数秒〜数十秒）も遊べる。
置き換わるまでは効果が無い。

置き換えは特質ごとに1回だけ。
特質の名前・説明・severity のどれかが変わったら（セーブエディタで直した など）、次の読み込みで頼み直す。
MOD の版が上がって量の決め方が変わったときも、次の読み込みで頼み直す（それまでは前の効果のまま効く）。
主人公の特質から消えた特質の控えは、その時点で片付ける。

AI の返事が読めなかったときは何も控えず、次の読み込みで頼み直す。

## 人物欄

`121_ui_character_sheet` を入れていると、人物欄の「特性:」の箱にマウスを乗せたときに出る説明に、特質ごとの効果が並ぶ。

    坑夫の勘
    ・判断+2
    ・依頼中判断+1
    地下で罠や崩落の気配を察知できる。

条件つきの効果は、いまその条件に当てはまらなければ灰色で出る（町に居るときの `依頼中判断+1` など）。
色の付いた効果が、いま数値に効いているもの。
効果の無い特質（数値にならない性質だけのもの）は、名前と説明だけ出る。

## severity の扱い

severity は特質の強さの数で、正は利点の重さ（作るときに才能点を使う）、負は代償の重さ（才能点が戻る）。
効果ごとに重さを数え、重さの合計の目安を severity の半分にする。
量は装備の能力値補正（1品で epic +1〜2、legendary +2〜3、mythic +3〜4）に揃えてあり、
severity 3 でおよそ常に +1〜2、severity 6 で +3 になる。

| 効果 | 重さ |
| --- | --- |
| 常に効く能力値の補正 | 量（+2 なら 2、-2 なら -2） |
| 条件つきの補正 | 量 × 依頼中・戦闘中 0.8、体力半分以下で 0.6、ボス戦で 0.4 |
| 店の値段 | 得になる向きの割合 ÷ 5（買値 -5% なら 1） |

依頼中と戦闘中をあまり割り引かないのは、能力値が効く場面（戦闘・依頼の出来事）がほとんど依頼と戦闘の中だから。

| 設定 | 意味 |
| --- | --- |
| 目安として渡す（既定） | AI に severity と重さの数え方を渡し、重さの合計を severity の半分に近づけるよう頼む。返ってきた効果はそのまま使う |
| 渡して、効果の重さを寄せる | 上に加えて、重さが目安から離れていたら量を同じ割合で縮める・伸ばす。向きが逆（利点だけの文に負の severity など）のときは寄せない |
| 渡さない（文だけで決める） | severity を渡さない。説明の文だけで効果を決める |

どの扱いでも、`out\trait_effects.log` に特質ごとの severity と重さが出る。
設定を変えても、置き換え済みの特質は変わらない（頼み直すには下の「置き換え直すには」）。

## 設定

| 設定 | 意味 |
| --- | --- |
| 能力値の補正を効かせる | 既定 ON。OFF でも置き換えはして、人物欄に出し続ける |
| 店の値段を変える | 既定 ON |
| LLM に効果の一覧を添える | 既定 ON |
| severity の扱い | 上の表。既定は「目安として渡す」 |
| 能力値ごとの補正の上限 | 既定 10。特質の補正を足した後の上限（装備などの補正とは別に数える）。0 で上限なし |
| 値段の割合の上限（％） | 既定 30。0 で上限なし |

## 記録の置き場

置き換えた効果は `state\trait_effects\<世界>×<主人公>.json` に控える。
セーブには何も書かない。
店の値段の変化もセーブに焼かない（保存の直前に外す）。

置き換え直すには、ゲームを止めてこのファイルを消す。
次に読み込んだときに全部の特質を頼み直す。

## 外すとき

MOD を外すと、能力値の補正と店の値段の変化はその場で効かなくなる。
人物欄の説明の窓にも効果が出なくなる。
`state\trait_effects\` は残る（戻せばまた効く）。

## 困ったとき

| 症状 | やること |
|---|---|
| 人物欄の説明に効果が出ない | `out\trait_effects.log` に `変換:` の行があるか。`変換を予約:` だけで `変換:` が無ければ AI の返事を待っているか、読めなかった（`読めなかったので控えない` の行） |
| 効果が文と合わない | 上の「置き換え直すには」で頼み直す。AI への頼みと返事は `output_data\<世界>\<主人公>\mod_trait_effects\` に残る |
| 条件つきの補正が効いていない | 同じログの `能力値: 条件` の行に、そのとき効いていた条件が出る |
| 店の値段が変わらない | 人物欄の説明に `買値`・`売値` の効果が出ているか。店に入り直すと組み直す |
| ログに何も出ない | `out\modloader.log` に `trait effects: installed` の行があるか |
