# `346_player_trait_effects`: 主人公の特質を能力値・戦闘・店の値段に効かせる

主人公の特質を、能力値の補正・戦闘の効果・店の値段に効かせる。

MOD なしのゲームの特質は、名前と説明の文と、強さの数（severity）だけでできている。
severity はキャラを作るときに才能点を数えるのに使われ、作った後はどこにも使われない。
説明の文は会話・戦闘・依頼の AI に渡るが、AI が文に触れることはほとんど無く、数値には何も効かない。

この MOD は、特質ごとに AI へ1回だけリクエストして、文を下の決まった効果に置き換える。
置き換えた効果はゲームの数値に効く。

## 効果の種類

| 効果 | 中身 | 人物欄の書き方 |
| --- | --- | --- |
| 能力値の補正 | 6つの能力値のどれかを -3〜+3。常に効くものと、下の条件のときだけ効くものがある | `判断+2`・`依頼中筋力+2` |
| 戦闘の効果 | 会心・軽減・不屈・耐性などの利点と、脆さ・隙などの代償（下の「戦闘の効果」）。戦闘の間だけ効く | `会心 10%`・`脆さ 受けるダメージ +10%` |
| 店の値段 | 店から買う値段か、店に売る値段を -20〜+20％ | `買値-5%`・`売値+5%` |

能力値の補正が効く条件:

| 条件 | 効くとき |
| --- | --- |
| 常に | いつでも |
| 依頼中 | 依頼の最中（道中・ダンジョン・戦闘・出来事）。ダンジョンは依頼の中にしか無いので、ダンジョンの中もこれに入る |
| 戦闘中 | 戦闘の間 |
| ボス戦で | ボスとの戦闘の間 |
| 体力半分以下で | 体力が最大の半分以下のとき |

能力値の補正は、ゲームが能力値を読むところに効く。
能力値そのものは書き換えないので、MOD を無効にしても数字はずれない。

| 場面 | 効く能力値 |
| --- | --- |
| 攻撃の威力 | 筋力（物理）・知力（魔法） |
| 受けるダメージ | 6つとも（ゲームの防御は6つの能力値の平均から出る） |
| 戦闘で動く順番 | 器用 |
| 依頼の出来事（罠・探索・交渉など） | 6つとも |
| 会話や依頼の後の印象 | 魅力 |
| `313_event_ability_check` の判定 | 6つとも（313 を入れているとき） |

- ステータス画面の能力値の後ろに、装備などの補正と合わせて `判断: 14(+2)` の形で出る。条件つきの補正は、その条件のときだけ数に入る
- 最大 HP には効かない
- 効くのは主人公だけ。仲間の特質には効かない

## 戦闘の効果

戦闘の一撃に効く効果。
`411_equipment_bonuses` の武器・防具の効果と同じ仕組み（ローダの戦闘の効果の連携 API）で効くので、411 を入れていなくても働く。
411 の品の効果と同じ種類は足して効く。

| 効果 | 中身 | 範囲 |
| --- | --- | --- |
| 会心 | 自分の攻撃が一段強く入る確率 | 1〜15% |
| 吸収 | 与えたダメージのうち体力に戻す割合 | 1〜10% |
| 貫通 | 敵の防御のうち無視する割合 | 1〜35% |
| 特効 | ボス戦・格上・手負い（体力半分以下）・無傷の敵のどれかへのダメージの上乗せ | 1〜30% |
| 毒 | 当たったときに敵に毒を付ける確率（3ターン、毎ターン最大体力の4%） | 1〜30% |
| 怯み | 当たったときに敵を怯ませる確率（2ターン、敵の一撃が30%弱まる） | 1〜30% |
| 不屈 | 倒れる一撃を体力 1 で耐える確率（戦闘に1回） | 1〜75% |
| 棘 | 受けたダメージのうち相手に返す割合 | 1〜30% |
| 再生 | 毎ターン戻る最大体力の割合 | 1〜3% |
| 守護 | 仲間への一撃を代わりに受ける確率 | 1〜25% |
| 耐性 | 戦闘で敵に付けられた状態異常を防ぐ確率 | 1〜50% |
| 軽業 | 敵の一撃をかわす確率 | 1〜15% |
| 火事場 | 体力が30%以下の間、受けるダメージを減らす割合 | 1〜30% |
| 軽減 | 受けるダメージを減らす割合 | 1〜15% |
| 回復促進 | 戦闘中に受ける回復（回復の術・吸収・再生）を増やす割合 | 1〜30% |

代償の効果（特質だけに付く）:

| 効果 | 中身 | 範囲 |
| --- | --- | --- |
| 脆さ | 受けるダメージが増える割合。軽減などを掛けた後に上乗せする | 1〜15% |
| 隙 | 自分の手で攻撃が空を切る確率。空を切った手は、その手の敵への一撃がすべて 0 になる | 1〜15% |
| 回復阻害 | 戦闘中に受ける回復（回復の術・吸収・再生）が減る割合 | 1〜45% |
| 反動 | 戦闘が終わったときに失う最大体力の割合（体力 1 で止まる。逃げたときも払う） | 1〜15% |

- 範囲の上限は、利点は 411 の legendary の品の効果の強さ、代償は重さ -3（能力値の補正の -3 と同じ）
- 代償は、不利になる戦闘の場面が説明に書かれているときだけ付ける
- 戦闘の外の環境（瘴気・寒さ・毒の沼など）への強さは耐性にせず、依頼中の耐久などにする
- 回復促進・回復阻害は戦闘の中の回復にだけ効く。宿での休息や、戦闘の外で使う回復アイテムには効かない
- 人物欄では戦闘の外は灰色で出る（ボス戦の特効はボス戦の外で灰色）
- 効いたときは、本文に「（…は不屈で踏みとどまった）」「（…の攻撃は空を切った）」「（…への回復が阻害され、20 減った）」「（…は反動で体力を 30 失った）」などの1行が出る

## 数値にならない性質

文の中で効果にできない性質（「教会の者に警戒される」「熱に弱い」など）は、短い1文にまとめて記録する。
この文と効果の一覧は、主人公の特質が AI に渡るたびに、特質の文の後ろに添える（設定「LLM に効果の一覧を添える」）。
審判や会話の AI が、数値と食い違う描写をしにくくなり、文の性質を判定に入れやすくなる。

## キャラ作成画面

キャラ作成画面でも特質を置き換え、効果を見てから物語を始められる。
気に入らなければ、特質のウィンドウの「生成」で特質ごと作り直すか、「効果を再生成」で効果だけをリクエストし直す。

| 場所 | 出るもの |
| --- | --- |
| 特質の箱の下 | 効果を1行で（`依頼中耐久+2・耐性 状態異常を防ぐ 20%`）。返事を待つ間は「効果を確かめています…」 |
| 特質のウィンドウ（箱を押すと開く） | 説明の欄の下側に効果を1行ずつ。ボタンの列に「効果を再生成」 |

- 特質ができるたび（ランダム作成・ウィンドウの「生成」・プリセットの読み込み）に、AI に1回リクエストする
- 「効果を再生成」は、前の効果を添えて違う置き換えをリクエストする。特質の文の幅が狭いと、量だけが変わることがある
- 返事が読めなかったときは「効果を確かめられなかった」と出る。「効果を再生成」でリクエストし直せる
- 物語を始めると、作成画面で決まった効果を引き継ぐ（もう一度はリクエストしない）
- 作成画面の特質は1つだけ（ゲームの作り）
- 設定「キャラ作成画面に効果を出す」を OFF にすると、作成画面ではリクエストしない。物語を始めた後の読み込みでリクエストする

## いつ置き換わるか

世界を読み込んだ後と、人物欄を開け閉めした後に、まだ置き換えていない特質があれば AI にリクエストする。
キャラ作成画面で置き換えた特質は引き継ぐ。
返事を待つ間（数秒〜数十秒）も遊べる。
置き換わるまでは効果が無い。

置き換えは特質ごとに1回だけ。
特質の名前・説明・severity のどれかが変わったら（セーブエディタで直した など）、次の読み込みでリクエストし直す。
MOD の版が上がって量の決め方が変わったときも、次の読み込みでリクエストし直す（それまでは前の効果のまま効く）。
主人公の特質から消えた特質の記録は、その時点で削除する。

AI の返事が読めなかったときは何も記録せず、次の読み込みでリクエストし直す。

## 人物欄

`121_ui_character_sheet` を入れていると、人物欄の「特性:」の箱にマウスを乗せたときに出る説明に、特質ごとの効果が並ぶ。

    坑夫の勘
    ・判断+2
    ・依頼中判断+1
    地下で罠や崩落の気配を察知できる。

条件つきの効果は、いまその条件に当てはまらなければ灰色で出る（町に居るときの `依頼中判断+1` など）。
色の付いた効果が、いま数値に効いているもの。
効果の無い特質（数値にならない性質だけのもの）は、名前と説明だけ出る。

## severity の扱い

severity は特質の強さの数で、正は利点の重さ（作るときに才能点を使う）、負は代償の重さ（才能点が戻る）。
効果ごとに重さを数え、重さの合計の目安を severity の半分にする。
量は装備の能力値補正（1品で epic +1〜2、legendary +2〜3、mythic +3〜4）に揃えてあり、
severity 3 でおよそ常に +1〜2、severity 6 で +3 になる。

| 効果 | 重さ |
| --- | --- |
| 常に効く能力値の補正 | 量（+2 なら 2、-2 なら -2） |
| 条件つきの補正 | 量 × 依頼中・戦闘中 0.8、体力半分以下で 0.6、ボス戦で 0.4 |
| 戦闘の効果 | 割合 ÷ 下の数。会心・軽業・軽減 5、吸収 3、貫通・特効・毒・怯み・棘・守護・火事場・回復促進 10、耐性 15、不屈 25、再生 1。特効はさらにボス戦 0.4、ほかの相手 0.6 を掛ける |
| 戦闘の代償 | 割合 ÷ 下の数を負に数える。脆さ・隙・反動 5、回復阻害 15 |
| 店の値段 | 得になる向きの割合 ÷ 5（買値 -5% なら 1） |

依頼中と戦闘中をあまり割り引かないのは、能力値が効く場面（戦闘・依頼の出来事）がほとんど依頼と戦闘の中だから。

| 設定 | 意味 |
| --- | --- |
| 目安として渡す（既定） | AI に severity と重さの数え方を渡し、重さの合計を severity の半分に近づけるようリクエストする。返ってきた効果は変えずに使う |
| 渡して、効果の重さを寄せる | 上に加えて、重さが目安から離れていたら量を同じ割合で縮める・伸ばす。向きが逆（利点だけの文に負の severity など）のときは寄せない |
| 渡さない（文だけで決める） | severity を渡さない。説明の文だけで効果を決める |

どの扱いでも、`out\trait_effects.log` に特質ごとの severity と重さが出る。
設定を変えても、置き換え済みの特質は変わらない（リクエストし直すには下の「置き換え直すには」）。

## 設定

| 設定 | 意味 |
| --- | --- |
| 能力値の補正を効かせる | 既定 ON。OFF でも置き換えはして、人物欄に出し続ける |
| 戦闘の効果を効かせる | 既定 ON。OFF でも人物欄に出し続ける |
| 店の値段を変える | 既定 ON |
| LLM に効果の一覧を添える | 既定 ON |
| キャラ作成画面に効果を出す | 既定 ON。特質ができるたびに AI を1回呼ぶ |
| severity の扱い | 上の表。既定は「目安として渡す」 |
| 能力値ごとの補正の上限 | 既定 10。特質の補正を足した後の上限（装備などの補正とは別に数える）。0 で上限なし |
| 値段の割合の上限（％） | 既定 30。0 で上限なし |

## 記録の置き場

置き換えた効果は `state\trait_effects\<世界>×<主人公>.json` に記録する。
セーブには何も書かない。
店の値段の変化もセーブに書かない（保存の直前に外す）。

置き換え直すには、ゲームを止めてこのファイルを消す。
次に読み込んだときに全部の特質をリクエストし直す。

## 外すとき

MOD を外すと、能力値の補正・戦闘の効果・店の値段の変化はその場で効かなくなる。
人物欄の説明にも効果が出なくなる。
`state\trait_effects\` は残る（戻せばまた効く）。

## 困ったとき

| 症状 | やること |
|---|---|
| 人物欄の説明に効果が出ない | `out\trait_effects.log` に `変換:` の行があるか。`変換を予約:` だけで `変換:` が無ければ AI の返事を待っているか、読めなかった（`読めなかったので控えない` の行） |
| 効果が文と合わない | 上の「置き換え直すには」でリクエストし直す。AI へのリクエストと返事は `output_data\<世界>\<主人公>\mod_trait_effects\` に残る |
| 条件つきの補正が効いていない | 同じログの `能力値: 条件` の行に、そのとき効いていた条件が出る |
| 戦闘の効果が効いていない | `out\trait_effects.log` に `戦闘の効果:` の行があるか。効いたときは `out\battle_effects.log` に `cut:`・`endure:`・`critical:`・`falter:`・`heal:`・`backlash:` などの行が出る |
| キャラ作成画面に効果が出ない | `out\trait_effects.log` に `作成画面: … を頼んだ` の行があるか。無ければ設定「キャラ作成画面に効果を出す」が ON か、特質の箱が空でないか |
| 店の値段が変わらない | 人物欄の説明に `買値`・`売値` の効果が出ているか。店に入り直すと組み直す |
| ログに何も出ない | `out\modloader.log` に `trait effects: installed` の行があるか |
