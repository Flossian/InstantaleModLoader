# `304_quest_end_keep_party`: クエストをクリアしても解散しない

そもそもパーティを解散しない。
クエストが終わっても仲間はそのまま同行し続ける（雇い直しが要らなくなるので、
ゲームバランスは意図的に変わる）。
外したくなったら会話から「ここで別れる」（`302`）。

| 設定 | 意味 |
| --- | --- |
| 解散を止めたときに出す文 | 既定「{name}はパーティに残り、引き続き行動を共にすることになった。」（`{name}` が仲間の名前になる） |
| クエスト放棄でも解散を止める | 既定 OFF |

解散するように戻したいなら一覧でこの MOD のチェックを外して保存し、
入れ直す（`303` の「いま居る町のギルドに残る」だけになる）。
`303` のチェックも外せばゲーム本来（雇った町へ帰る）に戻る。
1人だけ外したいなら会話から「ここで別れる」。
