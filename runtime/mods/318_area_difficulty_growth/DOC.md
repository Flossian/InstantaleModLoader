# `318_area_difficulty_growth`: 土地が育つ（依頼の難易度が上がる）

同じ土地で依頼を片付け続けると、その土地で受けられる依頼が少しずつ手強くなる。
合わせて店の品揃えも上がる。

素のゲームでは、土地の難易度は世界を作った時点で決まったまま動かない。
最初の町の依頼は 3・4・5 のまま何十回通っても 3・4・5 で、
店に並ぶ品も、鍛冶で打てるものもそこで止まる。
強くなりたければ土地を移るしかなく、**居着いた土地は何も育たない**。

この MOD が動かすのは依頼の難易度という数1つだけ。
**依頼を1つ片付けるたびに 3〜10 の乱数を引いて積み上げる**（上限まで）。

```text
最初の町（依頼 3 / 4 / 5）
  1回クリア（+7）    → 10 / 11 / 12
  2回目  （+4）      → 14 / 15 / 16
  3回目  （+9）      → 23 / 24 / 25
```

上がり幅が毎回違うので、同じ回数でも育ち方が世界ごとに変わる。
幅は設定で変えられ、最小と最大を同じ値にすれば固定になる。

## 在庫とクラフトが一緒に上がる理由

その土地の物価と品揃えは、その土地の依頼の難易度そのものだから。
実セーブ3世界・店23軒を突き合わせた結果、
店に並ぶ品の `value` は**その土地の依頼の難易度以外の数を取らない**
（完了済みの依頼も母数に入る。GAME.md §2.13.1）。

だからこの MOD は在庫にもクラフトにも手を触れない。
依頼の難易度を上げれば、ゲーム自身がそこから決めているものが全部付いてくる。

| 何が付いてくるか | 効き始め |
| --- | --- |
| 敵の強さ（レベルはおよそ 難易度+1） | 次に受ける依頼から |
| 報酬・才能・訓練・日雇いの実入り | 次に受ける依頼から |
| 店の品揃え | 品揃えが入れ替わってから（`312_shop_restock` が入れ替える。入れていない場合は初回のまま） |
| クラフトの成果物 | 素材が上がってから（成果物の値段 ＝ 素材の合計値段 × 倍率） |

4つとも実機で確かめてある。
土地0 の店に、素のデータからは出ない value 33 の武器と防具が並んだ。
素材 value 2 + 8 で打ったクラフトは value 27・攻撃力 116 の短剣になった
（GAME.md §2.13.1.2 / §2.14.2）。

## 設定

| 設定 | 意味 |
| --- | --- |
| 1回のクリアで上がる最小 | 既定 3。難易度は敵のレベルと能力値の両方を決めるので、+3 はレベル3ぶん |
| 1回のクリアで上がる最大 | 既定 10。最小と同じにすると乱数を回さず固定になる。最小より小さい値は最小まで引き上げて扱う |
| 1つの土地で上がる上限 | 既定 60。1回あたり平均 6.5 なので9回ほどで頭打ち。最初の町（3〜5）が最果ての土地（67〜73）を追い越さないための歯止め |
| 難易度の上限 | 既定 76（ゲーム自身の上限）。下げると世界全体の天井が下がる |
| 引き上げる依頼の範囲 | 既定 all。incomplete にすると掲示板だけが上がり、品揃えは元のままに近くなる（在庫は完了済みの依頼も母数に入れるため） |
| 上げた分を元に戻す | 既定 OFF。下の「セーブには残らない」 |
| 難易度が上がったときの1行 | 既定「この地に貼り出される依頼は、以前より歯応えのあるものになっている。」上限に達した後は出ない。空にすると何も出さない |

クリアは**依頼の出所の土地**に付く。
道中で受けた依頼を別の町で終わらせても、育つのは出所の土地。

数えた回数と素の難易度は `state\area_difficulty\<世界名>.json` に入る。

```json
{"0": {"cleared": 7, "bonus": 43, "day": 4270,
       "base": {"1": 3, "2": 4, "3": 5, "27": 4}}}
```

`bonus` がその土地に積み上がった上昇量。
乱数なのでクリア回数から計算し直せないため、値そのものを持っている。
`base` は素の難易度（この MOD が初めてその依頼を触ったときの値）。
**新しい依頼は素の難易度で生まれてくる**ので、そのまま控えてよい
（ゲームは今の難易度を見ずに、世界を作った時点の帯から選ぶ）。
だからこの MOD は、依頼を作らせるたびにその場で上げ直す。
上げないと、いま作らせた1件だけが素の難易度で差し出される。

## セーブには残らない（そういう作り）

書き換えているのは、遊んでいるあいだの依頼の一覧1箇所だけ。
ここはセーブに残らないので、**ロードすると難易度は素へ戻る**。
戻ったぶんは**セーブを読み込んだその瞬間に、世界じゅうまとめて書き直す**ので、
遊んでいる側からは切れ目なく続いて見える。

書き直す場面は5つ。

| いつ | どこを |
| --- | --- |
| セーブを読み込んだ直後 | 世界のすべての土地 |
| 依頼を探して新しく作らせたとき | その依頼（新しい依頼は素の難易度で生まれてくる） |
| 依頼を受ける直前 | その土地 |
| 掲示板を開いたとき | その土地 |
| 依頼を片付けたとき | その土地 |

ロードで世界ぜんぶを直すのは、**掲示板を通らない読み手のため**。
店の品揃えがその筆頭で、あれは「その土地の依頼の難易度」を直接読んでいる。
掲示板を開いた町だけ直していると、
まだ行っていない町の店だけ素のレベルで品を作ってしまう。

セーブに残らないことの見返りは大きい。

- MOD を外せばセーブは素のまま。外すために何かする必要は無い
  （`上げた分を元に戻す` は、いま動いているゲームを戻したいときの逃げ道）
- MOD の計算違いがセーブを壊すことがない。おかしくなったら
  `state\area_difficulty\<世界名>.json` を消せば、その世界は素に戻る

代わりに、**続きを持っているのは `state\` のほう**（クリア回数と素の難易度）。
ここを消すと、その世界の育ちがまるごと戻る。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 上がらない | `out\area_difficulty.log`。`clear: 土地 0 は 4 回目（3〜10 から +7 を引いて、いま +27）` の形で毎回出る。出ていなければ数えられていない |
| 作りたての依頼だけ低い | 同じログの `search:` 行。`頼み文へ渡す難易度 3 -> 23` と `依頼 N 難易度 3 -> 23` が対で出ていれば効いている（新しい依頼は素の難易度で生まれてくるので、この MOD が生成のたびに上げ直している） |
| クリアしたのに数えられない | 同じログの「終わった依頼の土地が読めなかった」。依頼に `neighboring_settlement_id` が無い場合で、その回は数えない |
| ある土地だけ上がらなくなった | 同じログの「上限に届いた」、または `clear:` の行の `いま +60` が動かない。`1つの土地で上がる上限` か `難易度の上限` に達している |
| 店の品揃えが上がらない | 品揃えは入れ替わるまで初回のまま。`312_shop_restock` を入れる（入れていれば `out\shop_restock.log` の `restocked:` を待つ） |
| 難易度だけ上がって歯応えが変わらない | 敵は次に**受ける**依頼から変わる。既に受けてある依頼は受注時の内容のまま |
