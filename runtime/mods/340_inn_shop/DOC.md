# `340_inn_shop`: 宿屋で食べ物・飲み物・酒を売り買いできる

素のゲームの宿屋には「売買する」が無く、泊まるか話すことしかできない。
この MOD は、宿屋に店と同じ「売買する」を足す。

```text
売買する / 宿泊する(3ヵ月) / 出る / 会話する
```

並びは `135_fix_inn_button_order` が入っているとき。入っていなければ `売買する / 出る / 宿泊する / 会話する` になる。

押した後は、ゲームの店と同じ売買の画面になる。
品揃えはゲームが作り、値段・確認の窓・値切りの交渉もゲームのまま動く。
初めて開いたときは、店と同じく品揃えの生成を少し待つ。

## 並ぶ品

ゲームは店の品揃えに武器と防具を必ず1つずつ入れる。
宿屋で品揃えを作るときだけ、その指示を「食料・飲み物・酒を中心に、武器・防具・素材は作らない」に替える。
それでも武器・防具・素材が返ってきたときは棚に入れない。
道具など、それ以外の品は残る。

`405_regional_economy` の特産品は宿屋にも1つ並ぶ。品目は土地の特産品のままで、食べ物とは限らない。

## 売る

売る側はゲームの店と同じで、宿屋の主に何でも売れる。

## ほかの MOD と一緒に使うとき

| MOD | 宿屋では |
| --- | --- |
| `312_shop_restock` | 宿屋の品揃えも日数で入れ替わる。入れ替えでも食べ物と飲み物で作り直す |
| `336_crime_overhaul` | 宿屋の棚からも盗める。盗んだ品はその宿屋では売れない |
| `338_town_incidents` / `336_crime_overhaul` の店主の委縮 | 店と同じく、宿屋の値段にも効く |
| `331_facility_investment` | 自分の宿には足さない。宿屋の売買は投資の売上に数えない |

## 外したとき

宿屋の「売買する」は次に宿屋へ入り直すと消える。
宿屋の主が持っている品と、ゲームが宿屋に書いた品揃えの雛形はセーブに残る。
どちらもゲームの店と同じ形なので、外しても遊びには響かない。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 宿屋に「売買する」が出ない | `out\inn_shop.log` の `entry: copied` と `sweep:` の行。`entry:` が無ければ、その世界にまだ店が1軒も無い（店から写すので、店のある街を一度読み込むと出る）。読み込んだ直後は、何か1つ選ぶと出る |
| ある宿屋にだけ「売買する」が出ない | 同じログの `withheld at inn` の行。セーブエディタで足した宿屋は世界の素データ（`world_data.json`）に入っておらず、ゲームの売買が開けない（押すとエラーになる）ので出さない。`146_fix_save_only_entities` の設定（既定 OFF）を入れていれば出る（その MOD が開けるようにする）。エディタで施設と主を `world_data.json` にも写しても出る |
| 宿屋に武器や防具が並ぶ | 同じログの `done at inn` の行。`rewrites=0` ならゲームの指示文が変わって差し替えが当たっていない。`dropped=` は棚に入れなかった数 |
| 売買の画面が開かない | `out\modloader.log` の例外。宿屋の主が引けないとゲームが売買を始められない |
