# `335_player_portrait_regenerate`: 人物欄から主人公の立ち絵を描き直せる

素のゲームで描き直せるのは会話相手・背景・最初の敵の画像だけで、主人公の立ち絵は作った後に描き直せない。
この MOD は、人物欄を開いたときに出る主人公の立ち絵の左上に描き直しのボタン（人の胸像と、やり直しの矢印の絵柄）を足す。
押すと主人公の立ち絵を描き直す。
Shift を押しながら押すと、外見のタグも作り直してから描く。

MoririnJP 氏の提案による。
人物欄から主人公を描き直すという発想と処理の骨組みは、同氏提供の `408_visual_changes_based_on_equipment` の主人公の再生成ボタンから来ている。

## 動作

- ボタンは立ち絵の位置と大きさに付いていき、主人公の立ち絵が出ているときだけ見えて押せる。
  立ち絵の上端が窓の上へはみ出しているときは、窓の上端から測って置く
- 描いている間はボタンが隠れ、描き終わると戻る
- 他の立ち絵（会話を始めたときの NPC など）を描いている最中なら、終わるまで最大30秒待ってから描く。待ちきれなければその回は取りやめる
- 外見を英語にする AI の返事は、遅くても最後まで待つ（120秒を過ぎたらログに出す）
- ボタンは人物欄を開閉したときに足すので、人物欄を開いている間に注入した場合は、一度閉じると出る

## 描き方を選ぶ

`343_stable_diffusion` の「高度設定」で、「img2img を使う」か「txt2img→img2img を使う」を入にしていると、ボタンを押したときに描き方の一覧が出る。

| 一覧 | 描き方 | 出るとき |
| --- | --- | --- |
| txt2img | 今までどおり描き直す | いつも |
| img2img | 今の立ち絵を下絵にして描き直す（服の柄や色・ポーズ・持ち物が残りやすい） | 343 の「img2img を使う」が入のとき |
| txt2img→img2img | 2つのモデルで続けて描く | 343 の「txt2img→img2img を使う」が入のとき |

- 一覧は、ボタンの右に出る。選ぶと閉じて描き始める。もう一度ボタンを押すか、人物欄を開け閉めすると閉じる
- 選べるのが txt2img だけ（343 が入っていない・どちらも切）のときは、一覧を出さずにすぐ描く
- Shift を押しながらボタンか一覧を押すと、外見のタグも作り直す
- プリセットと強さは 343 の「高度設定」の立ち絵の欄の値を使う

## 英語の外見

主人公はセーブに英語の外見プロンプトを持たない（持っているのは日本語の `look_description` だけ）。
日本語を画像生成（Stable Diffusion）へそのまま渡すことはしない。
LLM に日本語の外見文を渡し、英語の短いタグの並びにしてもらう。

- 見える物を全部、1〜3語のタグで書かせる（髪の内側の色まで・目・表情・体つき・上衣・鎧・ベルト・下衣・履き物・装飾・武器）。16個まで
- 16個までにしているのは、画像生成が1回に読める 75トークンに前置きと合わせて収めるため
- 英小文字・数字・空白・ハイフン・アポストロフィだけでできた4語以内の要素だけを使う
- 作った要素は外見文ごとに記録する（8件まで）。外見文が変わらない限り頼み直さない。外見文を書き換えて元に戻したときは、前の要素に戻る
- Shift を押しながらボタンを押すと、記録を使わずに頼み直し、新しい要素で記録を置き換える。頼み直せなかったときは記録の要素で描く
- タグを頼めなかったときは、本体が主人公作成時に使う `create_look` で作る（性別は `gender`、無ければ `category` から ♀ か ♂）
- どちらでも英語の要素が1つも取れなかったときは描き直さない

本体の `create_look` は「8要素以下」と頼むので、LLM が細部を長い言い回しに詰め込み、4語を超えた胸甲・ズボン・ブーツなどがここで落ちていた。
版4 から自前の頼みに替えた。
頼んだ内容と返事は `output_data` の `mod_335_player_look` に残る。

要素は配列で渡す。本体は配列を「, 」で繋ぎ、前置き（`full-body, masterpiece, …` と `category`）と後置き（`empty background, …`）の間に置く。

## ほかの MOD との組み合わせ

| MOD | 組み合わせたとき |
|---|---|
| `138_fix_character_image_refresh` | 描き直した立ち絵と顔がその場で画面に出る。無いと、ゲームを読み込み直すまで古い絵のまま |
| `408_visual_changes_based_on_equipment` | 装備の見た目が英語の短い語で描き足される |
| `121_ui_character_sheet` | 人物欄を広げる MOD。無くてもボタンは出る |
| `343_stable_diffusion` | 描き方の一覧（img2img・txt2img→img2img）が出る（上の「描き方を選ぶ」）。どの描き方を出せるかと選んだ描き方は、ローダの窓口を通して受け渡す |

MOD 同士は呼び合わない。どちらも同じ画像生成関数を通るので、それぞれがそこで働く。

## 記録

`state\player_portrait\` に周回（世界×主人公）ごとに1ファイル置く。
`looks` は外見文のハッシュごとの要素、`look` は最後に使った1件。

```json
{
  "looks": {
    "主人公の外見文のハッシュ": ["young woman", "messy dark hair", "short bob cut"]
  },
  "look": {
    "source": "主人公の外見文のハッシュ",
    "prompts": ["young woman", "messy dark hair", "short bob cut"]
  }
}
```

## 困ったとき

| 症状 | 見るところ |
|---|---|
| ボタンが出ない | 人物欄を一度閉じて開き直す。`out\player_portrait.log` |
| 押しても描き直されない | `out\player_portrait.log` の `skipped:` の行（外見文が無い・`create_look` が使えない・英語が取れない・他の立ち絵を描き続けていた） |
| 描き直したのに絵が変わらない | `138_fix_character_image_refresh` が入っているか |
| 描き直しても同じ要素が欠ける・同じ物が余計に付く | Shift を押しながら押してタグを作り直す。`out\player_portrait.log` に `rebuilding look on request` が出る |
