# `335_player_portrait_regenerate`: 人物欄から主人公の立ち絵を描き直せる

素のゲームで描き直せるのは会話相手・背景・最初の敵の画像だけで、主人公の立ち絵は作った後に描き直せない。
この MOD は、人物欄を開いたときに出る主人公の立ち絵の左上に描き直しのボタン（人の胸像と、やり直しの矢印の絵柄）を足す。
押すと主人公の立ち絵を描き直す。

MoririnJP 氏の提案による。
人物欄から主人公を描き直すという発想と処理の骨組みは、同氏提供の `408_visual_changes_based_on_equipment` の主人公の再生成ボタンから来ている。

## 動作

- ボタンは立ち絵の位置と大きさに付いていき、主人公の立ち絵が出ているときだけ見えて押せる。
  立ち絵の上端が窓の上へはみ出しているときは、窓の上端から測って置く
- 描いている間はボタンが隠れ、描き終わると戻る
- 他の立ち絵（会話を始めたときの NPC など）を描いている最中なら、終わるまで最大30秒待ってから描く。待ちきれなければその回は取りやめる
- 外見を英語にする AI が120秒返らなければ、その回は取りやめてボタンを戻す
- ボタンは人物欄を開閉したときに足すので、人物欄を開いている間に注入した場合は、一度閉じると出る

## 英語の外見

主人公はセーブに英語の外見プロンプトを持たない（持っているのは日本語の `look_description` だけ）。
日本語を画像生成（Stable Diffusion 1.5）へそのまま渡すことはしない。
本体が主人公作成時に使う `scripts.llm.llm_manager_character_create:create_look` を呼び、日本語の外見文から英語の要素を作る。

- 性別は人物に `gender` があればそれを、無ければ `category`（`young woman` など）から ♀ か ♂ を渡す
- 英小文字・数字・空白・ハイフン・アポストロフィだけでできた4語以内の要素だけを使う
- 作った要素は外見文のハッシュと一緒に控え、外見文が変わらない限り `create_look` は呼び直さない
- `create_look` を呼べない、または英語の要素が1つも取れなかったときは描き直さない

要素は配列で渡す。本体は配列を「, 」で繋ぎ、前置き（`full-body, masterpiece, …` と `category`）と後置き（`empty background, …`）の間に置く。

## ほかの MOD との組み合わせ

| MOD | 組み合わせたとき |
|---|---|
| `138_fix_character_image_refresh` | 描き直した立ち絵と顔がその場で画面に出る。無いと、ゲームを読み込み直すまで古い絵のまま |
| `408_visual_changes_based_on_equipment` | 装備の見た目が英語の短い語で描き足される |
| `121_ui_character_sheet` | 人物欄を広げる MOD。無くてもボタンは出る |

MOD 同士は呼び合わない。どちらも同じ画像生成関数を通るので、それぞれがそこで働く。

## 控え

`state\player_portrait\` に周回（世界×主人公）ごとに1ファイル置く。

```json
{
  "look": {
    "source": "主人公の外見文のハッシュ",
    "prompts": ["young woman", "messy dark hair", "short bob cut"]
  }
}
```

## 困ったとき

| 症状 | 見るところ |
|---|---|
| ボタンが出ない | 人物欄を一度閉じて開き直す。`out\player_portrait.log` |
| 押しても描き直されない | `out\player_portrait.log` の `skipped:` の行（外見文が無い・`create_look` が使えない・英語が取れない・他の立ち絵を描き続けていた） |
| 描き直したのに絵が変わらない | `138_fix_character_image_refresh` が入っているか |
