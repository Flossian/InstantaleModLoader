# `325_road_opening`: 街と街を結ぶ新しい道を切り開く

「他の土地へ行く」の一覧に「新たな道を探す」が1つ増える。
押すと、まだ繋がっていない街の一覧が金額と道の難易度つきで並ぶ。

```
陽光の砦（適正Lv 21〜30）
風鳴りの村（適正Lv 4〜6）
新たな道を探す              ← 増える
やめる
    ↓
霧の要塞都市（4,000G／難易度 14）
黄金の砂漠（6,000G／難易度 22）
やめる
    ↓
お金を支払い委託する（4,000G／14日）  支払って開削を委託する。14日後に開通（移動はしない）
自ら切り拓く（難易度 14）            道中のクエストを受注。踏破すれば道が開き、そのままその街に着く
やめる
```

開いた道は両方向に繋がり、以後は素の「他の土地へ行く」に普通に並ぶ。
徒歩でも馬車でも行ける（日数と料金は素のまま。`314_` の設定が効く）。
閉じる方（封鎖・崩落）は無い。

素の世界の街は、開始地点から3本の一本道が伸びる木の形に固定されている。
枝の先端から反対側の枝の先端へは、いちいちハブまで戻る。
この MOD はその木に、自分で選んだ枝を足す。
LLM が勝手に道を開くことはない。開通は必ず自分の選択から始まる。

## 金額と難易度は距離で決まる

いまの繋がりの上で最短の道筋を辿り、間に挟む街の数で加算する（開いた道も算入）。

| | 式（既定） |
| --- | --- |
| 金額 | 2,000G ＋ 1,000G × 挟む街の数 |
| 難易度 | 基準 ＋ 2 × 挟む街の数 |

隣の隣（挟む街1つ）なら 3,000G、木の反対側の枝の先端（挟む街5つ）なら 7,000G。
基準は `307_` と同じ語彙で、現在地と対象の適正の間から抽選（既定）、対象に合わせる、高いほう、から選べる。
適正はその街の依頼の難易度の平均で、`133_` の帯と同じものを読む。
まだ訪ねていない街は依頼が無いので、読めた側（現在地）だけで基準を決める。

移動網から完全に切り離された街（エディタで足した直後の街）には道筋が無いので、
「挟む街の数」は設定の固定値（既定 5）を使う。
その街へは「新たな道を探す」が唯一の正規の入口になる。

## 委託は日数がかかる

「お金を支払い委託する」を選ぶと、その場で支払い、「4,000G を支払い、黄金の砂漠への道の開削を委託した。開通まで 14日。」と出る。
日数は設定（既定 14。7=1週間、30=1ヵ月。0 で支払った場で開通）。
期日はゲーム内の日付で数え、移動や宿泊で日数が進んだときに開き、「開始の町と黄金の砂漠を結ぶ道が開かれた。」の1行が出る。
期日までは同じ街に二度払えない（「開削を委託済み。開通まであと N日」と出る）。
委託は `state\road_opening\<世界名>.json` の `commissions` に残るので、ゲームを閉じても続く。

## 自ら切り拓くは `307_` と同じ仕組み

道中のクエストが1件その場で作られ、いつもの受注画面が開く。
踏破して「帰還する」を押し、報酬を受け取った直後に道が開き、そのままその街へ移動する（14日）。
放棄すれば道は開かず、出発地に留まる。
体力が3分の1を切っていると断られる（委託は断られない）。
依頼の説明の末尾には「※このクエストをクリアすると「A」と「B」を結ぶ道が開き、「B」に移動します。」が足される。

`307_area_move_dungeon` を入れていなくても動く。両方入れても干渉しない。

## セーブには書かない

開いた道は `state\road_opening\<世界名>.json` に記録し、ロードのたびに当て直す。
世界の原本（`world_data.json`）にもセーブにも書かないので、
この MOD を外せば世界は素の繋がりに戻る。
`state\` を消すと開いた道も消える。

委託で開いたときは、その土地での活躍（会話にも載る功績）に「AとBを結ぶ新しい道が開かれた。」が1件足される。
踏破のときは依頼のクリアそのものが功績になるので、足さない。

| 設定 | 意味 |
| --- | --- |
| 一覧に足すボタンの文字 | 既定「新たな道を探す」 |
| お金で開くときの基本額 | 既定 2000（委託の金額） |
| 挟む街1つあたりの加算額 | 既定 1000 |
| 道の難易度の基準 | 既定「現在地と対象の間から抽選」。「対象に合わせる」「高いほう」も選べる |
| 挟む街1つあたりの難易度の下駄 | 既定 2 |
| 難易度に足す下駄（一律） | 既定 0 |
| 孤立した街の「挟む街の数」 | 既定 5 |
| 委託のボタンの表示 | 既定 `お金を支払い委託する（{price}G／{days}日）` |
| 切り拓くのボタンの表示 | 既定 `自ら切り拓く（難易度 {difficulty}）` |
| 委託してから開通するまでの日数 | 既定 14。7 なら1週間、30 なら1ヵ月。0 で支払った場で開通 |
| 委託したときに出す1行 | 既定 `{price}G を支払い、{target}への道の開削を委託した。開通まで {days}日。`。空で出さない |
| 踏破した後の到着にかかる日数 | 既定 14（馬車と同じ）。0 で進めない |
| 体力がこの割合を切ったら踏破を断る | 既定 33。0 で見ない |
| 開通のときに出す1行 | 既定「{a}と{b}を結ぶ道が開かれた。」。空で出さない |
| 委託で開いたとき功績に書く1件 | 既定「{a}と{b}を結ぶ新しい道が開かれた。」。空で書かない |
| 「長旅だ…」を出さない | 既定 ON。踏破した後の到着の移動中だけ |
| 街とみなす size | 既定 `village,town,city`。冒険エリア（dungeon）は候補に出ない。種類はセーブの辞書から読む（実行時の `Area` には無い） |
| 候補の1行の表示 | 既定 `{name}（{price}G／難易度 {difficulty}）`。`{hops}` も使える |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 「新たな道を探す」が出ない | `out\road_opening.log` の `list:` の行。`no unlinked town` なら全部の街と既に繋がっているか、土地の種類が読めていない（直前の `WARN size: cannot read the size` を見る）。行そのものが無ければ一覧のフックが効いていない（`out\modloader.log` の `applied`） |
| 候補の金額・難易度が思ったのと違う | 同じログの `candidate:` の行に `hops=`（挟む街の数）と両側の適正が出る。`isolated` は道筋が無い街 |
| 支払ったのに一覧に出ない | 委託は期日まで開かない（`commissioned: ... due day N` の行。日数を進めると `days: commission due` → `opened:`）。`opened:` の行があれば接続は書けている。その後に `WARN list: the game did not list the opened road` が出ていれば、ゲームが接続を別の場所から読んでいて、MOD が自前でボタンを足している |
| ロードしたら道が消えた | `load: applied N edge(s)` の行。無ければ世界名が変わっている（`state\road_opening\` のファイル名と突き合わせる） |
| 踏破したのに道が開かない・着かない | `cleared:` の行があるか。無ければその依頼が道のものとして認識されていない（`armed:` の行も見る）。`arrive: falling back to the confirmation screen` なら移動を組めなかったので、徒歩・馬車を自分で選ぶ |
| 同じ道に二度払った | 連打の2発目は `ignored ...: the previous press is still running` か `already linked` で捨てる。それでも引かれていればログのその2行が無いはずなので、`pressed` の行と一緒に報告する |
| 踏破の後の移動が3ヵ月かかった | `days:` の行が無い。`WARN arrived: elapse_days was never seen` が出ていれば、そのビルドの日数送りが `elapse_days` を通っていない |
