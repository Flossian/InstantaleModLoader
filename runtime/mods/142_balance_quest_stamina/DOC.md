# `142_balance_quest_stamina`: 依頼のクリアで減る体力を難易度と被弾で変える

ゲームのままだと、依頼をクリアするたびに体力が上限の半分減る。
依頼の難易度は効かず、レベルより大幅に易しい依頼でも同じだけ減る。
依頼を受けられるのは体力が上限の半分より多いときだけなので、
満タンから1件クリアすると、宿で休むまで次の依頼を受けられない。

この MOD は、減る量を依頼の難易度と自分のレベルの差で決め、依頼の間に受けた被弾のぶんを上乗せする。
難易度は、移動先の一覧に出る「適正Lv」と同じ数。

| 依頼 | 減る体力（既定） |
| --- | --- |
| レベルより 20 以上易しい | 上限の 10% |
| 適正（難易度＝レベル） | 上限の 33% |
| レベルより 20 以上難しい | 上限の 50% |
| その間 | 上の割合を直線でつないだ値 |
| 被弾 | 依頼の間に失った HP の合計が最大 HP の半分に届くと +20%（それより少なければ失った量に比例） |

例: 体力の上限が 49 の Lv72 なら、易しい依頼で 5、適正で 16、難しい依頼で 25 減る。
HP を最大 HP の4分の1失えば、さらに 5 減る。半分以上失えば 10 減る。
適正の依頼なら、満タンから被弾が少なければ2件続けて受けられる。

同行者も同じ決め方で、本人のレベルと本人の被弾で決まる。
体力が減ると最大 HP も下がるのはゲームのとおりで、置き直した体力に合わせて最大 HP も組み直す。

| 設定 | 意味 |
| --- | --- |
| 適正の依頼で減る体力（上限の %） | 既定 33。ゲームのままは 50 |
| 易しい依頼で減る体力（上限の %） | 既定 10。ゲームのままは 50 |
| 上位の依頼で減る体力（上限の %） | 既定 50 |
| 易しい・上位の割合に届くレベル差 | 既定 20。0 にすると、レベルより低い依頼はすべて易しい、高い依頼はすべて上位の割合になる |
| 被弾で上乗せする体力（上限の %） | 既定 20。0 で被弾を見ない |
| 上乗せが満額になる被弾（最大 HP の %） | 既定 50。依頼の間に失った HP の合計がこれに届くと満額。回復を挟んで失った分も足す |
| 同行者にも同じ決め方を使う | 既定 入。切ると同行者はゲームのまま半分減る |

3つの割合をすべて 50、被弾を 0 にすると、ゲームのままに戻る（MOD は何もしない）。

| 症状 | やること |
| --- | --- |
| 何も変わらない | `out\quest_stamina.log` を見る。クリアごとに、レベル差・割合・失った HP・減った量と前後の体力が1行ずつ出る。行が無ければ依頼の終わりを捕まえられていない |
| 被弾が少なく数えられる | 依頼の途中でロードし直すと、ロードより前の被弾は数えられない（クリアの時点で最大 HP に足りない分は数える） |
