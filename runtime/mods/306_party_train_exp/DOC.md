# `306_party_train_exp`: 宿屋の訓練で仲間も育つ

宿屋で月日を訓練に充てて経験値を得たとき、同行している仲間にも同じぶん入る。
プレイヤーの獲得経験値が出た後に「…も同じ月日を鍛錬に充て、経験を積んだ。」と出て、
レベルが上がればそれも出る。
施設で主に教わる訓練も同じ扱い。

| 設定 | 意味 |
| --- | --- |
| 宿屋の訓練で仲間にも入れる | 既定 ON |
| 施設の訓練でも仲間に入れる | 既定 ON。切ると宿屋の訓練だけになる |
| 休養でも仲間に入れる | 既定 OFF（休養は訓練ではないため） |
| 仲間に渡す割合 | 既定 1.0（プレイヤーと同じ点数）。`0.5` なら半分 |
| 仲間のレベルアップを画面に出す | 既定 ON |
| 経験値が入ったことも出す | 既定 ON。レベルが上がらない回でも1行出る（高レベルでは1回の訓練では上がらないため） |

## 困ったとき

| 症状 | やること |
|---|---|
| 訓練しても仲間に経験値が入らない | 仲間が同行していないと入らない（雇ってから）。同行しているのに入らないときは `out\party_train_exp.log` を見る。`shared 0 gain(s)` と `WARN` が出ていれば、その回はゲーム側が経験値を別の経路で渡している |
