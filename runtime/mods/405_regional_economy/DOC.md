# `405_regional_economy`: 街ごとの需給で売買の値段が変わる

素のゲームでは、どの街でも同じ品は同じ値段で、遠くまで運ぶ理由が無い。
この MOD は街（エリア）ごとに地域経済を1回だけ作り、余っている品を安く、足りない品を高くする。
鉱山の街では鉱石が安く薬が高い、という差が街ごとに固定され、安く仕入れて高く売る遊びが成り立つ。
値段そのものは `129_balance_item_price` が付けたものに土地の倍率を掛けるだけ。

## どう動くか

街に着いた時点で、その街の地域経済を LLM が1回だけ考える。

- 何を産業にしているか、特産品は何か、何が余って何が足りないか
- 品のジャンル32種それぞれに 1〜5 の需給の値（ジャンルはゲームが品に書いている細分。武器・防具・飲食と薬・道具と書物・素材と財宝の5つの種別に分かれる。3が平常、1に寄るほど余っていて安く、5に寄るほど足りなくて高い）

結果は世界ごとのファイルに残り、同じ街で2度考えない。
売買画面を開いたときは、並んだ品のジャンルで値段に倍率を掛けるだけで LLM は呼ばないので、画面が出るのが遅れず、同じ品の値段が開くたびに変わることもない。

### 名指しされた品はジャンルより優先する

その街の「余っている品」「足りない品」に名前が当たった品は、ジャンルの値を上書きして最も強い倍率にする。
「特産品」に当たった品は動かさない（関わりの強さであって、余りか不足かの向きを持たない）。
照合は名前が同じか、名前がそのまま商品名に入っているときだけ。「灼熱の鱗」と「炎竜の鱗」のような近い品は当たらず、ジャンルが受ける。

## 街の経済を作る間、ゲームは止まらない

LLM への問い合わせと控えの読み書きは裏のスレッドで行い、ゲーム側は「今どこに居るか」を控えて積むだけ。作り終わる前に売買画面を開いても補正なしで普通に開く。

## 街を出るとき、セーブするとき

倍率はアイテムそのものに書くので、次の2つで必ず外す。

- セーブの直前。保存が終わってから画面用の値段へ戻す。倍率がセーブデータへ混ざることはない
- 別の街へ移ったとき。元の値段へ戻してから控えを捨て、よその街の倍率が乗った品を持ち歩かない

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| エリアの産業や経済の要約文字数 | 300 | その街の経済の説明の長さの目安 |
| エリア産業の項目数 | 3 | 主要産業・特産品・余っている品・足りない品を、それぞれこの数だけ作る |
| 未知の産出物が製品になる段階数 | 2 | 架空の材料が使える品になるまでの採取と加工の回数。ドラゴンストーンからドラゴンランプなら2 |
| 強い変動 | 1.5 | 需給が大きく振れるジャンルの倍率。足りない側は掛け、余っている側は割る |
| 弱い変動 | 1.2 | 需給が振れるジャンルの倍率。同じく足りない側は掛け、余っている側は割る |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 値段が変わっている気がしない | `out\regional_economy.log`。街に着くと `summary queued`、出来上がると `summary saved` に全ジャンルの値が出る。売買画面を開くと `regional overlay: N price(s)` が出る |
| `no regional profile yet` が出た | まだその街の経済が出来ていない。補正なしで開き、裏で作り始めている。次にその街で開いたときから効く |
| `summary not saved: invalid LLM result` が続く | LLM がジャンルの値を返せていない。ジャンルが8種に満たない返答は保存しない。指示に従えるモデルを使う |
| どの街も似た値段になる | LLM がジャンルの値を全部3に寄せている。`summary saved` の行で確かめられる |
| 値段を作り直したい | `state\regional_economy\<世界名>.json` を消す。その世界の街の経済だけが初期化され、次に着いたときに作り直される |
| 129 を切っている | この MOD だけでは値段は付かない。素のゲームの値段に倍率が掛かるだけになる |

## 出どころ

MoririnJP 氏の試作（`405_regional_economy` v1）を提供してもらった。
提供された版は品1個ずつを売買画面で LLM に分類させる作りで、開くたびに最長 120 秒ゲームが止まり、`129_balance_item_price` より外側にあって倍率がその場で 129 に上書きされていた。
倍率の軸をジャンルへ移して売買画面から LLM を外し、名指しの層と街を出たときの後始末を足した。

## 129 との競合と、その直し方

129 は10箇所で値段を書き、元の関数の前に書くか後に書くかが地点ごとに違うので、包みの層を外側にも内側にも置けず、必ず半分の地点で負ける（TECH.md §3.3.1）。
129 に値付け直後の口（`sys._instantale_item_price_post`）を1つ作り、この MOD がそこへ登録する形にして、適用順にも経路にも依存しなくした。`mod.json` の `"shares"` で、この名前が自分のものではないことを断ってある。
実機の確認は VERIFICATION.md §3.19.1。
