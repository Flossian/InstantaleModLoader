# `111_llm_prompt_replace`: LLM への指示文を置換ルールで書き換える

ゲームが LLM へ送る文章を置換ルールで書き換える。
NPC の言動や要約の指示を調整するルールと、
ゲーム側の誤字・崩れた改行を直すルールが同梱されていて、そのまま効く。

はっきり違いが出るのは前者（LLM への指示そのものを書き換えるので、
使うモデルに依らず効く）。
後者は保険で、賢いモデルほど崩れた改行を自力で読み分けるため差は小さい。
JSON の書き方を直すルールも入っていたが、
既定では止めてある（VERIFICATION_LOG.md §2.24）。
出力の形は LLM 側の仕組みで既に保証されていて、意味が無いため。

ルールは設定画面から編める。
ローダの MOD の一覧でこの MOD を選んで「設定…」を押すと、置換ルールの画面が開く。

| 画面 | できること |
| --- | --- |
| タブ | 目的ごとにルールを分ける。タブごと切ると中のルールは全部止まる。追加・名前変更・削除・並び替えはタブ見出しの右クリック（一覧の「…」にも同じものがある） |
| 一覧 | 1行1ルール。「有効」「正規」の列はクリックで入切する。複製・上下の移動は右クリックかキー（Insert / Delete / Ctrl+D / Ctrl+↑↓） |
| 選んだルール | 置換前・置換後・メモを編む。確率と正規表現もここ。欄の改行はファイルでは `\n` の2文字になる |
| すべて | 全タブのルールを並べて見る。タブ名・置換前・置換後・メモで絞り込み、ダブルクリックでその行へ移動する |
| 置換テスト | 下の「▸ 置換テスト」を押すと開く。いまのルールを、貼り付けた文章に当てて確かめる。判定はゲームが送るときと同じ（本体をそのまま呼んでいる） |
| 設定… | ルールファイルの置き場（下の表）と、記録の ON/OFF |

保存すると次の応答から効く（ゲーム再起動は不要）。

ルールの置き場は `state\llm_prompt_replace\llm_replacements.txt`。
読む先は上から順に、**在るもの1つ**:

| 順 | 場所 | 扱い |
| --- | --- | --- |
| 1 | 設定「ルールファイルの置き場」に書いたファイルかフォルダ | 指定が在ればこれが最優先 |
| 2 | `state\llm_prompt_replace\llm_replacements.txt` | 手元のルール。**保存先はここ** |
| 3 | `runtime\mods\111_llm_prompt_replace\llm_replacements.txt` | 旧い置き場。読むだけ |
| 4 | `runtime\mods\111_llm_prompt_replace\llm_replacements.default.txt` | 同梱の既定。読むだけ |

`state\` に置くのは、MOD のフォルダが更新のたびに上書きされる場所だから。
旧い置き場のルールも読むので、前の版で書いたものが更新した途端に効かなくなることはない
（画面で保存すると `state\` へ移る。元のファイルは消さないが、以後は読まれない）。

手で編むこともできる。
`state\llm_prompt_replace\llm_replacements.txt` を作って書けばよい
（同梱の `llm_replacements.default.txt` をコピーするのが早い）。
書き方は「置換前=>置換後=>確率」で1行1ルール。
`InstantaleLlmProxy` のルールファイルは書式が同じなので、
上の置き場に置くか、設定「ルールファイルの置き場」でそのファイルを指せばそのまま動く
（その管理 GUI で編んだタブ・メモ・無効化も、この画面がそのまま読み書きする）。

LLM をローカル（llama.cpp）で動かす場合も、APIキーで外部サービスに繋ぐ場合も効く。
APIキー経由で効かなかったのは v1〜v3 の不具合。
v4 はプロバイダに依存しない形へ置き換え、v5 で取りこぼしをなくした。
効いているかは `out\prompt_bloat.log` に `[REPLACE]` が出ることで確かめられる。

> プロバイダを切り替えたら注入し直すこと。
> 送信の入口はプロバイダを選んだときに作られるので、
> 切り替えた後のぶんは入れ直すまで包まれない。

| 設定 | 意味 |
| --- | --- |
| ルールファイルの置き場 | 既定は空（`state\llm_prompt_replace\llm_replacements.txt`）。別名やフォルダを書くとそちらを先に読み、保存先もそこになる（相対は `state\llm_prompt_replace\` から） |
| 置換したことを記録する | 既定 ON。`out\prompt_bloat.log` の `[REPLACE]` |
| ルールの読込を記録する | 既定 ON。`out\prompt_bloat.log` の `[RULES]`（この設定を OFF にしても、書式を誤ったルールは必ず残る） |
