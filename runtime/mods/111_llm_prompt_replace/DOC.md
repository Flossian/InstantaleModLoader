# `111_llm_prompt_replace`: LLM への指示文を置換ルールで書き換える

ゲームが LLM へ送る文章を置換ルールで書き換える。
NPC の言動や要約の指示を調整するルールと、
ゲーム側の誤字・崩れた改行を直すルールが同梱されていて、そのまま効く。

はっきり違いが出るのは前者（LLM への指示そのものを書き換えるので、
使うモデルに依らず効く）。
後者は保険で、賢いモデルほど崩れた改行を自力で読み分けるため差は小さい。
JSON の書き方を直すルールも入っていたが、
既定では止めてある（VERIFICATION_LOG.md §2.24）。
出力の形は LLM 側の仕組みで既に保証されていて、意味が無いため。

自分で書き換えるときは、まず `runtime\mods\111_llm_prompt_replace\` を開く。
その中の `llm_replacements.default.txt` を、
同じフォルダに `llm_replacements.txt` としてコピーする。
編むのはそのコピー（そちらが優先され、MOD を新しい版にしても消えない）。
書き方は「置換前=>置換後=>確率」で1行1ルール。
保存すると次の応答から効く（ゲーム再起動は不要）。
`InstantaleLlmProxy` のルールファイルは書式が同じなので、
`llm_replacements.txt` として置けばそのまま動く。

LLM をローカル（llama.cpp）で動かす場合も、APIキーで外部サービスに繋ぐ場合も効く。
APIキー経由で効かなかったのは v1〜v3 の不具合。
v4 はプロバイダに依存しない形へ置き換え、v5 で取りこぼしをなくした。
効いているかは `out\prompt_bloat.log` に `[REPLACE]` が出ることで確かめられる。

> プロバイダを切り替えたら注入し直すこと。
> 送信の入口はプロバイダを選んだときに作られるので、
> 切り替えた後のぶんは入れ直すまで包まれない。

| 設定 | 意味 |
| --- | --- |
| 置換したことを記録する | 既定 ON。`out\prompt_bloat.log` の `[REPLACE]` |
| ルールの読込を記録する | 既定 ON。`out\prompt_bloat.log` の `[RULES]`（書式の誤りは切っても必ず残る） |
