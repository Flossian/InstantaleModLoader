# ============================================================
# LLMリクエスト置換ルール (111_llm_prompt_replace 用・同梱の既定)
#
# ★ 自分でルールを足すときは、このファイルを同じフォルダに
#    llm_replacements.txt という名前でコピーしてから編集すること。
#    そちらがあれば優先して読まれ、MOD を新しい版に差し替えても消えない
#    (このファイルは配布物なので、更新のときに上書きされる)
# ------------------------------------------------------------
# ・1行1ルール:  置換前=>置換後=>置換確率
# ・置換確率は0-100の整数。省略時は100 (常に置換)
# ・同じ置換前のルールが複数ある場合、確率に応じてどれか1つを選択
#   (確率の合計が100を超える場合は 値/合計 の割合で必ずどれかに置換)
# ・#tab:タブ名 の行から次のタブ行までが1つのタブ (区切りとして読む)
# ・#offtab:タブ名 は無効化されたタブ (中のルールはすべて無視)
# ・改行は \n で書く (\t はタブ、\uXXXX は文字コード。本物の \ は \\)
# ・行頭 # はコメント / UTF-8で保存
# ・行頭 #off: は無効化されたルール
# ・行頭 regex: は正規表現ルール
#   Python正規表現。置換後では $1 ${名前} $& でキャプチャを参照できる ($自体は $$)
#   プロンプト中の改行に当てるにはパターンに \n と書く (プロキシでは \\n だった)
#   時間制限が無いので暴走しやすいパターンを書かないこと
#   (照合に1秒以上かかったルールはその場で捨て、[RULES] に残す)
# ・#memo:メモ の行は覚え書きとして読み飛ばす (置換には影響しない)
# ・変更を保存すると次のLLMリクエストから自動反映 (ゲーム再起動不要)
# ------------------------------------------------------------
# ・読まれるのは MOD フォルダの中の次の2つだけ (探索はしない)
#     llm_replacements.txt          利用者のルール (あればこちら)
#     llm_replacements.default.txt  このファイル (無いときの既定)
#   置いた・消したは次のLLMリクエストで反映される
# ・InstantaleLlmProxy の llm_replacements.txt と書式が同じなので、
#   プロキシ用に書いたファイルは llm_replacements.txt として置けばそのまま動く
#   (管理GUI (InstantaleLlmProxy.exe) が書いたファイルも読める)
# ・プロキシとの違いは本文の形だけ。あちらは JSON にした後のリクエスト本文
#   (改行が \n の2文字・日本語が \uXXXX) を見ていたが、こちらは復号済みの
#   本文を見る。上の書き方で同じように当たるが、正規表現のパターンだけは
#   \\n ではなく \n を書くこと
# ・効いたかどうかは out\prompt_bloat.log の [REPLACE] を見る
#   ([SKIP] は確率で見送った行、[RULES] は読込と書式の誤り)
# ============================================================
