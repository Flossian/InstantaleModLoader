# `126_ui_title_version`: タイトル画面にローダの版を出す

タイトル画面の右上に `modloader vx.y.z` の1行が出る。
出るのはタイトル画面だけで、「開始する」を押せば消える。
遊びには何も影響しない。

ローダは注入で入るので、**ゲームの見た目はどこも変わらない**。
起動しただけでは、MOD が効いているのか判断できない。
注入に失敗しても画面は変わらない。
不具合を報告するときも「MOD 入りかどうか」の確認から始めることになる。
この1行がその答えになる。

ゲームを起動したままローダを注入し直したときも、
目の前のタイトル画面にその場で出る（一度タイトルへ戻る必要は無い）。

| 設定 | 意味 |
| --- | --- |
| 出す文字 | 既定 `modloader v{version}`。`{version}` はローダの版、`{mods}` は今入っている MOD の本数に置き換わる |
| 出す場所 | 右上（既定）／左上／右下／左下。右下はゲーム自身のバグレポートのボタンの場所 |
| 文字の大きさ | px（既定 14）。ゲーム側の画面拡縮に合わせて調整される |
| 文字の濃さ | 既定 0.55。1.0 で真っ白 |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 文字が出ない | `out\modloader.log` の `title version: installed` の行。出ていなければ MOD が入っていない |
| 注入し直しても古いまま | 同じログの `title version: N title screen(s) already open`。`0` ならタイトル画面が見つかっていない（ゲーム内の画面に居るときは `0` で正しい） |
| 文字が四角に化ける | 日本語に変えた場合のみ。フォントはタイトル画面から写しているが、写す相手が見つからないと Kivy の既定（日本語を持たない）になる |
