# `402_party_inventory_transfer`: 仲間とアイテムを受け渡し、仲間に装備を持たせる

素のゲームには、同行している仲間へアイテムを渡す手段が無い。
拾った武器も薬も全部プレイヤーが抱えたままで、自由入力で渡す以外に仲間に持たせることができない。
また、受け渡しが自由入力である以上、渡したアイテムが帰ってくる保証がない。

この MOD を入れると、現在のパーティーメンバーとの会話にだけ
「＜アイテムの受け渡し＞」という選択肢が増える（「会話を終了する」の直前）。
押すと、店の売買と同じ2枚並びの窓が開く。左が自分、右がその仲間で、
アイテムをドラッグすればどちらの向きにも移り、そのままセーブされる。

さらに、右側（仲間側）の武器・防具を右クリックすると
MOD専用の「装備する／外す」ボタンが出て、その仲間自身の装備を付け替えられる。

## 仲間の「装備」はこの MOD が作った層

素のゲームに NPC の装備装着は存在しない（NPC は武器を参照しない、という公式回答がある。
`319_battle_tactics` の DOC 参照）。だからこの MOD の装備は、
セーブの `equipments` 欄（全キャラクターが持つ項目）へ MOD が書き込む記録で、
素のゲームは読まない。

読むのは `401_battle_character_context` で、戦闘の審判へ
「この仲間は何を装備しているか」として渡る。つまり効き方は描写と裁きを通した間接的なもので、
ダメージの数字へ直接は乗らない（319 を入れていれば、審判の裁き経由で数字にも届く）。

401 を入れずにこの MOD だけ使うと、装備は持ち物の整理としてだけ機能する。

## どう動くか

- 選択肢が出るのは、会話相手が今のパーティーメンバーのときだけ。
  他人や、別れた後の元仲間には出ない
- 受け渡しの窓はゲーム自身の売買UIを場面名 `party_transfer` で借りている。
  右側の見出し「所持品」は仲間の名前に描き替える
- ドラッグで移すと、持ち物の実体・アイテムの id・持ち主の記録を同期し、
  少し待ってからゲーム自身の `save_game` で保存する。連続で動かしたときは
  最後の1回だけ保存が走る
- **装備したままのアイテムを渡すと、装備は自動で外れる**。
  外れないまま渡ると、後でプレイヤーの装備欄に触った瞬間にゲームごと落ちる
  （v16 まで実際に落ちた。v17 で修正済み）
- 装備の付け替えは、その仲間の `equipments` の weapon / wearable を直接書く。
  外すときは欄ごと消す（本体がプレイヤーの装備を外した後と同じ形）
- タイトルへ戻ってロードし直しても、会話中なら選択肢は復元される

## 外すとき

MOD を外しても受け渡し済みのアイテムはそのまま相手の持ち物に残る（セーブの正規の形なので無害）。
仲間の装備の記録もセーブに残るが、素のゲームは読まないので実害はない。
気になるなら、外す前に仲間の装備を全部「外す」にしておけばセーブから消える。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 選択肢が出ない | 会話相手が現在のパーティーメンバーか確認。仲間なのに出ないなら `out\modloader.log` の `party inventory` 行 |
| 移したのに保存されていない気がする | 通常の成功ログは出さない設計。`WARN save skipped` 等の警告が `modloader.log` に無ければ保存は走っている |
| 装備したまま渡したら装備が残った | v17 で自動で外れる。外れていなければ `modloader.log` を添えて報告。過去のセーブに残った宙ぶらりんは 2026-08-27 に修復済み |
| 「装備する」ボタンが見えない | 画面の右上・上端で右クリックした場合、本体popupの枠外に出る可能性が未確認のまま残っている。位置を変えて出るならその報告が材料になる |
| 装備の実際の動きを記録したい | デバッグモードで `223_probe_party_equipment` を有効にすると、popup と装備欄の中身が `out\party_equipment_probe.log` に写る |
