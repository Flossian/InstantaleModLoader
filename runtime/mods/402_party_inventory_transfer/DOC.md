# `402_party_inventory_transfer`: 仲間とアイテムを受け渡しできる

素のゲームには、同行している仲間へアイテムを渡す手段が無い。
拾った武器も薬も全部プレイヤーが抱えたままで、自由入力で渡すほかに仲間へ持たせる方法が無い。
また、受け渡しが自由入力である以上、渡したアイテムが帰ってくる保証がない。

この MOD を入れると、現在のパーティーメンバーとの会話にだけ
「＜アイテムの受け渡し＞」という選択肢が増える（「会話を終了する」の直前）。
押すと、店の売買と同じ2枚並びの窓が開く。左が自分、右がその仲間で、
アイテムをドラッグすればどちらの向きにも移り、そのままセーブされる。

右側（仲間側）の武器・防具を右クリックすると
MOD専用の「装備する／外す」ボタンも出るが、
これで仲間に武器・防具を装備させることはできない（次の節）。

## 「装備する」ボタンでは装備できない

素のゲームに NPC の装備装着は存在しない（NPC は武器を参照しない、という公式回答がある。
`319_battle_tactics` の DOC 参照）。「装備する」が書くのは
セーブの `equipments` 欄（全キャラクターが持つ項目）への記録だけで、
素のゲームは読まない。つまり仲間は武器・防具を装備できず、
渡したアイテムは持たせた状態にしかならない。

この記録を読むのは `401_battle_character_context` だけで、戦闘の審判へ
「この仲間は何を装備しているか」という文として渡る。
装備としてダメージや防御の数字に乗る仕組みは無い。

## どう動くか

- 選択肢が出るのは、会話相手が今のパーティーメンバーのときだけ。
  他人や、別れた後の元仲間には出ない
- 受け渡しの窓はゲーム自身の売買UIを場面名 `party_transfer` で借りている。
  右側の見出し「所持品」は仲間の名前に描き替える
- ドラッグで移すと、持ち物の実体・アイテムの id・持ち主の記録を同期し、
  少し待ってからゲーム自身の `save_game` で保存する。連続で動かしたときは
  最後の1回だけ保存が走る
- **装備したままのアイテムを渡すと、装備は自動で外れる**。
  外し方はゲーム自身の解除処理（`Item.unequip`）をそのまま呼ぶので、
  装備欄の表示も一緒に片付く（v17 までは装備の記録だけ直していたため、
  「装備中」の表示が残り、そこから外そうとするとゲームごと落ちた。v18 で修正済み）
- 保険として、装備の記録と食い違う「外す」操作はゲームへ通さず、
  1行記録して無視する。本体はその状況で必ず落ちるため
- 「装備する／外す」は、その仲間の `equipments` の weapon / wearable へ記録を直接書く。
  外すときは欄ごと消す（本体がプレイヤーの装備を外した後と同じ形）
- タイトルへ戻ってロードし直しても、会話中なら選択肢は復元される

## 外すとき

MOD を外しても受け渡し済みのアイテムはそのまま相手の持ち物に残る（セーブの正規の形なので無害）。
仲間の装備の記録もセーブに残るが、素のゲームは読まないので実害はない。
気になるなら、外す前に仲間の装備を全部「外す」にしておけばセーブから消える。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 選択肢が出ない | 会話相手が現在のパーティーメンバーか確認。仲間なのに出ないなら `out\party_inventory_transfer.log` に `added` の行があるか |
| 移したのに保存されていない気がする | `out\party_inventory_transfer.log` に `transfer synced` と `save_game complete` が並んでいれば保存は走っている。`WARN save skipped` なら移した品を見失っている |
| 装備したまま渡したら装備が残った | v18 で本体の解除処理ごと外れる。外れていなければ `out\party_inventory_transfer.log` を添えて報告 |
| `stale unequip ignored` が出た | 古い「装備中」表示から外す操作が飛んだのを無視した記録。素通しすると本体が落ちるため。頻発するなら報告の材料になる |
| 「装備する」ボタンが見えない | 画面の右上・上端で右クリックした場合、本体popupの枠外に出る可能性が未確認のまま残っている。位置を変えて出るならその報告が材料になる |
| 装備の実際の動きを記録したい | デバッグモードで `223_probe_party_equipment` を有効にすると、popup と装備欄の中身が `out\party_equipment_probe.log` に写る |
