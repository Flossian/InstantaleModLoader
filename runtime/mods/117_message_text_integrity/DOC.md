# `117_message_text_integrity`: 長い本文の表示を末尾に絞り、本文が消えるのを防ぐ

ゲームは画面に流れた本文を切らずに溜め続け、数十万文字になる。
表示ラベルは長すぎると、例外も出さずに何も描かれなくなる。
この MOD は保持している本文はそのままに、画面に載せる本文だけを末尾から絞る。
それより前は省略表示にする。
入ったかどうかは `out\modloader.log` の
`message text integrity installed` の行で分かる。

| 設定 | 意味 |
|---|---|
| 表示する末尾の文字数 | 既定 1000。画面に載せる最新本文の上限。上げすぎると本文が丸ごと消えることがある。消えたらまずここを下げる |
