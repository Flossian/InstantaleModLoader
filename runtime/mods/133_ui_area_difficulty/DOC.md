# `133_ui_area_difficulty`: 移動先に適正レベル帯を出す

「他の土地へ行く」の一覧に並ぶ土地の名前に、その土地の適正レベル帯を添える。

```
陽光の砦            →  陽光の砦（適正Lv 21〜30）
風鳴りの村          →  風鳴りの村（適正Lv 4〜6）
```

素のゲームの一覧は名前だけで、次に向かうべきレベル適正の土地を探すには
行ってみて掲示板を見るしかない。
その手間を無くすための表示で、遊びの数値は何も変えない。
推奨先の提示まではしない（どこへ行くかは自分で決める）。

帯はその土地の依頼の難易度の最小〜最大に 1 を足したもの
（敵のレベルは難易度+1 なので、掲示板の依頼を受けたときに相手するレベルと一致する）。
読むのはゲームが店の品揃えや敵の強さを決めるのと同じ依頼一覧なので、
`318_area_difficulty_growth` で難易度が育っていれば育った後の値が出る。

まだ訪ねていない街には依頼が無い（街の中身は初訪問のときに作られる）。
その街は「適正Lv 推定 48〜57」のように、推定の印を付けて出す。
ゲームは初訪問のときに、街の枠（開始地点から何番目の街か）で決まる範囲から
初期依頼3件の難易度を引くので、その範囲をそのまま出している
（実測。範囲は `runtime\mods\133_ui_area_difficulty\ui_area_difficulty.py` の `SLOT_RANGES`）。
訪ねた後は実値に変わる。
エディタで後から足した街は枠が無く、ゲームは 1〜76 の全域から初期依頼を引くので、
訪ねるまで「適正Lv 不明」。

徒歩・馬車を選ぶ確認画面にも同じ帯を出す。
ゲームの文言に土地の名前が入っていればそこへ添え、無ければ
「（陽光の砦の適正Lv: 21〜30）」の1行を足す。

ボタンの文字を書き換えるだけで、押したときの動きはゲームのまま
（押された文字列は素の名前に戻してからゲームへ渡す）。
この MOD を外せば一覧は素の表示に戻る。

「既定は素の値」の原則の例外で、既定で表示する。
素の値を変えず情報を足すだけの表示なので、`314_` の馬車の日数と同じ判断。

| 設定 | 意味 |
| --- | --- |
| 帯を出す | 既定 ON。切ると一覧も確認画面も素のまま |
| 難易度に足してレベルにする数 | 既定 1（敵のレベル＝難易度+1）。0 で難易度そのものを出す |
| ボタンの表示 | 既定 `{name}（適正Lv {band}）`。`{name}` は土地の名前、`{band}` は帯 |
| 帯の表記 | 既定 `{lv_min}〜{lv_max}`。`{min}` `{max}`（難易度）と `{count}`（依頼の数）も使える |
| 帯の表記（最小と最大が同じとき） | 既定 `{lv_min}` |
| 帯の表記（依頼が無くて引けないとき） | 既定 `不明`。空にするとその土地は名前のまま |
| 未訪問の街は枠から見積もる | 既定 ON。切ると未訪問の街は「不明」 |
| 帯の表記（未訪問の見積もり） | 既定 `推定 {lv_min}〜{lv_max}` |
| 確認画面に足す1行 | 既定 `（{name}の適正Lv: {band}）`。空で出さない。`{label}` でボタンと同じ表示が入る |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 一覧に帯が出ない | `out\ui_area_difficulty.log` の `label:` の行。無ければ一覧のボタンが `AreaMoveCofirmation` の形ではない（`no area for` / `leaving it alone` の行が理由を言う） |
| 全部「不明」 | 同じログの `no band (0 quest(s))`。`WARN get_quest_difficulties failed` があればゲーム側の関数が変わっている。`scanning world.quests instead` なら自前の走査に下がっている |
| 推定の帯と、訪ねた後の実値がずれる | 枠の範囲はゲームの版で変わりうる。`out\area_quest_difficulty.log`（`225_`）の `sample("range(lo, hi)")` の行と `SLOT_RANGES` を突き合わせる |
| 掲示板の難易度と帯が合わない | 帯は難易度+1（設定「難易度に足してレベルにする数」）。0 にすれば掲示板の数字そのものになる |
| 確認画面に1行余計に出る | ゲームの文言に土地の名前が無かったとき。「確認画面に足す1行」を空にすれば出ない |
| 押しても移動の確認画面に進まない | `choice text ... (our label, restored)` の行が出ているか。出ていれば押された文字列は素の名前に戻せている。出ていなければ `out\modloader.log` の例外を見る |
