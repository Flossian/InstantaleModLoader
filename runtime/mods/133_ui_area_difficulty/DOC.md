# `133_ui_area_difficulty`: 移動先に適正レベル帯を出す

「他の土地へ行く」の一覧の土地の名前に、その土地の適正レベル帯を添える。

```
陽光の砦            →  陽光の砦（適正Lv 21〜30）
風鳴りの村          →  風鳴りの村（適正Lv 4〜6）
```

素の一覧は名前だけで、次に向かう土地は行って掲示板を見るしかない。
表示だけで遊びの数値は変えず、推奨先も出さない。

帯はその土地の依頼の難易度の最小〜最大に 1 を足したもの（敵のレベルは難易度+1）。
ゲームが品揃えや敵の強さに使うのと同じ依頼一覧を読むので、`318_area_difficulty_growth` で育った後の値が出る。

未訪問の街には依頼が無い（街の中身は初訪問で作られる。GAME.md §2.9）ので、「適正Lv 推定 48〜57」と推定の印を付けて出す。
初期依頼3件の難易度は街の枠（開始地点から何番目か）で決まる範囲から引かれるので、その範囲をそのまま出す
（`runtime\mods\133_ui_area_difficulty\ui_area_difficulty.py` の `SLOT_RANGES`）。訪ねた後は実値に変わる。
エディタで後から足した街は枠が無く 1〜76 の全域から引かれるので、訪ねるまで「適正Lv 不明」。

徒歩・馬車の確認画面にも同じ帯を出す。
文言に土地の名前があればそこへ添え、無ければ「（陽光の砦の適正Lv: 21〜30）」の1行を足す。

ボタンの文字を書き換えるだけで、押された文字列は素の名前に戻してからゲームへ渡す。外せば素に戻る。
「既定は素の値」の原則の例外で既定 ON（情報を足すだけの表示。`314_` の馬車の日数と同じ判断）。

| 設定 | 意味 |
| --- | --- |
| 帯を出す | 既定 ON。切ると一覧も確認画面も素のまま |
| 難易度に足してレベルにする数 | 既定 1（敵のレベル＝難易度+1）。0 で難易度そのものを出す |
| ボタンの表示 | 既定 `{name}（適正Lv {band}）`。`{name}` は土地の名前、`{band}` は帯 |
| 帯の表記 | 既定 `{lv_min}〜{lv_max}`。`{min}` `{max}`（難易度）と `{count}`（依頼の数）も使える |
| 帯の表記（最小と最大が同じとき） | 既定 `{lv_min}` |
| 帯の表記（依頼が無くて引けないとき） | 既定 `不明`。空にするとその土地は名前のまま |
| 未訪問の街は枠から見積もる | 既定 ON。切ると未訪問の街は「不明」 |
| 帯の表記（未訪問の見積もり） | 既定 `推定 {lv_min}〜{lv_max}` |
| 確認画面に足す1行 | 既定 `（{name}の適正Lv: {band}）`。空で出さない。`{label}` でボタンと同じ表示が入る |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 一覧に帯が出ない | `out\ui_area_difficulty.log` の `label:` の行。無ければ一覧のボタンが `AreaMoveCofirmation` の形ではない（`no area for` / `leaving it alone` の行が理由） |
| 全部「不明」 | 同じログの `no band (0 quest(s))`。`WARN get_quest_difficulties failed` ならゲーム側の関数が変わっている。`scanning world.quests instead` なら自前の走査に下がっている |
| 推定の帯と、訪ねた後の実値がずれる | 枠の範囲はゲームの版で変わりうる。`out\area_quest_difficulty.log`（`225_`）の `sample("range(lo, hi)")` の行と `SLOT_RANGES` を突き合わせる |
| 掲示板の難易度と帯が合わない | 帯は難易度+1（設定「難易度に足してレベルにする数」）。0 で掲示板の数字そのもの |
| 確認画面に1行余計に出る | ゲームの文言に土地の名前が無かったとき。「確認画面に足す1行」を空にする |
| 押しても移動の確認画面に進まない | `choice text ... (our label, restored)` の行が出ていれば素の名前に戻せている。出ていなければ `out\modloader.log` の例外 |
