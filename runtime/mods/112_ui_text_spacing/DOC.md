# `112_ui_text_spacing`: 広すぎる本文の行間を詰める

LLM の応答やシステムメッセージの行間を詰め、段落の間に入る空行を減らす。
画面に出る見た目だけを変えるので、会話履歴やセーブの中身は元のまま。

| 設定 | 意味 |
| --- | --- |
| 行間 | ゲームの元の値に対する倍率（既定 0.8）。`1.0` でゲームのまま、空欄なら行間に触らない |
| 段落の間に残す空行の数 | 既定 0（空行なし）。`1` でゲームのまま、空欄なら本文の改行に触らない |

元の行間の値は `out\text_spacing.log` に出る（ゲームの値は `1.8`。
既定の 0.8 倍で `1.44` になる）。
詰めすぎ・緩すぎと感じたら 0.7〜0.9 で調整する。
