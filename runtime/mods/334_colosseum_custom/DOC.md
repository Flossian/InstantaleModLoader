# `334_colosseum_custom`: 闘技場の相手の強さと懸賞金を決める

素の闘技場は、勝つほど相手が際限なく強くなる。
相手の格はその土地の依頼の難易度から決まり、初戦は難易度の半分、1試合勝つごとに 2/9 ずつ増える
（難易度60の街なら 30 → 43 → 57 → 70 → 83 → 97 …。頭打ちは無い。GAME.md §2.11）。
ゲーム自身の説明で「伝説の勇者や魔王」に当たるのが格70なので、6試合目にはその上へ出る。
**負ければゲームオーバー**で、勝っても懸賞金は格が上がるほど伸びが鈍る
（格30で173G、格58で359G、格97で454G）。

この MOD は、その伸び方と払いを設定で決められるようにする。
**既定値はすべて素のゲームの値**なので、そのままでは何も変わらない。

| 設定 | 既定 | 何が変わるか |
|---|---|---|
| 初戦の相手の強さ（倍） | 1.0 | 初戦の格。0.5 で半分の相手から始まる |
| 1試合ごとに強くなる速さ（倍） | 1.0 | 勝ったときの伸び。0.5 でゆっくり、0 で初戦の格のまま |
| 相手の格の上限 | 0（上限なし） | ここで打ち止める。70 がゲームの言う「伝説の勇者や魔王」 |
| 初戦の相手を何に合わせるか | 土地の難易度 | 「プレイヤーのレベル」にすると自分の強さに合った相手から始まる（素はレベル1でも格30） |
| レベルに合わせるときの初戦の格 | 1.0 | 上を変えたときだけ効く。レベルの何倍の格にするか |
| 懸賞金の倍率 | 1.0 | 素の額に掛ける |
| レベル1ごとの上乗せ（倍） | 0.0 | 自分のレベルに応じて増やす。0.02 ならレベル50で約2倍 |
| 相手の格1ごとの上乗せ（倍） | 0.0 | 強い相手ほど割に合わせる |
| 申し込む前に相手の格を告げる | ON | 受付が「次の相手は歴戦の猛者」のように言う。自分の腕に対して重すぎれば一言付く |
| 倒れてもゲームオーバーにしない | OFF | 素は倒れたらゲームオーバー。ONなら体力1で踏みとどまり、負けを認めてその場で試合を切り上げる（ゲームが撤退のときに通るのと同じ終わり方。`current_phase` は進まず懸賞金も出ない） |
| 毎回同じ闘士が出てこないようにする | ON | 既に出た闘士の名前を頼み文に足す（`331_facility_investment` が自分の闘技場でやっているのと同じ手） |

## 相手の格の決め方

告げるときの格は、その土地の依頼の難易度の平均（整数に落とす）から素の式で見積もる。
相手の格は、ゲームが決めた値を**素の式から組み直して**渡す
（渡ってきた難易度と試合数から土地の難易度を戻し、設定を当ててから返す）。
だから設定が素のままなら1ランクも動かない。

ゲームは格を**3か所で別々に使う**（頼み文・施設に焼く値・敵の数値。GAME.md §2.11）。
頼み文だけを変えても相手は弱くならないので、この MOD は3か所とも揃える。
敵の数値を作る `get_enemy_exp_lvl` / `get_enemy_attributes_base_point` は依頼の敵も通る共有の関数なので、
触るのは**試合を仕込んでいる間の窓**（`申し込む` から戦闘が始まるまで）の中だけにしてある。

## 懸賞金

懸賞金は**倍率で乗せる**。素の式そのものはまだ当てていない（頭打ちに向かう形までは測れているが、
格70〜90の点が無い）ので、額を置き換えるのではなくゲームが出した額に掛ける。
画面の文（`報酬として<額>Gを貰った。`）も同じ額に書き換え、
**文を書き換えられたときだけ**所持金の差額を足す（表示と所持金を食い違わせないため）。

自分から撤退するのは素のゲームでもできる（逃げても `current_phase` は進まないので、
同じ格の相手が作り直される）。
撤退の後に次の戦闘が固まるのはゲーム本体の不具合で、`107_fix_battle_flag_stuck` が直す。

## 困ったとき

| 症状 | やること |
|---|---|
| 上限を下げたのに相手が強いまま | `out\colosseum_custom.log` に `prompt rank:` と `get_enemy_exp_lvl:` の両方が出ているかを見る。片方しか無ければ窓が閉じてから敵が作られている |
| 懸賞金の文と所持金の増えが合わない | 同じログの `reward:` の行を見る。`WARN` が出ていれば文を書き換えられなかった回で、そのときは所持金も触っていない |
| 倒れてもゲームオーバーになった | 闘技場の試合でだけ効く（依頼の戦闘では素のまま）。ログに `WARN surrender:` があれば終わり方を起こせていない |
