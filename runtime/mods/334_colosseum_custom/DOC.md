## 1. 遊び方（`docs\MODS.md` 相当）

### `917_colosseum_custom`: 闘技場の相手の強さと懸賞金を決める

素の闘技場は、勝つほど相手が際限なく強くなる。
相手の格はその土地の依頼の難易度から決まり、初戦は難易度の半分、1試合勝つごとに 2/9 ずつ増える
（難易度60の街なら 30 → 43 → 57 → 70 → 83 → 97 …。頭打ちは無い。GAME.md §2.11）。
ゲーム自身の説明で「伝説の勇者や魔王」に当たるのが格70なので、6試合目にはその上へ出る。
**負ければゲームオーバー**で、勝っても懸賞金は格が上がるほど伸びが鈍る
（格30で173G、格58で359G、格97で454G）。

この MOD は、その伸び方と払いを設定で決められるようにする。
**既定値はすべて素のゲームの値**なので、そのままでは何も変わらない。

| 設定 | 既定 | 何が変わるか |
|---|---|---|
| 初戦の相手の強さ（倍） | 1.0 | 初戦の格。0.5 で半分の相手から始まる |
| 1試合ごとに強くなる速さ（倍） | 1.0 | 勝ったときの伸び。0.5 でゆっくり、0 で初戦の格のまま |
| 相手の格の上限 | 0（上限なし） | ここで打ち止める。70 がゲームの言う「伝説の勇者や魔王」 |
| 初戦の相手を何に合わせるか | 土地の難易度 | 「プレイヤーのレベル」にすると自分の強さに合った相手から始まる（素はレベル1でも格30） |
| レベルに合わせるときの初戦の格 | 1.0 | 上を変えたときだけ効く。レベルの何倍の格にするか |
| 懸賞金の倍率 | 1.0 | 素の額に掛ける |
| レベル1ごとの上乗せ（倍） | 0.0 | 自分のレベルに応じて増やす。0.02 ならレベル50で約2倍 |
| 相手の格1ごとの上乗せ（倍） | 0.0 | 強い相手ほど割に合わせる |
| 申し込む前に相手の格を告げる | ON | 受付が「次の相手は歴戦の猛者」のように言う。自分の腕に対して重すぎれば一言付く |
| 倒れてもゲームオーバーにしない | OFF | 素は倒れたらゲームオーバー。ONなら体力1で踏みとどまり、負けを認めてその場で試合を切り上げる（ゲームが撤退のときに通るのと同じ終わり方。`current_phase` は進まず懸賞金も出ない） |
| 毎回同じ闘士が出てこないようにする | ON | 既に出た闘士の名前を頼み文に足す（`331_facility_investment` が自分の闘技場でやっているのと同じ手） |

告げるときの格は、その土地の依頼の難易度の平均（整数に落とす）から素の式で見積もる。
相手の格は、ゲームが決めた値を**素の式から組み直して**渡す
（渡ってきた難易度と試合数から土地の難易度を戻し、設定を当ててから返す）。
だから設定が素のままなら1ランクも動かない。

ゲームは格を**3か所で別々に使う**（頼み文・施設に焼く値・敵の数値。GAME.md §2.11）。
版1は頼み文だけを変えていたので、上限を当てても相手は弱くならなかった
（実機で上限70を当てたのに敵のレベルは 72 と 86 のまま）。
版2は3か所とも揃える。敵の数値を作る `get_enemy_exp_lvl` /
`get_enemy_attributes_base_point` は依頼の敵も通る共有の関数なので、
触るのは**試合を仕込んでいる間の窓**（`申し込む` から戦闘が始まるまで）の中だけにしてある。

懸賞金は**倍率で乗せる**。素の式そのものはまだ当てていない（頭打ちに向かう形までは測れているが、
格70〜90の点が無い）ので、額を置き換えるのではなくゲームが出した額に掛ける。
画面の文（`報酬として<額>Gを貰った。`）も同じ額に書き換え、
**文を書き換えられたときだけ**所持金の差額を足す（表示と所持金を食い違わせないため）。

自分から撤退するのは素のゲームでもできる（逃げても `current_phase` は進まないので、
同じ格の相手が作り直される）。

## 3. 実機で確かめること（`docs\VERIFICATION.md` §3 相当）

`settings\loader.json` を `{"debug": true}` にして `233_probe_colosseum` も一緒に入れると、
この MOD が動かした値が `out\colosseum.jsonl` に残る（`enemy_generator` 行の `difficulty` と
`match` 行の `rewards` / `gold_gained`）。残っている計測（懸賞金の式の格70〜90の点）も同じ回で採れる。

| # | 何 | どう確かめるか |
|---|---|---|
| 1 | 既定では何も変わらない | 設定を触らずに1試合。`out\colosseum_custom.log` に `rank:` も `reward:` も出ないこと。相手の格と懸賞金が素の式どおり（GAME.md §2.11 の表）であること |
| 2 | 上限が効く（**版1で外した所**） | `相手の格の上限` を今の相手より低い値（例 40）にして申し込む。`out\colosseum_custom.log` に `prompt rank:` と `get_enemy_exp_lvl:` の両方が出て、**敵のレベルが上限＋1になる**こと（`233_probe_colosseum` の `battle_start` 行の `level`）。施設に焼かれる `data.rank` も上限の値になること |
| 3 | 伸びが効く | `1試合ごとに強くなる速さ` を 0 にして2連勝。2戦目の格が1戦目と同じであること（`current_phase` は +2 されている） |
| 4 | レベル基準 | `初戦の相手を何に合わせるか` を「プレイヤーのレベル」にして、`current_phase` が 0 の闘技場（別の街）で申し込む。相手の格が自分のレベル付近になること |
| 5 | 懸賞金の倍率 | `懸賞金の倍率` を 2.0 にして勝つ。画面の文の額が素の2倍で、所持金の増えもその額と同じであること（`reward:` の行に `corrected` が出るのは、ゲームが素の額を入れた後にこちらが差を足したとき。額が食い違ったままなら `WARN`） |
| 6 | レベル連動 | `レベル1ごとの上乗せ` を 0.02 にして勝つ。額が `素の額 × (1 + 0.02 × (レベル-1))` であること |
| 7 | 格を告げる | 闘技場に入って `試合に出る` を押す。受付の口上の後に相手の格の行が出ること。自分のレベルの 1.2 倍を超える相手なら「命がいくつあっても足りん」の側が出ること |
| 8 | 負けても死なない | `倒れてもゲームオーバーにしない` をONにして、勝てない相手に挑む。倒れたところで退いた一文が出て、**ゲームオーバー画面にならず闘技場に戻る**こと。`out\colosseum_custom.log` に `surrender: ... ended the match as an escape`。`current_phase` が進んでいないこと（次の相手が同じ格）と、懸賞金が出ていないことも見る。`WARN surrender:` が出ていたら終わり方を起こせていない（試合が続いている） |
| 9 | 相手の使い回し | 同じ闘技場で3試合。3人とも別人であること（`variety:` の行に人数が出る） |
| 10 | よその戦闘に触らない | 依頼の戦闘で倒れたら、設定をONにしていても普通にゲームオーバーになること（`in_colosseum_battle` が立っていない） |
| 11 | `331_` の闘技場でも同じに効く | 自分で建てた闘技場で1〜2試合。既出の闘士の一文が二重に付かないこと（`331_` が先に足している） |
