# `348_party_departure`: 依頼後も仲間が残り、会話で別れられる

MOD なしのゲームでは、仲間は依頼をクリアするたびに解散して雇った場所へ帰り、それ以外では死別でしか外れない。
この MOD は仲間が離れるときの扱いを3つ変える。

| 機能 | 何が変わるか |
| --- | --- |
| 依頼が終わっても解散しない | 依頼をクリアしても仲間はそのまま同行する。離脱の文の代わりに残った旨が出る |
| 会話から仲間と別れられる | 仲間との会話に「ここで別れる」が出る。確認の後、会話を閉じてから別れる |
| 別れた仲間を会いに行ける場所に残す | 雇った土地で別れたら雇った場所へ、別の土地で別れたらいまの町のギルドへ残る |

雇い直しが要らなくなるので、解散を前提にしたゲームバランスは変わる。
1人だけ外したいときは会話から「ここで別れる」を使う。

以前は別々の MOD（`302_leave_party_in_conversation`・`303_quest_end_party_to_guild`・`304_quest_end_keep_party`）だった。
設定の値と入切はこの MOD へ引き継がれる。

## 設定

| 設定 | 意味 |
| --- | --- |
| 依頼が終わっても解散しない | 既定 ON |
| 会話から仲間と別れられる | 既定 ON |
| 別れた仲間を会いに行ける場所に残す | 既定 ON。OFF にすると雇った場所へ帰る（ゲームのまま）。会話の別れと依頼の解散の両方に効く |
| 依頼の放棄でも同じ扱いにする | 既定 OFF。ON にすると、依頼を放棄したときも上の「解散しない」「会いに行ける場所に残す」が効く |
| 依頼の解散で行き先を本文に出す | 既定 ON。「（名前）は（施設）に留まることになった。」 |
| 解散を止めたときに出す文 | 既定「{name}はパーティに残り、引き続き行動を共にすることになった。」（`{name}` が仲間の名前になる） |

「解散しない」を OFF にして「会いに行ける場所に残す」を ON にすると、依頼をクリアするたびに解散し、仲間はその町のギルドに残る（雇った土地なら雇った場所）。
両方 OFF でゲームのまま（雇った場所へ帰る）。

## 困ったとき

| 症状 | やること |
| --- | --- |
| 「ここで別れる」が出ない | 仲間との会話でしか出ない。戦闘中と依頼の最中も出ない |
| 「ここで別れる」を選んでも別れられない | 人の居る場所（町など）へ戻ってから。ダンジョンなど、置ける施設の無い土地では別れられない |
| 依頼をクリアしても仲間が離れない | 「依頼が終わっても解散しない」の効果。離したいなら設定で OFF にするか、会話から別れる |
| 別れた仲間がどこに居るか分からない | 別の土地で別れたなら、その町のギルドの「冒険者達と話す」に居る。記録は `out\party_leave.log` |
