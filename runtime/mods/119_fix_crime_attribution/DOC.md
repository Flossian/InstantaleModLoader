# `119_fix_crime_attribution`: 他人の犯罪が主人公のものになるのを直す

NPC や第三者が起こした犯罪を、ゲームが主人公の犯罪として扱ってしまうのを防ぐ。
記録は `out\crime_attribution_fix.log`。
判定を取り違えて本物の犯罪を消すより、誤判定を残してログに出す方を選ぶ作りなので、
確信が持てない場面では何もしない（そのぶん、効いていないように見えることがある）。

ローカル（llama.cpp）でも、APIキーで外部サービスに繋いでいる場合でも効く。
v1 はローカルの1か所しか見ていなかった。
APIキー経由では、判別の目印をプロンプトへ入れる処理が走らない。
そのため、この MOD は何もせず素通しになっていた（`crime_attribution_fix.log` に
`marker_missing` だけが並ぶ）。
v2 で、`111_llm_prompt_replace` が使っているのと同じ仕掛け口を共有して直した。
