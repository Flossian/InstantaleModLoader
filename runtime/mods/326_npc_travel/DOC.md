# `326_npc_travel`: NPCの街移動

素のゲームの NPC は生成された施設から一歩も動かない。
このMODは、街のギルドの冒険者が旅に出て、別の街のギルドか宿に現れ、期限が来たら帰ってくるようにする。
この版で動くのは冒険者（ギルドの「冒険者達と話す」に並ぶ人）だけ。

## 決まり

- 出るのは**友好度が 20 以上**の冒険者。会ったことのある人だけが動く。判定は出発の瞬間だけ
- 各街に**必ず 2 人は残る**。数えるのは一覧に出る人（生きていて、同行しておらず、旅に出ていない）。
  3 人の街なら 1 人ずつ、5 人の街なら 3 人まで同時に出られる
- 日が進むたびに（移動・宿泊）、冒険者 1 人あたり月 30% の確率で出発を引く
- 行き先は半々で、**別の街**か**同じ街の別の施設**
  - 別の街: 施設が生成済みの街（一度訪れた街）のギルドか宿。**30〜90 日**滞在する。
    ギルドに着いた人はそこの「冒険者達と話す」に並ぶので、**その街で雇える**
  - 同じ街: ギルド以外の施設（宿・店・役場など）。**7 日**滞在する。その施設の「会話する」で会える
- 旅の間は元の街の「冒険者達と話す」からは消える
- 出発も帰還も、プレイヤーがその施設に居る間は起こらない。施設を出ると果たされる
- 旅先で雇うと旅は終わり、帰らない。解散のときに置かれた街（素のゲームなら雇用地＝元の街、`303_quest_end_party_to_guild` が入っていれば居る街のギルド）の「冒険者達と話す」に入る
- `303_` が別の街のギルドへ置いた人（一覧は元の街のまま）は、旅には出ない。残す人数には数える
- 旅先で話しかけると、会話の文脈に「〈名前〉は〈元の街〉から旅をして来て、いまは〈場所〉に滞在している」の 1 文が入る。
  画面には出ない。元の街では何も出さない
- 1 つの施設に旅で来られるのは 2 人まで
- 世界から消された人（セーブエディタなど）の旅は、気付いた時点で忘れる

## 他の MOD との重なり

| MOD | どうなるか |
| --- | --- |
| `303_quest_end_party_to_guild` / `302_leave_party_in_conversation` | 旅先で雇った人の解散先を差し替える。326 は解散の後に「実際に置かれた街」の一覧へ入れるので、どちらが動かしても一覧と実体は一致する。既に別の街へ置かれていた人は旅に出ない |
| `320_guild_adventurer_recruit` | 旅で減った分は 320 の「募集」の人数に見える。既定（残す 2 人・募集は 1 人以下で）では重ならないが、「各街に残す人数」を 1 以下にすると旅の間に募集できるようになり、その街の冒険者が増える |
| `323_npc_carryover` | 連れて来た人はギルドか宿に置かれ、ギルドなら一覧に載るので、普通の冒険者と同じく旅に出る |
| `300_event_facility_arrival` | 旅で来ている人も、その施設の話者に選ばれる |
| `311_` / `403_` / `404_` | 会話の文脈への差し込みは、どれも複製の `profile` に足す形なので重ねて効く。並ぶ順は適用順 |

| 設定 | 意味 |
| --- | --- |
| 月あたりの出発確率（%） | 既定 30。冒険者 1 人あたり。0 で誰も出ない |
| 同じ街の中へ向かう割合（%） | 既定 50。残りは別の街へ。行き先の無いほうへは行かない |
| 各街に残す人数 | 既定 2 |
| 出発できる友好度 | 既定 20 |
| 別の街への滞在（下限・上限・日） | 既定 30〜90。日単位で引く |
| 同じ街の中の滞在（日） | 既定 7 |
| 1施設に来られる人数 | 既定 2。0 で上限なし |
| ロード時に全員を帰す | 既定 OFF。MODを外す前の片付け（下） |
| 別の街／同じ街で話すときに足す 1 文 | 会話の文脈に入る文型。空で足さない。`{name}` `{origin}` `{where}` `{days}` が使える |

## 記録

誰がどこへ何日まで、は `state\npc_travel\<世界名>.json` に持つ。
居場所そのものはセーブに書かれる（ゲーム自身の `move_npc_to_facility` で動かしている）。
ロードのときに両方を突き合わせる:

- セーブの日付が出発日より前（古いセーブを読んだ）なら、その旅は無かったことにする
- 行き先に居なければ置き直す

## MODを外すとき

旅の途中の人はセーブの中でも旅先に居るので、外すとそこに残ったままになる。
「ロード時に全員を帰す」を入れてロードし、セーブしてから外す。
`state\npc_travel\` は消してよい。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 誰も旅に出ない | `out\npc_travel.log` に `roll:` の行があるか。無ければ一覧が 2 人以下か、友好度 20 以上の人が居ない。`depart: player is at` なら、その施設に居る間は待っている |
| 旅先に居ない | 同ログの `depart:` の行の行き先。`move: facility ... not found` ならその街の施設が読めていない |
| 帰ってこない | 同ログの `return:` の行。`player is at` なら施設を出るまで待っている。日が進むまで期限は来ない |
| 元の街の一覧から消えたまま | 同ログの `closed:` か `return:` があるか。無ければ台帳（`state\npc_travel\`）に残っている。「ロード時に全員を帰す」で戻る |
| 旅先で雇って解散したのに、どの街の一覧にも出ない | 同ログの `hired: ... left the party; enrolled in area N`。無ければ解散した施設がどの街のものか読めていない（`stands nowhere known`） |
| 友好度が高いのに一度も出ない人が居る | 同ログの `skip: ... stands in area`。一覧の街と実体の街が食い違っている（`303_` が置いた人） |
| ロードしたら旅が消えた | 同ログの `reconcile: ... forgotten`。出発より古いセーブを読んだ |
