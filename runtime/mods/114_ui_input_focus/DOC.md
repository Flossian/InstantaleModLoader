# `114_ui_input_focus`: 自由入力のあと入力欄にフォーカスを戻す

自由入力を送るたびに入力欄からフォーカスが外れ、
次の一言を打つのに毎回クリックし直していたのを、
送ったあともそのまま打てるようにする。
Enter で送っても、送信ボタンを押しても戻る。
入力欄の中身や送信の仕組みには触らない。

LLM の応答を待つ間はゲームが入力を塞ぐので、その間は戻さず、応答が返った瞬間に戻る。
別の窓が開いているとき・他の入力欄に打っているときも横取りしない。

| 設定 | 意味 |
| --- | --- |
| フォーカスが外れたら戻す | 既定 ON。送信でも、画面のどこかを触ったときでも入力欄に戻る。OFF にすると次の項目だけが効く |
| 応答待ちが明けたら戻す | 既定 ON。応答が返って入力が解けた瞬間に戻す |
| 戻すまでの待ち（秒） | 既定 0.05。戻ってもすぐまた外れるようなら 0.1〜0.2 に上げる |

フォーカスが常に入力欄にあるので、
キーボードで他の操作をしている場合はそちらが効きにくくなる。
そのときは「フォーカスが外れたら戻す」を OFF にすると、送信の後だけ戻る形になる。
どの入力欄を掴んでいるかは `out\input_focus.log` に出る。
