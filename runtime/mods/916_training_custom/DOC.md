## 1. 遊び方（`docs\MODS.md` 相当）

### `916_training_custom`: 訓練所の代金・修行の年数・1年の日数を変える

訓練所は、代金が 300G で固定、1回の修行が3年、
活動を1つ選ぶと **その年数 × 365 日**の暦が一度に進む。
`新たな技を学ぶ(3年)` を選べば 1095 日、`ただ鍛える(1年)` でも 365 日。
主人公は3年ぶん歳を取り、世界の側も3年ぶん進む。
この MOD はその3つを設定から変えられるようにする。

**既定値はすべて素のゲームの値**（300G・3年・1年365日）で、
そのままならこの MOD は挙動を何も変えない。
設定を素の値から動かした項目だけが効く。

```text
[素のゲーム]        訓練を受ける(300G) → あと3年間 → 新たな技を学ぶ(3年) → 1095日
[1年=30日]          訓練を受ける(300G) → あと3年間 → 新たな技を学ぶ(3年) → 90日
[代金5000・1年30日] 訓練を受ける(5000G) → あと3年間 → ただ鍛える(1年) → 30日
[修行10年・1年30日] 訓練を受ける(300G) → あと10年間 → 活動を何段も受けられる（合計300日）
```

表示と実態は食い違わない（`314_area_move_custom` と同じ約束）。
ボタンに出す代金は設定値そのもので、ゲームが引き落とす額も同じ設定値。
代金と年数は**ゲームが受け取る引数を差し替えている**ので、
引き落としも残り年数の勘定も文言（`あと3年間`）もゲーム自身が行う。

| 設定 | 意味 |
| --- | --- |
| 訓練の代金 | 既定 300G（素の値。施設によらず固定）。300のままなら触らない。0でタダ。手持ちが足りないと押した時点で「（訓練の代金◯Gに足りない…）」と断る |
| 1回の修行の年数 | 既定3年（素の値）。修行内容を1つ選ぶたびにその年数ぶん減り、0で卒業。増やすと1回の代金で活動を何段も受けられる |
| 1年で進む日数 | 既定365日（素の値）。3年の活動は「3×この日数」進む。30にすれば `新たな技を学ぶ(3年)` が90日で終わる |
| 訓練を受けるボタンの表示 | 既定 `{name}({price}G)`。代金を変えたときだけこの形で表示し直す |
| 修行内容のボタンの表示 | 既定 `{name}({years}年)`（ゲームの表示と同じ形）。`{name}({days}日)` にすると実日数が出る |
| 代金に足りないときの一言 | 既定 `（訓練の代金{price}Gに足りない ― 手持ち{gold}G）` |

設定は2段ある（`314_` / `130_` と同じ形）。
mod.json の設定が全ワールド共通の一括設定で、
ローダの設定画面の「ワールド別の訓練所設定」を開くとワールドごとに上書きできる。
その世界だけ訓練所を安くする、その世界だけ1年を短くする、といった使い方ができる。
個別の控えは `state\training_custom\<世界名>.json` に、
一括設定と違う項目だけが入る（全部同じならファイルは消える）。

> **活動ごとの年数は変えられない。**
> `ただ鍛える(1年)` `基礎を積む(2年)` `技を磨く(2年)` `新たな技を学ぶ(3年)` の
> 年数はゲームの内側で決まっていて、引数にも出てこない。
> 残り年数の減り方も、残り年数に収まる活動だけを並べる判定も同じ場所に在る。
> 変えられるのは**1年の長さ**のほうで、こちらなら年数の勘定はゲームの中で
> 辻褄が合ったまま暦だけが縮む。
> そのぶん、1年を30日にしても年数の表示は `(3年)` のまま残る。
> 実日数を出したいときは修行内容のボタンの表示を `{name}({days}日)` にする。
>
> 卒業した施設で2回目を受けられないのはゲームの決まりで、この MOD は触らない
> （「十分に学んだ。これ以上ここで得るものはないだろう。」代金も日数も動かない）。

### 他の MOD への窓口

訓練の暦（1年の日数と1回の修行の年数）を、ローダの窓口
`durations`（TECH.md §3.3.2）に置いている。
訓練の長さに合わせたい MOD はそこに聞く。
この MOD は誰が聞くかを知らないし、この MOD を外せば窓口の答えも素のゲームの式に戻る。

日数を当てる側もローダの関所（日数送りは1枚だけが包む）に望みを出す形なので、
同じ日数送りに別の MOD が絡んでも、決めるのはローダの1か所になる。

### 困ったとき

| 症状 | やること |
| --- | --- |
| 代金が設定どおりに引かれない | `out\training_custom.log` の `price:` の行。「the game charged its own 300」が出ていたら、お使いのビルドは代金を引数ではなく別の場所で決めている（差額はその場で戻すので所持金は合う）。デバッグモードで `231_probe_training` を入れて録って、ログを添えて報告してほしい |
| 日数が縮まない | 同じログの `phase:` と `days:` の行。`WARN phase: no elapse_days call` が出ていたら、お使いのビルドの訓練の日数送りが `elapse_days` を通っていない。`231_probe_training` で録って報告してほしい |
| ボタンの表示が変わらない | 代金が素の300Gのままなら表示も元のまま（仕様）。1年の日数だけを変えたときも年数の表示は変わらない（仕様。上の注記） |
| 修行内容のボタンだけ表示が変わらない | 同じログの `no years in the phase label` の行。ゲームが `(N年)` の形をやめたビルドでは年数が読めないので触らない |
| 手持ちが少ないと訓練を受けられない | 設定した代金未満なら仕様。素の300G未満で断られるときはゲーム自身の判定 |

## 3. 検証の記録（`docs\VERIFICATION.md` §3 相当）

### 訓練所の代金・修行の年数・1年の日数（`916_`）: 未実機（2026-09-15、版1）

`231_probe_training` で録れた訓練の暦（GAME.md §2.17）に当てる MOD。
代金と1回の修行の年数は `TrainingStartManager.__init__` の引数を差し替え、
1年で進む日数はローダの関所（TECH.md §3.3.3）へ望みを出す。
活動ごとの年数（1年・2年・2年・3年）と残り年数の減り方はゲームの内側に在って
引数に出てこないので触っていない。

オフラインは `tools\tests\test_wip_training_custom.py`（47項目。偽の訓練所で
代金・拒否・年数・日数・表示・ワールド個別・窓口）で通っている。
残るのは実機で、見るのは8点。訓練所は `915_facility_investment` の道場で開ける。

| # | 確かめること | どう分かるか |
|---|---|---|
| 1 | 代金が設定額で引かれる | 代金を 5000 にして訓練所へ。ボタンが `訓練を受ける(5000G)` になり、所持金が 5000 だけ減る。`out\training_custom.log` に `price: charged 5000 in one deduction` |
| 2 | 代金が引数から決まっている | 同じログに `WARN price: the game charged its own 300` が**出ない**こと。出たらこのビルドは代金を別の場所で決めている（差額はその場で戻すので所持金は合う） |
| 3 | 1年の日数が効く | 1年を 30 日にして `新たな技を学ぶ(3年)` を押す。暦が 90 日だけ進み、ログに `days: 1095 -> 90 (916_training_custom decided 90)` |
| 4 | 修行の年数が効く | 6年にして3年の活動を押す。`あと6年間` と出て、1段目の後も選択肢が並び、2段目で卒業する |
| 5 | 手持ちが足りないと断られる | 代金より少ない所持金で押す。`（訓練の代金◯Gに足りない ― 手持ち◯G）` が出て、暦も所持金も動かない |
| 6 | 訓練の外の日数送りに触らない | 同じセッションで街移動と宿泊をして、`training_custom.log` に `days:` の行が1つも出ないこと |
| 7 | ワールドごとに変わる | 2つの世界に別々の代金を入れて両方をロードする。ボタンの額と引き落としが世界ごとの値になる |
| 8 | 実日数の表示 | 修行内容のボタンの表示を `{name}({days}日)` にすると `ただ鍛える(30日)` と並び、押すとその日数だけ進む |

同じ回で `231_probe_training` を入れておくと、関所より外で**素の日数**（1095 / 730 / 365）が
録れるので、差し替えの前後が1つのログで突き合わせられる。

まだ測っていないのは `231_` の宿題と同じ2つ。
開始時の年数（3）が施設や等級で変わるか、卒業前に施設を出て戻って続きができるか。
どちらもこの MOD の挙動を変えるものではないが、
前者が変わるビルドだと「1回の修行の年数」の既定（3）が素の値でなくなる。
