# `146_fix_save_only_entities`: セーブにしか無い施設・人物で落ちるのを直す

ゲームは世界のデータを2つのファイルに分けて持つ。世界の骨格（`world_data.json`）と、その周回の進み（`savedata.json`）。
セーブエディタで足した施設や人物は、進みの側にしか入っていないことがある。
すると次の場面で、ゲームが骨格の側を探して見つけられず、処理が止まる。

| 場面 | 素のゲームで起きること |
| --- | --- |
| 店・宿屋（`340_inn_shop`）の「売買する」 | 売買の画面が開かない |
| 初めて話す人物・訓練場の教官（人物の詳細を作る） | 会話や訓練の前に処理が止まる。その人物は「詳細を作成済み」の印だけが付き、話し方などが欠けたまま残る |
| 闘技場の「試合に出る」→「申し込む」 | 試合が始まらない |

**既定は切。** 設定の「セーブにしか無い施設・人物をセーブ側から引かせる」を入れたときだけ働く。
骨格に無い施設や人物を探すのが明確なゲームの不具合とは言い切れず、素のゲームでは起きない（セーブエディタで足したときだけ）ため。

入れると、探す相手が骨格の側に無いときだけ、その処理の間だけ進みの側を探させる。
作られた品揃えや人物の詳細は進みの側にだけ入り、骨格には書き足さない。
骨格に入っている施設や人物は、ゲームのまま扱う（品揃えの雛形・人物の詳細・闘技場の相手は骨格にも書かれる）。

`340_inn_shop` は、この設定が入っていれば、骨格に無い宿屋にも「売買する」を出す。切っていると、骨格に無い宿屋には出さない（押すと止まるため）。

| 設定 | 意味 |
| --- | --- |
| セーブにしか無い施設・人物をセーブ側から引かせる | 既定 OFF。入れると上の3つの場面で働く。切ると何もしない |

この MOD が入る前に処理が止まった人物は直らない。話し方が空のまま「作成済み」になっている人物は、前の版のゲームで作られた人物にも多く、見分けが付かないため。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| エディタで足した店で売買がまだ開かない | 設定が入っているか。`out\modloader.log` に `save only entities: off` が出ていれば切れている。入っていれば `out\save_only_entities.log` の `redirect on (shopping: …)` の行。無ければ、その店は骨格にあると判断された（止まった理由は別）。`out\modloader.log` の `KeyError` の数字が何の id かを見る |
| ふだんの店や人物で `redirect on` が出る | 骨格に無い施設や人物。エディタで足した覚えが無ければ、その id を `world_data.json` で確かめる |
