# `149_fix_injury_after_load`: セーブを読み込んだ後も怪我が能力値に効き続ける

依頼の出来事で怪我をすると、部位と怪我の重さに応じて能力値が下がる（胴体の軽傷なら耐久 ×0.95）。
MOD なしのゲームでは、セーブを読み込むと怪我は残ったまま能力値だけが元の値に戻る。
次に依頼の出来事で怪我の判定が走るまで、怪我があっても能力値は下がっていない。

この MOD を入れると、読み込みの直後に怪我を掛けた能力値へ組み直す。

| | MOD なし | この MOD |
| --- | --- | --- |
| 胴体が軽傷・腕が重傷で読み込んだ後の筋力 / 器用 / 耐久（元は 30 / 30 / 30） | 30 / 30 / 30 | 28 / 26 / 28 |

- 怪我が無ければ何もしない
- 怪我を持つのは主人公だけなので、同行者には関わらない
- 体力の上限は MOD なしでも下がったまま読み込まれるので、触らない
- 設定は無い

どの部位がどの能力値を下げているかは、`121_ui_character_sheet` を入れていれば人物欄の健康状態の欄で見られる。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 読み込んだ後も能力値が下がっていない | `out\injury_after_load.log` に `倍率を掛け直した` の行があるか。無ければ、主人公に怪我が無い |
| `WARN` の行が出る | ゲームの更新で能力値の組み直しの関数が変わっている |
