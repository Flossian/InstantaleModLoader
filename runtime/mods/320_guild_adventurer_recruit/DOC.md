# `320_guild_adventurer_recruit`: ギルドの冒険者の補充

素のゲームは、町の冒険者を土地の初回生成で3人作るきりで補充しない。
雇ったり死なせたりして減ると、その町のギルドの「冒険者達と話す」は
以後ずっと閑散としたままになる。

このMODは、一覧で会話できる冒険者が設定人数以下のとき
「冒険者を募集する」のボタンを足す。
押すと新しい冒険者を1人（設定で最大3人）LLMに書かせて、
その町のギルドに入れる。
名前・経歴・性格・口調・見た目はその場で書かれ、
強さはその土地の水準（居る冒険者と依頼の難易度の高いほう）に合わせる。
`318_` で土地が育っていれば、来る冒険者もその分強くなる。

| 設定 | 意味 |
| --- | --- |
| 募集ボタンを出す人数 | 既定 1。一覧で会話できる冒険者がこの人数以下のときだけボタンが出る。0 にすると誰も居なくなるまで出ない |
| 一度に補充する人数 | 既定 1。1人ごとにLLMの生成を1回待つので、多いほど募集に時間がかかる |

募集には所持金はかからない。
生成の間はボタンが「…」の待機表示になる（1人あたり十数秒〜1分程度。LLMの速さ次第）。

作った冒険者はゲーム自身の `npcs` 項目としてセーブに残る。
**MODを外しても消えない**（「MODを消せば完全に元通り」からは外れる）。
HP・スキル・立ち絵は空のまま作り、最初に会話や戦闘をするときにゲーム自身が埋める。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| ボタンが出ない | `out\adventurer_recruit.log` に `offered` の行があるか。無ければ一覧の人数が設定より多いか、画面を冒険者一覧と見分けられていない |
| 押しても誰も来ない | 同ログの `mod_adventurer_recruit:` の行。LLMの応答が読めなかったときは `募集をかけたが、応じる者は現れなかった。` と出て何も作らない |
| 別の町へ移ったら、店主が募集した冒険者になっている | ローダ 1.9.0 より前の `make_npc` はゲームの採番台帳 `index['npc']` を進めなかった。ゲームは町の生成でそこから id を振るので、募集した冒険者の id を踏んで店主の素データを差し替える（GAME.md §2.23）。同ログに `make_npc: index['npc'] -> N` の行が出ていれば直った版 |
| 作られたのに一覧に出ない | 同ログの `make_npc: created` と `enroll:` の行。`enroll: ... via nothing` なら名簿へ書けていない。ゲームがどの名簿から一覧を組むかの確認手順は VERIFICATION.md §3.39 |
| 同じ町で何度も募集できてしまう | 仕様。ただし一覧が設定人数以下のときしかボタンは出ないので、際限なくは増えない |
