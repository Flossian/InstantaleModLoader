## 1. 遊び方（`docs\MODS.md` 相当）

### `911_rival_adventurer`: ライバル冒険者の追加

素のゲームのギルドの冒険者は、雇われるまで何もしない。
この MOD を入れると、依頼をいくつか片付けたところで冒険者の1人がライバルとして現れ、掲示板の依頼を先に片付けようとする。
最初はプレイヤーを見下しているが、先を越したり親しくなったりすると態度が和らいでいく。

```text
[依頼を片付ける]
ギルドの片隅で、冒険者〈名前〉が〈主人公〉を値踏みするように眺めている。…（登場の語り）
[掲示板を開く]
冒険者〈名前〉が、掲示板の「〈依頼〉」に目を付けたようだ。
  〈依頼〉（〈名前〉が狙っている・あと25日）
                ↓ 日数が過ぎる（宿泊・街の移動）
[掲示板を開く]
掲示板から「〈依頼〉」の貼り紙が剥がされている。〈名前〉が片付けたらしい。
```

### 決まり

- ライバルは世界×主人公ごとに1人。ギルドの冒険者（`Area.adventurer_npcs`）の中から、プレイヤーと Lv がいちばん近い人を選ぶ
- 現れるのは依頼を片付けたとき。片付けた依頼（掲示板の依頼の完了数）が2件に届いたら、以後は片付けるたびに50%で抽選する。外れたら次に片付けたときにまた引く。死んだり世界から消えたりしたら、次に片付けたときから同じ抽選で別の人を引く。
  そのとき勝敗・態度・取り合いの記録・話の種は空にするが、ライバルが片付けた依頼は掲示板に戻さない（世界の中ではもう片付いているため）。
  その依頼の噂も、片付けた本人の名前のまま残る
- 現れたときに登場の語りを1度出す。LLM に1回だけ書かせ（裏で書くので依頼の終わりは待たせない）、書き上がって手が空いたときに出す。戦闘・会話・依頼の最中なら、次に掲示板を開いたときに出す。LLM が使えないか、返らないか、長すぎたときは文型の語りを使う
- 語りの材料は、ライバルの経歴・性格・話し方・Lv、世界の概要、プレイヤーの評判。評判は `317_reputation` の二つ名があればそれを、無ければ各地の功績の文（`area_history` の `achievements`）を使う
- 語りと一緒に「張り合う理由」を1文書かせ、ライバル本人の会話に渡す（初対面でもプレイヤーを知っている筋になる）
- 狙いは1度に1件。掲示板を開いたときと日数が進んだときに、その街の依頼から選ぶ（日数が進んだときにその街で狙える依頼が無ければ、ライバルの名簿の街で選ぶ）
- 狙うのは、ライバルの Lv + 10（設定）までの難易度の依頼だけ。物語の依頼・片付いた依頼・受けている最中の依頼・`301_quest_from_conversation` が会話から作った依頼は狙わない（頼んで作ってもらった依頼を横取りさせない）
- 狙われた依頼には、掲示板で名前と残りの日数が添えられる
- 期限（20〜40日後）までにプレイヤーが片付ければプレイヤーの勝ち
- 期限が来るとライバルが挑む。成功率は Lv と難易度の差で決まる（同じなら 60%、Lv 差1につき 3%、10〜95% に収める）
  - 成功：その依頼は掲示板から消え、ライバルの Lv が1上がる
  - しくじり：依頼は残り、ライバルは30日休む（その間は狙わない）。設定で切れば必ず成功する。
    休み明けに同じ依頼を狙い直して片付けたら、しくじりの記録は消える（掲示板で「しくじった」とは知らせず、尻拭いの機会も無くなる）
- 決着の後、10日は次を狙わない
- 日数は宿泊・街の移動・自由行動でしか進まない。依頼の最中は進まないので、目の前の依頼を片付けている間に取られることはない。効いてくるのは「宿に泊まる前に片付けるか」「街を離れる前に片付けるか」
- ライバルを仲間にしている間は張り合わない（狙いは取り下げる）
- ライバルが片付けた依頼は、その街の会話相手が90日間噂にする（会話の文脈に足す。画面には出ない）

### ライバルの態度

態度は4段で、最初は「見下す」。上がるだけで、下がらない。

| 段 | ライバル本人の会話に渡す文（既定） |
|---|---|
| 0 見下す | 格下だと見下していて、口を開けば嫌味や挑発が出る |
| 1 一目置く | 口では張り合っているが、腕は認め始めていて、嫌味にも以前ほどの棘は無い |
| 2 認める | 対等な好敵手と認め、敬意を持って競い合っている |
| 3 慕う | 実力にすっかり感服していて、張り合うより認められたがり、何かと持ち上げる |

段が上がる機会は3つ。

- 先取り：狙われた依頼を先に片付けたとき。1勝ごとに1段（設定）。その場で「態度から棘が抜けた」などの一文を出す
- 尻拭い：ライバルがしくじった依頼をプレイヤーが片付けたとき。1つのしくじりにつき1度、1段（設定で切れる）。その場で「〈名前〉がしくじった〈依頼〉を、代わりに片付けた」と段の一文を出す
- 好感度：ライバルの好感度（ゲーム自身の `relationship.player.affinity`）が上がったとき。30ごとに1段（設定。30 は「興味がある」、60 は「仲間だと感じている」の段。GAME.md §2.25.1）。見るのはライバルと話すときで、会話の文にはすぐ効き、知らせる一文は次に掲示板を開いたときに出す

好感度はゲームの中で会話ではほとんど上がらず、主に依頼へ同行してのクリアで上がる（§2.5）。
ライバルを仲間にして依頼を片付けたときの「共闘」は別の機会として足さず、ゲーム自身の好感度の上がり方に任せる。

### ギルドでライバルから声をかけてくる

ライバルが名簿に載っている街（`326_npc_travel` で旅に出ていれば旅先）のギルドに入ると、話の種があればライバルの方から声をかけてくる。
ゲームの会話そのもの（`300_event_facility_arrival` と同じ起こし方）で、第一声の頼み文だけを「あなたの方から声をかけた。用件: 〈種〉」に読み替える。

| 話の種 | いつ積まれるか | 用件（既定） |
|---|---|---|
| 初対面 | ライバルが現れたとき | 張り合う相手として初めて現れ、名乗りを上げに来た |
| 先を越した | ライバルが依頼を片付けたとき | 〈依頼〉を先に片付けたことを見せつけに来た |
| 先を越された | 狙われた依頼をプレイヤーが先に片付けたとき | 〈依頼〉を先に片付けられ、そのことで声をかけてきた |
| 尻拭いされた | しくじった依頼をプレイヤーが片付けたとき | 自分がしくじった〈依頼〉を片付けられ、そのことで声をかけてきた |

- 種は1つにつき1回だけ使う。初対面は他より先に、残りは新しいものから。溜めておくのは初対面のほかに3つまで（同じ種類は新しい方だけ。初対面は押し出されない）
- 種があれば必ず声をかける（確率は設定で下げられる。0 で声をかけない）
- 登場の語りが書き上がるまでは声をかけない（声かけの後に語りが出て順番が逆になるため。LLM が返らなくても文型の語りが入るので、待ち続けることはない）。書けていてまだ画面に出ていなければ、声をかける前に出す
- 種を使うのは会話を始められた後。始められなければ次の到着でまた使う
- 会話の調子は、ライバル本人に渡す文（態度の段・張り合う理由・最近の取り合い）がそのまま効く
- 声をかけないとき：ライバルを仲間にしている間、戦闘・会話・依頼の最中、施設の最初の画面ではないとき（着いた先で衛兵に見つかったなど）
- `300_event_facility_arrival` も同じ到着で話しかけようとしたら、ローダの窓口 `arrivals`（TECH.md §3.3.7）で 300 が譲る。ライバルの優先度は 10、300 は 0

### ライバル本人が知っていること

ライバルと話すと、会話の文脈（画面には出ない）に次を足す。

- 張り合う理由（登場のときに書いたもの）
- いまの態度の段の文
- 勝敗の数（どちらが何回先に片付けたか）
- 最近の取り合い3件（「〈依頼〉はあなたが先に片付けた」「〈依頼〉は〈主人公〉に先を越された」「〈依頼〉はあなたがしくじった」「〈依頼〉はあなたがしくじった後、〈主人公〉に片付けられた」）
- 今の狙いと残りの日数。しくじって休んでいる間はそのこと

ほかの場面（会話の要約、会話中の行動の判定、雇う交渉、戦闘）には足さない。
会話の要約にはライバルの台詞として張り合いが写りうる（足した文そのものは写らない）。

### ゲームに残るもの

- **ライバルの Lv はセーブに残る**（実行時の人物と素データの両方を上げる）。MOD を外しても下がらない
- 依頼には何も書かない。ライバルが片付けた依頼は `state\rival_adventurer\` の控えで隠しているだけなので、MOD を外すと掲示板に戻る
- 控えより古いセーブを読んだとき（控えを書いてから次の保存までにゲームが落ちたときだけ起きる）は、セーブの日付より後の片付けた依頼・狙い・しくじり・取り合いの記録・話の種と、それが決めた「次に狙ってよい日」を忘れる。
  勝敗の数と態度の段は戻さない（ずれても決着1回ぶん）
- 掲示板の依頼名の添え字は、掲示板を開いたまま保存すると、その画面のボタンの文字として残る。掲示板を開き直せばゲームが組み直すので消える

## 2. 設計の根拠

### 2.1 片付けた依頼に `completed` を書かない

掲示板に出る依頼は「その街の依頼で、`config.status` が `incomplete`」（GAME.md §2.9）。
`completed` にすれば掲示板から消えるが、`317_reputation` は「その土地で `completed` の依頼」をプレイヤーの手柄として評判に編む（`317_reputation/material.py` の `completed_quests`）。
ライバルの手柄がプレイヤーの評判になるので、台帳に控えて掲示板のボタンから外す形にした。

完了した依頼も店の品揃えの母数に入る（`318_` の docstring。GAME.md §2.13.1）ので、隠した依頼をどちらに数えても品揃えは変わらない。

### 2.2 「クエストを探す」は未完了の依頼が2件以上あると出ない

`206_probe_quest_flow` の記録で、掲示板を開いたときの `get_active_quest_count()` と、並んだボタンを突き合わせた（94回）。

| 未完了の数 | 回数 | 「クエストを探す」 |
|---|---|---|
| 0 | 10 | 出る |
| 1 | 31 | 出る |
| 2 | 40 | 出ない |
| 3 | 13 | 出ない |

依頼のボタンの数は、94回中90回で未完了の数と同じだった。
ボタンから外すだけだと、ゲームは隠した依頼をまだ未完了として数えるので、2件取られた街では依頼も「クエストを探す」も無い掲示板になる。
`DisplayQuestChoice.get_active_quest_count` の答えから、その街で隠している未完了の依頼の数を引く。

### 2.3 日数の進み方

依頼の最中は日数が進まない（GAME.md §2.18。クエスト側の LLM 2,029件で `elapse_days` は0件）。
進むのは宿泊（素のゲームで月単位）・街の移動（馬車で14日前後）・自由行動（0〜7日）。
期限の既定 20〜40日は、宿泊1回か街の移動1〜2回で過ぎる長さとして決めた。

### 2.4 冒険者の Lv の幅

手元のセーブ2つで、ギルドの冒険者は27人と26人、Lv は 7〜84 に散らばっていた（主人公は Lv72 と Lv83）。
どの段階のプレイヤーにも Lv の近い相手が居るので、「いちばん近い1人」で選ぶ。

### 2.5 好感度の幅

手元のセーブで会話したことのある NPC 189人の好感度は、0 が154人、10台が1人、20台が23人、40以上が11人だった（最大 162）。
段の境目は 30 / 60 / 100（「興味がある」「仲間だと感じている」「盟友だと思っている」。GAME.md §2.25.1）。
既定の 30 ごとに1段だと、何度か話して「興味がある」に届けば一目置き、「仲間」で認める、という並びになる。

### 2.6 登場の語りを依頼の終わりで待たせない

ゲームの処理（`execute`）は別のスレッドで走るので、その中で LLM を待てば待機表示はゲームが出す（`301_` がこの形）。
ただ依頼の終わりは要約・報酬の流し込みで既に長いので、抽選と台帳の更新だけをそこで済ませ、語りは背景の待ち行列（`jobs.Worker`）で書く。
書き上がったら手が空くのを待って出し、戦闘・会話・依頼の最中なら見送って、次に掲示板を開いたときに出す。
