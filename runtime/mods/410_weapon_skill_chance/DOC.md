# `410_weapon_skill_chance`: 武器にたまにスキルが付く

素のゲームでスキル付きの武器が出るのは店の品揃えだけで、8本に1本ほど。
クラフトで作った武器や、テキストで頼んだ・イベントや依頼で手に入る武器には付かない。

この MOD を入れると、武器が作られたとき・手に入ったときに抽選して、当たった武器にスキルが付く。
スキルの中身（属性・効果・強さ・使用回数）は、ゲーム自身が店の品に使っているスキル生成で品に合わせて作る。
強さは品の価値とレア度で決まるので、良い武器ほど強いスキルになりやすい。
当たる確率は、主人公の INT と DEX が高いほど上がる（作り手の腕前）。
INT と DEX は、装備などの補正を足した値（ステータス画面の `知力: 16(+3)` なら 19）で見る。

- スキル付きの武器は、装備すると戦闘でそのスキルを使える。仲間に装備させれば仲間も使う（下の「仲間の武器のスキル」）
- 説明欄には、スキル名の下に効果と使用回数が出る。ゲームが元から付けたスキルにも出る
- スキルを作るのに LLM を1回使うので、当たったときだけ品が出るまで数秒長くかかる
- 外れた品は引き直さない。もともと持っている武器には付かない

| 設定 | 意味 |
| --- | --- |
| クラフトで作った武器 | 既定 20%。0 にするとゲームのまま（付かない） |
| テキスト・イベントで手に入る武器 | 既定 5%。テキストで頼んで作った武器と、イベント・依頼で手に入る武器。0 にするとゲームのまま（付かない） |
| 店の武器（上乗せ） | 既定 0%。ゲームがスキルを付けなかった店の武器に、もう一度だけ抽選する。店の品揃えを入れ替える MOD（`312_shop_restock` など）が並べた武器と、仲間の初期装備（`407_npc_starting_equipment`）のように、店の主や仲間に作られた武器も、この確率で抽選する。戦闘で敵が持って現れる武器は、テキスト・イベントの確率で抽選する |
| INT・DEX で確率を変える | 既定 ON。主人公の INT と DEX で、上の確率に倍率を掛ける（下の表）。切ると上の確率のまま |
| 倍率を掛ける武器 | 既定「クラフトとそれ以外の武器」。「クラフトだけ」にすると、テキスト・イベントの武器は上の確率のまま。店の武器には掛けない |
| 100% になる値・0% になる値・2段目になる値・3段目になる合計・各段の倍率 | 下の表の数字。既定 60 / 10 / 25 / 61 / 2倍 / 3倍。100% になる値は 0 で使わない |
| 説明欄にスキルの効果を出す | 既定 ON。表示だけで、セーブには残らない |
| 仲間も武器のスキルを使う | 既定 ON。切ると素のゲームのまま（仲間は武器のスキルを使わない） |

INT と DEX による倍率（上から順に見て、最初に当てはまったもの。100% で頭打ち）:

| 主人公の INT・DEX | 確率 | 既定のクラフト 20% / テキスト・イベント 5% のとき |
| --- | --- | --- |
| どちらかが 60 以上 | 必ず付く | 100% / 100% |
| どちらかが 10 以下 | 0（付かない） | 0% / 0% |
| 合計が 61 以上 | 3倍 | 60% / 15% |
| どちらも 25 以上 | 2倍 | 40% / 10% |
| それ以外 | そのまま | 20% / 5% |

設定を変えたら、ゲームを起動し直すと効く。

## 仲間の武器のスキル

素のゲームでは、仲間はスキル付きの武器を持っていても、そのスキルを使わない。
仲間の技は本人のスキル一覧から選ばれ、武器のスキルはそこに入らないため。

この MOD は戦闘の間だけ、仲間が身に着けている品のスキルを仲間の技に加える。
仲間の手番で、AI の審判がほかの技と同じようにそれを選ぶ。

- 使った回数は武器に残る。仲間の残りは宿屋で休養すると上限へ戻る
- 戦闘が終わると技の一覧から外す。セーブの仲間の技にも入らない
- 仲間が同じ名前の技を元から持っていれば、本人の技のほうを残す
- 素のゲームでは仲間に装備させられない。`402_party_inventory_transfer` の受け渡しのウィンドウで仲間の装備欄へ入れる
- 使い切ったスキルを選ばせないのは `137_fix_npc_skill_uses`。入れていないと、回数が尽きても選ばれ続ける

## 知っておくこと

- スキルの効果のうち、能力値を上げ下げするもの（強化・弱体）は、素のゲームの戦闘では数値に効かない。
  `319_battle_tactics` を入れていれば状態異常として効く
- 「敵単体」のスキルでも、戦闘の判定が複数の敵に当てることがある。
  ゲーム自身の判定のくせで、この MOD のスキルに限らず起きる
- `129_balance_item_price` を入れていると、スキル付きの武器は値段が上がる

## 困ったとき

| 症状 | やること |
|---|---|
| スキルが一度も付かない | `out\weapon_skill_chance.log` を見る。`INT=… DEX=… -> low` なら能力値が低くて 0%。`missed the` だけなら抽選に外れている |
| `skill generation failed` が出る | LLM の応答が受け取れなかった。品はスキル無しのまま。続くならその行ごと報告する |
| 説明欄に効果が出ない | 設定「説明欄にスキルの効果を出す」が ON か。スキルの無い品には出ない |
| 仲間が武器のスキルを使わない | 戦闘の始めに `battle: <仲間> can use '<スキル>'` の行が出ているか。出ていなければ、仲間がその武器を装備欄に入れていない。出ていれば、審判がほかの技を選んでいるだけ |
| ログに何も出ない | `out\modloader.log` に `weapon skill chance: installed` の行があるか。MOD が読み込まれているか |
