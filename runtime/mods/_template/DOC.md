# `_template`: 新しい MOD を作るときの雛形

遊ぶ側から見て何が変わるかをここに書く（TECH.md §2.7）。
`docs\MODS.md` はこの1枚を綴じ直したもので、`tools\build_mods.py` が組む。

1行目の名乗りはフォルダ名と合っていないと生成が止まる。
コピーして番号を付けたら、ここも一緒に書き換える。

綴じるときに見出しが2つ下がる（`#` → `###`、`##` → `####`）ので、
中の小見出しは `##` で書く。

設定がある MOD は表にする。`mod.json` の `settings` と同じものを、
遊ぶ側の言葉で書く（この雛形に設定は無い）。

| 設定 | 意味 |
| --- | --- |
| （`label` の日本語） | 既定値と、変えると何が変わるか |

## 困ったとき

効かなかったときに何を見ればいいかを書く。
`out\` のどのログの、どの行かまで書けると、報告がそのまま材料になる。

| 症状 | やること |
|---|---|
| 何もログに出ない | `out\modloader.log` の `applied` の行。MOD が読み込まれているか |
