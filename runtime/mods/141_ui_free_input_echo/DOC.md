# `141_ui_free_input_echo`: 会話の外で送った文も本文に残す

会話の中で送った文は、ゲームが「主人公名: 文」の1行で本文に出す。
会話の外（自由行動・戦闘・裁判の釈明など）で送った文は、本文のどこにも出ない。
GM の語りがいきなり始まるので、読み返すと自分が何をしたのか分からない。
この MOD は、会話の外で入力欄から送った文を、そのまま1行で本文に足す。
発言に見えないよう、名前は付けない。

足すのはゲームが送信を受け付けたときだけで、会話の中では足さない（ゲームが出すので2行になる）。
`122_ui_conversation_log` を入れていれば、読み返しの窓にも同じ行が残る。
送った文の中身や、ゲームへの渡し方は変わらない。

記録は `out\free_input_echo.log`（送信ごとに送り先と出したかどうかを1行。300行まで）。

## 困ったとき

| 症状 | やること |
|---|---|
| 送った文が本文に出ない | `out\free_input_echo.log` を見る。`echoed` なら出している。`send was not dispatched` ならゲームが送信を受け付けていない。行が無ければ MOD が当たっていない（`modloader.log` を見る） |
| 会話の中で自分の発言が2行出る | `out\free_input_echo.log` のその送信の行に出ている送り先の名前を添えて知らせる |
