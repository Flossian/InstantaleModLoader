# `317_reputation`: 評判と二つ名

プレイヤーの行いから土地ごとの評判を編み、会話する NPC に渡す。
初対面の相手が「噂は聞いている」から入る。
1つの土地で名が上がるとその土地での呼び名が付き、複数の土地に評判が立つと世界に1つの二つ名で呼ばれるようになる。

```text
【陽光の砦での<プレイヤー名>の評判】
盗賊団を退けた者としてよく知られている。
この土地では「<呼び名>」と呼ばれている。
土地を問わず「<二つ名>」の二つ名で知られている。
これはこの土地に広まっている噂で、あなたも耳にしている。
<プレイヤー名>への好悪はあなた自身の性格が決める。
```

素材は**ゲーム自身が既に書いているもの**（`area_history` の成した事・手配度・
完了した依頼・物語の依頼・闘技場の戦績・滞在日数）。
この MOD が新しく記録するのは悪名の累計だけ（下の「名声と悪名」）。
読み込み・移動・日送りのたびに評判の立つ土地をすべて照合し、素材が変わった土地だけ別スレッドで LLM を1回ずつ回して評判文へ編纂する。
その土地に着くのを待たないので、読み込んだ時点で各地の評判と呼び名がそろう（遊び込んだ世界を初めて読み込んだ回は、評判の立つ土地の数だけ LLM を呼ぶ）。
会話フックの中では編纂済みの文字列を注入するだけなので、会話は遅くならない。
セーブには一切書かず、編纂した文は `state\reputation\` に置く。

## 評判は土地ごと、二つ名は世界に1つ

- 評判が立つのは「成した事＋完了した依頼＋果たした物語の依頼＋闘技場の勝ちが既定2件以上」または「手配中」の土地だけ。
  何も成していない土地では**何も注入しない**（素のゲームと同じ挙動）
- 注入するのは NPC が「知っている」情報だけで、好悪は書かない
  （好意・敵意の向きは NPC の性格が決める。`125_` が直した轍を踏まないため）
- 呼び名は、その土地の名声と悪名の合計が既定 100 以上になってから、評判と一緒に編む。その土地の会話にだけ渡す
- 二つ名は、名声と悪名の合計が既定 100 以上で、評判の立つ土地が2つ以上になってから付く。
  それまでは土地の評判だけを渡す
- 呼び名も二つ名も、プロンプトにいままでの名を渡すので、覆す材料が無ければ同じ名が続く
- 二つ名は各地の評判文から編み、**質的な変化**（評判の立つ土地の増減・手配の反転・
  行いの倍増）のときだけ編み直す
- 二つ名は `121_ui_character_sheet` の人物欄（レベル行の続き）に出る。
  右の引き直しのボタンで引き直せる（いまの名を除いて編み直す）

## 名声と悪名

開始の村で害獣の駆除を数件片付けただけで、名が土地を越えて広まるのは早すぎる。
そこで呼び名と二つ名は、件数ではなく行いの重さで数えた名声と悪名が届いてから付ける。

| 足すもの | 数え方 |
| --- | --- |
| 片付けた依頼 | 1件ごとに難易度の2乗÷25。難易度 25 の依頼で 25、50 で 100、開始の村の依頼（難易度 1〜5）は1件 1 にも満たない |
| 依頼の付かない成した事 | 道が開けた・街の出来事など。その土地の依頼の難易度の中央値で同じく数える |
| 果たした物語の依頼 | 同じ数え方の2倍 |
| 闘技場の勝ち | 破った相手の格で同じく数える（闘技場の格は依頼の難易度と同じ目盛り） |
| 悪名 | 手配が重くなった分の累計。名声とは別に数える |

- 2乗で数えるので、軽い依頼を何件重ねてもほとんど増えず、重い依頼ほど大きく効く
- 既定の 100 は、中盤の街の依頼4件、または難易度 50 の依頼1件に当たる。開始の村の依頼では届かない
- 悪名は手配の重さ（手配度が 0 を下回った分）が増えるたびに、その分を足す。
  時効・罰金・恩赦で手配が軽くなっても減らない。また重くなれば、また足す
- 名声はゲームの記録から毎回数え直す。悪名だけはゲームに経過が残らないので、この MOD が照合のたびに見て積む。
  入れる前の罪と、この MOD を切っていた間の罪は、入れたときの手配の重さから数え始める
- 片付けた依頼の成した事は依頼と同じ出来事なので、二重には数えない
- 届く前に付いていた二つ名（版5まで）は出さない。届いたときに、前の名を引き継がずに付け直す

## 評判の画面

画面左下の MOD 用のボタンの一覧から「評判」を開くと、次のものが見られる。

- 上の枠: 二つ名（まだなら付く条件）と、名声＋悪名の目盛り、評判の立つ土地の数
- 下の「各地の評判」の枠: 土地ごとの札（名声＋悪名の大きい順）。土地の名前と呼び名、名声・悪名・手配度、その土地の評判の文
- 二つ名と、呼び名の付いた土地の札の右に、再生成のボタン（人物欄の引き直しと同じさいころの絵）。
  いまの名を除いて付け直し、終わると画面が開き直して新しい名が出る。付け直している間はさいころが薄くなり押せない。
  土地の呼び名の再生成は呼び名だけを付け直し、評判の文はそのまま（前の編纂の後に行いが増えていた土地だけ、評判の文も編み直す）

開いた瞬間に名声と悪名を数え直すので、出ている数はそのときの値。
開いている間に編纂が終わったときも、画面が開き直して新しい評判が出る。

## 設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 会話に効かせる | ON | 会話5関数で、話し相手の複製の profile に評判を足す |
| 情景描写に効かせる | OFF | narrator に渡る player_profile に評判を足す |
| 二つ名を使う | ON | OFF なら二つ名を付けない。二つ名の編纂も止まる |
| 二つ名が付く名声＋悪名 | 100 | 名声と悪名の合計がこれに満たなければ二つ名は付かない |
| 二つ名が付く土地の数 | 2 | 評判の立つ土地がこれに満たなければ、名声が足りていても付かない |
| 土地ごとの呼び名を使う | ON | OFF なら呼び名を付けない |
| 呼び名が付く土地の名声＋悪名 | 100 | その土地の名声と悪名の合計がこれ以上で呼び名が付く |
| 二つ名の文字数の上限 | 8 | 呼び名にも使う。超えた名は切り詰めずに捨てて前の名を残す |
| 二つ名の長さを揺らす | ON | 編纂のたびに狙う長さを3〜上限で引いてプロンプトに載せる |
| 評判が立つ最低件数 | 2 | 満たない土地では何も注入しない。手配中の土地は件数を問わない |
| 注入の長さ | 短い | 短い=1文120字 / 詳しい=3文300字。プロンプトは毎回全文載るので短い方が安全 |
| 素材の形をログに残す | ON | 起動ごとに1回、`out\reputation.log` に素材の形を出す |

## 二つ名が編み直される契機

二つ名は噂話が属人化したものなので、行いが1件増えるたびに変わっては困る。
名声が届いた後、編み直すのは**質的な変化**の3つだけで、どれも既にある素材から数えている。

| 契機 | 意味 |
| --- | --- |
| 評判の立つ土地が増減した | 噂の届く範囲が変わった。役場で手配を解いて外れる側も拾う |
| 手配が反転した（`lawfulness` が 0 をまたぐ） | 善悪の転換。人物像を覆す筆頭 |
| 全土地の行いの合計が**前回編纂時の2倍**になった | 「駆け出しの◯◯」が古びる頃合い。倍々なので終盤ほど動かない |

加えてプロンプトにいままでの名を渡し「明確に覆すのでなければ同じ名を返す」と縛る。
契機で回数を、指示で結果を絞る二段構えなので、
節目が来ても人物像が変わっていなければ名は据え置かれる。
呼び名はその土地の評判を編み直すたびに一緒に頼むが、同じくいまの名を渡して据え置きを既定にする。

## 素材とプロンプトの重なり

ゲーム自身が会話に `area_achievements`（その土地で成した事）を渡している
（GAME.md §2.24）。素材をそのまま要約し直すと同じ事実が言い換えで2度載るので、
編纂のプロンプトで「出来事を並べ直さない」と縛り、注入は既定で1文120字までにしてある。
プロンプトは毎回全文が送られる（`311_` 併用時は会話開始時点で2,206字の実測）ので、
長くするほど他の内容を押し出す。

## 控えの形（`121_` と共有している）

編纂した文は `state\reputation\<世界名>×<主人公名>.json` に入る（版4）。
評判も二つ名も主人公の行いから編むので、同じ世界で主人公を作り直すと、新しい主人公は評判なしから始まる。
同じ名前で作り直したときは同じ主人公とみなして引き継ぐ。
版3までの `<世界名>.json` は、その世界を次に遊んだ主人公のものとして移す。
その世界を別の主人公でも遊んだことがあれば、誰のものか分からないので移さない。
人物欄に二つ名を出す `121_ui_character_sheet` はこのファイルを読む
（MOD どうしは import しない決まりなので、繋がるのはファイルだけ。TECH.md §3.2.3）。
**鍵と並びは MOD をまたいだ取り決め**なので、読む側が居る前提で固定してある。

```json
{"areas": {"7": {"area": "7", "name": "<エリア名>", "day": 120,
                 "updated": "<書いた時刻。YYYY-MM-DD HH:MM:SS>",
                 "reputation": "<編纂した評判の文>",
                 "nickname": "<呼び名>",
                 "fingerprint": "<素材の指紋。16桁の16進>"}},
 "epithet": {"epithet": "<二つ名>",
             "description": "<名の由来>",
             "day": 120, "updated": "<書いた時刻>",
             "mark": {"qualifying": ["3", "7"], "wanted": [], "deeds": 6, "fame": 160}},
 "fame": {"total": 130, "notoriety": 30, "threshold": 100, "lands": 2, "min_lands": 2,
          "eligible": true, "land_threshold": 100,
          "areas": {"3": {"fame": 40, "notoriety": 30, "standing": true},
                    "7": {"fame": 90, "notoriety": 0, "standing": true}}},
 "notoriety": {"3": {"total": 30, "last": 10}}}
```

- `description` は**ゲームには出さない内部データ**。
  後から控えを読んだときに名の由来を追うためのもの
- `nickname` は呼び名の線を越えた土地にだけある。空文字は「頼んだが名が付かなかった」
- `fingerprint` / `mark` は編纂し直すかの判定に使う印。手で消すと次の照合で編み直る。
  `mark.fame` は名声＋悪名
- `fame` は照合のたびに数え直した名声と悪名の写し（版6）。`areas` は名声か悪名が 0 でない土地と、評判の立つ土地（`standing`）。
  人物欄は `eligible` が false のあいだ二つ名を出さない。
  `fame` が無いファイル（版5まで）は、読んだ直後の照合で足される
- `notoriety` は積んだ悪名（`total`）と、前の照合で見た手配の重さ（`last`）。
  この欄だけはゲームの記録から作り直せない。消すと悪名はいまの手配の重さから数え直しになる
- 人物欄の引き直しボタンは `<世界名>×<主人公名>.reroll.json` を書き、この MOD が次の照合で消す
  （在るかだけを見て、中身は読まない）
- この MOD を切ると人物欄の二つ名も消える（`121_` はファイルが無ければ何も足さない）

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 評判が出ない | `out\reputation.log`。「素材が薄いので評判を立てない」なら件数が既定未満（そのまま遊べば立つ）。「評判はまだ無い」なら編纂前（読み込み・移動・日送りで編纂が走る） |
| 二つ名や呼び名が付かない | まず評判の画面で名声・悪名・評判の立つ土地の数を見る。線に届いていなければ仕様（そのまま遊べば付く）。届いているなら同ログの「二つ名:」「呼び名:」の行。「読めなかった」が続くなら LLM が JSON を返していない。素材が揃っていれば次の照合で引き直す |
| 二つ名や呼び名が変わらない | 仕様（質的な変化のときだけ編み直し、覆す材料が無ければ据え置く）。変えたければ評判の画面の再生成のボタン（二つ名は人物欄の引き直しのボタンでも） |
| 引き直しても同じ名になる | 同じ評判からは同じ連想が出やすい。もう一度押すか、上限や「長さを揺らす」を変えると散る |
| 会話が重くなった気がする | この MOD は会話中に LLM を呼ばない。編纂は別スレッドで、`output_data\` の `mod_reputation_compile` / `mod_reputation_epithet` にプロンプトと返答が残る |
