# `317_reputation`: 評判と二つ名

プレイヤーの行いから土地ごとの評判を編み、会話する NPC に渡す。
初対面の相手が「噂は聞いている」から入り、世界に1つの二つ名で呼ばれることもある。

```text
【アッシュでのアーリの評判】
盗賊団を退けた者としてよく知られている。
土地を問わず「灰の街の盾」の二つ名で知られている。
これはこの土地に広まっている噂で、あなたも耳にしている。
アーリへの好悪はあなた自身の性格が決める。
```

素材は**ゲーム自身が既に書いているもの**だけ（`area_history` の成した事・手配度・
完了した依頼・滞在日数）。この MOD が新しく記録を始めるものは無い。
素材が変わったときだけ別スレッドで LLM を1回回して評判文へ編纂し、
会話フックの中では編纂済みの文字列を注入するだけなので、会話は遅くならない。
セーブには一切書かず、編纂した文は `state\reputation\` に置く。

## 評判は土地ごと、二つ名は世界に1つ

- 評判が立つのは「成した事＋完了した依頼が既定2件以上」または「手配中」の土地だけ。
  何も成していない土地では**何も注入しない**（素のゲームと同じ挙動）
- 注入するのは NPC が「知っている」情報だけで、好悪は書かない
  （好意・敵意の向きは NPC の性格が決める。`125_` が直した轍を踏まないため）
- 二つ名は各地の評判文から編み、**質的な変化**（評判の立つ土地の増減・手配の反転・
  行いの倍増）のときだけ編み直す。頼み文にいままでの名を渡すので、
  覆す材料が無ければ同じ名が続く
- 二つ名は `121_ui_character_sheet` の人物欄（レベル行の続き）に出る。
  右の ⟲ ボタンで引き直せる（いまの名を除いて編み直す）

## 設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 会話に効かせる | ON | 会話5関数で、話し相手の複製の profile に評判を足す |
| 情景描写に効かせる | OFF | narrator に渡る player_profile に評判を足す |
| 二つ名を使う | ON | OFF なら評判文のみ。二つ名の編纂も止まる |
| 二つ名の文字数の上限 | 8 | 超えた名は切り詰めずに捨てて前の名を残す |
| 二つ名の長さを揺らす | ON | 編纂のたびに狙う長さを3〜上限で引いて頼み文に載せる |
| 評判が立つ最低件数 | 2 | 満たない土地では何も注入しない。手配中の土地は件数を問わない |
| 注入の長さ | 短い | 短い=1文120字 / 詳しい=3文300字。プロンプトは毎回全文載るので短い方が安全 |
| 素材の形をログに残す | ON | 起動ごとに1回、`out\reputation.log` に素材の形を出す |

## 二つ名が編み直される契機

二つ名は噂話が属人化したものなので、行いが1件増えるたびに変わっては困る。
編み直すのは**質的な変化**の3つだけで、どれも既にある素材から数えている。

| 契機 | 意味 |
| --- | --- |
| 評判の立つ土地が増減した | 噂の届く範囲が変わった。役場で手配を解いて外れる側も拾う |
| 手配が反転した（`lawfulness` が 0 をまたぐ） | 善悪の転換。人物像を覆す筆頭 |
| 全土地の行いの合計が**前回編纂時の2倍**になった | 「駆け出しの◯◯」が古びる頃合い。倍々なので終盤ほど動かない |

加えて頼み文にいままでの名を渡し「明確に覆すのでなければ同じ名を返す」と縛る。
契機で回数を、指示で結果を絞る二段構えなので、
節目が来ても人物像が変わっていなければ名は据え置かれる。

## 素材とプロンプトの重なり

ゲーム自身が会話に `area_achievements`（その土地で成した事）を渡している
（GAME.md §2.24）。素材をそのまま要約し直すと同じ事実が言い換えで2度載るので、
編纂の頼み文で「出来事を並べ直さない」と縛り、注入は既定で1文120字までにしてある。
プロンプトは毎回全文が送られる（`311_` 併用時は会話開始時点で2,206字の実測）ので、
長くするほど他の内容を押し出す。

## 控えの形（`121_` と共有している）

編纂した文は `state\reputation\<世界名>.json` に入る。
人物欄に二つ名を出す `121_ui_character_sheet` はこのファイルを読む
（MOD どうしは import しない決まりなので、繋がるのはファイルだけ。TECH.md §3.2.3）。
**鍵と並びは MOD をまたいだ取り決め**なので、読む側が居る前提で固定してある。

```json
{"areas": {"4": {"area": "4", "name": "ルナ・ミスト", "day": 4393,
                 "updated": "2026-08-24 15:43:07",
                 "reputation": "崩落や怪物を討ち果たした流れ者として知られている。",
                 "fingerprint": "650e28d622cf021b"}},
 "epithet": {"epithet": "浄化の嵐",
             "description": "各地の脅威を払ったという評判から来た名。",
             "day": 4393, "updated": "2026-08-24 15:50:11",
             "mark": {"qualifying": ["4"], "wanted": [], "deeds": 6}}}
```

- `description` は**ゲームには出さない内部データ**。
  後から控えを読んだときに名の由来を追うためのもの
- `fingerprint` / `mark` は編纂し直すかの判定に使う印。手で消すと次の照合で編み直る
- 人物欄の引き直しボタンは `<世界名>.reroll.json` を書き、この MOD が次の照合で消す
  （在ることが頼みで、中身は読まない）
- この MOD を切ると人物欄の二つ名も消える（`121_` はファイルが無ければ何も足さない）

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 評判が出ない | `out\reputation.log`。「素材が薄いので評判を立てない」なら件数が既定未満（そのまま遊べば立つ）。「評判はまだ無い」なら編纂前（移動か日送りで編纂が走る） |
| 二つ名が付かない | 同ログの「二つ名:」の行。「読めなかった」が続くなら LLM が JSON を返していない。素材が揃っていれば次の照合で引き直す |
| 二つ名が変わらない | 仕様（質的な変化のときだけ編み直し、覆す材料が無ければ据え置く）。変えたければ人物欄の引き直しボタン |
| 引き直しても同じ名になる | 同じ評判からは同じ連想が出やすい。もう一度押すか、上限や「長さを揺らす」を変えると散る |
| 会話が重くなった気がする | この MOD は会話中に LLM を呼ばない。編纂は別スレッドで、`output_data\` の `mod_reputation_compile` / `mod_reputation_epithet` に頼み文と返答が残る |
