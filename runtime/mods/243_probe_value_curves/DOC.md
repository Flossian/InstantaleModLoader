# `243_probe_value_curves`

難易度と品の価値から数を作るゲームの関数が、76 を超えたときにどう振る舞うかを録る。セーブを読み込んだ後に1プロセス1回、報酬・才能点・働いた報酬・訓練の経験・品の値段の段・武器と回復の数値・NPC の数・段ごとの敵・スキルの有用性・切りを、包む前の素の関数で 0〜100 の全部の値について呼び、曲線と値が最後に変わった所（`plateau_from`）と最初の例外を残す。値段→段階の逆引きと、持ち物の写しで測る品の値段も録る（乱数の状態は戻す）。遊んでいる間は、品を作る入口の中で呼ばれた数値の関数と、切りが値を切った回を呼び出し元つきで残す。76 を超えた難易度と品の価値を報酬と品の強さにも効かせる MOD の下調べ（VERIFICATION.md §3.112 の続き）。出力は `out\value_curves.log` / `out\value_curves.jsonl`
