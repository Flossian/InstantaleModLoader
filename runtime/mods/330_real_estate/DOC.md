# `330_real_estate`: 家を借りる・買う

素のゲームで腰を落ち着けられる場所は宿屋だけで、泊まるたびに宿代と30日を払い直す。
荷物を置く場所も無く、24マスが埋まったら捨てるしかない。

この MOD は役場の選択肢に、家を借りる・買うための窓口を1つ足す。

```text
[役場]  労働の募集をみる / 市民権の発行 / 家を借りる・買う / 出る
                                ↓
        借りる(1,600G・480日) / 建売を買い取る(30,000G) / やめる
                                ↓
        その街の入口に建物が1軒増える

[入口]  中央居住区 / 外縁スラム / 借りている家 ←これ / 街を出る
                                ↓
[家]    滞在する / 保管庫をあける / 家から出る
```

建物はその土地の入口に繋ぐ。
街に着いて最初に立つのが入口で、区画（`ward`）はその先にある。
自分の家は区画の奥ではなく、着いてすぐ入れる場所に置いてある。

物件は土地ごとに1軒。
別の街の役場へ行けば、その街にもう1軒持てる。

## 建物の中でできること

| | |
| --- | --- |
| 滞在する | 宿屋の宿泊とまったく同じ経路。休養・訓練・労働・物乞いから1つを選ぶ。宿代は取られない。暦は宿屋と同じく30日進む（賃貸なら、その30日ぶんの家賃は引かれる） |
| 保管庫をあける | 仲間へアイテムを渡すときと同じ2枚並びの窓が開く。左が自分、右がこの保管庫。ドラッグでどちらの向きにも移せて、移した時点で保存される |
| 家から出る | 入口へ戻る。ゲームは自分で足した施設の出口を作らないので、この1つも MOD が出している（VERIFICATION.md §3.62） |

宿屋の活動のうち2つは自分の家では出ない（宿屋の側はそのまま）。

| 出さない活動 | 理由 |
| --- | --- |
| 他者と交流 | 誰と会うかを決めるのはゲームで、自分の家では大家（物件を貸した役場の役人）が相手になる。その場面は通らない |
| アイテム作成 | 自分の家ではまだ成り立っていない |

1回の滞在でできる活動は1つ（素のゲームの宿泊と同じ「1泊＝活動1回」）。
活動を1つ終えるとその滞在は終わり、建物の選択肢に戻る。
もう一度過ごしたければ「滞在する」を押し直せばよい（宿代は取られず、暦だけ進む）。

> `327_inn_quality` は宿屋で部屋の等級に応じて活動の数を増やすが、
> 自分の家では増えない。ここは等級によらず1回に固定してある。

滞在の部屋の等級は設定で決める（既定は個室）。
効くのは描写と、等級を読む MOD（活動の数以外）。家の中の絵はゲームが名前で生成する（VERIFICATION.md §3.62）。

## 保管庫は建物ごと／世界で1つ、どちらにもできる

既定は建物ごと。
その家に預けた品は、その家でしか出し入れできない。

設定の「保管庫を世界で1つにする」を入れると、どの物件からも同じ中身が開く。
街から街へ荷物を持ち回らずに済む形で、離れた土地の家に預けた品もその場で取り出せる。

切り替えたときの中身は次のように動く。

| 切り替え | 預けてあった品 |
| --- | --- |
| 建物ごと → 世界で1つ | 次に保管庫を開いたとき、各建物の中身が共有の側へ移る（1度だけ。ログに `moved N item(s)` が出る） |
| 世界で1つ → 建物ごと | 共有の側に残る。どの建物へ返すか決められないので動かさない。設定を戻せばまた同じ中身が見える |

契約が切れたときの扱いも少し違う。
建物ごとなら、その家の保管庫が役場の預かりになる。
世界で1つのときは、ほかに物件が残っているあいだは取り上げない（別の家から同じ中身を開けるため）。
最後の1軒を失ったときだけ、開く手段が無くなるので役場へ移る。

## 家賃と期限

賃貸の1期は、宿泊4回ぶんの日数。
1期を1回ぶんにすると、家を借りても宿に泊まり直すのと変わらないので、
既定は4回ぶんをまとめて借りる形にしてある。
その間は何度でも戻って過ごせて、家賃は1度きり。

宿泊1回の長さはゲームの宿屋と同じで、自分の家の滞在もその長さで起きる。
素のゲームは3ヵ月から年齢で伸びる変動式（30代 +1・40代 +2・50代以上 +3、上限6ヵ月）。
`315_vacation_custom` で宿泊期間を変えていれば、そちらが効く。
この MOD は自分では決めず、宿屋で実際に使われた月数を覚えて使う。
まだ宿屋に泊まっていない世界では年齢から見積もる。

```text
31歳・素のゲーム    宿泊4ヵ月＝120日 → 1期 480日
315 で1ヵ月に変更   宿泊30日        → 1期 120日
```

契約の周期は、結んだ時点の長さで固定する。
年を取って宿泊が伸びても、いま借りている契約の期限は動かない。

引かれるのは日数が進んだとき（移動・宿泊・依頼）で、何期ぶんか飛んだ場合はまとめて払う。

期限が近づくと1行出る。

```text
借りている家の契約はあと5日で切れる。
```

所持金が足りない日が来ると契約は切れる。
建物は街から消え、保管庫にあった品は役場が預かる。
預かった品は、どこの役場でも引き取り料（既定 2,000G）を払えば戻る。

建売（買い取り）には家賃も期限も無い。

自分から引き払うときは、窓口の「解約する」。
このときも保管庫の中身は役場の預かりになるので、先に引き取ってから解約するほうが安い。

## 建物はセーブに残らない

足しているのは遊んでいる最中の街だけで、世界のファイルにもセーブにも施設は書かない。
ロードのたびに建て直していて、MOD を外せば街は素のままに戻る。
建物も、そこへ繋がる道も残らない。

控えは2つに分かれている。

| ファイル | 中身 |
| --- | --- |
| `state\real_estate\<世界名×主人公名>.json` | 契約（いつまで・いくら）と保管庫の中身、役場の預かり |
| `state\modfacility\<世界名×主人公名>.json` | 建物そのもの（名前・説明・どの土地のどこに建っているか） |

建物のほうはローダが持っている（この MOD だけのものではない）。

保管庫の中身は契約と同じ控えの中にある。
預けた品はプレイヤーの持ち物から外れるので、預けた時点でゲーム自身の保存が走る。

> MOD を外すと、控えは残るが建物は建たない。
> 保管庫に預けたままの品はその控えの中に居るので、入れ直せば戻る。

| 設定 | 意味 |
| --- | --- |
| 家賃 | 既定 1,600。1期ぶん |
| 賃貸の1期＝滞在何回ぶん | 既定 4。宿泊1回の長さは宿屋と同じ（素は3ヵ月から年齢で伸び、315 を入れていればその設定） |
| 建売の価格 | 既定 30,000。買い切りで、以後の家賃も期限も無い |
| 家賃を自動で払う | 既定 ON。切ると、期限が来た時点で必ず契約が切れる |
| 期限を知らせる日数 | 既定 7。0 で知らせない |
| 預かり品の引き取り料 | 既定 2,000 |
| 保管庫を世界で1つにする | 既定 OFF＝建物ごと。ON にすると、どの物件からも同じ中身が開く |
| 滞在の部屋の等級 | 既定 個室（`private_room`）。ゲームの宿屋と同じ語彙（長さは宿屋と同じなので設定は無い） |
| 借りた物件の名前 / 買った物件の名前 | 街の中に並ぶときの名前 |

## 世界ごとに分かれている

契約も、保管庫も、役場の預かりも、**世界ごとに別**。
控えのファイルが世界ごとに1つできる（`state\real_estate\<世界名×主人公名>.json`）。

| もの | 分かれ方 |
| --- | --- |
| 契約（どの土地に何を借りたか） | 世界ごと |
| 保管庫の中身 | 世界ごと。「世界で1つ」の設定も、その世界の中で1つ |
| 役場の預かり品 | 世界ごと |
| 覚えた宿泊期間 | 世界ごと |
| 建物 | その世界を遊んでいる間だけ建つ。別の世界を読むと消える |

見分けているのは**セーブの世界名**（`world_data.name`）。
だから外部のツールで世界名を書き換えると、その世界の控えは引けなくなる
（ファイルは残るので、名前を戻せば戻る）。
同じ名前の世界を2つ作った場合も、同じ控えを共有する。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 役場に「家を借りる・買う」が出ない | 会話・戦闘・買い物の最中は出さない。それ以外で出ないときは `out\real_estate.log` に `office` の行があるか |
| 借りたのに建物が見当たらない | 同じログの `modfacility: built` の行。無ければ `WARN sign:` か `WARN modfacility:` を見る（`no hub facility` はその土地に入口も広場も無い） |
| 街の一覧に建物が並ばない | ゲームはこの施設を一覧に出さないので、道は MOD が足している（機能は同じ）。ボタンも無いときは、その土地の契約が切れている |
| 建物に入っても選択肢が出ない | ログの `modfacility: where:` の行。`inside=-` なら居場所の読み取りが外れている（その行の `facility=` が家の id か見る）。契約が切れた建物は取り壊し待ちなので、出口だけを出す |
| 家の中なのに背景が街の景色のまま | 初めて入るときは生成の待ちがある（ゲームが名前で生成する。ローダは絵に触らない）。出ないなら `location_image` の値を添えて報告してほしい |
| 家から出られない | 上と同じ。出口はゲームの移動を起こすだけなので、動かないときは `WARN modfacility: cannot reach` が出ているはず |
| 滞在で宿代が引かれた | ログの `stay: refunded` が無ければ返せていない。滞在では暦が30日進むので、同時に家賃も引かれる（そのぶんは返らない。行の末尾に額が出る） |
| 交流を選ぶと止まる | ログの `WARN background: the game's own ... raised` があれば、本体の不具合を握って先へ通している（絵が変わらないだけ）。無いのに止まるなら別の原因なので、`crash_log.txt` の当日分を添えて報告してほしい |
| 滞在を押すと「…」のまま戻らない | ログの `WARN stay: the game's stay failed:` の行。ゲームの宿泊が落ちた記録で、例外の種類とそのときの建物の姿が出る。この場合でも宿代は返り、操作は戻るはず（戻らなければその行を添えて報告してほしい） |
| 保管庫が開かない | `WARN storage:` の行。`cannot build the holder` なら、試した3通りの失敗が並んでいる（ゲームの更新で持ち主の作り方が変わった合図）。`the holder has no inventory dict` は持ち物の持ち方が変わった合図 |
| 預けた品が次に遊んだら消えた | ログの `storage sync` と `save_game complete` が並んでいるか。控えは `state\real_estate\<世界名×主人公名>.json` の `contracts[].storage`（世界で1つの設定なら根の `shared`） |
| 家賃が引かれない | 同じログの `rent:` の行。日数が進んでいない（移動も宿泊もしていない）と引かれない |
| 契約をやり直したい | `state\real_estate\<世界名×主人公名>.json` を消す。建物はロードし直すと消える（保管庫の中身も一緒に消えるので、先に取り出しておくこと） |
