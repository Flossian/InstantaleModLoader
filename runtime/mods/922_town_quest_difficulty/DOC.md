# `922_town_quest_difficulty`: 街ごとに依頼の難易度の範囲を決める

街ごとに、これから作られる依頼の難易度の範囲を決める。

素のゲームは、街の依頼の難易度を街の番号で決まった範囲から引く。
番号 0〜8 の街は開始の街から順に 1〜5、3〜10、…、67〜76 と決まっていて、世界の道のつながりとは関係が無い。
9番目より後の街（世界の一括生成やエディタで足した街）には範囲が無く、1〜76 の全域から引かれる。
開始の隣の村でレベル70の依頼が出たり、最果ての都市で難易度3の依頼が出たりする。

この MOD は、設定画面で決めた範囲をゲームが数を引く所で使う。

| 場面 | 引かれる数 |
| --- | --- |
| 街を初めて訪ねたとき | 初期の依頼3件（重ならない3つの数） |
| 掲示板で「クエストを探す」を押したとき | 新しい依頼1件 |

引いた数はゲームがそのまま使うので、依頼の文・敵の強さ・報酬・店の品揃えが同じ数に揃う。
`318_area_difficulty_growth` を入れていれば、その街の育ちはこの数の上に乗る。

すでにある依頼は変わらない。
範囲を決めていない街は素のまま。
MOD を外すと、それ以降に作られる依頼は素の範囲に戻る（それまでに作られた依頼はそのまま残る）。

## 設定画面

設定画面の「街ごとの難易度を決める」から開く。
世界を選ぶと、その世界の街が並ぶ。

| 列 | 中身 |
| --- | --- |
| つながる街 | 道でつながっている街 |
| ゲームの範囲 | 素のゲームが使う範囲。9番目より後は「1〜76（全域）」 |
| 今の依頼 | いまある依頼の難易度の最小〜最大と件数。訪ねていない街は「まだ無い」 |
| 下限・上限 | 決める範囲。3つ以上の数を含む幅にする（狭すぎると広げて保存する） |
| 固定 | 下のボタンで動かさない街 |
| 適正Lv | 範囲に 1 を足したもの（敵のレベルは難易度+1） |

範囲を変えて「保存」を押すと、次に作られる依頼から効く。
ゲームを起動したままでも効く。

### なだらかにする

開始の街から最も遠い街まで、道に沿って難易度が少しずつ上がるように範囲を並べ直す。

1. 開始の街（番号 0）を「開始の街」の範囲にする（既定 1〜5）
2. 開始から最も多く道を通る街を「最も遠い街」の範囲にする（既定 67〜76）
3. ほかの街は、道でつながる街の平均の高さに寄せ、「幅」の範囲にする（既定 9）

固定した街は動かさず、基準として使う。
たとえば途中の街を 30〜38 で固定すると、その手前と先がそこへ向かってなだらかになる。
道でたどり着けない街は動かさない。

### ほかのボタン

| ボタン | すること |
| --- | --- |
| ゲームの範囲に戻す | 固定していない街を素の範囲に戻す |
| 今の依頼に合わせる | 依頼のある街を、いまある依頼の最小〜最大にする（固定した街と依頼の無い街はそのまま） |

ボタンを押しただけでは保存されない。
「保存」を押すまで、ゲームに効くのは前に保存した範囲。

## 設定

| 設定 | 意味 |
| --- | --- |
| 範囲の上限 | 既定 76（ゲームが依頼の難易度に使う上限）。100 まで上げられる。設定画面の範囲もこの数で頭打ちになる |

76 を超えた分は、敵だけが強くなる。
報酬・才能点・店の品は、ゲームが 76 で止めるので増えない。
`923_beyond_76` を入れていれば、報酬と品も 76 を超えて伸びる。
設定画面でも、76 を超えた範囲があるとどちらかを表示する。

## 記録の置き場

決めた範囲は `state\town_quest_difficulty\<世界名>.json` に入る。
世界ごとの設定なので、同じ世界でキャラクターを作り直しても効く。
消すと、その世界は素の範囲に戻る。

```json
{"towns": {"9": {"lo": 8, "hi": 12, "pinned": false}},
 "smooth": {"start": [1, 5], "end": [67, 76], "width": 9}}
```

素の範囲と同じで固定もしていない街は書かない。

## ほかの MOD との関係

| MOD | 関係 |
| --- | --- |
| `133_ui_area_difficulty` | 訪ねる前の街の「推定」の帯を、この MOD の範囲から出す（9番目より後の街にも推定が出る） |
| `318_area_difficulty_growth` | この MOD が引いた数を素の難易度として、その上に育ちを積む |
| `307_area_move_dungeon` / `325_road_opening` | 道の危険度は街の依頼の難易度の平均から決まるので、範囲を決めた街の依頼が増えるほどそちらへ寄る |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 範囲どおりにならない | `out\town_quest_difficulty.log`。`初訪問: 土地 9 range(1, 77) -> 8〜12 を引いた [10, 8, 12]` や `探す: 土地 9 randint(1, 76) -> 8〜12 を引いた 11` の形で毎回出る |
| ログに「範囲を決めていない」と出る | その世界のその街の範囲が保存されていない。設定画面で世界名と保存を確かめる |
| 何も出ない | 新しい依頼が作られていない。すでにある依頼は変わらない |
| 設定画面に世界が出ない | 世界の骨格（`worlds\<世界名>\world_data.json`）が無い世界は出ない |
