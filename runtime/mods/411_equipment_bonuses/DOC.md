# `411_equipment_bonuses`: 高品質の装備に能力値補正や武器・防具の効果が付く

epic・legendary・mythic の武器や防具が作られたときに、
「筋力 +3」のような能力値補正がランダムに付く。
武器と防具にはさらに、「会心: 15%」のような効果が付くことがある。
店の品揃え・クラフト・イベントや依頼で手に入る品のどれにも付く。
補正と効果は品の説明欄に出て、セーブにも残る。

- common・rare・magical には付かない
- この MOD を入れる前から持っている品には付かない。1つの品を抽選するのは1回だけ
- 能力値は 筋力・器用・耐久・知力・判断・魅力 の6つ。1つの品に同じ能力値は重ならない
- 効果は武器と防具に下の10種類ずつ。1つの品に同じ種類は重ならない

既定の量:

| レア度 | 能力値補正の数 | 1つあたり | 武器・防具の効果の数 |
| --- | --- | --- | --- |
| epic | 1 | +1〜2 | 0〜1 |
| legendary | 1〜2 | +2〜3 | 1 |
| mythic | 2〜3 | +3〜4 | 1〜2 |

## 能力値補正が効くところ

主人公と仲間が身に着けている品の補正が、ゲームが能力値を読むところに効く。
能力値そのものは書き換えないので、MOD を切っても古いセーブを読んでも数字はずれない。

| 場面 | 効く補正 |
| --- | --- |
| 攻撃の火力 | 筋力（物理）・知力（魔法）。ゲームが攻撃力を出すのと同じく、補正 × レベル係数が攻撃力に乗る |
| 防御 | 6つとも（ゲームの防御は6つの能力値の平均から出る） |
| 戦闘の手番の順 | 器用 |
| 依頼の出来事 | 6つとも |
| 会話や依頼の後の印象 | 魅力（主人公だけ） |
| `313_event_ability_check` の判定 | 6つとも（313 を入れているとき） |

- ステータス画面の能力値の後ろに、補正が `筋力: 30(+4)` の形で出る
- 最大 HP には効かない（耐久の補正は防御と依頼の出来事に効く）
- 敵には効かない
- 仲間の装備は `333_equipment_slots` の装備欄から読む。素のゲームはロードで仲間の装備を外すので、333 と一緒に使う

## 武器の効果

身に着けている武器の効果が、その者が敵に当てた一撃に効く。
主人公だけでなく、仲間が身に着けている武器の効果も、その仲間の手で効く（設定「効かせる相手: 仲間」）。
敵の武器には効かない。

| 効果 | 説明欄 | 中身 | 強さ（epic / legendary / mythic） |
| --- | --- | --- | --- |
| 特効 | `特効: ボス戦 +30%` | 決まった相手へのダメージが上がる。相手はボス戦・格上（自分よりレベルが上）・手負い（体力が半分以下）・無傷（体力が満タン）のどれか | +20% / +30% / +40% |
| 会心 | `会心: 15%` | この確率で、AI の審判が裁いた一撃の重さが1段上がる（普通 → 強い など。必殺級はそれ以上に上がらない） | 10% / 15% / 20% |
| 吸収 | `吸収: 10%` | その手で敵に与えたダメージのこの割合だけ、自分の体力が戻る。敵の残りの体力を超えた分は数えない | 6% / 10% / 15% |
| 貫通 | `貫通: 35%` | 敵の防御のこの割合を無視する | 20% / 35% / 50% |
| 毒 | `毒: 命中時 30%` | 当たった敵がこの確率で「毒刃」に侵され、3ターンの間、毎ターン最大体力の4%を失う。毒刃では倒れない（体力 1 で止まる） | 20% / 30% / 40% |
| 怯み | `怯み: 命中時 30%` | 当たった敵がこの確率で「怯み」、2ターンの間、その敵の一撃が3割弱まる | 20% / 30% / 40% |
| 呪い | `呪い: +50%・当てると体力 -3%` | 与えるダメージが上がる。代わりに、敵に当てた手で最大体力の3%を失う。呪いでは倒れない（体力 1 で止まる） | +30% / +40% / +50% |
| 成長 | `成長: +4% / 10体（討伐 34）` | 敵を倒した数が説明欄に残り、10体ごとに与えるダメージが上がる（+100% まで）。節目で `（鉄の剣が手に馴染んできた: 討伐 10）` の行が出る | 10体ごとに +3% / +4% / +5% |
| 処刑 | `処刑: 残り体力 15% 以下` | 当てた後の敵の体力がこの割合以下なら、そのまま倒す | 10% / 15% / 20% |
| 連携 | `連携: 味方の後 +30%` | 直前に別の味方が当てた敵へのダメージが上がる。自分の手の続きでは上がらない | +20% / +30% / +40% |

- 会心・特効・連携・処刑が起きると、その手の後に `（主人公の会心の一撃）`・`（特効: 無傷）` のような行が出る
- 特効・呪い・成長・連携の上乗せは足してから1回掛ける
- `308_battle_damage_display` を入れていれば、吸収の回復と呪いの体力は `主人公 は 吸収 で 34 回復した` の形で戦闘の文に出る。切っていると行は出ず、体力の数字だけが変わる
- 毒刃と怯みは、ゲームの状態異常と同じ入れ物に入る。308 を入れていれば、付いた・切れたも戦闘の文に出る
- 素のゲームは、敵の防御が素点の1割ほどしかないので、貫通はあまり目立たない。`319_battle_tactics` の割り算の防御や、硬い敵で効いてくる
- 素のゲームの戦闘は一撃で終わりがちなので、吸収・毒・怯み・処刑は、戦闘が長くなる `319_battle_tactics` と一緒のほうが効く
- 素のゲームでは、仲間のダメージに武器の攻撃力は入らない（公式の仕様）。それでも武器の効果は仲間の手に効く

## 防具の効果

身に着けている防具の効果が、その者が敵から受ける一撃に効く。
主人公だけでなく、仲間が身に着けている防具の効果も効く（設定「効かせる相手: 仲間」）。

| 効果 | 説明欄 | 中身 | 強さ（epic / legendary / mythic） |
| --- | --- | --- | --- |
| 不屈 | `不屈: 75% 戦闘に1回` | 倒れる一撃を受けたとき、この確率で体力 1 で耐える。耐えられるのは戦闘に1回 | 50% / 75% / 100% |
| 棘 | `棘: 受けたダメージの 30%` | 受けたダメージのこの割合を、その敵に返す。棘では敵は倒れない（体力 1 で止まる） | 20% / 30% / 40% |
| 再生 | `再生: 毎ターン 最大体力の 3%` | 毎ターン、最大体力のこの割合が戻る。倒れた者は戻らない | 2% / 3% / 4% |
| 重装 | `重装: 受けるダメージ -25%・器用 -4` | 受けるダメージが下がる。代わりに器用が 4 下がり、手番が遅くなる（防御と依頼の出来事にも響く） | -20% / -25% / -30% |
| 守護 | `守護: 仲間をかばう 25%` | 別の味方への一撃を、この確率で肩代わりする。受けると倒れるなら肩代わりしない。かばった者の重装と棘が効く | 15% / 25% / 35% |
| 耐性 | `耐性: 状態異常を防ぐ 50%` | 敵に付けられた状態異常を、この確率で防ぐ。味方の補助は防がない | 30% / 50% / 70% |
| 軽業 | `軽業: 一撃をかわす 15%` | 敵の一撃を、この確率で無効にする | 10% / 15% / 20% |
| 火事場 | `火事場: 受けるダメージ -30%（体力 30% 以下）` | 体力が最大の 30% 以下の間、受けるダメージが下がる | -20% / -30% / -40% |
| 呪縛 | `呪縛: 受けるダメージ -40%・与えるダメージ -20%` | 受けるダメージが大きく下がる。代わりに、与えるダメージが 20% 下がる | -30% / -40% / -50% |
| 威光 | `威光: 店の買値 -7%` | 主人公が着ているときだけ、店の買値が下がる。売値は変わらない | -5% / -7% / -10% |

- 不屈・守護・耐性・軽業が起きると、その手の後に `（主人公は不屈で踏みとどまった）`・`（仲間が主人公をかばった）` のような行が出る
- 308 を入れていれば、棘・再生・守護の体力は `敵 に 棘 で 6 のダメージ` の形で戦闘の文に出る
- 重装・火事場・呪縛は足さずに順に掛かる。-30% と -50% なら -65%
- 審判の文は効果を知らないので、軽業や守護で傷を負わなくても、文には当たったと書かれることがある

## 複数の装備

`333_equipment_slots` で複数の部位に装備しているとき、補正と効果のまとめ方はこの MOD の設定で決まる。
333 の「装備欄の品を合算する」の設定とは関係しない。
防具の効果だけはこの設定によらず、同じ種類を複数の部位に着ても重ならない。最大の1品だけが効く。

| 設定 | 意味 |
| --- | --- |
| 補正のまとめ方 | 既定は「全部位を足す」。「能力値・効果ごとに最大の1品」にすると、筋力 +2 と +4 の品を着けても +4、会心 10% と 15% の武器を持っても 15% になる |
| 能力値ごとの上限 | 既定 15。まとめた後の能力値補正がこれを超えない。0 で上限なし。武器の効果の確率と割合は 100% で止まる |
| 自由枠の品も数える | 既定 OFF。333 の自由枠2つに入れた品を数えるか |

333 を入れていないときは、ゲームの武器1つ・防具1つの補正と効果をまとめる。

## そのほかの設定

| 設定 | 意味 |
| --- | --- |
| epic / legendary / mythic の能力値補正 | 補正の数の下限・上限と、1つあたりの量の下限・上限 |
| 武器の効果の数・防具の効果の数 | レア度ごとの、効果の数の下限・上限。0 にすると付かない |
| 付ける武器の効果・付ける防具の効果 | 種類ごとの ON/OFF。OFF の効果はこれから作られる品に付かない |
| 効かせる相手: 仲間 | 既定 ON。OFF にすると主人公にだけ効く |

設定を変えても、すでに付いた補正と効果は変わらない。変わるのはこれから作られる品だけ。
「付ける武器の効果」「付ける防具の効果」を OFF にしても、すでに付いている効果は効き続ける。

## 外すとき

MOD を外しても、品の説明欄の「筋力 +3」「会心: 15%」などの行は残る。ただの表示になり、何にも効かない。

## 困ったとき

| 症状 | やること |
|---|---|
| 補正や効果が付かない | `out\equipment_bonuses.log` に `generated:`・`craft:`・`text:` のどれかで始まる行があるか。品のレア度が epic 以上か。epic の品は効果が付かないこともある（既定 0〜1） |
| ステータス画面に (+n) が出ない | 補正のある品を身に着けているか。333 の自由枠に入れていないか |
| 着けている品の補正が数えられていない | 333 の自由枠に入れていないか。数えるなら「自由枠の品も数える」を ON にする |
| 武器の効果が出ない | 同じログの `hit:` の行に、その者の名前と敵の名前が出ているか。出ていなければ、武器を身に着けていない（333 の自由枠も数えない）か、敵に当たっていない |
| 防具の効果が出ない | 防具を身に着けているか（333 の自由枠は数えない）。同じログの `endure:`・`thorns:`・`regen:`・`armor cut:`・`guardian:`・`resist:`・`evade:` の行があるか。回避した一撃（`319_`）には効かない |
| ログに何も出ない | `out\modloader.log` に `equipment bonuses: installed` の行があるか。無ければ MOD が読み込まれていない |
