# `131_sharp_portrait`: 立ち絵・敵・背景の縮小と減色を通さず、背景抜きと顔の検出を確かにする

ゲームは Stable Diffusion で描いた絵を、保存する前にわざと荒くしている。
立ち絵は 512x1024 で描いた絵を 165x330 まで縮め、2倍に伸ばして 16色に減色する。顔画像もそこから切り出される。
敵は 96〜200 の四方まで縮め、雑音を乗せて 64色に減色し、2倍に伸ばす。
背景は半分に縮めて2倍に戻し、雑音を乗せて 16色に減色する（経路は GAME.md §2.30）。

背景抜きは敵によって本体まで薄くなり、ゲームのモデルでも荒くする前から透けることがある。

この MOD は3つのことをする。
画像生成の方式（sdcpp の cuda・vulkan・cpu と diffusers_openvino）のどれでも、選ばれている方式の工程に掛かる（GAME.md §2.33）。

1. **縮小と減色を通さない**（立ち絵・敵・背景を、それぞれ設定で入れたとき）。描いた絵の細かさがそのまま残る。
   立ち絵は背景を抜いた 512x1024 の絵がそのまま立ち絵になり、顔もそこから 256x256 で切り直す
2. **背景抜きのモデルを選べる**。敵は2つのモデルを合わせて、本体が消えたり透けたりしにくくできる。
   荒くする設定とは関係なく効く
3. **顔をまず YuNet（OpenCV の深層学習の顔検出）で探す**。
   素のゲームは 16% の NPC で顔を見つけられず、全身の小さな縮小（32x64）を顔の代わりにする。
   見つけたつもりで服や鎧を顔として切ることもある。
   手元の 695 体では、YuNet を先に掛けると顔が見つからない NPC が 45 体から 7 体に減り、服や鎧を切る回もほぼ無くなった。
   YuNet が外したときはゲームの検出に任せ、それも外れたら前処理した絵で検出をやり直す

効くのは**これから作られる画像だけ**。既にある絵は荒いまま残る。
敵は同じ名前の絵を使い回すので、既に出会った敵は描き直すまで変わらない。
戦闘中に設定の画面の「画像の再生成」を押すと、最初の敵を描き直せる。
背景も、その場所で同じボタンを押すと描き直せる。

| 設定 | 意味 |
| --- | --- |
| 立ち絵を荒くしない | 既定は切（ゲームのまま。330x660 のドット絵寄り）。入れると 512x1024 の絵がそのまま立ち絵になる。**縮小と減色は別々には切れない**。縮めた絵の減色だけ飛ばしても細かさは戻らず、縮小だけ飛ばすと 1024x2048 の 16色になる |
| 敵の絵を荒くしない | 既定は切（ゲームのまま）。入れると縮小と減色を通さず、雑音も落とす。暗い色調は残る。衛兵と、NPC の戦闘用の絵も含む。戦闘画面での敵の大きさは変わらない |
| 敵の絵に縁を付ける | 既定は切。「敵の絵を荒くしない」が入のときだけ効き、ゲームの白い縁を付ける。暗い背景で暗い敵の輪郭が分かりやすくなるが、線は細く途切れ、足元の影なども囲む。絵を描くときに決まるので、既に描いた敵は変わらない |
| 背景を荒くしない | 既定は切（ゲームのまま）。入れると縮小と減色を通さず、雑音も落とす。暗い色調は残る |
| 背景の切り抜きのモデル | 既定は game（ゲームのまま。汎用の u2net）。isnet-anime はゲームのフォルダにあるアニメ絵向けのモデルで抜き、人物を削りにくい。生き物や機械の敵は薄くなることがあるので、敵には下の設定を使う |
| 敵の背景抜きを2つのモデルで合わせる | 既定は切。敵だけ u2net と isnet-anime の結果を合わせ、薄い所を濃くする。本体が消えたり透けたりしにくくなるが、翼の内側などに黒い地が残ることがある |
| 顔の検出に YuNet を使う | 既定は入。ゲームの検出より先に YuNet で顔を探す。切るとゲームの検出だけになる。検出は縮小の前の絵に対して走るので、立ち絵の設定と関係なく効く |
| 顔の検出をやり直す | 既定は入。YuNet もゲームも顔を見つけられなかった回だけ動く |

既定で効くのは顔の検出だけで、立ち絵・敵・背景の画風はゲームのまま。
ドット絵寄りの画風は縮小と減色が作っていたもので、通さなければ滑らかな絵になる。
滑らかな絵にしたいものの設定を入れる。絵の見た目は変わる。

背景抜きの2つの設定は CPU で動き、VRAM は使わない。1枚の時間は isnet-anime が 0.4〜0.8 秒、2つのモデルが 0.5〜1.2 秒。
`343_stable_diffusion` で選んでいた切り抜きのモデルは、こちらの設定へ移した。入れていた isnet-anime は、この版で初めて起動したときに引き継ぐ。
設定を変えたら、ゲームを起動し直すと効く。

YuNet が外し、やり直しで拾った顔は、ときどき顔でないもの（髪・暗い鎧・肩章など）を切る。
素のゲームでは全身の縮小になっていた回なので、素より悪くはならない。
気になる個体は `out\sharp_portrait.log` の `箱` の座標で分かる。

YuNet のモデル（`models\face_detection_yunet_2023mar.onnx`、232KB）はこの MOD に同梱している。
配布元は opencv_zoo（https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet）で、ライセンスは MIT（`models\LICENSE.yunet.txt`、NOTICE）。
顔の検出はゲームが同梱している `cv2` / `numpy` / `PIL` を使う。
ゲームが同梱をやめれば、顔の検出の手当てだけが効かなくなり、素の結果に落ちる。

立ち絵を後から差し替える外部の道具とは衝突しない。
あちらはゲームが書き終えた後に立ち絵を上書きするだけで、顔の切り出しには間に合わないので、
顔の側はこの MOD の持ち分になる。

## 既に居る NPC の顔を切り直す（設定画面から）

MOD 本体はこれから作る絵にしか効かない。
既に居る NPC の顔を直すには、ローダの設定画面でこの MOD を選んで「設定…」を押す。
MOD の設定（上の8つ）もその画面で変える。

| できること | 内容 |
| --- | --- |
| 数える | 手元の全世界の NPC を、顔が切られているか・全身の縮小のままか・顔画像が無いかで数える |
| 検出し直す | 顔が見つかっていない個体（既定）か全員に、YuNet を先に、外れたらゲームと同じ検出を素の絵で試し、それも外れたら前処理で拾い直す。全員を選ぶと、服や鎧を顔として切っていた個体も直る |
| 切り出し元 | 立ち絵（いまの見え方に合わせる）か、背景を抜いた元絵（立ち絵が荒くても顔だけ高画質に） |
| 検出だけ | 書かずに、何体で顔が見えるかだけ見る |
| 元に戻す | 書く前に `face_image.orig.png` を残す。1体ずつ、または控えのある全員を戻せる。前と今の顔を並べて見られる |

手元の Python に `cv2` が要る（ゲームの同梱は別の Python なので借りられない）。
無ければ画面に「cv2 を入れる」のボタンが出る。押すと `pip install "opencv-python-headless<5"` で入れ、
入ったら画面が開き直る（ネットワークを使う。それまでは設定の部分だけ使える）。
書くのは `worlds\<世界>\characters\<名前>\face_image.png` とその控えだけで、セーブは触らない。

記録は `out\sharp_portrait.log` に1体につき4〜5行（NPC の生成のたびにしか書かない）。

```text
縮小: 512x1024 をそのまま通す
減色: 1024x2048 を控えの 512x1024 に戻す
顔: YuNet が見つけた (146, 33, 402, 289)（箱 (226, 113, 96, 96)、確かさ 0.89）
顔: (94, 21, 259, 186) を (146, 33, 402, 289) に戻して切り直した
```

## 困ったとき

| 症状 | やること |
| --- | --- |
| **NPC の生成が進まない** | `out\live_crashes.log` に `Thread-N (generate_images)` のクラッシュが無いか見る。あれば縮小の工程の戻り値の形がゲームの更新で変わっている。この MOD を切って確かめる |
| ピクセル化した絵のまま | `out\sharp_portrait.log` に `減色: ... を控えの 512x1024 に戻す` の行が出ているか見る。無ければ経路を通っていない。行が出ているのに絵が荒いなら、その NPC の絵は前から在ったもの |
| 立ち絵が 1024x2048 で 5MB | `減色: ... 控えが無いのでそのまま通す` が出ている。縮小の包みを通らずに減色だけ来た回。手前の `縮小:` の行が同じスレッドに在るか見る |
| 顔が左上にずれる（165x165） | 切り直しが効いていない。ログに `顔: (...) を (...) に戻して切り直した` が無い。`はみ出すので切り直さない` が出ていれば箱が立ち絵の外 |
| 顔が小さい全身（32x64） | YuNet もゲームも、やり直しも見つけられなかった回。ログに `顔: YuNet は見つけられず`・`顔: 見つからず（4 通り試した）`・`顔の代わりを作る回なのでゲームに任せる` が出る |
| ログに `顔: YuNet のモデルが読めない` か `検出器が作れない` | YuNet を使えず、ゲームの検出だけで探している。`models\` にモデルがあるか見る。MOD を入れ直すと戻る |
| 顔の位置に鎧や服が切られている | YuNet が外れた後の、ゲームの検出かやり直しの誤検出。ログの `顔: ゲームは見つけられず、... で拾った` の `箱` の座標で分かる。位置の絞り（`FACE_TOP` / `FACE_WIDTH`）を狭める |
| `顔: 見つからず（... こちらは見えたがゲームの関数は None ...）` | こちらの検出は箱を見たのに、ゲームの関数が拒んだ。カスケードの渡し方がゲームの呼び方（`顔: ゲームの呼び方` の行）と食い違っている |
| 敵が透ける・本体が消える | 「敵の背景抜きを2つのモデルで合わせる」を入れて、戦闘中に「画像の再生成」で描き直す。`out\sharp_portrait.log` に `背景抜き: 2つのモデル` の行が出る |
| 敵の周りに黒い地が残る | 2つのモデルを合わせたときに起きる。残るのは描かれた背景で、本体を欠けさせないために削っていない。気になる敵は描き直す |
| `背景抜き: … が無いのでゲームの切り抜きで抜く` か `抜けなかったので` | モデルが使えず、その回はゲームの抜き方に戻している。ゲームのフォルダの `runtime\models\u2net\` にファイルがあるか見る |
| 敵の絵が荒いまま | 既に描かれた敵かもしれない。戦闘中に「画像の再生成」で描き直す。`out\sharp_portrait.log` に `敵: 縮小` の行が無ければ新しく描かれていない |
| 敵の絵の画像が 2048x2048 などと大きいまま | ログに `敵: 2倍の絵を戻せず` か `戻り値に戦闘画面の絵が無い` が出ている。表示の大きさは変わらないので、遊ぶぶんには困らない |
| 背景が荒いまま | 既にある背景かもしれない。その場所で「画像の再生成」を押す。ログに `背景: 縮小` の行が無ければ、方式に合う工程に当たっていない |
| 次の NPC の立ち絵だけ荒い | 旗が前の生成から残っている。`縮小: ... ゲームに任せる` が減色の直後ではなく生成の頭で出ていればそれ |
| `modloader.log` に `safe hook failed on image_generation...` | こちらの工程が壊れ、その回は素の結果に落ちている。生成は止まらない。`safe hook on image_generation...: the original raised` はゲーム側の失敗をそのまま通した印で、こちらの不具合ではない |
