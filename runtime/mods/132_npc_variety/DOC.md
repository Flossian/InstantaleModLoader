# `132_npc_variety`: NPC の外見・性格・経歴に種を渡す

LLM が作る NPC は髪も瞳も肌も書かれず、役職の型（宿屋の主人は皺と灰色のローブ、鍛冶師は筋肉質でエプロン、書記官は眼鏡とインクの染み）が町をまたいで再現され、
画像の頼み文もそれを写すので立ち絵まで同じ顔になる。
原因は頼み文に人を見分ける材料が無いこと。
「没個性を避けよ」（`111_` の既定ルール）は効かず、「髪色を必ず書け」と要素名を足しても値は同じ（宿屋の主人の瞳は 10 回とも「鋭い灰色」。VERIFICATION_LOG.md §2.82）。

この MOD は人物ごとに表から値を引いて渡す。

- 外見9軸（髪色・髪の長さ・髪型・瞳・肌・体格・年齢の見え方・目立つ特徴・服）、
  性格6軸（口数・人との距離・大事にするもの・弱み・癖・気分の傾向）、
  来歴9軸（出自・過去の一件・ここにいる理由・隠し事・家族・前の生業・今の悩み・恩と恨み・町での評判）
- 軸の順は混ぜ、性格と来歴は3つずつ（全部渡すと書き出しが表の語に寄る）
- 目立つ特徴（顔を横切る傷・眼帯・入れ墨・片腕が無い）は 25% の人物だけ。欠けた前歯や短い指のような細部は LLM も画像生成も描き分けられないので表に無い
- 鍵=値ではなく句点で繋いだ文で渡し、「見出しや「=」は書かない」と添える（鍵=値だと本文に「髪=…」が写る）
- 町生成は必須施設の主5人・住民4人・冒険者3人を番号で名指しして渡す。余りは捨てられる

```
【この人物について決まっていること】
赤茶の髪を短く刈っている。鳶色の瞳。そばかすだらけ。小柄で丸い。左耳が欠けている。苔色の服。無口。金より義理。川向こうの漁村の生まれ。火事で店を失った。
これらを description・personality・look_description の文章に溶かして書くこと。見出しや「=」の形は書かない。
```

効き目はローカル LLM（Gemma4 26B）で測ってある（`tools\npc_variety_probe.py`。VERIFICATION_LOG.md §2.82、VERIFICATION.md §3.47）。
指定は 94〜99% で本文に載り、髪色・瞳・肌・体格の記載率は 18% / 3% / 3% / 9% から 97% / 96% / 96% / 97% へ、役職の型の語は 59% → 15%、「鋭い眼光」は 17% → 3%。
この MOD の形でも役職の型の語 10%・「鋭い眼光」5%、書式の写り 0、老人と子どもは素と同じ幅（108人で特徴付きは 25人）。

対象は単体生成（`master_ai_npc_generater`）と町生成（`create_settlement_detail`）。
衛兵と闘技場の敵は同じ「【生成するNPC】」の形でも触らない（「- 名前:」「- 概要:」が無く「衛兵NPC」「闘技場で戦う」の語がある方で見分ける）。
`320_` の募集は自前の頼み文なので対象外。
効くのは新しく生まれる NPC だけ。

表は `runtime\mods\132_npc_variety\seeds.default.json`。
差し替えは同じフォルダに `seeds.json` としてコピーしてから編む（そちらが優先され、MOD を更新しても消えない。次の生成から効く）。
書式は `{"look": {"軸": ["句", ...]}, "personality": {...}, "description": {...}}`。軸の名前は自由。

- `{"chance": 25, "rows": ["句", ...]}`: その軸は 25% の人物にしか付かない（同梱の「目立つ特徴」）
- `{"rows": [...], "drops": {"句": ["軸名"]}}`: その句を引いたら後ろの軸を省く。節をまたげる
  （同梱は「髪は短く刈っている」で「髪型」を、「まだ子どもと言ってよい年頃」で来歴の「家族」「前の生業」「今の悩み」を省く）
- `{"rows": [...], "not_for": {"owner": ["句"]}}`: その役にはその句を出さない。
  役は `owner`（必須施設の主）/ `resident` / `adventurer` / `single`（単体生成）。句の並びの代わりに `true` で軸ごと付けない
  （同梱は施設の主に子どもの年齢を出さず、単体生成には年齢の軸を付けない。概要の「中年男性」と食い違うため）

句はそのまま世界に現れるので、読み物として置ける文にする。
性別は種を引く時点では決まらないので、妻・夫・娘のような性別を決める語は入れない（同梱は「連れ合い」「遠くに嫁いだ妹」）。
付けた種は `out\npc_variety.log` に残り、セーブの look_description と突き合わせられる。

| 設定 | 意味 |
| --- | --- |
| 種を付ける割合（%） | 既定 100。人物ごとに引く。0 で素のゲームと同じ |
| 外見の軸をいくつ渡すか | 既定 9（全部）。目立つ特徴は表の側で 25% |
| 性格の軸をいくつ渡すか | 既定 3。6 で全部 |
| 来歴の種をいくつ渡すか | 既定 3。9 で全部 |
| 町生成で種を付ける住民の人数 | 既定 4 |
| 町生成で種を付ける冒険者の人数 | 既定 3（素のゲームが作る人数） |
| 付けた種を記録する | 既定 ON。`out\npc_variety.log` の `[SEED]` |

| 症状 | やること |
| --- | --- |
| 何も変わらない | `out\npc_variety.log` に `[SEED]` が出ているか。無ければ `[TABLE]` の行で表が読めているか、`modloader.log` の `armed on` で仕掛かっているか |
| 本文に「髪=」のような書式が写る | 表の句に `=` や見出し語を入れていないか。同梱の表では出ない |
| 老人や子どもばかりになる | 「年齢の見え方」の軸を `seeds.json` で薄くする（句を減らすか、`chance` で間引く） |
| 子どもの役人が出る | 同梱の表では出ない（`not_for`）。十代の店主は出る。冒険者や住民にも出したくなければ、その役を `not_for` に足す |
| 傷や眼帯の人物が多すぎる・少なすぎる | 「目立つ特徴」の `chance`（既定 25）を変える |
| 語がそのまま本文に出て読みにくい | 表の句を文に近い形へ書き直す。モデルは頼み文の語を写す |
