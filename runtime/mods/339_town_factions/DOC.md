# `339_town_factions`: 勢力ごとに主人公の見られ方が変わり、その勢力の NPC の態度に表れる

世界の設定に書かれた勢力（国・教団・組織など）ごとに、主人公がどう見られているかを持つ。
その勢力の街の NPC は、見られ方に応じた態度で接する。
同じ主人公でも、ある勢力の街では歓迎され、別の勢力の街では警戒される。

## 決まり

- 世界ごとに有効にする（設定の「世界ごと」のタブ）。有効にしていない世界では何もしない
- 「新しく作る世界に組織を設ける」を入れておくと、世界を作るときに世界観に合った組織が2〜4つ設けられ、地理の説明と街の案内文に書き込まれる。その世界では勢力が最初から有効になる。組織を自分で決めたいときは、世界を作るときの概要に書けばよい（`145_fix_world_overview` を入れていれば、書いたとおりに残る）
- 有効にした世界を読み込むと、世界の設定と街の案内文から勢力を読み取る。初回だけ少し時間がかかる（裏で LLM に2回聞く）
- 設定に勢力が2つ以上書かれていない世界（一つの国が治める世界・勢力の話が無い世界）では、勢力を作らない
- 設定に書かれていない勢力・関係は作らない
- 冒険者に当たる人々（設定での呼び名が何であれ）、職業や身分の呼び名、一人の人物や役職は勢力にしない
- 会話で口先だけ調子を合わせても、見られ方は上がらない
- 見られ方は勢力ごとに -100〜100 で、段階は 敵対（-61 以下）・緊張（-21 以下）・中立・友好（20 以上）・盟友（60 以上）。勢力どうしの仲と同じ言葉で、一番上だけ「同盟」ではなく「盟友」
- 最初の見られ方は、読み取った後に1回だけ決める。新しく始めた主人公は出自（経歴）だけから決める。
  遊んでいる途中の主人公は、その勢力の街での功績の数・滞在日数・手配から土台を決め、功績の中身と経歴しだいで1段階まで上下する。
  手配されている勢力は功績があっても緊張より上にならず、手配度 -40 以下なら敵対
- 世界ごとの設定で「この世界に組織を設ける」を入れると、設定に勢力が書かれていない世界にも組織が設けられる（勢力の仕組みの中だけで、ゲームの依頼や街の案内文には出てこない）。
  勢力を有効にした後から入れても、次に世界を読み込んだときに設けられる。LLM が答えなかったときも、次に読み込んだときにもう一度試す
- 勢力の街の NPC は、その勢力との関わり方（立場）と見られ方の段階に応じた態度で話す。立場は人物紹介から裏で LLM が街ごとに1回決める（住人が増えたら、その分だけ）
  - 勢力の一員: 見られ方の段階に応じた態度で接する。中立なら何も変わらない。段階によっては、その勢力の者たちのあいだでの主人公の呼び名も知っている
  - 一員ではないが従っている住人: 勢力が主人公をどう見ているかを知っていて、勢力の目を気にする
  - 表向き従い、内心では反感を持つ住人: 勢力に睨まれていることを、主人公を嫌う理由にしない。人目のある所では本音を出さない
  - 勢力に関心の無い住人: 何も足さない（その人の性格のまま話す）
  - 別の勢力の者として公然と街にいる住人（よその勢力から置かれた者など）: その勢力の者として、その勢力からの見られ方で接する
  - 別の勢力にひそかに通じている住人: その勢力からの見られ方で接するが、表には出さない
- 立場が決まる前の住人と、住まいの分からない相手は「従っている住人」として扱う
- 仲間にしている NPC は、主人公を個人として知っているので態度は変わらない
- 会話を閉じるたびに、その会話での主人公の言動が相手の勢力にどう映ったかを判定し、見られ方が動く。判定するのは勢力の一員（別の勢力の側にいる住人なら、その勢力）との会話だけ。上がるのは同じ勢力から1日1回、下がる方は毎回
- ある勢力に好かれると、その勢力と対立している勢力からは少し疎まれる
- その勢力の街で手配されている間は、会話や出来事で見られ方が緊張より上へ上がらない。手配度が -40 以下なら敵対より上へ上がらない
- 見られ方が一度 -81 以下まで落ちた勢力は、会話や出来事でいくら上がっても敵対のまま。
  ただし、その勢力の者との会話で、敵意を改めるに足る理由（確かな証し・償い・筋の通った説得など）を示して相手を納得させれば、この縛りは外れる。謝罪や口先だけでは外れない
- 宿泊や移動で日数が進むと、勢力どうしの仲もときどき動く。起きたことは噂として NPC が知っている
- 世界の設定にもともと書かれている勢力どうしの関係は、簡単には動かない
- 穏やかな世界観では、勢力どうしが敵対まで悪くなることはない

## 勢力の刺客

見られ方が敵対の勢力が治める街を歩いていると、その勢力の刺客が行く手を塞ぎ、勝負を挑んでくる。

- 現れるのは、その勢力の街の中で移動したとき（街に着く・施設に入る・施設を出る）。確率は設定で決める（既定 20％）。設定で、緊張の勢力の街でも現れるようにできる
- 刺客は、勢力の種類と説明に合った役職の人物として新しく作られる（教団なら異端審問官、など）。作る間は待機の表示が出る
- 会話の選択肢は「受けて立つ」だけになる。話はできるが、会話を終えるには戦うしかない
- 勝つと刺客は死ぬ。その勢力からの見られ方が下がり（既定 10）、その街の手配度も下がる（既定 10。ゲームが下げた分は重ねない）
- 逃げると刺客は生き残る。その後は新しい刺客と同じく、日数が空いてから確率で現れる。そのときは新しく作らず、逃げられた同じ刺客がまた来る。逃げても見られ方と手配度は変わらない
- 負けるとゲームオーバー（ゲームのまま）
- 刺客が現れてから次の刺客が現れうるまで、既定で 10 日空く
- 着いた先で衛兵に見つかったときや、ほかの会話の最中には現れない。現れなかった分は日数に数えず、次の移動でまた確かめる

## 勢力と情勢を見る

画面左下のアイコン（持ち物・設定・キャラ情報・クラフト）の右にある MOD 用のボタン（歯車）を押すと、MOD の機能の一覧が開く。
勢力を有効にしている世界では「勢力と情勢」の行が出て、選ぶとウィンドウが開く。
住人ごとの立場は出さない（会話の態度から察する）。

- 左に勢力ごとの札。主人公への態度（敵対・緊張・中立・友好・盟友）を色と5段の目盛りで、ほかに勢力内での呼び名・説明・影響下の街・他勢力との関係を出す
- 手配や、一度 -81 以下まで落ちたことで態度が上がらないときは、札にその旨が出る
- 右上は最近の噂（この1年）。噂の下に、それで勢力どうしの関係がどうなったかを添える
- 右下は主人公への態度の推移（この1年）。会話・街の出来事・張り合う勢力への響きで態度が動いた回が並び、会話の回は判定の理由も出る
- 札の欄・噂・推移は、それぞれスクロールできる

新しい噂が出たときと、態度の段階が変わったときは、ボタンの右上と「勢力と情勢」の行に赤い点が付く（行を選ぶと消える）。

## 他の MOD との重なり

| MOD | どうなるか |
|---|---|
| `338_town_incidents` | 街の出来事を主人公が片付けると、その街の勢力からの見られ方が上がる。出来事は勢力どうしの情勢のきっかけにもなる。338 は勢力のことを知らないので、338 だけでもそのまま動く |
| `337_conversation_affinity` | 同じ会話の要約に2つの判定を相乗りさせる。LLM を呼ぶ回数は増えない |
| `321_area_chronicle` | 321 が書き換えた案内文ではなく、セーブにある元の案内文から勢力を読み取る |
| `145_fix_world_overview` | 入れていれば、入力したとおりの世界の概要から勢力を読み取れる。入れていなければ、ゲームが書き直した概要から読む（細かく書いた勢力が落ちていることがある） |

## 設定

設定はローダの設定画面の「設定…」から開く同梱の画面で変える。
全部の世界に共通の設定と、世界ごとの設定のタブがあり、各項目は既定値と説明つきで出る。

- 「勢力を有効にする」「この世界に組織を設ける」は世界ごとのタブで入れる（既定は切）
- 「新しく作る世界に組織を設ける」は全部の世界に共通の設定で、世界ごとのタブでは効かない（既定は切）
- 会話で上がる量・下がる量、街の出来事を片付けたときに上がる量、情勢が動く間隔とそのばらつき、噂が聞こえる日数を変えられる
- 刺客が現れる確率（敵対・緊張）、次の刺客までの日数、刺客を討ったときに下がる見られ方と手配度を変えられる
- 情勢が動く間隔は、決めた日数（既定 30 日）に 0〜ばらつきの日数（既定 15 日）をランダムに足した日数。足す日数は情勢が動くたびに決め直す

## 勢力を手で直す

設定から勢力をうまく読み取れなかった世界では、台帳を手で直して勢力を足したり差し替えたりできる。
台帳は `state\town_factions_ledger\<世界×主人公>.json`（UTF-8 の JSON）。
ゲームを閉じてから直す（起動中に直すと、ゲームが上書きする）。

- `factions` に勢力（`id`・`name`・`kind`・`note`）、`towns` に街の持ち主（`"街の id": {"faction": "勢力の id"}`）、`relations` に勢力どうしの仲（`"f1|f2": {"stage": -2〜2}`）、`standing` に主人公の見られ方（`{"score": -100〜100}`）を書く
- 勢力を足したり街の持ち主を変えたりしたら、`people` を `{}` にする。次に読み込んだとき住人の立場を決め直す
- 書き漏らした勢力どうしの仲と見られ方は、読み込むときに中立で足す。知らない勢力を指す街・仲・住人の立場は外す。直したことはログの `repair:` の行に出る
- 街の id は `output_data\<世界>\<主人公>\mod_town_factions_extract\` のプロンプトに `town_id 3: 街の名前` の形で載っている

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 態度が変わらない | `out\town_factions.log`。`build: … ready:` の行に、読み取った勢力・街・見られ方が出る。`no factions` なら、その世界の設定から勢力が2つ以上読み取れなかった |
| 勢力の読み取りがおかしい | `output_data\<世界>\<主人公>\mod_town_factions_extract\` にプロンプトと返答がそのまま残る。根拠の原文が設定に見つからなかった項目は `build: dropped` の行に出る |
| 見られ方の動き | 同じログの `judge:`（会話）・`incident:`（街の出来事）・`trend:`（情勢）の行 |
| 住人の態度が立場に合っていない | 同じログの `people:` の行に街ごとの立場の数が、`stance:` の行に会話で足した文の頭と立場が出る。決めた立場と理由は `state\town_factions_ledger\<世界×主人公>.json` の `people` |
| 刺客が現れない・現れたのに呼び止めない | 同じログの `hunter:` の行。抽選の結果（`roll`）、作った刺客、呼び止めなかった理由（`not launched (…)`）が出る。刺客の控えは台帳の `hunters` |
| 作り直したい | `state\town_factions_ledger\<世界×主人公>.json` を消すと、次に読み込んだときに作り直す |
