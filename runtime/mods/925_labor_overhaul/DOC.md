# `925_labor_overhaul`: 労働に職種・出来事・勤続を足す

開発中。

残りの作業は「未確認項目と確認手順」にある。

役場の労働と裏の事務所の闇労働に、仕事の種類・働く合間の出来事・雇い主ごとの勤続を足す。

MOD なしの労働は、役場が短い契約と長い契約の2択、裏の事務所が条件1つだけで、「働く」を決まった回数だけ押すと決まった額が入る。
能力値も、街の様子も、どこで働いたかも関わらない。
賃金は依頼の難易度が上がるほど依頼の報酬から離れ、終盤は長い契約を務めても依頼1件の2割に届かない。

この MOD を入れると、「労働の募集をみる」「闇労働の募集をみる」の先が次のように変わる。

## 役場の労働

「労働の募集をみる」を押すと、その街の仕事の一覧が出る。

| 仕事 | 中身 |
| --- | --- |
| 〈施設名〉の手伝い | その街の、主のいる施設の仕事。3件が並び、顔ぶれは1ヵ月ごとに入れ替わる。能力値と勤続で賃金が変わる |
| 前回の仕事 | その街で前回務め終えた施設の仕事は、3件に選ばれていない月も追加で並ぶ。途中でやめた後と、施設でない仕事の後は並ばない |
| 日雇いの人足 | いつも並ぶ。MOD なしの労働と同じで、賃金は変わらず、出来事も起きない |
| 臨時の募集・〈出来事の名前〉の対応 | 街に困り事が起きている間だけ出る（「街の出来事」の節） |

同じ月のうちは、一覧を開き直しても顔ぶれは変わらない。

施設の種類ごとに、賃金に効く能力値が2つ決まっている。

| 施設 | 効く能力値 |
| --- | --- |
| 鍛冶屋 | 筋力・耐久 |
| 宿屋 | 魅力・耐久 |
| 雑貨屋 | 魅力・賢さ |
| 専門店 | 知力・器用 |
| 医療施設 | 賢さ・器用 |
| ギルド | 知力・魅力 |
| 役場 | 知力・賢さ |
| 訓練所 | 筋力・器用 |
| 闘技場 | 耐久・筋力 |

仕事を選ぶと契約の長さ（短い・長い）を選び、「働く」を押すたびに暦が進んで賃金が入る。
MOD なしの労働は、選択肢に割増こみの額を出すが、実際に入るのは割増なしの額になっている。
この MOD では、最後まで務めると割増（短い契約 12.5%、長い契約 25%）が付き、雇い主の好感度が上がる（短い契約 +3、長い契約 +6）。
「途中でやめる」を選ぶと割増は付かず、その雇い主での勤続が 240 日ぶん減り、180 日のあいだその雇い主の仕事が一覧に出ない。

## 賃金

1回ぶんの賃金は、MOD なしの賃金に次の3つを掛けた額になる。

| 掛けるもの | 倍率 |
| --- | --- |
| 能力値 | 効く2つの平均が 11 で 1倍、30 で 2倍（間は直線）。11 より低いと下がり、下限は 0.8倍 |
| 勤続 | 「勤続」の節の表 |
| 街の出来事 | 「街の出来事」の節 |

能力値が 11 で勤続が無く、街に出来事も無ければ、MOD なしと同じ額になる。
1回の長さを設定で変えると、賃金は長さに比例する（30日なら 90日の 3分の1）。

## 街での実績

MOD なしの賃金は、主人公が片付けた依頼の最高難易度だけで決まる。
依頼をしない主人公は難易度 0 のままで、1回働いて 6 にしかならない。

この MOD では、契約を務め終えるたびにその街での労働の実績が積み上がり、賃金の基準の難易度に足される。

| 務め終えた契約 | 上がる実績 |
| --- | --- |
| 短い契約・臨時の募集 | +2 |
| 長い契約 | +5 |

1つの街で上がるのは +60 まで。
連続で働く必要は無く、間に旅をしても、別の雇い主で働いても、その街で務め終えた回数で決まる。
途中でやめた契約と闇労働は数えない（闇労働の賃金には、街の実績が乗る）。
施設の仕事・日雇いの人足・臨時の募集のどれも、基準の難易度から賃金が決まるので、3つとも上がる。

| その街の実績 | 依頼をしない主人公（難易度 0） | 難易度 30 の主人公 |
| --- | --- | --- |
| 0 | 6 | 178 |
| +10 | 100 | 264 |
| +30 | 178 | 371 |
| +60 | 371 | 449（難易度 76 で頭打ち） |

1回ぶんの賃金で、能力値 11・勤続なしのとき。
一覧を開くと「この街での労働の実績は +30（務め終えた契約 6 回）」と出る。

雇い主ごとの勤続は別の数で、街の実績で上がった賃金にさらに掛かる。

## 年齢

MOD なしの労働と同じく、年を取るほど1回が長くなり、老いると働けなくなる。

| 年齢 | 1回（1期）の長さ | 役場 | 裏の事務所 |
| --- | --- | --- | --- |
| 29 まで | 設定の長さ（既定 3ヵ月） | 働ける | 働ける |
| 30〜34 | 4/3 倍 | 働ける | 働ける |
| 35〜49 | 5歳ごとに 1/3 ずつ増える | 働ける | 働ける |
| 50〜54 | 8/3 倍 | 働ける | 断られる |
| 55 から | | 断られる | 断られる |

1回の賃金は年齢で変わらないので、年を取るほど同じ賃金に長くかかる。
断られる年齢では MOD の一覧は出ず、MOD なしと同じく「今の体力では、とても働けそうにない...」と出て「乞食をする」に進める。
働いている途中で断られる年齢になっても、その契約は最後まで働ける。

## 働く合間の出来事

「働く」を押したとき、ときどき出来事が起きる（既定は 90日につき 50%）。
急ぎの頼まれ事、同じ持ち場の者との揉め事、帳尻の合わない金、賃金の話、預かり物をくすねる誘いなどで、どの仕事でも起きるものが 12 件、施設の種類ごとのものが 3 件ずつある。

出来事には選択肢が2つか3つ出る。
能力値で判定する選択肢には、使う能力値と成功の確率が出る（例:「引き受ける(耐久 60%)」）。
確率は、その能力値が 11 から1つ上がるごとに 3% 上がる（5%〜95%）。

結果で動くのは、その回の賃金・勤続の日数・雇い主の好感度の3つ。
くすねる誘いに乗ってしくじると、その場で暇を出され、その土地の手配度が 3 下がる。

## 勤続

雇い主ごとに、働いた日数が積み上がる。

| 段階 | 働いた日数 | 賃金 | その店の買値 |
| --- | --- | --- | --- |
| 見習い | 0 | 1倍 | そのまま |
| 一人前 | 480 | 1.25倍 | 5% 引き |
| 任される | 1,440 | 1.5倍 | 10% 引き |
| 右腕 | 2,880 | 2倍 | 15% 引き |

雇い主の人物が替わると、その施設での勤続は 0 に戻る。
日雇いの人足と臨時の募集には、勤続が無い。

## 街の出来事

街の出来事の MOD（`338_town_incidents`）を入れていると、その街の出来事が労働に効く。

| 街の様子 | 労働への効き方 |
| --- | --- |
| 良い出来事（祝祭・豊作など） | 段階が進むほど賃金が上がる（1.1倍・1.2倍・1.3倍）。景気が崩れている段階は 0.7倍 |
| 困り事 | 役場の一覧に「臨時の募集・〈出来事の名前〉の対応」が出る |

臨時の募集は賃金が 1.5倍で、効く能力値は耐久と賢さ。
1回の長さの設定が 30日以下ならその長さ、30日より長ければ 30日 × 3回の契約になる。
最後まで務めると、その出来事が収まる側へ1段階動く。
最初の段階で務め終えると、その出来事は収まる。

## 裏の事務所の闇労働

「闇労働の募集をみる」を押すと、裏の仕事の一覧が出る。

| 仕事 | 危険度 | 賃金 | 起きやすい危険 | 危険を減らす能力値 |
| --- | --- | --- | --- | --- |
| 荷の運び | 1 | 2倍 | 取り締まり | 器用・耐久 |
| 見張り | 1 | 2倍 | 仕返し | 賢さ・耐久 |
| 取り立て | 2 | 3倍 | 仕返し | 筋力・魅力 |
| 帳簿の細工 | 2 | 3倍 | 裏切り | 知力・器用 |
| 押し込みの手引き | 3 | 4倍 | 取り締まり | 器用・賢さ |

賃金は、役場の同じ長さの賃金に対する倍率。
能力値では賃金は変わらない。
MOD なしと同じく、受けたら途中でやめられない。

期ごとに、危険が起きることがある。
確率は 90日の1期につき、危険度 1 で 10%、2 で 18%、3 で 28%（能力値が 11 のとき）。
その仕事の能力値2つの平均が高いほど下がり、30 で 4割になる。
11 より低いと上がる（最大 1.3倍）。
一覧には、いまの能力値での確率が出る。

| 危険 | 起きること |
| --- | --- |
| 取り締まり | その期の賃金が入らない。その土地の手配度が、危険度1つにつき 2 下がる |
| 仕返し | その期の賃金が入らない。加えて賃金2期ぶんを奪われる |
| 裏切り | この契約でここまでに稼いだ額を失い、その土地の手配度が 1 下がり、仕事が打ち切りになる |

事務所ごとにも勤続がある。
段階が上がるごとに危険の確率が 1割ずつ下がり（右腕で 0.7倍）、押し込みの手引きは「一人前」から一覧に出る。

街に困り事が起きている間は、裏の仕事の賃金が 1.3倍になる。
その間に裏の仕事を最後まで務めると、その困り事が悪くなる側へ1段階動く。

## 設定

設定は「数の設定と試算」の画面で変える。
左に、数を表の形で入れる（短い契約と長い契約、勤続の4段階、危険度 1〜3）。
右に、その設定での試算が出る。
依頼の最高難易度・この街の実績・能力値の平均・勤続をつまみで動かすと、役場の1回の賃金と内訳、契約の稼ぎ、素の労働と依頼1件との比べ、闇労働の危険度ごとの賃金と危険の確率が変わる。
左の数を変えると、保存する前でも右の試算がその場で変わる。
欄に入ると、その項目の説明と既定が下に出る。
「期間のひな形」のボタンで、素のゲームと同じ期間（3ヵ月 × 4回 / 8回）か、1ヵ月刻み（1ヵ月 × 3回 / 6回）を入れられる。
試算の金額は、ゲームの賃金と報酬を難易度 0〜76 で測った表から出す目安。

主な設定は次のとおり。

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 役場の「働く」1回の長さ（日） | 90 | 29歳までの長さ。MOD なしは 90（3ヵ月）。賃金は長さに比例する |
| 短い契約の回数 / 長い契約の回数 | 4 / 8 | MOD なしは 29歳までなら 12ヵ月と 24ヵ月 |
| 闇労働の1期の長さ（日） / 期の数 | 90 / 3 | MOD なしは 3ヵ月 × 3期 |
| 出来事が起きる確率（%） | 50 | 90日あたり。0 で起きない |
| 能力値による賃金の上限（%） | 200 | 効く能力値の平均が 30 のときの賃金。100 で能力値が効かない |
| 年齢の決まり | ON | 30歳から5歳ごとに1回が長くなり、役場は 55 歳・裏の事務所は 50 歳から断られる。境目の年齢も変えられる |
| 街ごとの労働の実績 | ON | 務め終えるたびにその街の賃金の基準が上がる。上がる幅（短い契約 2・長い契約 5）と上限（60）も変えられる |
| 雇い主ごとの勤続 | ON | OFF にすると勤続を数えず、賃金も危険も勤続で変わらない |
| 働いた店での値引き | ON | 勤続の段階による買値の値引き |
| 街の出来事との連動 | ON | 街の出来事の MOD が入っているときだけ効く |
| 闇労働の賃金・危険度1 / 危険度3（%） | 200 / 400 | 危険度2はその中間 |
| 闇労働の危険の起きやすさ（%） | 100 | 危険が起きる確率に掛ける。0 で起きない |

1回を 1ヵ月にして遊ぶなら、長さを 30、回数を 3 と 6 にすると、契約が 3ヵ月と 6ヵ月になる。

この文書に出てくる期間と数は、どれも設定で変えられる。

| まとまり | 変えられる数（既定） |
| --- | --- |
| 一覧 | 並べる施設の仕事の数（3）、顔ぶれが入れ替わる間隔（30日） |
| 満了 | 割増（短い契約 12.5%・長い契約 25%）、上がる好感度（3・6） |
| 途中でやめる | 減る勤続（240日）、一覧に出ない日数（180日） |
| 勤続 | 段階に届く日数（480・1,440・2,880）、賃金（125%・150%・200%）、値引き（5%・10%・15%） |
| 能力値と判定 | 能力値が低いときの賃金の下限（80%）、判定で能力値1つにつき上がる成功率（3%） |
| 良い出来事 | 段階ごとに上がる賃金（10%）、上限（130%）、崩れた段階の賃金（70%） |
| 臨時の募集 | 賃金（150%）、1回の長さ（30日）、回数（3）、務め終えたときに収まる側へ動く段階の数（1） |
| 闇労働 | 危険度ごとの確率（10%・18%・28%）、困り事の間の賃金（130%）、務め終えたときに悪くなる側へ動く段階の数（1） |
| 危険の結果 | 取り締まりで下がる手配度（危険度1つにつき 2）、裏切りで下がる手配度（1）と減る勤続（90日）、仕返しで奪われる額（賃金2期ぶん） |

## ゲームに残るもの

- 進行中の契約と、雇い主ごとの勤続は `state\labor_overhaul\` に、世界と主人公の組ごとに記録する
- 契約を終えるたびに、主人公の人生の記録に「労働の記録」が1行足される（MOD なしの労働と同じ形）
- MOD を外すと、「労働の募集をみる」「闇労働の募集をみる」は MOD なしの労働に戻る。稼いだ金・下がった手配度・上がった好感度は残る
- 契約の途中で MOD を外した場合、その契約は無かったことになる（そこまでの賃金は払われている）

## 困ったとき

| 症状 | やること |
| --- | --- |
| 一覧に施設の仕事が出ず、日雇いの人足だけが出る | その街に、主のいる施設が無い。または途中でやめた雇い主だけが残っている（180日で戻る） |
| 「労働の募集をみる」を押すと MOD なしの画面が出る | `out\labor_overhaul.log` に行が増えているかを見る。増えていなければ MOD が読み込まれていない |
| 働く画面が閉じて役場の選択肢に戻った | 役場（裏の事務所）の選択肢の「仕事に戻る」を押すと続きから働ける |
| 臨時の募集が出ない | 街の出来事の MOD が入っていて、その街で困り事が起きている間だけ出る。良い出来事では出ない |
