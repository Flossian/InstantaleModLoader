# `227_probe_shop_stock`

買った品が店の棚へ戻るのはどこかを録る。**決着済み**で、棚に並ぶのはゲーム自身（`shopping_start_method_1`）が店を開いたときに雛形 `config['goods']` から作り直した別の現物（結果は GAME.md §2.13.1.3、対処は `312_shop_restock`）。録るのは、店の場面の中で生まれた品（`scripts.items:Item.__init__`）の id・持ち主・`attributes` とゲーム側の呼び出し元（ファイル名と行）、店の経路の境目（`ShoppingStartManagerRemake.execute` / `shopping_start_method_1` / `toggle_twin_inventory_window` / `buy_item` / `sell_item` / `close_shopping_window_process` / `Item.buy` / `Item.sell` / `InventoryItem.change_inventory`、店の場面の中の `set_item_from_world_data` / `generate_item_in_shopping` / 生成の3入口）ごとの主と手持ちの鍵の増減、品揃えの雛形の要約（件数・`stock_tier`・`stock_update_date`）と今日の日数、採番台帳 `index['item']`。店の外の品の誕生は既定で録らない（`ITEM_SAMPLES` で件数を決めて録れる）。境目の記録は差分の文だけで、前後の持ち物の丸写しは残さない。出力は `out\shop_stock.log` と `out\shop_stock.jsonl`
