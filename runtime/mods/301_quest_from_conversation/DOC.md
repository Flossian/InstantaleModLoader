# `301_quest_from_conversation`: 会話から依頼を受けられる

話している相手が出した依頼がこの町の掲示板にあると、会話中に「依頼を受ける」が出る。
相手の依頼が無ければ出ない。
いま話した内容から依頼を1件作らせることもでき、作った後はその相手に「依頼を受ける」が出る。

会話から開いた依頼一覧には、**その相手の依頼と「やめる」しか出さない**。
ゲーム自身の「クエストを探す」も、他の MOD が掲示板に足したボタンも出ない（会話の流れで受注する画面なので、
そこで土地の依頼を新しく探し始めると噛み合わない）。
ギルドの「クエスト掲示板」から普通に開いたときは今までどおり全部出る。

依頼を片付けると、そのことが依頼人との会話に伝わる（版2）。
それまでは、クリアしてから依頼人に話しかけても
「まだ出発していないのか」と言われた。
会話に毎回渡っている4つの欄のどこにも依頼の結末が入らないため、
NPC の側は依頼を頼んだところで時間が止まっている。
伝わるのはその相手に出してもらった依頼だけで、判定は上の絞り込みと同じ。
`336_crime_overhaul` の裏の仕事と処刑場からの脱出も、事務所の主と手引き役が依頼人になる。
自分から話を切り出させはしない。
食い違うことを言わなくなるだけで、話題にするかは会話の流れ任せ。

ゲームが作る依頼の多くは、依頼人の名前が実在の人物と結びついていない。
そうした依頼も、片付けるとその街の住人が噂として知る。
住人は依頼人としてではなく、主人公がこの街で片付けた依頼として話す。
裏の仕事と処刑場からの脱出は、誰がやったかは知られず、そういうことがあったらしいという噂になる。
同行している仲間には噂を伝えない。

仲間になっている NPC は依頼人から外れる（既定）。
同行している相手に依頼を出してもらうと、受注した時点でその相手は隣に居る。
依頼人が現地へ付いて来ている形になるので、
パーティに居る間は「依頼を受ける」も「この話から依頼を作る」も出さない。
外れてまた話しかければ、今までどおり出る。

主人公が閉じ込められている間（牢の中の会話など）も、どちらも出さない。
依頼を受ければ牢から出られてしまうため。
閉じ込められているかは、閉じ込める側の MOD がローダの窓口 `confinement` に置く（TECH.md §3.3.13）。

どの依頼を誰に出してもらったかは `state\quest_clients.json` に控え、世界と主人公の組ごとに分けて持つ（版5）。
同じ世界で主人公を作り直すと、前の主人公の依頼の出所は引き継がない。
同じ名前で作り直したときは同じ組とみなして引き継ぐ。
版4までの世界ごとの控えは、その世界を次に遊んだ主人公のものとして移す。
その世界を別の主人公でも遊んだことがあれば、誰のものか分からないので移さない。

| 設定 | 意味 |
| --- | --- |
| その NPC の依頼だけを見せる | 既定 ON。切ると、会話から開いた一覧に町の依頼が全部出て、「依頼を受ける」は相手の依頼が無くても出る |
| 「この話から依頼を作る」を出す | 既定 ON |
| 依頼を作るのに使う会話の発言数 | 既定 12。多いほど話の流れを汲むが、生成が長くなる |
| 同じく文字数の上限 | 既定 2500 |
| 会話の内容を覚えている移動回数 | 既定 3。`0` にすると、会話を出た時点で作れなくなる |
| 仲間になっている NPC は依頼人にしない | 既定 ON。同行中の相手との会話には「依頼を受ける」も「この話から依頼を作る」も出さない。切ると仲間からも依頼を受けられる |
| 依頼人の人物像を依頼の生成に使う | 既定 ON。`311_npc_profile_memory`（NPCが会話を覚える）が覚えた人物像を添えて、依頼人の口ぶりをその人物に寄せる。その MOD を入れていなければ何も起きない |
| 片付いた依頼を依頼人との会話に伝える | 既定 ON。その相手に出してもらった依頼をクリアしていると、会話にその事実が伝わる。切ると、クリア済みでも「まだ出発していないのか」と言われる |
| 会話に伝える依頼の件数 | 既定 3。新しいものから数える。`0` にしても伝わらなくなる |
| 街で片付けた依頼を住人との会話に噂として伝える | 既定 ON。依頼人のいない依頼も、その街の人物が噂として知る。裏の仕事は誰の仕業かを伏せた噂になる |
| 噂として伝える依頼の件数 | 既定 3。新しいものから数え、表の依頼と裏の仕事を別々に数える。`0` にしても伝わらなくなる |

## 困ったとき

| 症状 | やること |
| --- | --- |
| 会話に「依頼を受ける」が出ない | その相手の依頼がこの町の掲示板に無い。`out\quest_offer.log` の `no offer:` に `has no quest on the board here` が出る。依頼は会話の「この話から依頼を作る」で作れる。いつも出したいなら「その NPC の依頼だけを見せる」を切る |
| 会話から開いた一覧に「クエストを探す」が出ない | 仕様。会話から受注する画面なので、依頼と「やめる」だけに絞っている。ギルドの掲示板から開けば出る |
| 仲間との会話中にセーブして、ロードしたら仲間に「依頼を受ける」「この話から依頼を作る」が出る | 版3と版6で直した。ロード中は人物も名簿もまだ揃わず、相手を仲間と見分けられない。版6からは揃うまで2つとも出さず（`the characters are not loaded yet`）、揃ってから組み直したときに仲間でなければ出す |
| 会話中のセーブをロードすると「この話から依頼を作る」に前に話した別の人の名前が出る | 版5で直した。ロードで再開した会話は開始の処理を通らないので、相手を前の会話の控えから引いていた。いまは画面の会話相手から引き、会話中は前の話に落とさない |
| 依頼人の人物像が反映されている気がしない | `out\quest_offer.log` の `inject:` の行に `persona=N chars` が出る。`0` なら記録がまだ無いか、`311_` を入れていない |
| クリアしたのに「まだ出発していないのか」と言われる | `out\quest_offer.log` の `starter:` / `facilitator:` の行を見る（第一声か、そのあとの入力か）。`no completed quest for` なら、その依頼が `state\quest_clients.json` に無いか、依頼の状態がまだ完了になっていない。依頼人の名前が実在の人物でない依頼は、依頼人ではなくその街の住人に噂として伝わる。`+N chars into profile` が出ているなら渡ってはいるので、モデルが古い記憶の方を取っている |
| 別の人が出した依頼まで片付いたことになっている | 依頼人の名前がその NPC と同じ。ゲームが元から持っている依頼の依頼人名は実在の NPC と結び付いていないので起こりうる。「片付いた依頼を依頼人との会話に伝える」を切ると止まる |
