# `115_ui_item_list_fit`: はみ出すアイテム一覧を画面内に収める

入力欄の左下のアイコンから開くアイテム（スキル）の一覧は、
入力欄を下端にして上へ積まれる。
持ち物が増えると画面の上端を突き抜け、先頭の数件が画面の外に出て押せなくなる。
何件で溢れるかは画面の解像度で変わるので、そのときの窓の高さに合わせて収める。

収め方は列を増やすことだけ。
一覧が1列で入り切らなくなったら 2列・3列…と折り返す。
位置も行の大きさも文字の大きさも変えないので、見え方は今までのまま高さだけが減る。
行は1件も隠さない。

| 設定 | 意味 |
| --- | --- |
| 一覧が画面の高さに占めてよい割合 | 既定 0.9。小さくすると早く2列目へ折り返す |
| 列数の上限 | 既定 4。1 にすると列を増やさない（＝この MOD は何もしない） |
| 列数を固定する（0 で自動） | 既定 0 ＝ 件数と画面の高さから自動。2 にすると、収まっていても常に2列 |

一覧が1列で収まっているときは何も触らない。
上限の列数でもまだはみ出す件数のときは `out\item_list.log` にその旨が出るので、
「列数の上限」を上げる。
見つけた一覧の構成（型・親・行数・矩形）も同じログに出る。
