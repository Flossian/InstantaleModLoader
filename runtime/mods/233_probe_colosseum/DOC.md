# `233_probe_colosseum`

闘技場の試合を録る。相手の強さの伸びと報酬を設定で決める MOD の下調べ。試合を1つの窓にして（`ColosseumMatchStart.execute` で開き、勝ちは `BattleEndInColosseum.end_phase`、逃げは `BattleEndManager.end_phase`、負けは `GameOverManager` で閉じる）、窓の前後の所持金と日付・窓の間の文言と `elapse_days`・通った地点の列を `out\colosseum.jsonl` に1行、読む用を `out\colosseum.log` に残す。所持金は**変わった地点で**録る（`add_text` / `elapse_days` / 各段の出入りで見張り、前回と違えば呼び出し元つきで1行。窓が閉じた後も 180 秒は見張る）。報酬の文（`受付: おめでとう！...報酬として<額>Gを貰った。`）は窓の文言の上限とは別枠に採り、額は `ui.parse_coin` で読む（`130_currency_unit` が表記を変えていても読める）。相手の側は `ColosseumMatchStart.generate_enemy_data` の引数と戻りのランク、`llm_manager:colosseum_enemy_generator` の難易度の渡り方と実値、その土地の依頼の難易度（`get_quest_difficulties`。版2で追加）を残す。施設の `config`（`current_phase` と phase ごとのランク）は闘技場に立つたびと各段で写す。ゲームは変えない（200番台の約束どおり読み取りだけ。どの包みも `orig` の戻りをそのまま返す）。**ランクの側は決着**（版1の実機。4つの闘技場・16点が `rank(n) = round(D * (9 + 4n) / 18)` に乗った。`D` は土地の依頼の難易度、`n` は `current_phase` / 2。初戦は D の半分、1試合ごとに D の 2/9 ずつ増え、頭打ちは無い。プレイヤーのレベルには依らず、レベル1でも 30 で始まった。詳細は GAME.md §2.11）。難易度は第4位置引数で渡るが、ゲームは格を頼み文・施設に焼く値・敵の数値の3か所で別々に使うので、頼み文だけ変えても相手は弱くならない（GAME.md §2.11）。報酬は `end_phase` の中で所持金に入る（`instantale.py:8105`、ワーカースレッド）。勝つと `current_phase` は +2、逃げると据え置きで相手が作り直され、負けると即ゲームオーバー（レベル1で `hp = -107`）。報酬に**乱数は乗っていない**（版2の実機。同じランク58でセーブ → 勝つ → ロード → 勝つ を通し、相手の名前が変わっても2回とも 359）。ただし**ランクだけでは決まらない**（ランク30 が `D` 60・61 の初戦では 173、`D` 32 の3試合目では 177）。施設に焼いた `data.rank` も読まない（`334_colosseum_custom` の上限で下げても、下げる前のランクの額が出た）。`D` は一覧の**平均を四捨五入した値**と決まった（4つの闘技場で一致。中央値では合わない。平均 31.67 の土地で切り捨てと分かれた）。**残るは報酬の式そのもの**で、`D` と試合数から別に計算していると見られる。伸びは高いランクで鈍り、ランク70を超えると頭打ち（点は GAME.md §2.11 の表）。版2では `BattleEndManager` の `__init__` と `execute`（`end_type` の実値と呼び出し元。倒れたときに負けとして試合を終えるための材料）と、敵の数値を作る `scripts.functions:get_enemy_exp_lvl` / `get_enemy_attributes_base_point` の引数と戻り（相手の**実際の強さ**はここで決まる。頼み文の格を変えても敵は弱くならない）も録る。版3では、戦闘を終える判定（`BattlePhaseManager.check_battle_end`）の中で終わり方が作られた回に、その戻り値と前後で変わった app と HUD の値を `check_battle_end_ended` 行に、終わり方（`BattleEndManager.execute`）の前後の差を `battle_end_manager_execute` 行に残す（`334_colosseum_custom` が負けを逃走扱いで切り上げると、画面からプレイヤーが消えて敵が一覧に残った。ゲーム自身の逃走が何を片付けているかを比べる材料）。オフラインは `tools\tests\test_colosseum_probe.py`
