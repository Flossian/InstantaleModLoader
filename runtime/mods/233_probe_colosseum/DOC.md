# `233_probe_colosseum`

闘技場の試合を録る。相手の強さの伸びと報酬を設定で決める MOD の下調べ。試合を1つの窓にして（`ColosseumMatchStart.execute` で開き、勝ちは `BattleEndInColosseum.end_phase`、逃げは `BattleEndManager.end_phase`、負けは `GameOverManager` で閉じる）、窓の前後の所持金と日付・窓の間の文言と `elapse_days`・通った地点の列を `out\colosseum.jsonl` に1行、読む用を `out\colosseum.log` に残す。所持金は**変わった地点で**録る（`add_text` / `elapse_days` / 各段の出入りで見張り、前回と違えば呼び出し元つきで1行。窓が閉じた後も 180 秒は見張る）。報酬の文（`受付: おめでとう！...報酬として<額>Gを貰った。`）は窓の文言の上限とは別枠に採り、額は `ui.parse_coin` で読む（`130_currency_unit` が表記を変えていても読める）。相手の側は `ColosseumMatchStart.generate_enemy_data` の引数と戻りのランク、`llm_manager:colosseum_enemy_generator` の難易度の渡り方と実値、その土地の依頼の難易度（`get_quest_difficulties`。版2で追加）を残す。施設の `config`（`current_phase` と phase ごとのランク）は闘技場に立つたびと各段で写す。ゲームは変えない（200番台の約束どおり読み取りだけ。どの包みも `orig` の戻りをそのまま返す）。**ランクの側は決着**（版1の実機。4つの闘技場・16点が `rank(n) = round(D * (9 + 4n) / 18)` に乗った。`D` は土地の依頼の難易度、`n` は `current_phase` / 2。初戦は D の半分、1試合ごとに D の 2/9 ずつ増え、頭打ちは無い。プレイヤーのレベルには依らず、レベル1でも 30 で始まった。詳細は GAME.md §2.11）。難易度は第4位置引数で渡り、渡した値がそのまま `data.rank` に焼かれるので、差し替えはこの1点でよい。報酬は `end_phase` の中で所持金に入る（`instantale.py:8105`、ワーカースレッド）。勝つと `current_phase` は +2、逃げると据え置きで相手が作り直され、負けると即ゲームオーバー（レベル1で `hp = -107`）。報酬も**ランクだけで決まり、乱数は乗っていない**（版2の実機。同じランク58でセーブ → 勝つ → ロード → 勝つ を通し、相手の名前が変わっても2回とも 359。土地が違っても同じランクなら同じ額）。**残るは報酬の式そのもの**で、実測5点（ランク 30 → 173 / 43 → 282 / 44 → 288 / 58 → 359 / 97 → 454）は頭打ちに向かう形、`833 - 3614 / sqrt(rank)` なら 97 以外の4点が誤差1以内（97 だけ +12）。ランク 70〜90 の点が要る（漆黒斗技場はあと2〜3戦で 71 / 85 / 99）。`D` は一覧の**平均を整数に落とした値**と決まった（3つの闘技場で一致。中央値では合わない。切り捨てか四捨五入かだけ未分離）。残るは懸賞金の式そのもの（7点あるが形が出ていない）と、`D` の丸め（平均の切り捨てか四捨五入か。小数部が .5 以上の土地に当たれば分かれる）の2つ。`観戦する` の行き先を録る包みも張ってあるが、**観戦を作ると決めるまで測る意味は無い**（押した回だけ勝手に1行残る）。版2では `BattleEndManager` の `__init__` と `execute`（`end_type` の実値と呼び出し元。倒れたときに負けとして試合を終えるための材料）と、敵の数値を作る `scripts.functions:get_enemy_exp_lvl` / `get_enemy_attributes_base_point` の引数と戻り（相手の**実際の強さ**はここで決まる。頼み文の格を変えても敵は弱くならない）も録る。オフラインは `tools\tests\test_colosseum_probe.py` 63件
