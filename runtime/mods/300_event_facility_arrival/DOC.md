# `300_event_facility_arrival`: 施設でNPCから話しかけてくる

宿屋や店へ入ると、そこに居る NPC の方から会話を始めてくることがある。
ゲーム本来の会話なので、立ち絵と履歴が普通に付く。

| 設定 | 意味 |
| --- | --- |
| イベントの出方 | 会話が始まる（既定） / 情景描写に一言足すだけ |
| 発生率を固定 | 空欄なら施設ごとの既定値。`1.0` にすると必ず発生（動作確認用） |
| 同じ施設で続けて出さない訪問回数 | 一度出たら、その施設に何回入るまで出さないか（既定 2 ＝ 3回に1回まで）。`0` で毎回抽選 |
| NPCから話しかけた体裁にする | 既定 ON。切ると、こちらから話しかけたときと同じ第一声になる |
| 無視された相手が黙るまでの回数 | 話しかけられて一言も返さずに終えた回数（既定 2）。達した相手はその世界で二度と声をかけてこない。`0` で止めない |
| 施設ごとの発生率 | 宿 0.50 / ギルド 0.30 / 雑貨屋 0.25 / 専門店 0.25 / 鍛冶屋 0.15 / 診療所 0.20 / 市政庁 0.25 / 闇市 0.20。`0` にするとその種類の施設では出なくなる |

> 発生率は「その施設に入った1回あたり」の値。
> 同じ宿に何度も寄れば、そのたびに抽選する。
> 同じ相手に何度も話しかけられると感じたら、**「同じ施設で続けて出さない訪問回数」を増やす**。
> 数えているのはその施設への訪問回数なので、間に別の場所へ寄っても回数は進まない。

> **相手を黙らせたいときは、返事をせずに会話を終える。**
> 既定では2回でその NPC は声をかけてこなくなる。
> こちらから話しかける分は今までどおりで、止まるのは「NPC の方から始まる」イベントだけ。
> 数えた結果は `state/arrival_event/` に世界ごと残るので、ゲームを閉じても続く。
> やり直したいときはそのファイルを消す。

## 困ったとき

| 症状 | やること |
| --- | --- |
| NPC の立ち絵が消えず、移動しても付いてくる | その NPC ともう一度会話して、普通に「会話を終了する」を押す |
| 一度戦闘したらNPCから話しかけられなくなった | `107_fix_battle_flag_stuck` を入れて注入し直す |
