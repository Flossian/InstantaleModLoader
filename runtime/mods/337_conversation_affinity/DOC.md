# `337_conversation_affinity`: 会話による好感度の変動

素のゲームでは、NPC の好感度は依頼のクリアで同行者に +20 されるだけで、会話ではほとんど動かない。
この MOD を入れると、会話を閉じるたびに相手の気持ちがどう動いたかを判定し、好感度が上下する。
判定はゲーム自身の会話の要約に相乗りさせるので、LLM を呼ぶ回数は増えない。
画面には何も出ない。
好感度の段が変わると、相手の態度（ゲームの感情の文）に表れる。

## 決まり

- 判定は会話を閉じたときに1回。-3〜+3 の段で、用件だけのやり取りや普通の雑談はほぼ 0。おだてたり媚びたりしただけでは上がらない
- 上がるときは1段 +2（最大 +6）、下がるときは1段 -4（最大 -12）
- 会話だけで上がるのは好感度 60（「仲間だと感じている」）まで。それより上は依頼に同行して上げる
- 他の MOD が相手ごとに上限を狭めていれば、そちらで止まる（ローダの窓口 `talk_affinity`）
- 同じ相手から上がるのは1日1回まで。日数は宿泊・街の移動でしか進まないので、同じ街で話し続けても稼げない
- 下がる方は会話のたびに毎回効く。失礼な会話を繰り返せばそのぶん嫌われる
- 話しかけてすぐ閉じただけの会話は判定しない。何か言ったか、贈り物・売り買いなどの行動があれば判定する
- 判定するのは会話の相手1人だけ。`404_party_talk` で同席した仲間は判定しない
- MOD の NPC（`330_` の管理人・`331_` の主人）は対象にしない
- 判定の答えは要約の文・会話の記憶・セーブに混ざらない
- 会話を正規の経路で閉じなかったとき（会話の途中でタイトルへ戻ったなど）は、ゲームの要約と同じく判定も走らない

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 上がる1段あたり | 2 | 判定 +1〜+3 の1段ごとに足す |
| 下がる1段あたり | 4 | 判定 -1〜-3 の1段ごとに引く |
| 会話で上げられる上限 | 60 | 会話だけではこれより上へ上がらない |
| 上がるのは同じ相手から1日1回 | ON | 下がる方は毎回効く |

## 他の MOD との重なり

| MOD | どうなるか |
| --- | --- |
| `326_npc_travel` | 旅に出る条件の「友好度 20 以上」に、会話でも届くようになる |
| `125_balance_charisma_impression` | 好感度が上がると「親しさ」の不足が減り、魅力の段が上がる |

## 困ったとき

| 症状 | やること |
| --- | --- |
| 話しても動かない | `out\conversation_affinity.log` の `judge:` の行の `zero`（判定 0）・`daily`（今日はもう上がった）・`ceiling`（上限）で理由が分かる。他の MOD が上限を狭めた相手は行末に `[ceiling 30 by <MOD>]` と出る。`skip:` なら判定していない |
| 動き方が大きすぎる・小さすぎる | 「上がる1段あたり」「下がる1段あたり」を変える。依頼のクリア1回は同行者に +20 |
| 会話を閉じてから次の画面までが遅い | 要約の返答に判定の2項目が増えたぶんだけ延びる（実測で会話を閉じる処理は全体 1.8 秒）。`retry:` が出ていれば、判定を足した形で要約が失敗し、元の形で送り直している |
