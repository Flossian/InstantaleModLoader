# `327_inn_quality`: 宿の部屋の等級を効かせる

素のゲームでは 10G の部屋と 1000G の部屋で起きることが同じで、高い部屋を選ぶ理由が無い。
体力も仲間の回復もどの部屋でも全快する。
この MOD は等級に3つの意味を足す。

## 1. 高い部屋ほど1回の宿泊で多く過ごせる

素のゲームは宿泊1回につき活動（訓練・休養・労働・社交・物乞い）が1回で、宿代と30日をもう一度払わないと次の活動ができない。
高い部屋なら同じ宿代・同じ30日で複数の活動ができる。

| 部屋 | 活動の数（既定） |
| --- | --- |
| 犬小屋 | 1 |
| 簡易寝台 | 1（素のまま） |
| 個室 | 2 |
| 高級個室 | 3 |

活動を1つ終えると、残りがあるあいだは「まだ宿泊する／宿泊を終える」の前に活動の選択肢がもう一度並ぶ。
文言も中身もゲーム自身の活動で、この MOD が足すのは並べ直しだけ。

## 2. 宿の主が常連を覚える

宿泊のたびに宿の主の好感度が部屋の等級ぶん上がる（既定 犬小屋 0 / 簡易寝台 +1 / 個室 +2 / 高級個室 +4）。
宿泊で上がるぶんは宿の主ごとに累計 +20 で止まる。
初対面の「警戒心がある」から「嫌いではない」までで、それより先は会話で築く範囲になる。
会話で好感度が動くぶんはこの上限に数えない。

宿の主と話すときは、AI に渡す本文へ宿泊の履歴が1行入る。

```text
【宿の客として】プレイヤーは宿にこれまで5回泊まっている（個室2回・高級個室3回）。最後の宿泊は12日前。
```

記録は `state\inn_regular\<世界名>.json` に宿の主ごとに入る。
`311_npc_profile_memory` の記録は読みも書きもしない。
宿の主がこの1行を台詞にすれば、次の会話から 311 が自分で覚える。

## 3. 社交で会う相手が部屋で変わる

素のゲームの社交は、泊まっている宿に居る人から相手が選ばれる（宿の主が多い）。
この MOD は部屋の等級で、どこまで上の段から相手を選ぶかを決める。
相手の段は上から 同行者 → このエリアで好感度の高い相手 → このエリアの生成済み NPC からランダム。

| 部屋 | 相手（既定） |
| --- | --- |
| 犬小屋 | ランダム |
| 簡易寝台 | ゲームのまま |
| 個室 | 好感度の高い相手から。居なければランダム |
| 高級個室 | 同行者から。居なければ好感度の高い相手、居なければランダム |

社交の中身（描写・好感度の変動）はゲームのままで、変わるのは誰と会うかだけになる。

| 設定 | 意味 |
| --- | --- |
| 部屋ごとの活動の数 ×4 | 既定 1 / 1 / 2 / 3。素のゲームは全部屋 1 |
| 宿の主が常連を覚える | 既定 ON。切ると好感度も会話の1行も動かない |
| 部屋ごとに上がる好感度 ×4 | 既定 0 / 1 / 2 / 4 |
| 宿泊で上がる好感度の上限 | 既定 20。宿の主ごとの累計 |
| 宿の主との会話に足す1行 | 使える変数 `{name}` `{stays}` `{rooms}` `{ago}` |
| 部屋ごとに社交する相手 ×4 | 既定 ランダム / ゲームのまま / 好感度 / 同行者 |
| 「好感度の高い相手」の下限 | 既定 10 |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 活動を終えても選択肢が戻らない | `out\inn_quality.log`。`stay: no elapse_days in the window` なら宿泊が成立していない（宿代が足りない等）。`menu:` の行が無ければ、活動の一覧を写せていない |
| 好感度が上がらない | 同じログの `regular:` の行。`has no relationship['player']` なら初対面の主で、一度会話してから泊まると上がる。`granted 20/20` なら上限 |
| 会話に履歴の1行が出ない | `prompt at` の行が無ければ、会話相手が記録に無い主（別の宿）か、まだ一度も泊まっていない |
| 社交の相手が変わらない | `out\inn_quality.log` の `social:` の行。`untouched (game default)` はその部屋の設定が「ゲームのまま」。`no candidate` は同行者も生成済み NPC も居ない。`WARN swap ineffective` はゲームが宿の名簿以外から相手を選んでいて、この MOD の差し替えが届いていない |
| 記録をやり直したい | `state\inn_regular\<世界名>.json` を消す。好感度の既に上がったぶんはセーブに残る |
