# `340_shop_lineup`: 宿屋と鍛冶屋でも売買でき、店の種類ごとに品揃えの傾向が付く

素のゲームの宿屋と鍛冶屋には「売買する」が無い。
宿屋は泊まるか話すだけ、鍛冶屋は装備の強化だけになる。
また、ゲームはどの店の品揃えにも武器と防具を必ず1つずつ入れるので、診療所や香水店にも剣と鎧が並ぶ。

この MOD は、宿屋と鍛冶屋に店と同じ「売買する」を足し、店の種類ごとに並ぶ品の傾向を付ける。

```text
宿屋    売買する / 宿泊する(3ヵ月) / 出る / 会話する
鍛冶屋  売買する / 装備の強化 / 出る / 会話する
```

宿屋の並びは `135_fix_inn_button_order` が入っているとき。入っていなければ `売買する / 出る / 宿泊する / 会話する` になる。

店の主と同じく、宿屋と鍛冶屋の主と話している間も「売買する」が先頭に出る。

押した後は、ゲームの店と同じ売買の画面になる。
品揃えはゲームが作り、値段・確認の画面・値切りの交渉もゲームのまま動く。
初めて開いたときは、店と同じく品揃えの生成を少し待つ。

## 並ぶ品

品揃えを作るとき、「武器と防具を必ず1つずつ」の指示を店の種類ごとの傾向に替える。

| 店 | 中心に並ぶ品 |
| --- | --- |
| 雑貨屋・道具屋 | 回復アイテム・道具・武器・防具・素材を幅広く |
| 鍛冶屋 | 武器と防具 |
| 宿屋 | 料理・飲み物・酒。回復薬も少し |
| 診療所・薬屋 | 回復薬・ポーション・薬・薬草 |
| 専門店（宝飾店・香水店など） | 店の名前と説明に合う品。武器や防具は看板に合うときだけ |

傾向は「中心」を頼むだけで、ほかの品が混じるのは止めない（鍛冶屋に回復薬が並ぶこともある）。
宿屋や診療所に武器・防具が1つずつ紛れるのが気になるときは、設定の「店の種類に合わない武器・防具も並べる」を切る。
切ると宿屋と診療所では武器・防具を作らず、返ってきても棚に入れない。
初めて開いた店で武器・防具を外したときは、棚が寂しくならないように、その店の傾向の品を2〜6品足す（足す数はその都度変わる。LLM を1回待つ）。
専門店は看板が武器・防具の店もあるので、この設定では止めない。
`405_regional_economy` の特産品はどの店にも1つ並ぶ。品目は土地の特産品のままで、店の傾向とは限らない。

傾向が付くのは品揃えを作るときだけ。
すでに品揃えのある店は、そのままの棚で売り続ける。
`312_shop_restock` が入っていれば、入れ替えのときに傾向どおりの棚へ替わる。

## 設定

| 設定 | 意味 |
| --- | --- |
| 店の種類に合わない武器・防具も並べる | 既定 ON。切ると宿屋と診療所では武器・防具を作らない（`312_shop_restock` の入れ替えでも同じ）。初めて開いた店で外したときは、傾向の品を2〜6品足す。すでに棚にある品は、次の入れ替えまでそのまま |

## 売る

売る側はゲームの店と同じで、宿屋と鍛冶屋の主にも何でも売れる。

## ほかの MOD と一緒に使うとき

| MOD | この MOD と一緒だと |
| --- | --- |
| `312_shop_restock` | 宿屋と鍛冶屋の品揃えも日数で入れ替わる。入れ替えでも店の種類ごとの傾向で作る |
| `336_crime_overhaul` | 宿屋と鍛冶屋の棚からも盗める。盗んだ品はその店では売れない |
| `338_town_incidents` / `336_crime_overhaul` の店主の委縮 | 店と同じく、宿屋と鍛冶屋の値段にも効く |
| `331_facility_investment` | 自分の施設には足さず、傾向も付けない（自分の施設は 331 が開く） |

## 外したとき

宿屋と鍛冶屋の「売買する」は、次に入り直すと消える。
主が持っている品と、ゲームが施設に書いた品揃えの雛形はセーブに残る。
どちらもゲームの店と同じ形なので、外しても遊びには響かない。
次に品揃えを作るときから、ゲームの指示（武器と防具を1つずつ）に戻る。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 宿屋や鍛冶屋に「売買する」が出ない | `out\shop_lineup.log` の `entry: copied` と `sweep:` の行。`entry:` が無ければ、その世界にまだ店が1軒も無い（店から写すので、店のある街を一度読み込むと出る）。読み込んだ直後は、何か1つ選ぶと出る |
| ある宿屋・鍛冶屋にだけ「売買する」が出ない | 同じログの `withheld at` の行。セーブエディタで足した施設は世界の素データ（`world_data.json`）に入っておらず、ゲームの売買が開けない（押すとエラーになる）ので出さない。`146_fix_save_only_entities` の設定（既定 OFF）を入れていれば出る（その MOD が開けるようにする）。エディタで施設と主を `world_data.json` にも写しても出る |
| 店の傾向と違う品ばかり並ぶ | 同じログの `done at` の行（種類ごとの数が並ぶ）。`rewrites=0` ならゲームの指示文が変わって差し替えが当たっていない。`dropped=` は設定で棚に入れなかった武器・防具の数。前から品揃えのある店は、作り直すまで元の棚のまま |
| 売買の画面が開かない | `out\modloader.log` の例外。主が引けないとゲームが売買を始められない |
