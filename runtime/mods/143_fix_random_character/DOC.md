# `143_fix_random_character`: ランダムで作るキャラを世界観に合わせ、作りもばらつかせる

ゲームのままだと、キャラを作る画面のランダム作成は世界の設定を見ない。
生成 AI に渡るのは「大人向けの無骨で無慈悲なダークファンタジーRPG」という決まった一文と才能点だけで、
どの世界でも同じプロンプトになる。
剣も魔法も無い世界でも、戦場を渡り歩く傷だらけの傭兵が出やすい。
続けて立ち絵の英語の要素を作るプロンプトも世界を受け取らないので、立ち絵の装いも世界と関係なく決まる。
才能点は貯まっている点がそのまま渡り、プロンプトの目安（30 で一端の冒険者・150 で伝説）に引かれて、毎回同じくらいの点数と年齢に落ちる。

この MOD は2つのことをする。

**世界観を渡す。**
ランダム作成のプロンプトと立ち絵の要素のプロンプトに、いま作っている世界の名前・概要・情勢と、次の指示を足す。

- 冒頭の役の説明にあるジャンル（ダークファンタジーなど）より、世界のデータを優先する
- 名前・出自・生業・装い・持ち物は、その世界にありうるものにする
- スキルの名前・属性・効果は、その世界の技術・道具・文化から作る。属性は火・水・毒・闇に寄せない
- 特質は、その世界での暮らし・生業・体験から作る
- 世界の概要と食い違うもの（概要が否定している技術・魔法、世界の雰囲気に合わない生き物・道具・職業）は使わない。概要が触れていないことは、概要の雰囲気から自然に補ってよい（剣や魔法を書いていないだけの短い概要の世界で、それらまで避けないため）

世界のデータが読めないとき（世界名と `worlds\` の下のフォルダ名が違う世界など）は世界を足さない。
`144_fix_hardcoded_worldview` も世界の無いプロンプトのジャンルは外さないので、そのときのランダム作成はゲームの既定（ダークファンタジー）のまま作られる。
- 出自はその世界に暮らす人々のさまざまな身分・生業から選び、傭兵や兵士に決め打ちしない
- 立ち絵の英語の要素にも、その世界の装い・技術水準・種族が分かる語を入れる

**作りをばらつかせる。**
ランダム作成のボタンを押すたびに、次の目安を引いてプロンプトに足す。

- 使う才能点: 下限〜上限（既定 10〜150）から引く。貯まっている点が上限より少なければ、貯まっている点まで
- 年齢: 20〜50 歳から、若いほど出やすく引く（平均は約 30 歳、40 歳以上は1割台）。ゲームの決まりでは若くするほど才能点が要るので、若い年齢を引いた回は、その年齢に届くところまで使う才能点を引き上げる（20 歳ならおよそ 132 点以上）。貯まっている点が足りなければ、届く年齢から引き直す
- 能力値: 6つのうち2つを高く、1つを最も低くする

才能点を実際に数えるのは画面で、生成 AI は目安に沿って配分する。目安の点数ちょうどになるとは限らない。

作成画面でスキルや特質の枠から生成するとき（スキル・特質の生成のプロンプト）にも、同じ世界と「スキルの名前・属性・効果は世界の技術・道具・文化から作る（属性は火・水・毒・闇に寄せない）」「特質は世界での暮らし・生業・体験から作る」を足す。
ランダム作成の指示にも同じ2つが入っている。

プロンプトの冒頭の「ダークファンタジーRPG」と、絵の前置きの `medieval` などを外すのは `144_fix_hardcoded_worldview`。

`132_npc_variety` も入っていれば、ランダムで作った主人公に髪・瞳・肌・体格・服と来歴の種も付く（同じ世界で同じ型が続くのを止める）。

人物欄から主人公の立ち絵を描き直すとき（`335_player_portrait_regenerate`）も、立ち絵の要素のプロンプトに遊んでいる世界が付く。

| 設定 | 意味 |
| --- | --- |
| ランダム作成と立ち絵の要素のプロンプトに世界を渡す | 既定 入。概要と情勢は全文を渡す |
| 世界の情勢も渡す | 既定 入。世界を作ったときの「いま世界で起きていること」。切ると名前と概要だけ |
| 才能点・年齢・能力値をランダム作成のたびに引く | 既定 入。切ると点数と年齢は生成 AI のまま |
| ランダム作成で使う才能点の下限 | 既定 10 |
| ランダム作成で使う才能点の上限 | 既定 150。貯まっている点が少なければそこまで |
| したことを記録する | 既定 入。`out\random_character.log` |

| 症状 | やること |
| --- | --- |
| 世界に合わない | `out\random_character.log` に、ランダム作成のボタンを押した時刻の `[WORLD] … character` が出ているか。`[SKIP]` なら世界のデータが読めていない（世界名と `worlds\` の下のフォルダ名が違う世界など） |
| 点数や年齢が目安とずれる | 同じログの `[BUILD]`（引いた目安）と `[COST]`（画面が数えた残りと年齢）を見比べる |
| 何も出ない | `out\modloader.log` の `random character: armed on` で仕掛かっているか |
