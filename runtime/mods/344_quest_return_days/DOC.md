# `344_quest_return_days`: 依頼から帰還すると日付が進む

素のゲームは依頼の間に日付が進まないので、出発前の会話がその日の続きになり、戻ってきても「さっきの件は」と言われることがある。

この MOD を入れて設定を有効にすると、依頼を片付けるか放棄して帰還したときに日付が進む。
出発前の会話は前の日の出来事になる。

**既定は切。** 設定の「依頼から帰還すると日付を進める」を入れたときだけ働く。

- 進むのは宿の宿泊1回の日数で、上限で止まる。上限の既定は30日
- 素のゲームの宿泊は3ヵ月以上なので、`315_vacation_custom` で宿泊期間を短くしていなければ毎回30日進む
- 帰還の文の後に「帰還してから30日が過ぎた。」と出る
- 依頼の戦闘から逃げただけでは進まない。依頼は続いているため
- `307_area_move_dungeon` と `325_road_opening` の道中の依頼を片付けたときは足さない。到着までの日数が別に進むため。放棄したときは進む

日付が進むので、日数で動くものも依頼のたびに動く。

- 家賃や施設の売上、街の出来事、追手、NPC の旅などが今より早く進む
- 仲間の体力は全快する（ゲームの日数送りの動き）
- 主人公の体力は戻らない。宿で休む必要は今までどおり

| 設定 | 意味 |
| --- | --- |
| 依頼から帰還すると日付を進める | 既定 OFF。入れると上の動きになる。切ると何もしない |
| 進める日数の上限 | 既定 30（1〜30）。宿の宿泊日数がこれより長いときは、この日数で止まる |

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 日付が進まない | 設定が入っているか。`out\modloader.log` に `quest return days: off` が出ていれば切れている。入っていれば `out\quest_return_days.log` の `cleared` / `abandoned` の行 |
| 進む日数が思ったのと違う | `out\quest_return_days.log` の `day 12 -> 42 (30 day(s), the limit is 30)` の形の行。宿泊期間の設定と上限を見る |
