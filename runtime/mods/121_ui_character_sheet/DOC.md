# `121_ui_character_sheet`: 人物欄に手配度・スキル・特性を出す

> `317_reputation` を入れていると、レベル行の続きに二つ名が出て、
> その右に引き直しのボタンが付く（あちらが保存したファイルを読むだけなので、
> あちらを OFF にすれば何も出ない）。
> 読むのはいま遊んでいる世界と主人公の組の保存データで、同じ世界で作り直した前の主人公の二つ名は出ない（版5）。
> あちらの名声がまだ二つ名の線に届いていなければ、二つ名もボタンも出ない（版6）。

プレイヤーのプロフィール画面を左・上・下へ広げ、そこに手配度・スキル・特性を足す。
MOD なしのプロフィール欄は右半分が能力値と空の箱、左半分が出自と健康状態だけで、
キャラクタが持っている手配度・スキル・特性はどこにも出ていない。

特性はゲームが作ったまま一度も使っていない空の箱を借り、
手配度とスキルは新しく2枚足す。
文字の書体・大きさ・色は隣の健康状態の欄からコピーするので、
見た目はゲームのまま変わらない。
枠線もゲーム自身の描画を借りている。
能力値だけは中央寄せから左詰めに直す（列に並べると中央寄せは浮いて見え、
書体によっては右端が欠けるため）。
出自・手配度・能力値の3列は上端を揃えてある。

手配度は土地ごとに並ぶ（ダンジョンは除く）。
0 未満が犯罪者で、平常値は 10。
どの土地でいくつ手配されているかは、ここで初めてまとめて見られる。

スキルと特性の箱は狭く、名前が1つぶんしか見えない。
箱にマウスを乗せると、全部の名前と説明を並べたウィンドウが出る。
スキルは残りの使用回数と属性も並ぶ。
特性に数値の効果を付ける MOD を入れていれば、特性の効果も並ぶ（いまの場面で効いていない効果は灰色）。
マウスを箱から外すか、人物欄を閉じると消える。

出自と手配度も、文が箱に収まらないときはマウスを乗せると全文のウィンドウが出る（版9）。
手配度は上限で並べなかった土地も含めて全部並び、0 未満の土地は赤で出る。
箱に収まっているときは何も出ない。

健康状態の欄は、怪我のある部位を `胴体: 軽傷` の形で1行ずつ並べる（版8）。
欄に入るのは2行までなので、3部位からは1行に2つか3つ並ぶ。
MOD なしでは `body: hurt, ` と英語のまま出て、何が下がったかはどこにも出ない。
欄にマウスを乗せると、部位ごとに下がっている能力値と怪我の重さを並べたウィンドウが出る。

```
胴体　軽傷
・耐久 30 → 28（×0.95）
・体力の上限 ×0.97
怪我の重さ 12（30 で重傷）
```

怪我の重さは依頼の出来事で増える数で、10・30・60・100 に届くたびに段階が1つ重くなる。

| 部位 | 1段階目 | 2段階目 | 3段階目 | 4段階目 |
| --- | --- | --- | --- | --- |
| 腕 | 軽傷：器用 ×0.95 | 重傷：筋力 ×0.95・器用 ×0.85 | 麻痺：筋力 ×0.85・器用 ×0.75 | 使用不能：筋力 ×0.75・器用 ×0.75 |
| 脚 | 軽傷：器用 ×0.95 | 重傷：耐久 ×0.95・器用 ×0.85 | 麻痺：耐久 ×0.85・器用 ×0.75 | 使用不能：耐久 ×0.75・器用 ×0.75 |
| 胴体 | 軽傷：耐久 ×0.95 | 重傷：筋力 ×0.95・耐久 ×0.85 | 重体：筋力 ×0.85・耐久 ×0.75 | 危篤：筋力 ×0.75・耐久 ×0.75 |
| 頭 | 軽傷：魅力 ×0.95 | 重傷：知力 ×0.95・魅力 ×0.85 | 重体：知力 ×0.85・魅力 ×0.75 | 危篤：知力 ×0.75・魅力 ×0.75 |
| 内臓 | 軽傷：耐久 ×0.95 | 重傷：耐久 ×0.85 | 重体：耐久 ×0.75 | 危篤：耐久 ×0.75 |
| 精神 | 軽い不調：判断 ×0.95 | 重い不調：知力 ×0.95・判断 ×0.85 | 衰弱：知力 ×0.85・判断 ×0.75 | 錯乱：知力 ×0.75・判断 ×0.75 |

体力の上限は部位によらず、段階ごとに ×0.97・×0.95・×0.9・×0.85。
倍率はどれもゲームが掛けているもので、この MOD は見せるだけ。
4段階目も能力値が下がるだけで、部位を失うことも死ぬこともない。

能力値の行が `耐久 ×0.95` と倍率だけで灰色のときは、その倍率がいまの能力値に効いていない。
ゲームはセーブを読み込んだ直後、怪我を残したまま能力値だけを元の値に戻す。
次に依頼の出来事で怪我の判定が走ると、また効く。
`149_fix_injury_after_load` を入れていれば、読み込みの直後から効く。

立ち絵は人物欄の外にあるので動かない。
広げるのは左・上・下で、右は立ち絵に被らないところで止めてある。

| 設定 | 意味 |
| --- | --- |
| 枠の左端／右端 | 画面幅に対する割合（既定 0.02 / 0.645）。左端は画面下のステータス欄に揃え、右端は立ち絵の手前 |
| 枠の上端／下端 | 画面高さに対する割合・上から測る（既定 0.03 / 0.65）。下端は画面下の情報欄の手前 |
| 手配度に並べる土地の数の上限 | 既定 24。箱に入り切らないぶんは並べない（マウスを乗せたウィンドウには全部出る） |

人物欄はゲームが開くたびに寸法を入れ直すので、この MOD も開いた直後に毎回再適用する。
ウィンドウの大きさを変えたときも同じ。
遊んでいる途中で MOD を外すと、
広げた寸法はその回のあいだ戻らない（ゲームを起動し直せば戻る）。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 欄が広がらない | `out\modloader.log` の `character sheet: panel at ...` の行。出ていなければ人物欄を見つけられていない |
| 他の欄に食い込む | 同じ行に実際の四辺が出る。`枠の下端`（既定 0.65）を小さくすると上へ戻る |
| 手配度が空のまま | `character sheet: N area(s)` の N が 0 なら、その土地でまだ手配度が付いていない |
| 健康状態の説明の能力値が灰色 | 読み込み直した後は、怪我が能力値に効いていない。上の説明のとおりで、MOD の不具合ではない。`149_fix_injury_after_load` を入れると出なくなる |
