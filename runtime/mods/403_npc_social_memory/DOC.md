# `403_npc_social_memory`: NPC同士がお互いを認知し、関係を覚える

`311_npc_profile_memory` を入れると、NPC はプレイヤーとの会話を覚えるようになる。
だが NPC 同士はお互いを知らないままで、仲間を連れて誰かと話しても、
会話相手はその仲間が視界に入っていないかのように振る舞う。
昨日プレイヤーと口論した仲間を連れて同じ店に入っても、店主は何も覚えていない。

この MOD は、その「NPC から見た別の NPC」を作る。仕事は2つ。

## 1. 会話の場に同行者を立たせる

仲間を連れて NPC と話すと、会話相手のプロンプトに1枚足される:

```
【現在この場に同行している人物】
以下の人物は現在プレイヤーと同行し、この会話の場にいる。あなたが演じるのは
会話相手であるあなた自身だけで、同行者の台詞を代行してはならない。
ただし存在・発言・既知の関係は認識してよい。
- プレイヤー (id=80)
  ゲーム側の基本情報（短縮）: profile: 宿の娘。...
  311の人物像（短縮）: ...
  プレイヤーから見た主人公: ...
  403が記録した関係（短縮）: 信用していない。値切りの件を根に持っている。
```

会話相手は同行者の存在と関係を踏まえて話すが、同行者の台詞は演じない。
まだ関係の記録が無い相手については「初対面か既知かを捏造しない」と明示する。

## 2. 会話が進むたびに関係を更新する

会話が1ターン進むごとに、直近のやり取り（既定10往復・最大2,600字）と
参加者全員の情報を抽出用のLLMへ渡し、
「誰が誰をどう認識し直したか」を裏で更新する。記録は**方向つき**で、
プレイヤー→仲間と仲間→プレイヤーは別々に持つ。プレイヤーについての記録は作らない
（そちらは 311 の仕事）。

- 記録は各方向「現在の認識の短い要約」（既定600字目安）と、
  確定した事実の控え（既定で最大10件）の2本立て
- 抽出は裏のワーカーが1本ずつ処理する。会話はその間も止まらない
- 311 が既に持っている人物像・プレイヤー観は抽出の材料として読む。
  嫉妬や対抗心のような反応は、その人物設定から自然に導けるときだけ記録される
- 参加者は会話相手＋同行者で、既定6人まで。1対1で同行者がいなければ何もしない

## しまい方

- 記録は `state\npc_social_memory\<世界名>.json`。世界ごとに別で、
  この MOD だけが書く。消せば関係の記憶だけが消え、ゲーム本体は無傷
- 311 の記録は読むだけで、書き換えない
- MOD を外しても、セーブや 311 側には何も残らない

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| 関係抽出に載せる直近のやり取りの数 | 10 | 増やすと取りこぼしが減るが、抽出への入力が増える |
| NPC→NPC関係記録の目標長 | 600 | 各方向の要約の目安。保存や注入で機械的には切らない |
| NPC間で判明した事実を残す件数 | 10 | 方向ごとの追記控え。要約で落ちた認識を次回抽出へ戻す。0で残さない |
| 会話相手へ同行NPCの人物情報も見せる | ON | OFF にすると名前と関係だけになる |
| 1回の関係抽出で扱うNPC上限 | 6 | 大人数時のプロンプト肥大を防ぐ |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 関係が育っている気がしない | `out\npc_social_memory.log`。ターンごとに `extract queued`、更新されれば `updated 誰→誰` が出る |
| `extract skipped: fewer than two NPC participants` | 1対1の会話で同行者がいない。記録するNPCのペアが無いので何もしない、の正常な報告 |
| 反映が1歩遅れる | 仕様。抽出は裏で走るので、今の会話の変化が載るのは次のターン以降 |
| `structured route unusable` が出た | 構造化応答を返せない LLM 構成。以後は普通の JSON で聞き直す経路に固定される。ローカルLLMでは正常な切り替え |
| 覚え違いをリセットしたい | `state\npc_social_memory\<世界名>.json` を消す。その世界のNPC同士の記憶だけが初期化される |
