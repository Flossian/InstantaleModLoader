# `302_leave_party_in_conversation`: 会話から仲間と別れられる

本来は死別とクエスト解散でしか外れない仲間を、会話から「ここで別れる」で外せる。
別れた相手は雇われた場所（土地を跨いだ場合はいまの町のギルド）に残る。

| 設定 | 意味 |
| --- | --- |
| 雇った場所に戻す | 既定 ON。OFF にするとゲーム任せ |

## 困ったとき

| 症状 | やること |
| --- | --- |
| 仲間と別れるボタンが出ない | 仲間が居ないと出ない。まず NPC を雇う |
| 「ここで別れる」を選んでも別れられない | 人の居る場所（町など）へ戻ってから。ダンジョンでは別れられない |
| 仲間との会話中にセーブして、ロードしたら「ここで別れる」が無く依頼の選択肢が出る | 版2で直した。ロード中に本体が選択肢を組む時点では名簿が `['player']` だけで、相手が仲間と分からない。名簿が復元されてから選択肢を組み直す（ローダの `ui.refresh_choices_after_load`）。`out\party_leave.log` に `refreshed the choices after the load` が出る。最初の直しは `app.buttons` だけ直して画面に塗らず、文字は古いまま押すと「ここで別れる」が走った（実機）。塗る処理（`via hud.update_button_texts`）まで通してある |
