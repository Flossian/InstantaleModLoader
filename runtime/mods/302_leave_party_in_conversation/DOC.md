# `302_leave_party_in_conversation`: 会話から仲間と別れられる

> `348_party_departure` が取り込んだため無効化。
> デバッグモードのときだけ読み込まれます（README「デバッグモード」）。
> 348 の「会話から仲間と別れられる」が同じ選択肢を出します（348 の DOC.md）。「別れた相手を雇った場所に戻す」の値は 348 の「別れた仲間を会いに行ける場所に残す」へ引き継がれます。

本来は死別とクエスト解散でしか外れない仲間を、会話から「ここで別れる」で外せる。
別れた相手は雇われた場所（土地を跨いだ場合はいまの町のギルド）に残る。

| 設定 | 意味 |
| --- | --- |
| 雇った場所に戻す | 既定 ON。OFF にするとゲーム任せ |

## 困ったとき

| 症状 | やること |
| --- | --- |
| 仲間と別れるボタンが出ない | 仲間が居ないと出ない。まず NPC を雇う |
| 「ここで別れる」を選んでも別れられない | 人の居る場所（町など）へ戻ってから。ダンジョンでは別れられない |
| 仲間との会話中にセーブして、ロードしたら「ここで別れる」が無く依頼の選択肢が出る | 版2で直した。ロード中に本体が選択肢を組む時点では名簿が `['player']` だけで、相手が仲間と分からない。名簿が復元されてから選択肢を組み直す（ローダの連携 API `choices`。TECH.md §3.3.14）。`out\modloader.log` に `choices: after load: refreshed` が出る。画面のボタンの文字も一緒に更新する（`via hud.update_button_texts`） |
