# `130_currency_unit`: 通貨の呼び名と所持金の表示を変える

素のゲームの通貨は「ゴールド」。
画面には長い形（`1000ゴールドを支払った。`）と
短い形（`馬車(1000G)` / `簡易寝台(10G)` / `貴族権(1,000,000G)`）の2つで出る。
この MOD はその2つを好きな表記に差し替える。
「円」「シルバー」「ドル」「クレジット」など、入れた文字がそのまま使われる。

ゲーム内の LLM も同じ表記で話す。
ゲームが LLM へ送る指示文にも通貨は書かれている
（雇用費・治療費・宿代・市民権の値段）。
それも画面と同じ1点（`scripts.languages:tr`）を通るので、
差し替えた表記のまま LLM に届く。
NPC はその呼び名で値段を言い、こちらの入力もその呼び名の世界として読まれる。

表記を変える前に貯まった人生ログ・会話の記憶・世界観には
「ゴールド」が残っている。
これらは送る直前に直すので（設定「LLM へ送る文章も直す」。既定 ON）、
古いセーブで始めても LLM から見える通貨は1つに揃う。

同梱の他の MOD が出す文言も一緒に変わる
（`309_` の罰金、`314_` の馬車代、`315_` の宿代）。

## 画面上部の `Gold:` も変えられる

画面上部の能力欄（`Atk` `Def` `Exp` `Gold:` `Age:` …）は翻訳の表に載っておらず、
日本語で遊んでいても `Gold:13184` と英語のまま出る。
ここの `Gold` も通貨の呼び名なので、**呼び名を変えれば一緒に変わる**。
「シルバー」にすれば `シルバー:13184` になる。設定は要らない。

見た目そのものを決めたいときは、設定「画面上部の所持金の表示」に書式を書く:

| 書いたもの | 画面 |
| --- | --- |
| `Gold:{amount}` | 既定。呼び名に合わせて `シルバー:13184` |
| `所持金:{money}{short}` | `所持金:13,184Slv` |
| `{money} {long}` | `13,184 シルバー` |
| `${money}` | `$13,184` |

使える変数は4つ。
`{amount}` はゲームが書いた数字そのまま、`{money}` は3桁ごとに区切ったもの、
`{long}` と `{short}` は上で決めた通貨の表記。
呼び名は素のままにして表示だけ変える、という使い方もできる。

変えないのは**額そのもの**で、値段も所持金も1つも動かない。
文中の短い形は数の後ろにしか置けない（`$1000` のような書き方は
画面上部の欄でだけできる）。
画面上部の他の見出し（`Atk` / `Def` / `Exp` / `Age` / `Sta` / `Location`）と、
キャラクタ作成画面の `所持金` には触らない。

効いたかどうかは `out\currency_unit.log` に置換の例が出ることで分かる
（既定で 20 件）。
呼び名も書式も素のままなら、何も仕掛けない。

> セーブには跡が残る。
> `1000Gを手に入れた。` のような行動ログは表記を差し替えてから書かれるので、
> 変えた後に貯まるぶんは新しい表記で残る。
> 古い行と混ざるが増えるものは無く、外せば以後は素の表記に戻る
> （既に書かれた行はそのまま）。

| 設定 | 意味 |
|---|---|
| 長い表記 | 既定「ゴールド」。文中で使われる形 |
| 短い表記 | 既定「G」。数のすぐ後ろに付く形（`馬車(1000G)` の `G`） |
| 画面上部の所持金の表示 | 既定 `Gold:{amount}`。見出しは呼び名に合わせて自動で変わる。使える変数は `{amount}` `{money}` `{long}` `{short}` |
| LLM へ送る文章も直す | 既定 ON。古いセーブに残った「ゴールド」も送る直前に直す |
