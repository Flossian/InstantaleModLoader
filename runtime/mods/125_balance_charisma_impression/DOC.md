# `125_balance_charisma_impression`: 魅力が高いと初対面から全員に好かれるのを直す

NPC がプレイヤーに対して抱いている感情は2つの文で持たれていて、1つ目が好感度、
2つ目が見た目の魅力。
この2つ目はプレイヤーの魅力だけで決まり、
相手が誰かもどこまで打ち解けたかも入らない。
そのため魅力に振ったキャラは、
初対面から世界の全員に最上段「耐え難いほど魅力的に見えている」で見られ続ける。

この文は会話のたびに、LLM へ渡るプロンプトに丸ごと載る。
そのため**誰に何を頼んでも無条件に友好的な返事が返る**。
交渉や説得が勝手に通り、難易度が下がる。

段（文言）はゲームのものをそのまま使い、どの段になるかだけを2つの要素で決め直す。

- 相手ごとの好み … 同じ魅力でも、相手によって見え方が違う。
  相手ごとに固定なので、同じ人はいつも同じように見る（会話のたびに揺れない）
- どこまで打ち解けたか … 好感度が浅いうちは上の段まで行かない。
  最上段は「多少の好意がある」以上の相手にだけ出る

魅力が低いキャラを不利にはしない。
好みや親しさで「ひどく醜く思っている」に落ちることはなく、
素で最下段のキャラの段を下げることもない。
好感度の段そのものにも触らない。

段の並びと閾値は**起動のたびにゲーム自身から読む**ので、
ゲームが更新されて段が増減しても追従し、日本語以外の言語でも効く。
読み取った並びは
`out\charisma_impression.log` の先頭に出る（ここが「効いているか」の確認箇所）。

| 設定 | 意味 |
| --- | --- |
| 相手ごとの好みの幅（段） | 既定 1。0 にすると誰から見ても同じ段になる（親しさだけが効く）。2 以上にすると散り方が大きくなる |
| 魅力が満額で効くまでに要る好感度の段数 | 既定 4（＝「多少の好意がある」）。最上段が出るのもここに届いてから。0 にすると初対面から満額で効く |
| 最上段「耐え難いほど魅力的に見えている」を残す | 既定 入。打ち解けた相手にだけ出る。切ると上限が「強い魅力を感じている」になる |

| 症状 | やること |
| --- | --- |
| 何も変わらない | `out\charisma_impression.log` の先頭を見る。段の並びが出ていなければゲーム側の作りが変わっている（その理由も同じ行に出る） |
| 相手による差が出ない | 同じログに `相手が拾えない` が出ていれば、話している相手を特定できていない（親しさのぶんだけが効いている状態）。その下に、そのときの呼び出し元の中身が写してある。**そこごと報告してほしい** ― 相手がどこに居るかが分かれば拾えるようになる |
| 誰からも冷たく見られる | 「相手ごとの好みの幅」を下げるか、「魅力が満額で効くまでに要る好感度の段数」を小さくする |
| 元の一律に戻したい | MOD を切る。既に保存された文は、その相手と次に会話した時点で書き直される |
