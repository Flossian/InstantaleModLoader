# `345_date_display`: 現在地の下に日付を表示する

画面左下の欄の `Location` の下に、`Date:1年7月17日` のように日付を出す。
素のゲームは日数を数えているが、画面には出さない。

- 宿泊や街の移動で日数が進むと、すぐに書き変わる
- 表示するだけで、日数の進み方は変えない。NPC は日付を知らないし、年齢もこの暦では動かない
- `Location` が長く折り返しても、日付はその下に出る。欄に入らないときは行間を詰め、それでも入らなければ字を小さくする

## 設定

「設定…」の画面で決める。
「一括設定」はどの世界でも効き、「ワールド個別設定」はその世界だけに効く。

| 設定 | 意味 |
| --- | --- |
| ゲーム開始の年 | 既定 1。経過0日がこの年の最初の月の1日になる |
| 1年の日数 | 既定 365。変えると各月へ均等に割り振り直す |
| 月数 | 既定 12。変えると各月へ均等に割り振り直す。1年の日数は変わらない |
| 月の名前 | 既定は空。空なら `3月` のように番号で出る。`,` と `:` は使えない |
| 月の日数 | 既定は 31,28,31,30,31,30,31,31,30,31,30,31。直すと1年の日数がその合計になる |
| 表示の形 | 既定 `Date:{year}年{month}{day}日`。使える名前は下の表。空にすると日付を出さない |

| 名前 | 中身 |
| --- | --- |
| `{year}` | 年 |
| `{month}` | 月の名前。無ければ `3月` |
| `{month_number}` | 月の番号 |
| `{day}` | 日 |
| `{day_of_year}` | 年の中の何日目か |
| `{elapsed}` | 開始からの日数 |

一括設定は次の注入から、ワールド個別設定は次にその世界を開いたときから効く。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 日付が出ない | `out\date_display.log` の `WARN no Location line` の行。あれば欄の形がゲームの更新で変わっている。表示の形が空でも出ない |
| 月の設定が効かない | 同じログの `WARN the months` の行。読めない暦は既定の暦に置き換えている |
| 欄の字が小さくなった | 同じログの `fit:` の行。Location が長いときの動きで、短い場所へ移ると戻る |
