# `336_crime_overhaul`: 犯罪まわりの全面改修

素のゲームの犯罪は、自由行動のその場で LLM が出す金品しか見返りが無く、額も出すかどうかも LLM 任せだった。
この MOD は犯罪の実入りを増やし、手配の重さを暮らしに効かせ、捕まる前後に打つ手を足す。
機能は11あり、どれも設定で個別に切れる。

| 機能 | 何が起きるか |
|---|---|
| 盗みの稼ぎ | 自由行動の盗みの額を、その土地の依頼の報酬を目安に整える |
| 店が委縮して値を下げる | 手配中の土地の店では、買値が下がり売値が上がる |
| 時効 | 離れている土地の手配度が、時とともに平常へ戻る |
| 店で盗む | 売買画面で店の品を盗める。盗品は盗んだ店では売れず、よその店では半額 |
| 盗品買取商 | 裏の事務所で、盗品を正規の7割で売れる |
| 裏の仕事 | 裏の事務所の「裏の依頼掲示板」で、報酬5〜10倍の裏の仕事を受ける |
| 衛兵の買収 | 衛兵に見つかったとき、金を握らせて見逃してもらう |
| 裁判の改修 | 釈明の知らせ・弁護人・司法取引・袖の下・情状 |
| 脱獄 | 服役中に備えを積み、看守との戦闘で牢を破る |
| 同房の囚人 | 懲役の始まりに囚人が同じ房に入る。親しくなれば脱獄に加勢し、出所後は雇える |
| 処刑場からの脱出 | 死刑の判決のとき、親しい人物の手引きで脱出のダンジョンに挑む |

「手配の重さ」は手配度が 0 からどれだけ下か（手配度 -20 なら 20）。
額の多くは「その土地の依頼1件の報酬」を物差しにしている（難易度30の土地で 4,234G）。
下の数はどれも既定値。

## 盗みの稼ぎ

```text
[自由行動] 商店の金庫をこじ開けて中の金を奪う
……（ゲームの語り）
盗みの稼ぎは合わせて2,117ゴールドになった。
```

行動の締めの要約で、LLM が盗んだ金の規模を 0〜4 で判定する（LLM を別に呼ばない）。

| 規模 | 例 | 目安（依頼1件の報酬に対して） |
|---|---|---|
| 0 | 金を奪っていない（暴行・品物だけ・失敗） | なし |
| 1 小銭 | 財布をすった | 5% |
| 2 まとまった額 | 店のレジ、一人の有り金 | 20% |
| 3 大金 | 商店の金庫、裕福な屋敷 | 50% |
| 4 財産 | 銀行や領主の宝物庫 | 100% |

LLM が渡した額が目安の 50% に満たなければそこまで足し（1枚も渡さなければ目安どおり）、200% を超えればそこまで削る。
見つからずに済んだ盗みも数える。品物の盗みは対象外。

## 店が委縮して値を下げる

手配中の土地の店では、手配の重さ × 0.5%（上限 30%）だけ買値が下がり、売値が上がる。
店に入ったときに1行出る。値段はその土地に居る間だけ動き、セーブには焼き付けない。

```text
手配書の顔に気づいた店主は、怯えたように値を改めた。（買値 -10%・売値 +10%）
```

## 時効

手配された土地を離れている間、3ヵ月ごとにその土地の手配度が 10 戻る（平常の 10 まで）。
エリア移動の日数も離れていた日数に数え、3ヵ月に満たない端数は持ち越す。新しい罪は戻った後の値に足される。

全域手配の間は止まる。全ての土地の手配の重さの合計が `316_bounty_hunter` の「追手が来る手配の重さの合計」（既定 40）以上なら、
合計が線に届いたところで止め、追手は来続ける（そこから先は役場の罰金）。`316_` が入っていない・追手が来ない設定なら止めない。

| 手配度 | 時が経つと |
|---|---|
| ある土地だけ -30 | -20 → -10 → 0 → 10 |
| ある土地だけ -170 | -160 → … → -40 で止まる |
| 居る土地 -30・離れた土地 -30 | 離れた土地が -10 で止まる（合計 40） |

## 店で盗む

売買画面で店の品を右クリックすると、「購入」と「盗む」が出る（MOD が建てた店の品には出ない）。

```text
盗む → 〈品〉を盗む　成功率 39%　被発見率 48%  [はい] [いいえ]
          ↓
器用の判定 ── 成功 → 品が手持ちに入る
    └ しくじり → 判断の判定 ── 成功 → 手を引く（何も起きない）
                      └ しくじり → 「泥棒だ！」売買の窓が閉じて衛兵との戦闘
```

- 抜き取れる確率は器用 15 で 30%、1点ごとに 3%（上限 90%）。
  同じ店で同じ日に続けるほど（1回ごとに 10%）、大きく・高く・レア度の高い品ほど下がる（下限 5%）。続けた分は日付が進むと戻る
- 視線に気づく確率は判断から同じ式で求める。確認の画面には、抜き取れる率と見咎められる率が出る
- 衛兵戦はゲーム自身のもので、戦えばその土地の手配度が 10 下がる（ゲームの決まり）
- 装備品は盗めば棚から消える。回復薬や道具は次に店を開いたときゲームが作り直す
- 盗んだ品は、盗んだ店では売れない。「売る」を押すと主人公が気づいて取りやめ、品は手持ちに残る
  （「……いや、〈品〉はこの店で盗んだ品だ。／ここで売れば、盗んだことがばれてしまう。」）。
  よその店では、盗品の買い取り額が正規の半分になる

## 盗品買取商

裏の事務所に「盗品を売る」が出る（盗品を持っているときだけ）。
押すと売買の窓（左の見出しは「買取」）が開き、盗品を正規の7割で買い取る。売り方は店と同じドラッグ。

- 正規の額は、その土地の店で盗品でない品として売るときの額
- 盗品でない品は押し返され、買い取った品を買い戻すこともできない
- 司法取引で裏の事務所を売った締め出しの間は出ない

## 裏の仕事

裏の事務所の「裏の依頼掲示板」を押すと、ギルドの掲示板と同じ形の一覧が出る。
依頼はゲームの通常の依頼と同じダンジョンで、受注画面もゲームのまま。

```text
[裏の依頼掲示板]  〈仕事の題名〉 … / 裏の仕事を探す / やめる
                ↓  仕事を受けて片付ける
20,000ゴールドの報酬を受け取った。（素の報酬 2,500 の 8倍）
〈街〉の官憲が、強盗の下手人を追い始めた。（手配度 -20 → -40）
```

| 種類 | 何をするか | 解禁（手配の重さの合計） | 報酬 | 手配度 |
|---|---|---|---|---|
| 密輸 | 禁制品を運び込む | 誰でも | 5倍 | -10 |
| 盗掘 | 禁足の墓所・遺跡を荒らす | 誰でも | 5倍 | -10 |
| 破壊工作 | 倉庫・砦・水門を焼き討ち・爆破 | 10 | 7倍 | -20 |
| 脱獄の手引き | 牢獄から捕らわれた者を連れ出す | 10 | 7倍 | -20 |
| 強盗 | 屋敷・商隊・金庫に押し入る | 20 | 8倍 | -20 |
| 暗殺 | 標的を始末する | 40 | 10倍 | -30 |

- 種類は受けられる中から選ばれる。報酬は帰還したときのゲームの報酬に倍率を掛けた額で、片付けると依頼の街の手配度が下がる
- 未完了の裏の仕事が2件より少ないときだけ「裏の仕事を探す」が出る（ギルドの掲示板と同じ決まり）
- ギルドの掲示板には出ない
- 「裏の依頼掲示板」は公式では未実装の枠。公式が実装したら、この MOD は枠に触らず、裏の仕事は出なくなる

## 衛兵の買収

手配中の土地で衛兵に見つかると、「大人しく捕まる」「抵抗する！」の下に「金を握らせる」が出る。
素のゲームでも入力欄に買収を書けるが、判定は LLM 任せで率も見えない。こちらは魅力の判定で、率が画面に出る。

```text
金を握らせる（24,216G・成功率 28%）
  受け取られた → 「……今日のところは、何も見なかった」 → 居る場所に戻る
  突き返された → 「役人を買おうとは、いい度胸だ。来い」
                   大人しく捕まる → 裁判（贈賄の分、刑が5年延びる。袖の下は出ない）
                   抵抗する！     → ゲーム自身の衛兵戦
```

- 額は依頼1件の報酬で、受け取られても突き返されても払う。払えないときは出ない
- 見逃してもらえる確率は魅力 15 で 50%、1点ごとに 3%、その土地の手配の重さ1ごとに 0.5% 下がる（5〜95%）
- 見逃されても手配は残る
- 突き返された後にロードし直しても、金を握らせるはもう出ない

## 裁判の改修

検察の求刑の後の画面で、入力欄に書いて送った言葉がそのまま判事への釈明になる（素のゲームの作りだが、画面には出ていなかった）。
裁判の画面に入ったときに、このことを本文に出す。
判事と検察には、手配の重さ・その土地での活躍・人生の記録（情状）も渡る。

裁判の画面には口を出す手が3つ並ぶ。押しても判決へは進まず、同じ画面に戻る。

| 手 | 額 | 効き目 |
|---|---|---|
| 弁護人を雇う | 依頼1件の報酬 | 死刑にならず、刑は求刑の7割まで |
| 司法取引（裏の事務所を売る） | 無し | 死刑にならず、刑は求刑の半分まで。牢を出てから1年、どの裏の事務所も仕事を回さない。裏の仕事を片付けたことがあるときだけ出る |
| 袖の下を渡す | 依頼1件の報酬の2倍 | 魅力の判定。受け取られれば死刑にならず、刑は求刑の3割まで。突き返されれば刑が5年延びる |

重ねると掛け合わせる（弁護人と司法取引で求刑の 0.7 × 0.5）。求刑が死刑なら20年を基に数え、判事の刑がそれより軽ければ判事の刑のまま。
刑を改めたときは、判決の後に1行出る。

## 脱獄

服役中の毎年の画面に「脱獄を試みる」が出る。

```text
[服役中]  服役する / 脱獄を試みる（備え 0/5）
              ↓
          壁を削る（器用 95%・露見 10%） / 看守を手懐ける（12,108G） / 抜け道を探る（判断 41%・露見 10%）
          脱獄を決行する（備え 0/5） / やめる
```

- 備えはその年の服役と引き換え（1年が過ぎ、刑期も1年減る）。5つまで積める
- 壁を削る・抜け道を探るは器用・判断の判定。露見すると備えが潰れ、刑期が2年延びる（露見は 10% ＋ 備え1つごとに 5%）
- 看守を手懐けるは依頼1件の報酬の半分で買う備えで、必ず実り、露見しない
- 決行すると看守（ゲーム自身の衛兵）と戦う。相手は備え1つごとに 15% 弱い。
  勝つか逃げ切れば牢の外へ出て、その土地の手配度が 20 下がる。倒れたらゲームオーバー
- 刑期を務め上げた・新しく刑を受けたときは、備えを持ち越さない

## 同房の囚人

懲役が始まると、50% の確率で新しい囚人が同じ房に入る（その場で作る人物。名前・罪状・人柄は LLM が書く）。
毎年の画面に「〈名前〉と話す」が出て、ゲームの会話で話せる（年は進まない）。

- 同じ房で1年過ごすたびに好感度が 10 上がる
- 好感度 40 以上なら、脱獄の決行で仲間に加わって一緒に戦い、牢を出た後も仲間のまま。戦闘で倒れれば仲間の死として退場する
- 主人公が牢を出ると囚人も牢を出て、その街のギルドの冒険者に加わる（ゲームの手順で雇える）
- 雇った後も、同じ房にいたことを覚えて話す。好感度 60 に届けば処刑場からの脱出の手引き役にもなる
- 一度に1人。ギルドの無い街で捕まったときは現れない

## 処刑場からの脱出

死刑の判決のとき、好感度 60 以上の人物（仲間・知人）がいれば、「嫌だ！」の下に「〈名前〉の手引きに賭ける」が出る。
押すと、その街の監獄と処刑場を舞台にした脱出のダンジョンが、受注画面を通さずに始まる。

- 難易度は「土地の難易度とパーティの平均レベルの高いほう ＋ 10」。クリアを前提にしない強さ
- クリアすれば外へ逃れ、捕まった土地の手配度が 30 下がる（報酬は無い）。撤退すれば処刑、全滅はゲームオーバー
- 死刑が裁判の手で懲役に改まったときは出ない

## 設定

設定はローダの設定画面の「設定…」から開く同梱の画面で変える。
左に上の11の機能が並び、選んだ機能の項目（入切・額・確率など）が既定値と説明つきで右に出る。どの世界でも効く。

この MOD が動いたときのログは `out\crime_overhaul.log` に出る（`out\` はゲームを起動すると配布フォルダにできる）。
