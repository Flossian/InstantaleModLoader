# `225_probe_area_quest_difficulty`

街を初めて訪ねたとき、依頼の難易度を誰がどう決めるかを録る。`settlement_quest_generator` に渡る `quest_difficulties` の実値と呼び出し元、街が作られる経路の順と前後の `level_of_detail`、到着の移動と「クエストを探す」の間に呼ばれた `scripts.functions` の関数（同じ引数の組は1回だけ）と `random.*`。`133_ui_area_difficulty` が未訪問の街に帯を出す材料（VERIFICATION.md §3.49 #5。結果は VERIFICATION_LOG.md §2.84）
