# `147_fix_party_flee`: 主人公が逃げると仲間も一緒に戦闘から逃げる

素のゲームで仲間を連れて戦闘から逃げると、主人公だけが戦闘から抜ける。
仲間は残って戦い続け、画面には主人公の手番のボタン（攻撃・スキル・防御・発言する・逃げる）が並んだままになる。

この MOD を入れると、主人公の「逃げる」が通った手で、仲間も一緒に戦闘を離れる。
戦闘は主人公1人で逃げたときと同じく逃走で終わり、全員が一緒に元の場所へ戻る。
本文には、審判の文の後に次の1行が出る。

```text
リュウとジーンも後に続いて戦いを離れた。
```

- 逃げるのに失敗した手では何も変わらない
- 逃げる手で敵も倒し切ったときは、ゲームが勝ちで戦闘を終える。そのときも仲間は一覧に戻る
- 設定は無い

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 逃げたのに仲間が残って戦っている | `out\party_flee.log` に `the player fled; … followed` の行があるか。無ければ、主人公が逃げた手をこの MOD が見ていない |
| 逃げた後に仲間が一覧から消えた | 同じログの `put back by hand` か `WARN` の行 |
