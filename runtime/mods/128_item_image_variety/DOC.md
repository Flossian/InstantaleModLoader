# `128_item_image_variety`: アイテム画像を似た候補から散らして選び、素材に無い武器・防具・服・消耗品の絵を足し、素の絵を描き直した絵で見せる

アイテムの画像は、生成時の外見文（英語一文）に最も似た1枚が毎回選ばれる。
乱数が無いので、外見文が定型的な品種では同じ画像に集中する（実測ではポーション 52個中35個が同じ1枚。調査の数値は
VERIFICATION.md §3.26）。

この MOD は「外見文 → 画像」の対応の表を世界ごとに
`state\item_image\<世界>.json` に残す（版6）。

- 同じアイテムの再入手は同じ画像になる。同じ敵の同じドロップは、クエスト生成時に
  保存された同じ外見文で選定に来るので、表が同じ画像を返す。
  画像が追加されたり描き直されたりして、表の画像がその外見文の候補から外れたときは、次に手に入る品から選び直す（版12。持っている品の画像は変わらない）
- 初めての外見文には、似た候補（top1 の類似度の一定割合以上、最大枚数まで）の
  中からまだ使われていない画像を割り当てる。「別の名前なのに同じ画像」がここで消える
- 表はファイルに残るので、再起動・別セッションをまたいで効く。乱数は無く、
  同じ履歴・同じ手順なら同じ画像になる

埋め込み辞書に載っていない305枚に説明文を付けた追加辞書も同梱し、
選択肢に加える。
内訳は document 105 / creature_part 171 / mushroom 28 / accessory 1。
この305枚は MOD なしのゲームでは一度も選ばれない。

さらに、ゲームの素材に無い武器・防具・服・装身具・消耗品・部品・素材の画像を足す。
MOD なしのゲームでは、ライフルを手に入れても槍や剣の画像になり、制服を着ても鎧の画像になり、包帯は4枚しかない薬の画像のどれかになる。
武器はゲームの武器の1.5倍の寸法（小型 48x48・中型 48x96・大型 48x144・長物 48x192・投擲 48x48）、防具類と装身具は 64x64、消耗品と部品はゲームの素材の1.5倍の 48x48。
占めるマスの数は品の種類で決まるので、どれも素材と同じマスに描かれる。
胴の品は画像を見て、鎧や防弾ベストのように身を守る品を胴鎧に、シャツ・上着・外套・ローブを服に分けてある。
画像は画像生成 AI で作った一枚絵から起こした。

足した画像は、品の種類とジャンルでまとめた58の分類に分けてある（銃：サイバーパンク、武器：中世、防具：学園と学生服など）。分類ごとに使い方を3通りから選ぶ。

剣や槍の外見文 331 件で試して、銃の画像が付いたのは光る核を埋めた SF の大剣の1件だった。

画像は、品を作るときに LLM が書く英語の見た目の一文（外見文）で選ばれる。
ゲームのイベント（遺品を拾う・祭壇を調べるなど）で手に入る品は、ゲームがプロンプトで外見文の書き方を指定していないので日本語で返り、品と関係ない画像が付く。
この MOD は、イベントの判定のプロンプトに「外見文は英語で」の一文を足す。

品の種類（道具・薬・素材など）はゲームが外見文と一緒に決めるので、包帯が道具として、ダイナマイトが薬瓶として来ることがある。
その種類の画像に合うものが無いときは、同じ大きさ（1マス）のほかの種類の画像も探す（「部位をまたいで探す」。既定は ON）。
またぐのは、その種類でいちばん似た画像がはっきり合わず、ほかの種類にはっきり合う画像があるときだけ。
変わるのは画像だけで、品の種類や装備できる欄は変わらない。武器・防具はまたがない（種類ごとに画像の大きさが違う）。
使った画像のコピーは `state\item_image_cross` に置く。

外見文と画像の近さは文全体で比べるので、色や材質が同じだと物が違っても近いと判定されることがある（革のベルトに革の小袋、短い槍に長剣）。
「物の種類を AI に確かめる」を ON にすると、近い順の上位10枚の説明を AI に見せ、外見文と同じ種類の物の画像と、その中でいちばん合う1枚を答えさせる（既定は OFF）。
いちばん近い画像がその1枚なら、候補から違う種類の画像だけを外す（似た画像へ散らすのは OFF のときと同じ）。
別の画像なら、AI が答えた1枚を付ける。
AI への問い合わせは、初めて出た品1つにつき短いものが1回増える（クラウドの AI では、その分の料金がかかる）。
AI が答えないとき、同じ種類の画像が無いときは、OFF のときと同じ画像になる。
ON にする前に付いた画像はそのまま。

ゲームの元の画像は、足した画像と絵柄が揃っていない。
そこで元の画像を、同じ物・同じ向きのまま足した画像の絵柄で描き直した画像を同梱し、元の画像の代わりに見せる（「素の絵を描き直しで見せる」。既定は OFF）。
描き直しも画像生成 AI で描いた。
描き直しの無い画像は、元の画像のまま出る。
替わるのは所持品・装備欄・売買・製作の画面に出る画像で、既に持っている品の画像も替わる。
セーブには元の画像のパスが残るので、設定を OFF にするか MOD を外せば元の画像に戻る。
選ぶときも、描き直した画像は描き直した画像の説明で比べる。
元の画像の説明が画像と違う物を指していた画像（皿の山の画像が蛇と説明されているなど）も、画面に出る画像が外見文に合うように選ばれる。

選び方には、見た目に合わない画像を減らす設定が2つある。

- 「候補にする類似度の差の上限」（既定 0.05）。いちばん似た画像からこの差より離れた画像は、候補にしない。
  別の品と同じ画像になるのを避けるために候補の中から散らして選ぶので、候補の幅が広いと、いちばん似た画像よりはっきり合わない画像が付く
- 「色・材質が違う絵を下げる量」（既定 0.05）。外見文と画像の説明で、色の語（赤・青・金など）や材質の語（鉄・木・ガラス・革など）が食い違う画像を、その分だけ似ていない扱いにする。
  「淡い青の小瓶」に橙の小瓶が付く、といったことが減る。
  比べるのは説明の分かる画像（足した画像・追加辞書の画像・描き直した画像）だけで、合う色の画像が無ければ違う色の画像も選ばれる。
  「素の絵を描き直しで見せる」を ON にしているときだけ効く（OFF だと元の画像の色が分からず、足した画像だけが下がる）

既に持っているアイテムの画像は変えない。
効くのは MOD を入れてから新しく生成される分だけ。

設定は MOD の設定画面（「絵の分類と一覧」）で変える。

- 分類ごとの使い方を決める。一括設定はどの世界でも効き、ワールド個別設定はその世界だけ一括設定を上書きする。
  たとえば一括で銃を使わないにし、近代の世界だけ銃を使う、という分け方ができる
- 「ジャンルの重み」（0〜1）を世界ごとに置くと、そのジャンルに合う分類の画像が選ばれやすくなる。
  SF の世界なら「SF 1・サイバーパンク 0.5」、和風の世界なら「和風 1」のように置く。
  中世は魔法の無い中世の品、ファンタジーは魔法の要素がある品。剣と魔法の世界なら「中世 1・ファンタジー 1」、暗い世界なら「ダークファンタジー 1」を足す既定はどれも 0（今までどおりの選び方）
- 「ジャンル内の重み」のタブで、分類ごとにどのジャンルにどれだけ合うかを変えられる（既定値は同梱。「既定に戻す」で戻る）。
  画像の類似度に「世界のジャンルの重み × 分類のジャンル内の重み × 重み1のときに足す類似度（既定 0.15）」を足してから選ぶ
- 「画像一覧」のタブで、分類・小分類（分類にまとめた元の一枚絵。「全て」も選べる）・種類を選ぶと、その画像を並べて見られる。画像にマウスを載せると、選ぶときに比べる英語の一文が出る。「背景」で画像の地を明るい灰色・黒・ゲームの暗い緑に切り替えられる
- 使わない分類の画像は、新しく手に入る品に付かなくなる。既にその画像が付いた品はそのまま見える
- ワールド個別設定はゲームを開いたままでも、次に品が作られるときから効く

| 症状 | やること |
| --- | --- |
| 何も変わらない | `out\item_image.log` に `chose` の行が出ているか見る。無ければフックが効いていない |
| 見た目と説明が合わない画像が出る | 「候補にする類似度の差の上限」を下げる（0 に近いほど、いちばん似た画像に近い画像だけになる）。色や材質が違うなら「色・材質が違う絵を下げる量」を上げる。`out\item_image.log` の `for '…'` が日本語なら、外見文が日本語で返っている（ほかの MOD が LLM に品を作らせるプロンプトで、外見文を英語にするよう指定していない） |
| それでも同じ画像ばかり出る | その品種の在庫自体が少ない可能性（medicine は4枚しかない）。ログの `qualified` の数を見る |
| 足した画像の付いた品の画像が空になった | 版の更新で描き直して外した画像は、読み込んだときか、所持品・装備欄・売買の画面でその品を出したときに、同じ種類のいちばん似た今の画像に自動で付け替わる（ログに `retired:` の行が出る）。それ以外は、この MOD を外すか、その分類のフォルダ（`images\<分類>`）を消すと、その画像の付いた品は画像が無くなる（画像は MOD のフォルダにある）。戻せば画像も戻る |
| ある分類の画像がすべて要らない | 設定画面でその分類を「使わない」にする。容量も減らしたいなら `images\<分類>` と `data\<分類>` を消してもよい（消しても MOD は動く） |
| 履歴をリセットして最初からにしたい | その世界の `state\item_image\<世界>.json` を消す。世界を消したときにこのファイルが残っても、消してよい |
| ゲームの元の画像が描き直しにならない | 設定の「素の絵を描き直しで見せる」を ON にする（既定は OFF）。ON にしても替わらない画像は、その画像の描き直しがまだ無い。描き直しを見せた画像は `out\item_image.log` に `redraw: shown` の行が出る |
| 品の種類と違う画像が付いた（薬の小瓶に魔物の素材の画像など） | 「部位をまたいで探す」で付いた画像。ログの `chose` の行に `from <種類>` が付く。要らなければ設定で OFF にする（既に付いた画像はそのまま） |
| 色や材質は合うが、物が違う画像が付く（ベルトに小袋など） | 設定の「物の種類を AI に確かめる」を ON にする。替えた画像はログの `kind: top1 …` の行、同じ種類の画像が無かった品は `kind: no picture of the same kind` の行に残る |
