# `128_item_image_variety`: アイテム画像を似た候補から散らして選び、素材に無い武器・防具・服・消耗品の絵を足す

アイテムの画像は、生成時の外見文（英語一文）に最も似た1枚が毎回選ばれる。
乱数が無いので、外見文が定型的な品種では同じ画像に集中する（実測ではポーション 52個中35個が同じ1枚。調査の数値は
VERIFICATION.md §3.26）。

直し方の芯は1つの表（版6）。**「外見文 → 絵」の対応を世界ごとに
`state\item_image\<世界>.json` に残す**。

- **同じアイテムの再入手は同じ絵**。同じ敵の同じドロップは、クエスト生成時に
  保存された同じ外見文で選定に来るので、表がそのまま同じ絵を返す
- **初めての外見文には、似た候補（top1 の類似度の一定割合以上、最大枚数まで）の
  中からまだ使われていない絵**を割り当てる。「別の名前なのに同じ絵」がここで消える
- 表はファイルに残るので、再起動・別セッションをまたいで効く。乱数は無く、
  同じ履歴・同じ手順なら同じ絵になる

もう1つ、**埋め込み辞書に載っていない305枚**に説明文を付けた追加辞書を同梱し、
選択肢に加える。
内訳は document 105 / creature_part 171 / mushroom 28 / accessory 1。
この305枚は素のゲームでは一度も選ばれない。

さらに、**ゲームの素材に無い武器・防具・服・装身具・消耗品・部品・素材の絵**を足す。
素のゲームでは、ライフルを手に入れても槍や剣の絵になり、制服を着ても鎧の絵になり、包帯は4枚しかない薬の絵のどれかになる。
武器はゲームの武器と同じ大きさ（小型 32x32・中型 32x64・大型 32x96・長物 32x128・投擲 32x32）、防具類は 64x64、消耗品と部品は 32x32。
胴の品は絵を見て、鎧や防弾ベストのように身を守る品を胴鎧に、シャツ・上着・外套・ローブを服に分けてある。
絵は作者が画像生成 AI で作った一枚絵から起こした。

足した絵は、元画像1枚ごとの分類に分けてある。分類ごとに使い方を3通りから選ぶ。

| 使い方 | 選ばれ方 |
| --- | --- |
| 使わない | その分類の絵は選ばれない |
| 素の絵と混ぜる | ゲームの素材と同じ候補に入る。剣や鎧の絵の種類が増える |
| 似ているときだけ使う | 外見文にいちばん似た絵がその分類で、素の絵よりはっきり似ているときだけ、その分類の中から選ぶ。ダークファンタジーの世界で「麻のチュニック」に制服の絵が付く、といったことが起きない |

剣や槍の外見文 331 件で試して、銃の絵が付いたのは光る核を埋めた SF の大剣の1件だった。

絵は、品を作るときに LLM が書く英語の見た目の一文（外見文）で選ばれる。
ゲームのイベント（遺品を拾う・祭壇を調べるなど）で手に入る品は、ゲームが外見文の書き方を頼んでいないので日本語で返り、品と関係ない絵が付いていた。
この MOD は、イベントの判定の頼みに「外見文は英語で」の一文を足す。

既に持っているアイテムの画像は変えない。
効くのは MOD を入れてから新しく生成される分だけ。

設定は MOD の設定画面（「絵の分類と一覧」）で変える。

- 分類ごとの使い方を決める。一括設定はどの世界でも効き、ワールド個別設定はその世界だけ一括設定を上書きする。
  たとえば一括で銃を使わないにし、近代の世界だけ銃を使う、という分け方ができる
- 「ジャンルの重み」（0〜1）を世界ごとに置くと、そのジャンルに合う分類の絵が選ばれやすくなる。
  SF の世界なら「SF 1・サイバーパンク 0.5」、和風の世界なら「和風 1」のように置く。既定はどれも 0（今までどおりの選び方）
- 「ジャンル内の重み」のタブで、分類ごとにどのジャンルにどれだけ合うかを変えられる（既定値は同梱。「既定に戻す」で戻る）。
  絵の類似度に「世界のジャンルの重み × 分類のジャンル内の重み × 重み1のときに足す類似度（既定 0.15）」を足してから選ぶ
- 「画像一覧」のタブで、分類と部位（「全て」も選べる）を選ぶと、その絵を並べて見られる。絵にマウスを載せると、選ぶときに比べる英語の一文が出る
- 使わない分類の絵は、新しく手に入る品に付かなくなる。既にその絵が付いた品はそのまま見える
- ワールド個別設定はゲームを開いたままでも、次に品が作られるときから効く

| 症状 | やること |
| --- | --- |
| 何も変わらない | `out\item_image.log` に `chose` の行が出ているか見る。無ければフックが効いていない |
| 見た目と説明が合わない画像が出る | 「候補にする類似度の下限」を上げる（0.9 なら素にかなり近い）。`out\item_image.log` の `for '…'` が日本語なら、外見文が日本語で返っている（ほかの MOD が LLM に品を作らせる頼みで、外見文を英語で頼んでいない） |
| それでも同じ画像ばかり出る | その品種の在庫自体が少ない可能性（medicine は4枚しかない）。ログの `qualified` の数を見る |
| 足した絵の付いた品の絵が空になった | この MOD を外すか、その分類のフォルダ（`images\<分類>`）を消すと、その絵の付いた品は絵が無くなる（絵は MOD のフォルダにある）。戻せば絵も戻る |
| ある分類の絵をまるごと要らない | 設定画面でその分類を「使わない」にする。容量も減らしたいなら `images\<分類>` と `data\<分類>` を消してもよい（消しても MOD は動く） |
| 履歴をリセットして最初からにしたい | その世界の `state\item_image\<世界>.json` を消す。世界を消したときにこのファイルが残っても、消してよい |
