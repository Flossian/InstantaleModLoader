# `144_fix_hardcoded_worldview`: 頼み文と絵の世界観の決め打ちを外す

ゲームが生成 AI に送る頼み文の多くは、どの世界でも「あなたはダークファンタジーTRPGのゲームマスターである」「あなたはダークファンタジーRPGのキャラクター生成AIだ」のように、ジャンルを決め打ちした一文で始まる。
語り・依頼の進行・休暇・訓練などの頼みには世界の情報が1字も入らないので、生成 AI はこの一文だけを頼りに書く。
絵にも、人物なら `medieval, dark fantasy, ... shabby`、背景なら `fantasy setting, medieval` が必ず前に付き、背景の否定には `modern, urban` が入る。
剣も魔法も無い世界でも、語りや絵が中世のダークファンタジーに寄る。

この MOD は次のものを外す。

| 外すもの | どこに | どうするか |
| --- | --- | --- |
| 役の一文のジャンル | 語り・依頼・NPC の生成・休暇・訓練・背景など約30種 | 「あなたは（いわゆる大人向けの無骨で無慈悲な）ダークファンタジーTRPG / RPG の〜」「あなたは中世ファンタジーRPGの〜」を「あなたはTRPG / RPG の〜」にする |
| 世界の情報が無い頼み | 上のうち約20種 | 遊んでいる世界の名前と概要と「描写・人物・品物はこの世界に合わせる」を足す |
| 会話の調子 | 会話（`111_` の同梱ルールが足す文） | 「この世界は救いのないダークファンタジーであり、優等生的・現代的な言い回しや…」を「優等生的な言い回しや…」にする |
| 許可の理由 | 会話・自由行動・世界の審査 | 「ダークファンタジーであるため、窃盗、暴力…は許可する」を「ゲームであるため、」にする。許可そのものは残す |
| 【共通世界観】の冒険者 | 世界・ストーリー・町を作る頼み | 「夢のある仕事ではない…元奴隷…」を外し、ギルドと冒険者がいることと「呼び名や描写は世界に合わせてよい。ただし施設の種類は決められた値を使う」だけにする。エリアの説明はゲームの仕組みなので残す |
| 絵の前置き | 人物・背景・敵 | `medieval` `dark fantasy` `shabby` `fantasy setting` を前置きから、`modern` `urban` を否定から抜く。頼み文の「[medieval, …] は自動で追加」の一覧からも抜く |

世界の情報が無い頼み（概要を空にして作る世界の生成、世界が読めないときの語りやキャラ作成など）は、ジャンルに関わる書き換え（役の一文・会話の調子・魔法の前提・【共通世界観】・「自動で足す」一覧）をせず、ゲームの既定（ダークファンタジー）のまま送る。
ジャンルだけ外すと、生成 AI が世界観を何も知らない頼みになるため。
会話は世界の概要を持たないが、その土地の説明（【土地情報】）を持つので、世界の情報があるものとして直す。
許可の理由と絵の前置きは、世界の有無に関わらず直す。

`watercolor` など絵の画風の語は残す。
キャラを作る画面の5つの頼み（さいころ・立ち絵の要素・スキル・特質・内容の審査）には世界を足さない（作成中の世界は `143_fix_random_character` が渡す）。
特質の頼みにある「この世界の誰もが魔法、精霊、神、悪魔、自然の力を借りた大いなる術を唱えられるわけでは無し、…」は、役の一文と一緒に「誰もが戦いのための明確な力をもつとは限らない。」にする。
【共通世界観】は新しく作る世界と町から効き、既にある世界と町は変わらない。
絵は描き直した分から変わる。人物のフォルダの `prompts.json` も描いた後に同じに直す。

| 設定 | 意味 |
| --- | --- |
| 役の一文からジャンルを外す | 既定 入。会話の調子の文も一緒に外す |
| 世界の情報が無い頼みに世界の概要を足す | 既定 入。頼みが長くなるぶん、ローカル LLM では少し遅くなる |
| 許可の理由を「ゲームであるため」にする | 既定 入 |
| 【共通世界観】の冒険者の設定を外す | 既定 入 |
| 絵の前置きから決め打ちの語を抜く | 既定 入 |
| したことを記録する | 既定 入。`out\hardcoded_worldview.log` |

| 症状 | やること |
| --- | --- |
| 語りがまだダークファンタジー寄り | `out\hardcoded_worldview.log` に `[TEXT] … role+world` が出ているか。出ていなければ、その頼みの役の一文が別の書き方 |
| 絵にまだ medieval が付く | 同じログの `[IMAGE]` と、描いたフォルダの `prompts.json` を見る |
| 何も出ない | `out\modloader.log` の `hardcoded worldview: armed on` で仕掛かっているか |
