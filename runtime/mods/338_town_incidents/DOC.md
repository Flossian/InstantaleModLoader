# `338_town_incidents`: 街に盗賊や疫病などの困り事や、祝祭や豊作などの良い出来事が起き、日を追って移り変わる

素のゲームの街は、プレイヤーが何もしなければ何も変わらない。
この MOD を入れると、日数が進むうちに各地の街で出来事が起きる。
盗賊・疫病・魔物の襲来などの困り事は、放っておくと 兆し → 悪化 → 深刻 と進み、最後は自然に収まる。
その街のギルドの掲示板に出る依頼で片付けられる。
祝祭・豊作などの良い出来事は依頼が出ず、兆し → 盛況 → 収束 のように出来事ごとの段階を進んで収まる。
出来事の起きている街では、値段・会話・情景描写に情勢が出る。
出来事はファイルで足したり、同梱のものを書き換えたり止めたりできる（「出来事を足す」）。

```text
[宿に泊まる・街を移る]
[灰の都に着く]
咳き込む人の姿が、街のあちこちで目に付く。
灰の都冒険者ギルドに行けば、この件で人手を求める依頼が出ているかもしれない。
[店に入る]
病が流行り、薬の類が飛ぶように売れて値が上がっている。
[ギルドで掲示板を開く]
掲示板に、感染症の流行にまつわる依頼が新しく貼り出されている。
                ↓ 放っておくと 兆し → 悪化 → 深刻 → 自然に収まる
[依頼を片付ける]
灰の都の感染症の流行は、これで収まるだろう。
```

呼び名や情景の文は、出来事が起きたときに LLM がその世界の言葉で1回だけ書く（上の例は LLM を使わないときの文）。
西部劇の世界なら「無法者の一味」、サイバーパンクなら「ギャングの抗争」のように、出来事の中身はその世界に合わせて書かれる。

## 決まり

- 日数が進むと（宿泊・街の移動・自由行動。依頼の最中は進まない）、通算で15〜45日ごと（基準30日を前後に15日までずらす。抽選のたびに決め直す）に世界全体で1回だけ抽選し、25%で出来事が起きる
- 起きるのは、訪れたことがありギルドのある街だけ（村・町・都市）。いまいる街にも起きる
- 1つの街に起きるのは1つまで。世界全体で同時に3つまで。終わった街には180日のあいだ起きない
- 一度に何日進んでも、起きるのは1つまで（徒歩の90日で3つ起きることはない）
- 放っておくと60日ごとに次の段階へ進み、最後の段階になってから90日で自然に収まる。困り事の段階は 兆し → 悪化 → 深刻 の3つ、良い出来事は出来事ごと
- 一度に進む段階は1つまで。徒歩の移動のように一度に長く日数が進んでも、兆しから深刻へ飛ぶことはない
- 困り事が発生から自然に収まるまでは、既定だと宿で7泊、徒歩の移動なら3回ぶん
- 困り事を片付ける依頼は、その街のギルドで掲示板を開いたときに作られる（ゲーム自身の依頼の生成に、出来事の説明を渡す）。難易度と報酬はゲームが決めたまま
- 依頼をしくじっても、放棄しても、出来事は続く
- 自然に収まったときは、片付けられないまま残った依頼を世界から片付ける（受けている最中なら、帰ってから）
- 自然に収まると「〜らしい」の一文で知らせる。その街に居ればその場で、よその街に居れば次にその街に着いたときに1度だけ
- プレイヤーが片付けた依頼は普通の依頼と同じく残り、その街の功績になる（`317_reputation` の評判や `321_area_chronicle` の案内文に拾われる）
- 良い出来事は依頼を作らず、ギルドへの案内も添えない。起こりやすさは困り事の半分

## 起こりうる出来事

値段は段階ごとの上げ下げ。買値は店の品、売値は手持ちを売る額。

### 困り事（兆し / 悪化 / 深刻）

| 出来事 | 世界ごとの例 | 値段への影響 |
|---|---|---|
| 無法者の横行 | 盗賊団／無法者の一味／ギャング／略奪者 | 全品の買値 +10 / 20 / 35% |
| 感染症の流行 | 疫病／コレラ／生体ウイルス／変異病 | 薬の類の買値 +25 / 50 / 100%、食べ物の類 +10 / 20 / 30% |
| 外敵の襲来 | 魔物の群れ／狼やコヨーテの群れ／暴走した戦闘ドローン／変異生物の群れ | 武器・防具の買値も売値も +15 / 30 / 50% |
| 騒乱 | 一揆／鉱夫のストライキ／暴動／配給を巡る騒ぎ | 全品の売値 -10 / 20 / 35%、買値 +5 / 10 / 15% |
| 物資の途絶 | 凶作／旱魃／工場の停止・物流の断絶／水源の汚染 | 食べ物の類の買値 +20 / 40 / 80%、宿代 +20 / 40 / 80% |
| 災害の後 | 大火／竜巻／大規模な停電・設備の崩落／砂嵐・地震 | 素材・道具の買値も売値も +15 / 30 / 50% |
| 通貨の信用の揺らぎ | 偽金／偽札／決済の改竄・クレジットの偽造／配給札の偽造 | 全品の売値 -10 / 20 / 35% |
| 買い占め | 商人の結託／鉄道会社の独占／企業の独占／水を握った一派 | 品の種類を1つ選び、その買値だけ +30 / 60 / 120% |
| 不可解な怪事 | 怪異／幽霊話／謎の信号・電脳の幽霊／異常地帯の拡大 | 道具の買値 +15 / 30 / 50%、宿代 +10 / 25 / 50% |
| 失踪の続発 | 人さらい／人狩り／臓器狩り／奴隷狩り | 宿代 +20 / 40 / 80% |
| 闇物資の氾濫 | 密輸品／密造酒／違法な改造部品／略奪品の横流し | 全品の買値も売値も -10 / 15 / 25% |
| 締め付けの強化 | 衛兵の検問／保安官の締め付け／企業警備の戒厳／軍閥の統制 | 武器・防具の買値 +20 / 40 / 60%、全品の売値 -5 / 10 / 15% |
| 権力の空白 | 領主の急死／保安官の殺害／企業幹部の暗殺／首領の死 | 全品の買値 +5 / 10 / 20%、売値 -5 / 10 / 20% |
| 人の流入 | 難民／開拓民／移民／避難民 | 食べ物の類の買値 +10 / 25 / 50%、宿代 +25 / 50 / 100% |

### 良い出来事（依頼なし）

| 出来事 | 段階 | 世界ごとの例 | 値段への影響 |
|---|---|---|---|
| 祝祭 | 兆し / 盛況 / 収束 | 収穫祭／建国の記念の祭典／新しい鉄道の開通の祝い／企業の記念式典 | 全品の売値 +5 / 15 / 5%、食べ物の類の買値 +5 / 15 / 5%、宿代 +10 / 30 / 10% |
| 豊作 | 兆し / 盛況 / 収束 | 豊作／豊漁／培養槽の当たり年／汚れていた水源の回復 | 食べ物の類の買値 -10 / 25 / 10% |
| 交易の活況 | 兆し / 盛況 / 収束 | 隊商の来訪／港の賑わい／新しい航路の開通／補給船の到着 | 全品の買値 -5 / 12 / 5% |
| にわか景気 | 予兆 / 過熱 / 崩壊 / 収束 | 新しい鉱脈／ゴールドラッシュ／技術の流行／遺物の発見 | 全品の買値 +5 / 15 / -10 / -5%、売値 +10 / 30 / -25 / -10% |

- にわか景気は過熱のあとに弾ける。過熱のうちに売れば稼げるが、崩壊の段では売値が大きく下がる
- 食べ物の類は、ゲームの分類で回復の品に入っている食べ物・飲み物も含む（保存食・酒など）。薬の類は、それ以外の回復の品
- 外敵の襲来は売値が上がり、闇物資の氾濫は買値が下がる。片付けずに稼ぐこともできる
- 街の規模で起こりやすさが変わる。村は外敵・物資の途絶・失踪・豊作、町は無法者・買い占め・人の流入・にわか景気・祝祭・豊作・交易、都市は感染症・騒乱・通貨・闇物資・締め付け・権力の空白・祝祭・交易が起きやすい。災害の後と不可解な怪事はどこでも同じくらい
- LLM が「この世界には合わない」と答えた出来事は、別の種類に引き直す（2回まで）。平和な世界観で血なまぐさい出来事を避けるため。ただ、たいていは LLM がその世界にありうる形へ書き換える（争いもお金も無い動物の島々では、外敵の襲来が「正体不明の獣の群れ」、偽金が「貝殻札の偽物」になった）。特定の種類を起こしたくないときは、設定の「出来事の種類」で切る
- 値段は、出来事の起きている街に居る間だけ動く（保存のときは外れるので、セーブには残らない）

## 各地の状況を見る

画面左下のアイコン（持ち物・設定・キャラ情報・クラフト）の右に、MOD 用のボタン（歯車）が1つ増える。
ゲームの4つは少し左に詰まる。ほかの MOD の機能もこのボタンにまとまるので、MOD を増やしてもボタンは1つのまま。
押すと MOD の機能の一覧が開き、「各地の出来事」を選ぶと窓が開く。
新しい出来事が起きたときと段階が進んだときは、ボタンの右上と「各地の出来事」の行に赤い点が付く（行を選ぶと消える）。

窓の見出しの下に、いまいる街と、その街で進行中の出来事が出る。
左は進行中の出来事の札で、段の重いものが上。右は「この1年に終わったもの」。どちらもスクロールできる。

- 札の上段に、街の名前・出来事の呼び名・段階。困り事は兆し・悪化・深刻を黄・橙・赤、良い出来事は兆し・盛況を緑、収束を灰で出す（にわか景気の崩壊は赤）
- 段階の数だけの目盛り（最初から今の段まで塗る）と、「発生から75日。悪化するまで約45日。」（良い出来事なら「盛り上がるまで」「弾けるまで」のように出来事ごとの言い方）
- 概要。いまの段階の様子を1文で出す。出来事が起きたときに LLM が呼び名と一緒に、段階ごとの文をその世界の言葉で書く（LLM が書くのは4段階目まで。5段階目より後は最初の段階の文）。LLM が使えなかったときは、出来事の種類ごとの説明（「街で病が広がり、人々が倒れている」など）が出る
- 影響（「薬の類の買値 +50%、食べ物の類の買値 +20%」）。数字は、主人公から見て得なら緑（買値が下がる・売値が上がる）、損なら赤（買値が上がる・売値が下がる・宿代が上がる）、買うのも売るのも同じ向きに動くものは橙
- 依頼（困り事だけ）。「掲示板に出ている。」「まだ出ていない（〈その街のギルドの名前〉で掲示板を開くと出る）。」、ほかの冒険者がその依頼を狙っていれば「冒険者の〇〇が解決に向けて動き始めた。」
- 終わったものは、日付・街と呼び名・終わり方（解決した＝緑、冒険者の〇〇が解決した＝橙、自然に収まった・落ち着いた・収束した＝灰）

日付は「日数」（「発生から75日。悪化するまで約45日。」）か「あいまい」（「長く続いている。しばらく先に悪化するかもしれない。」）、
値段の影響は「数字」（「薬の類の買値 +50%」）・「言葉」（「薬の類が値上がり」）・「出さない」から設定で選べる。

一覧の「各地の出来事」の行の絵は注意の標識（黄色の三角に感嘆符）。

## 出来事を足す

出来事の表は MOD のフォルダの `incidents.default.json` に入っている（同梱の18種）。
足すときは、MOD のフォルダに `kinds` フォルダを作り、1つの出来事を1つの `.json` ファイルに書く（ファイルの名前は自由）。
同梱の出来事と同じ `key` で書くとその出来事を差し替え、`{"key": "…", "enabled": false}` だけを書くとその出来事を止める。
表を丸ごと書き直すときは、`incidents.default.json` を `incidents.json` の名前で写して直す（あればそちらを読む。更新で上書きされない）。

ゲームを起動し直すと読み直す。
書き間違えた出来事は飛ばし、ほかはふだんどおり起きる。
飛ばした理由は `out\town_incidents.log` の `WARN kinds:` の行と、設定画面の「出来事の種類」タブの下に出る。
起きている最中の出来事の `key` は消さない（記録は `key` で表を引く）。

### 出来事の項目

| 項目 | 要るか | 中身 |
|---|---|---|
| `key` | 要る | 英数字と `_` の名前。記録に書くので、一度遊んだら変えない |
| `name` | 要る | 呼び名。LLM が書けなかったときと、一覧の既定 |
| `what` | 要る | 何が起きているかの説明。LLM に渡し、LLM が書けなかったときは一覧の概要になる |
| `examples` | 任意 | 世界ごとの例を `／` で区切って並べる。LLM に渡す |
| `size` | 任意 | 起きやすい街の規模。`village`（村）・`town`（町）・`city`（都市）の並び。書かないとどこでも同じくらい（`"any"`） |
| `weight` | 任意 | 起きやすさの倍率。既定 1。同梱の良い出来事は 0.5 |
| `quest` | 任意 | 片付ける依頼の中身（LLM が書けなかったときの文）。書かないか `null` なら依頼の出ない良い出来事になる |
| `stages` | 要る | 段階の並び（下の表）。数は自由 |
| `end` | 任意 | 最後の段階から収まるまでの言い方（「終わるまで約90日」の「終わる」）。既定「収まる」 |
| `ended` | 任意 | 自然に収まったときの、終わった欄の言い方。既定「自然に収まった」 |
| `shop` | 任意 | 店に入ったときの1行（LLM が書けなかったとき） |
| `shop_turn` | 任意 | 値段の向きが途中で変わる出来事（値上がりの後に値崩れするなど）の、変わった後の店の1行。書かなければ `shop` |
| `settled` | 任意 | 自然に収まったときの知らせ。`{town}` が街の名前になる |
| `rumor` | 任意 | よその街の住人の噂。`{town}` が街の名前になる |
| `enabled` | 任意 | `false` で止める |

`shop`・`shop_turn`・`settled`・`rumor`・段階の `arrive` の中の `{goods}` は、`random` で選んだ品の種類の名前になる。
店の1行は、その段階で値段が動いているときだけ出る（値段の効き目の強さを 0% にしたときも出ない）。

### 段階の項目

| 項目 | 要るか | 中身 |
|---|---|---|
| `name` | 要る | 段階の名前。一覧の目盛りと見出しに出る |
| `tone` | 要る | `bad`（困り事の色）・`good`（良い出来事の色）・`calm`（灰）。`bad` が続けば黄・橙・赤、1つだけなら赤 |
| `into` | 2段目から要る | この段階へ移るときの言い方（「悪化するまで約45日」の「悪化する」） |
| `arrive` | 要る | 街に着いたときの1行（LLM が書けなかったとき。LLM が書くのは4段目まで） |
| `prices` | 任意 | 値段の効き目の並び。`goods` に `"all"`（全品）・`"random"`（起きたときに1種選ぶ）・品の種類の並び、`buy`・`sell` に % |
| `inn` | 任意 | 宿代の % |

品の種類は `weapon`（武器）・`wearable`（防具）・`medicine`（薬の類）・`food`（食べ物の類）・`utility`（道具）・`material`（素材）。

### 書き方の例

同梱の無法者の横行を止める（`kinds\no_outlaws.json`）。
設定画面のチェックでも止められる。ファイルで止めると、設定を消しても止まったまま。
どちらで止めても、新しく起きなくなるだけで、いま起きている分は最後まで進む。
足した出来事のファイルを消すと、その出来事の中身が無くなるので、いま起きている分は次に日数が進んだときに自然に収まった扱いで終わる（掲示板の依頼も片付ける）。

```json
{"key": "outlaws", "enabled": false}
```

同梱の豊作を、2段階で値下がりの大きいものに差し替える（`kinds\harvest.json`）。

```json
{
  "key": "harvest",
  "name": "豊作",
  "what": "作物や獲物がよく採れ、街に食べ物があふれている",
  "size": ["village"],
  "weight": 0.5,
  "end": "終わる",
  "ended": "落ち着いた",
  "stages": [
    {"name": "兆し", "tone": "good",
     "prices": [{"goods": ["food"], "buy": -20}],
     "arrive": "畑や網の具合がいいという話を、あちこちで耳にする。"},
    {"name": "盛況", "tone": "good", "into": "盛り上がる",
     "prices": [{"goods": ["food"], "buy": -40}],
     "arrive": "通りの店先に食べ物が山と積まれ、安く売られている。"}
  ]
}
```

新しい困り事を足す（`kinds\water_feud.json`）。
`quest` を書いたので、掲示板に片付ける依頼が出る。

```json
{
  "key": "water_feud",
  "name": "水争い",
  "what": "水の分け方を巡って住人どうしが争っている",
  "examples": "井戸の取り合い／用水路の堰き止め／給水塔の占拠／水源を巡る抗争",
  "size": ["village", "town"],
  "quest": "水を巡って争う住人のあいだを取り持ち、争いを収める依頼",
  "stages": [
    {"name": "兆し", "tone": "bad", "inn": 10,
     "arrive": "水汲みの列で、言い争う声が聞こえる。"},
    {"name": "悪化", "tone": "bad", "into": "悪化する", "inn": 20,
     "prices": [{"goods": ["food"], "buy": 20}],
     "arrive": "水場に見張りが立ち、よそ者を睨んでいる。"},
    {"name": "深刻", "tone": "bad", "into": "悪化する", "inn": 40,
     "prices": [{"goods": ["food"], "buy": 40}, {"goods": "all", "sell": -10}],
     "arrive": "水を巡る争いで怪我人が出たと、街じゅうが殺気立っている。"}
  ],
  "shop": "水が手に入りにくく、食べ物の値が上がっている。",
  "settled": "{town}の水争いは、なんとか収まったらしい。",
  "rumor": "{town}で水を巡って揉めているらしい。"
}
```

## 他の MOD との重なり

| MOD | どうなるか |
| --- | --- |
| `315_vacation_custom` | 宿代の上げ下げは、315 で決めた宿代の上に掛かる |
| `405_regional_economy` / `336_crime_overhaul` | 値段の上げ下げは掛け算で重なる |
| `317_reputation` / `321_area_chronicle` | プレイヤーが片付けた出来事の依頼は、ゲームが功績に書くので、評判と案内文に拾われる。この MOD は案内文を書き換えない |
| `318_area_difficulty_growth` | 出来事の依頼も普通の依頼なので、片付ければ土地が育つ。この MOD は難易度に触らない |
| `328_quest_from_world` | 328 が街の描写を伏せた回も、依頼に出来事の説明は残る |
| `339_town_factions` | 主人公が出来事を片付けると、その街の勢力からの見られ方が上がる。勢力どうしの趨勢を決めるときに、良い出来事も含めて各地の出来事を材料にする。この MOD は勢力を知らないので、こちらだけでも動く |

## 設定

設定はローダの設定画面の「設定…」から開く同梱の画面で変える。
タブは6つで、起こり方・進み方・値段と文章・一覧・出来事の種類の5つが設定、記録が出来事の記録を読む欄。
各項目は既定値と説明つきで出る。
一覧のタブには、選んだ出し方で描いた一覧の見本が出る。
出来事の種類のタブには、表から読んだ出来事が呼び名・英名・段階の並び（良い出来事には「依頼なし」）で並び、チェックを外した出来事は起きなくなる。
記録のタブは、記録（世界と主人公の組ごとに1つ）を選んで、一覧と同じ行を日数と数字で並べ、次が起きるまで休んでいる街も出す。
「記録を消す」はゲームを閉じてから使う（起動中に消すと、次のセーブで書き戻される）。

版1 で出来事ごとに切っていた設定は、版2 の「出来事の種類」タブでチェックを外した状態で出る（保存すると新しい設定に移る）。

記録は `state\town_incidents\<世界×主人公>.json` で、同じ世界で主人公を作り直したら引き継がない。

## 困ったとき

| 症状 | やること |
| --- | --- |
| 出来事が起きない | `out\town_incidents.log` の `roll:` の行。行が無ければ抽選の日に届いていないか、外れ。候補の街（訪れたことがありギルドのある街）が無いと起きない |
| 起きたのに何も変わらない | 同じログの `start:` の行。`roll:` だけで `start:` が無ければ、LLM の答え待ち（`mod_town_incidents_text` の行）。答えが返らなければ表の文で始まる |
| 掲示板に依頼が出ない | 同じログの `quest:` の行。`no quest was generated` ならゲームの依頼の生成が失敗した（次に掲示板を開くと作り直す）。良い出来事には依頼が出ない |
| 足した出来事が起きない | 同じログの `WARN kinds:` の行と、設定画面の「出来事の種類」タブの下。理由の出た出来事は飛ばしている |
| 左下の MOD 用のボタンが出ない | `out\modloader.log` の `hud icons:` の行。`icon row was not found` ならゲームのアイコンの列を見つけられなかった |
