# `319_battle_tactics`: 戦闘を複数手の駆け引きにする

素の戦闘は、レベルが上がるほど「先に殴ったほうが一撃で終わらせる」になっていく。
数字を調べたら理由は単純で、ダメージが「攻撃力 − 防御力」の引き算だから
（GAME.md §2.10.2）。攻撃力は武器と一緒にどこまでも伸びるのに、
敵の体力はそこまで伸びない。だから必ずどこかで一撃を超える。

この MOD を入れると、**一撃の大きさは自分の武器と能力（＝火力）で決まる**。
相手が雑魚でもボスでも同じ帯の数字が出て、
硬い相手・格上には通りが悪くなり、**決着の手数は相手の体力なりに決まる**。
雑魚は2〜3発、同格は7発前後、体力の多いボスはそれだけ長持ちする。
「大きい相手ほど大きい数字が出る」ようなことはない。

互角の相手とは自然と数手の殴り合いになる（普通の一撃で体力の15%前後、必殺級でも6割）。
格がまるごと離れていれば一撃は出る。
最強の英雄は初期村の魔物を一撃で払えるし、圧倒的な強敵は駆け出しを一撃で沈める。
一撃を禁じる上限のような細工は無く、全部が1本の式から出る。

## 一撃の重さは AI の審判が裁く

このゲームの戦闘は、毎回の攻撃を AI の審判が見ていて、
「今回の一撃はどれくらい重いか」を5段階で裁いている
（弱い／普通／強い／大技／必殺級。状況が良ければ1.5倍などの補正も付ける）。
素のゲームではこの裁きがほとんど数字に出ていなかった。
この MOD では、裁きが**火力の何%を1発に乗せるか**になる:

| 審判の裁き | 火力の何%か（既定） |
| --- | --- |
| 弱い | 18% |
| 普通 | 30% |
| 強い | 45% |
| 大技 | 65% |
| 必殺級 | 90% |

つまり、戦い方の描写（弱点を突く、体勢を崩してから追撃する）が
審判の裁きを動かし、裁きがダメージを動かす。
最後に1発ごとに ±10%（既定）の揺らぎが乗るので、
同じ相手に同じ手を出しても数字は毎回少しずつ違う。

一撃の数字に上限は無い。格下に振るえば普段と同じ物差しのまま相手の体力を超え、
過剰殺傷がそのまま見える（「スライムに 806 のダメージ（撃破）」）。

## 武器は素直に効く

火力の元は武器と能力（掛けて平方根）なので、武器を強くすれば
どの相手への数字も同じ倍率で伸びる。最弱23から最強500まで替えると約4.7倍:

| 持っている武器 | 雑魚（体力460） | 同格（体力1560） |
| --- | --- | --- |
| 最強クラス（攻撃力500） | 240 → 2手 | 226 → 7手 |
| 上等（攻撃力245） | 166 → 3手 | 156 → 10手 |
| 中くらい（攻撃力96） | 104 → 5手 | 98 → 16手 |
| 初期装備級（攻撃力23） | 51 → 10手 | （挑む装備ではない） |

（実測のキャラクタ、普通の一撃どうし。揺らぎを除いた目安で、実際は ±10% 振れる）

武器を買い替えれば数字がそのまま伸び、難しい土地へ行けば
相手の体力と防御が増えて歯応えが戻る。防具は受けるダメージを減らす。

## 敵の強さと、回復なしの連戦

敵の一撃は控えめ（既定で火力の半分）にしてある。
複数の敵に囲まれても、ダンジョンを回復なしで連戦しても、
削り殺されずに進める:

| 相手 | 1発あたりの被弾（体力1560のとき） |
| --- | --- |
| 格下の雑魚（弱い一撃） | 25 前後 |
| 同格（普通の一撃） | 144 前後 |
| 15レベル上のボス（体力1500、必殺級） | 830。防御すれば 415 |

雑魚の群れとの1戦で減る体力は2割前後。
物足りなければ設定「敵の火力」を上げれば、そのぶん一律に手強くなる。

## レベル差は「格の差」

レベルの離れた相手は、数字の上でもはっきり別格になる:

| レベル差 | 扱い | 効き（既定） |
| --- | --- | --- |
| 10 まで | 適正 | 補正なし。対等の殴り合い |
| 15 | 強敵 | 上の側の与えるダメージ2倍。下の側は半分 |
| 20 以上 | 格が違う | 上の側3倍で、一撃で倒すことがある |

間は徐々に効き始める（1レベルで景色が変わる崖は無い）。
15 上のボスは痛く硬い強敵で、20 上はそもそも勝負にならない。
逆に自分が 20 上なら、駆け出しの獲物は一薙ぎで終わる。
しきい値も倍率も設定で変えられる。

## 同行の仲間はちゃんと戦力になる

仲間と敵の一撃は本人の体力から測る。
仲間の武器が数字に乗らないのは素のゲームも同じで
（NPC は武器を参照しない、という公式の回答がある）、この MOD もそれに合わせている。
体力の低い仲間は相手に合わせて底上げされ、
「その場に立てている一員」として同格の敵をちゃんと削る。
仲間の成長は本人のレベルで効く（宿の訓練で仲間も育てる `306_party_train_exp`
と噛み合う）。

## 毒や能力低下がちゃんと効く

審判は「泥に足を取られて筋力が落ちた」のような状態異常をよく語ってくるが、
素のゲームではそれは**文章だけ**で、数字は1つも動いていない。
この MOD を入れると:

- 毒などの継続ダメージは、ターンごとに体力を削る（ただしそれだけでは死なない。
  とどめは誰かの攻撃で刺す）。`308_battle_damage_display` を入れていれば
  「エリス は 泥の浸食 で 29 のダメージを受けた」と**何によるダメージかまで出る**
- 能力の上げ下げは、与えるダメージ・受けるダメージに響く（±10〜40%）。
  掛かった瞬間に「（筋力低下: 与えるダメージが下がる）」と画面に出る

MOD を外せば元の「文章だけ」に戻る。セーブに余計なものは残らない。

## 「防御」ができる

- 戦闘のスキルのボタンが**「スキル・防御」**になり、開いた一覧に
  「防御」が並ぶ（スキル1・（スキル2）・**防御**・やめる の順）。
  押すと1回の行動を使って身を固め、次に自分が動くまで受けるダメージが
  半分になる。ボスが大技を溜めていそうな場面で使う。
  戦闘画面に直接ボタンを足さないのは、5つ目のボタンが画面右へあふれて
  右側の表示と重なるため
- ボタンを使わず、自由入力に「盾を構えて受ける」のような防御的な文を
  打っても同じ構えになる。描写は審判がそのまま拾う

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| 弱い〜必殺級の強さ | 18/30/45/65/90% | 審判の裁き5段階それぞれが、火力の何%を1発に乗せるか |
| 防具の効きにくさ | 800 | 小さくすると防具が強く効く。防御力がこの値と同じで被ダメほぼ半分 |
| 防御中のダメージ軽減 | 50% | 「防御」してから次に動くまでの被ダメージから引く分 |
| ダメージの揺らぎ | ±10% | 1発ごとの振れ幅。0 で毎回きっかり同じ数字 |
| 敵の火力 | 50% | 敵の一撃の強さ。仲間には掛からない。上げるほど歯応えが増す |
| 適正と見なすレベル差 | 10 | ここまでは互角扱いで補正なし |
| 強敵と見なすレベル差 | 15 | この差で「強敵の倍率」が丸ごと掛かる |
| 格が違うと見なすレベル差 | 20 | この差以上は勝負にならない領域。上の側は一撃で倒すことが多い |
| 強敵の倍率 | 200% | レベルが上の側の与ダメに掛かる。下の側は同じ率で割られる |
| 格が違う倍率 | 300% | 「格が違う」差での倍率 |
| 毒や能力低下をちゃんと効かせる | ON | OFF にすると素のゲームと同じ文章だけに戻る |
| スキル一覧に「防御」を出す | ON | スキルのボタンが「スキル・防御」になる。OFF でも自由入力の防御は効く |

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| ダメージが素のまま大きい | `outattle_tactics.log`。効いた1発ごとに `hit:` の行（火力・レベル・最終値）が出る。代わりに `unmatched` が出ていたら、その戦闘の形をこちらが読めていない ＝ ログを添えて報告 |
| 「防御」がスキル一覧に出ない | 同じログの `guard into the skill list at N:` の行。並んだボタンの一覧が写るので、想定と違う画面ならそのまま報告の材料になる |
| 防御を押しても敵の番が来ない | 同じログの `battle input spec:` の行。`BattlePhaseManager` 以外が写っていたらその画面は未対応で、構えだけ付いて行動は消費されない（`guard button (no turn)`） |
| 状態異常が文章のまま | 同じログに `restored ...` が無ければ、審判がその状態異常に中身を付けてこなかった回（無いものは作らない）。設定の「毒や能力低下をちゃんと効かせる」が OFF になっていないかも見る |
| ダメージの数字を画面で見たい | `308_battle_damage_display` を一緒に入れると、1手ごとに増減が並ぶ |
