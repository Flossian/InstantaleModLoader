# `234_probe_busy_display`

待機表示（選択肢の枠の「…」）を録る。ゲーム標準の「…」と、MOD がローダの `ui.Screen.busy_on` で出す「…」を同じ物差しで並べ、見た目の違いの元を探すための下調べ。ローダの側は `301_quest_from_conversation` がゲームの「クエストを探す」を画面で見て真似たもの（点が `.` → `..` → `...` と約0.3秒で進む・全枠・押せない・送信ボタン無効。VERIFICATION_LOG.md §2.23）で、ゲームがどの仕組みで出しているかは測っていない。ゲームは Nuitka ビルドで中のコードが読めない（`232_probe_facility_choices` の記録）ので、外から録る。見張りは 0.05 秒ごと（メインスレッド）に、左右の選択肢の枠（`hud.buttons` / `hud.right_buttons`）の文字・`disabled`・`opacity`、`is_button_enabled`、`is_adding_text`、`to_display_buttons`、選択肢の数、送信ボタンの `disabled` を読み、**変わったときだけ**前の変化からの秒数つきで1行書く。呼び出しは、選択肢を塗る手（`InstantaleApp.display_button_load` / `InstanTaleHUD.update_button_texts`）、組み直し（`refresh_choice_buttons` / `set_buttons_to_normal`）、場面の区切り（`process_choice`）、送信ボタンの有効・無効、点だけの `add_text` を、スレッド名と呼び出し元つきで残す。MOD が出している区間は、その MOD のログの `busy on` / `busy off` の行（`ui.Screen` が書く。例 `out\real_estate.log`）と時刻で突き合わせる（時刻はミリ秒まで）。版2では背景も録る。見張りに背景の絵（`location_image` のフォルダ名＝場所の名前）を加え、背景を替える手（`change_background_image_to_current_location` / `change_background_image_from_location_id` / `change_background_image_to_inn_room`）と、HUD が絵を差し替える手（`InstanTaleHUD.update_image_source`）を呼び出し元つきで残す（`330_real_estate` の滞在で背景が何度も切り替わった件の裏取り。原因と見た `modfacility` の保存のあいだの差し替えは外してある）。読む用は `out\busy_display.log`、数える用は `out\busy_display.jsonl`。ゲームは変えない（200番台の約束どおり読み取りだけ。どの包みも `orig` の戻りをそのまま返す）
