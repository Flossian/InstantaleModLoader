# `341_shopkeeper_attitude`: 店主の人柄と主人公との関係で売買の値段が変わる

素のゲームの店は、誰が来ても同じ値で売り買いする。
この MOD を入れると、店主の性格・主人公との関係・それまでの記録から、店主がどう応じるかを LLM が決め、値段が動く。

```text
〈店主の名前〉は「あんたには世話になったからな」と、帳面の数字を書き直した。（買値 -10%・売値 +10%）
```

## 決まり

| 場面 | 応じ方 | 値段 |
| --- | --- | --- |
| 平時 | 負ける | 買値が下がり、売値が上がる |
| 平時 | 普段どおり | いつもどおり（何も出ない） |
| 平時 | ふっかける | 買値が上がり、売値が下がる |
| 手配中 | 怯える | 買値が下がり、売値が上がる |
| 手配中 | 動じない | いつもどおり |
| 手配中 | 足元を見る | 買値が上がり、売値が下がる |

- 判定の材料は、店主の性格・プロフィール・口調・主人公との関係と感情・好感度・会話した回数・人生ログ。手配中は手配度も
- 性格や関係に根拠が無ければ、平時は普段どおり、手配中は怯える
- 手配中の場面は `336_crime_overhaul` が入っているときだけ。率は 336 の「店が委縮して値を下げる」の設定（手配の重さ × 0.5%、上限 30%）に従い、336 自身は値段を動かさなくなる
- 判定は店に着いたときに裏で頼む。売買を押した時に済んでいなければ、待機表示を出して待つ
- 同じ店主の応じ方は 30 日のあいだ変わらない。好感度か手配度が変われば決め直す
- 初めて決まったときは店主の反応の1文が出る。2回目からは決まった文と値段の動き
- LLM が答えなかったときは、平時は普段どおり、手配中は好感度 40 以上なら動じない、下なら怯える
- MOD の人物が主の施設（`330_` の管理人・`331_` の主人）は判定せず、決まった決め方で応じる
- 値段はその場だけ動き、セーブには焼き付けない

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| 手配されていない土地でも値段が動く | ON | 切ると手配中の土地だけ働く |
| 平時に負ける・ふっかける率（%） | 10 | 手配中の率は 336 の設定 |
| 売値も動かす | ON | 切ると買値だけ |
| 売買を押したら知らせる | ON | 平時の普段どおりは出さない |
| 応じ方を決め直すまでの日数 | 30 | 好感度か手配度が変われば、日数の前でも決め直す |
| 判定が無いとき手配中でも動じない好感度 | 40 | 40 は「多少の好意がある」 |

## 他の MOD との重なり

| MOD | どうなるか |
| --- | --- |
| `336_crime_overhaul` | 手配中の店の値段は、この MOD が店主の応じ方で動かす（336 の怯える1行と値下げは出なくなる） |
| `337_conversation_affinity` | 会話で好感度が動くと、次に店に入ったとき応じ方を決め直す |
| `340_inn_shop` | 宿屋の「売買する」でも同じように働く |
| `405_regional_economy` | 値段の上げ下げは掛け算で重なる |

## 困ったとき

| 症状 | やること |
| --- | --- |
| 値段が動かない | `out\shopkeeper_attitude.log` の `shop [usual] … usual` か `fallback`。判定が普段どおりか、LLM が答えていない |
| 売買を押すと待たされる | 店に着いてすぐ押した。`[waited]` の行。裏の判定が終わるのを待っている |
| 判定が出ない | `no usable answer` の行。LLM の答えが読めなかった |
