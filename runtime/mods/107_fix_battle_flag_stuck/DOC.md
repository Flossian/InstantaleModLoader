# `107_fix_battle_flag_stuck`: 戦闘と売買の後に残る「最中」の印を下ろす

戦闘が終わっても「戦闘中」のフラグが下ろされないことがあり、残ったフラグが次の場面に効いてしまう。この MOD は戦闘の終わりとロードの直後に、残っているフラグを下ろす。戦闘の最中に保存したセーブは、ロードの後に戦闘の画面へ戻ったときだけ触らない（場所の画面になったときは、フラグと一緒に残った敵も片付ける）。

いちばん重い症状は闘技場からの撤退で起きる。撤退すると「闘技場で戦っている」のフラグが残り、次の戦闘の終わりにゲームがそのフラグを見て闘技場用の後始末を選ぶ。闘技場に立っていないので処理が途中で止まり、画面は待機表示（`...`）のまま進まなくなる。

`in_battle`（戦闘中のフラグ）のほうは本体が main_024 で直したので、この MOD は普段は何もしない。闘技場のフラグは本体が直していないので、こちらで下ろす。

逃げる手で審判が敵も倒すと、ゲームは逃走ではなく勝ちとして試合を終える。
逃げた者（主人公も）は逃げる手で一覧から外されて預けられたままになり、勝ちの終わり方はそれを戻さないので、主人公が画面から消える。
この MOD は戦闘の終わりとロードの直後に、預けられたままの者を一覧へ戻す。

売買の画面を開くと「売買中」のフラグが立ち、ゲームは画面を閉じても店を出ても下ろさない。
フラグはセーブにも残るので、一度でも売買した世界ではずっと立ったままになる。
ゲーム自身はこのフラグを使わないが、フラグを見て選択肢を出し分ける MOD は、店に寄った後ずっと選択肢を出さなくなる。
この MOD は画面を閉じたときとロードの直後に、このフラグを下ろす。

## 困ったとき

| 症状 | やること |
| --- | --- |
| 闘技場で撤退した後、次の戦闘が終わらない（`...` のまま） | 入れ直す。次の戦闘から直る。既に止まってしまった場面はセーブを読み直す |
| ロードすると戦闘BGMで始まる | 入れ直す。読み込んだ時点で直る |
| 一度戦闘したらNPCから話しかけられなくなった | 同上（同じ原因） |
| 逃げたのに勝ちになり、主人公が画面から消えた | 入れ直してセーブを読み直す。読み込んだ時点で主人公が一覧へ戻る |
| 店に寄った後、別の MOD の選択肢が出なくなった | 入れ直す。入れた時点でフラグが下りる |
