# `107_fix_battle_flag_stuck`: 闘技場から撤退した後に次の戦闘が固まるのを直す

戦闘が終わっても「戦闘中」の印が下ろされないことがあり、残った印が次の場面に効いてしまう。この MOD は戦闘の終わりとロードの直後に、残っている印を下ろす。

いちばん重い症状は**闘技場からの撤退**。撤退すると「闘技場で戦っている」の印が残り、次の戦闘の終わりにゲームがその印を見て闘技場用の後始末を選ぶ。闘技場に立っていないので処理が途中で止まり、画面は待機表示（`...`）のまま進まなくなる。

`in_battle`（戦闘中の印）のほうは本体が main_024 で直したので普段は出番が無く、この MOD は無音で素通りする。闘技場の印は本体が直していないので、こちらで下ろす。

## 困ったとき

| 症状 | やること |
| --- | --- |
| 闘技場で撤退した後、次の戦闘が終わらない（`...` のまま） | 入れ直す。次の戦闘から直る。既に止まってしまった場面はセーブを読み直す |
| ロードすると戦闘BGMで始まる | 入れ直す。読み込んだ時点で直る |
| 一度戦闘したらNPCから話しかけられなくなった | 同上（同じ原因） |
