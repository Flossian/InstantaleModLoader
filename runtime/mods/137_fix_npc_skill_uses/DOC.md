# `137_fix_npc_skill_uses`: 仲間と敵は使い切ったスキルと効果中の強化・弱体を使わず、宿で休むと回数が戻る

スキルには使える回数があり、ゲームは使うたびに残りを減らす。
プレイヤーは残りが 0 になると選べなくなるが、仲間と敵には止めが無い。
仲間と敵の手は AI の審判がスキル一覧から選ぶ。一覧には残りがマイナスのスキルもそのまま載り、審判はそれを選び続ける。
実際に、仲間が効果の見えない自己強化を毎手繰り返して一度も攻撃しない戦闘や、ボスが全体の弱体化を回数を越えて使い続ける戦闘が出た（残りは −23 と −2 まで減っていた）。
回数の残っているうちも同じで、仲間は強化を使い切るまで毎手重ねがけし、その間は戦力にならなかった。

この MOD を入れると:

- 残りが 0 以下のスキルは、審判に見せない。仲間も敵も、使い切ったら通常攻撃やほかのスキルで戦う。
  通常攻撃と、回数に上限の無いスキル（逃げるなど）は常に残る
- 強化・弱体だけのスキル（自分の敏捷を上げる、敵の賢さを下げる など）は、一度使うと効果の続く手番数（スキルの期限。書かれていなければ3手番）のあいだ審判に見せない。
  重ねがけせずに攻撃へ移り、効果が切れたらまた使える。数えるのはその者の手番で、戦闘が変わると数え直す
- 仲間の回数は、宿屋で休養をとったときに上限まで戻る。クエストの終わりや訓練では戻らない。
  ゲームは仲間の回数を戻さないので、この MOD が戻す
- プレイヤーの回数はゲームのまま（ゲームがクエストの終わりから宿屋の休養までの間に戻している。どちらで戻すかは測っていない）
- 敵は戦闘ごとに作り直されるので、戻す必要が無い

入れる前の戦闘で残りがマイナスになっていた仲間のスキルは、次に宿屋で休養するまで使われない。

素のゲームでは、スキルの強化・弱体は文章だけで数字は動かない。
`319_battle_tactics` を一緒に入れると、強化・弱体が状態異常として付き、期限の間ダメージの出入りに効く。

審判に見せないのは審判を呼んでいる間だけで、スキルそのものは消さない。
その間にセーブが走っても、セーブには全部のスキルが入る。MOD を外せば元どおり。

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 仲間が回数を越えてスキルを使う | `out\npc_skill_uses.log` に `hid from the referee: spent=[…]` の行が出ているか。出ていなければ、その手は別の審判の経路を通っている ＝ ログを添えて報告 |
| 仲間が強化を続けて使う | 同じログに `used … (buff/debuff); resting it for N turn(s)` と、次の手の `resting=[…]` が出ているか。そのスキルに攻撃の効果も入っていると外さない |
| 休んでも仲間のスキルが戻らない | 同じログに `rest:` の行が出ているか。宿屋の「休養をとる」で戻る。訓練や社交では戻らない |
