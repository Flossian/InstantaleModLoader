# `116_ui_party_expand`: 4人目以降の仲間も表示する

仲間を3人雇って4人パーティになっても、画面右のパーティ欄には3人までしか出ない。
ゲームが欄の枠を3つしか作らないため。
名簿から漏れているわけではなく、会話と戦闘は4人目を含めて進んでいる。

4人目が居るときだけ、パーティ欄のすぐ上に小さなボタンが1つ出る。
押すと欄が上へ伸びて足りないぶんの枠が現れ、もう一度押すと元の3枠に戻る。
1人ぶんの大きさは変わらない（欄が伸びるだけ）。
増えた枠も押せば、その仲間との会話に入る。

元から出ている3人の枠は1ドットも動かない。
増えた枠にはゲームと同じ枠線が付く。
仲間を雇った・別れた・入れ替えたときは、その場で枠の数と中身が追う。

広げると、そこに元から在ったものが欄の下に入る。
始末は相手によって2通り。

- ゲームの選択肢ボタンには触らない。
  代わりに、新しく覆った場所を黒い板で塞ぐ。
  下の文字は透けず、
  そこを押しても板で止まる（欄の枠を押したときは今までどおり会話に入る）。
  戻すと板を外すだけなので、ゲーム側の状態は一切書き換わらない
- 他の MOD が足したボタン（既定では `113_ui_text_expand` の切り替えボタンがちょうどこの位置に出る）は、
  広げている間だけ見えなくなり押せなくなる。
  戻すと元に戻る

| 設定 | 意味 |
| --- | --- |
| 広げたときに出す人数の上限 | 既定 8。画面に入る行数のほうが少なければそちらで頭打ち |
| 広げている間、重なるボタンを隠す | 既定 ON。OFF にすると、隠れたボタンがそのまま押せる状態で残る |
| 足した枠の立ち絵の入れ方 | 枠に収める（既定・縦横比のまま枠内に収める）／枠いっぱい（縦横比を無視して枠を埋める。元の3枠は絵を切り取って埋めているので、そちらに近づけたいとき） |
| ボタンの置き場所 | 帯の上（既定・右寄せ）／帯の右上（欄の内側）／右上／左上／右下／左下 |
| ボタンの絵柄 | 二重山形（既定）／山形／矢印／人／枠／文字。背景なしの白い線で描き、押すと上下が入れ替わる |
| アイコンの線の太さ・濃さ | 既定 2.0px / 0.85 |
| ボタンの大きさ | px（既定 32） |
| ボタンの文字 | 絵柄に「文字」を選んだときだけ使う（広げる前「仲間」／広げた後「戻す」） |
| 収まっているときもボタンを出す | 既定 OFF（3人までのときは出さない） |
| 最初から広げておく | 既定 OFF |

名簿・セーブ・戦闘には触らない。
増やした枠は、今そこに在る枠を実行時に複製して作る。
見つけた欄の構成と、複製した枠に誰を入れたかは `out\party_expand.log` に出る。
4人目の枠が空のまま出るときは、そのログの `cell fields:` の行を見ると、
枠のどこに何を入れているかが分かる。
