# `324_place_bgm`: 施設と土地のBGMを置いた曲から選んで鳴らす

素のゲームの BGM は土地に1曲ずつ決まっていて（セーブの `areas[id]["bgm"]`）、
宿屋に入ってもギルドに入っても同じ曲が鳴り続ける。
曲を足す手段も、比率で選ばせる手段も無い。

この MOD を入れると、施設に入ったときはその施設の種類の曲を、通りに居るときはその土地の種類の曲を、
置いてある曲から重みで1曲選んで鳴らす。
戦闘の曲は触らない（`322_battle_bgm` の領分）。

| 場所 | 何を置くか |
|---|---|
| `<ゲーム>\Assets\sounds\musics\` | 素の曲が居る場所（`town\calm\…` のように2段。直下の単発曲も含む）。`battle\` は戦闘曲なので見ない |
| `<ローダ>\state\musics\place\` | 足したい曲を置く場所。下にフォルダを切ってよい |

対応は `.mp3` / `.ogg` / `.wav`。
曲は `musics\` からの相対パス（`town\calm\曲.mp3`）で見分け、同じ相対パスが両方にあれば `state\` 側が鳴る。

曲を置いただけでは**鳴らない**。設定画面で「使う」に入れた曲だけが候補になる。
何も入れていない種類の施設では土地の曲がそのまま続き、何も入れていない種類の土地では素の曲が鳴る。
つまり入れただけでは何も変わらず、決めたところだけが変わる。

## どの曲が鳴るか

いま居る場所から上の段へ順に見て、候補が1曲でもある段の重みで選ぶ。

| 段 | 何で決まるか | どこに書くか |
|---|---|---|
| 1 | その施設（土地 id と施設 id） | `state\musics\place\worlds\<世界>.json` の `facilities`（画面の「ワールド個別設定」） |
| 2 | 施設の種類（宿屋・ギルド・雑貨店 …） | `playlist.json` の `inn` / `guild` / `general_store` … |
| 3 | その土地（土地 id） | 同 `worlds\<世界>.json` の `areas`（同上） |
| 4 | 土地の種類（町・村・都市・ダンジョン） | `playlist.json` の `area:town` / `area:village` / `area:city` / `area:dungeon` |
| 5 | どこにも無い | 素の曲（土地に焼き付いた曲） |

施設の段が土地の段より常に先。
ある町の曲を個別に決めていても、その町の宿に入れば宿の曲になる。
通路（入口・出口・区画・ダンジョンの場所）は施設の段を持たない。
段は混ざらず、勝った段の重みだけで抽選する。
この優先順位の図解が MOD のフォルダの `priority.html` にある（ブラウザで開く読み物）。

曲が変わるのは場所が変わったときだけ。
宿に入れば宿の曲、通りへ出れば土地の曲に戻り、通りから通りへ歩いても曲は続く。
土地の曲は最初に選んだものをその土地の曲として覚え、次に来たときも同じ曲が鳴る
（素のゲームと同じく土地に曲が付く）。
施設は入るたびに選び直す。どちらも設定で変えられる。
依頼で入るダンジョンは1回きりの土地なので覚えない。

## 設定画面

ローダの設定画面でこの MOD を選んで「設定…」を押すと、この MOD の画面が開く（TECH.md §3.12）。
直接 `python runtime\mods\324_place_bgm\tool.py` で開いてもよい。

- 左はタブ2つ。「一括設定」は場所の種類の一覧（施設 13 種、土地 4 種）、「ワールド個別設定」はセーブの世界 → 土地 → 施設の木。
  どちらも選ぶと右がその場所の選曲になり、「使う曲」の列に入れた曲の数が出る
- 「ワールド個別設定」は一括設定より先に見る指定。その町だけ・その宿だけの曲を決める。
  世界を開くとセーブ（`savedata.json`）を読んで土地と施設を並べる（通路は出さない。依頼のダンジョンは「ダンジョン（N）」に畳む）。
  施設は初訪問で作られるので、まだ行っていない町の施設は並ばない（GAME.md §2.31）。
  本体が土地に覚えた曲は右の見出しに出て、「覚えた曲を消す」で次に入ったとき選び直す。
  セーブは読むだけで書かない。書くのは `state\musics\place\worlds\<世界>.json`
- 右は左右2段で、左が置いてある曲の全部（曲名・フォルダ・置き場）、右がその場所で使う曲（曲名・フォルダ・置き場・重み・確率）。
  左をダブルクリック（または「使う >>」）で右へ入り、右をダブルクリック（または「<< 外す」）で外れる
- 右で選んだ曲の重みは下の欄で変える。確率の列は重みの合計に対する割合をその場で出す
- 一覧の上の欄で列ごとに絞り込める（曲名は部分一致、フォルダと置き場は選択、重みは下限）。
  絞り込みは表示だけを変え、「全て使う / 全て外す」は表示中の曲だけに効く。
  「町の calm を全部使う」はフォルダで `town/calm` に絞って「全て使う」の2手
- 「保存」で `state\musics\place\playlist.json`・`settings\mod_settings.json`・開いた世界の `worlds\<世界>.json` に書く。
  ゲームを起動したまま保存しても次の移動から効く。世界のファイルは本体も書く（覚えた曲）ので、保存の直前に読み直して指定の分だけ差し替える
- セーブの置き場は `%LOCALAPPDATA%\Darmabeko\Instantale\saves\`。別の場所なら環境変数 `IML_INSTANTALE_DATA` で指す（`323_` と同じ）
- 窓の大きさと位置は覚える（`settings\gui.json` の `tool_window`）

| 種類 | 鍵 | いつ |
|---|---|---|
| 宿屋 / ギルド / 雑貨店 / 専門店 / 鍛冶屋 / 医療施設 / 役場 / 裏の事務所 / 闘技場 / 奴隷市場 / 訓練施設 / 名所 / 自由生成施設 | `facility_type` そのもの | その施設に入っている間 |
| 町 / 村 / 都市 / ダンジョン | `area:town` / `area:village` / `area:city` / `area:dungeon` | 通路に居るとき、または施設の段に候補が無いとき |

| 設定 | 意味 |
| --- | --- |
| 「使う」に入れたときの重み | 既定 100。設定画面で曲を右（使う）へ入れたときの初期値 |
| 前回と同じ曲を続けて選ばない | 既定は入。同じ種類の場所で候補が2曲以上あるときだけ効く。覚える場所には効かない |
| 土地の曲は一度決めたら覚える | 既定は入。切ると土地に入るたびに選び直す |
| 施設の曲は一度決めたら覚える | 既定は切。入れるとその宿・その店ではいつも同じ曲が鳴る |

## 重みの意味と `playlist.json`

重みは比率で、同じ種類の合計に対する割合が確率になる。合計を 100 に揃えれば書いた数字がそのままパーセント。
`0` か無ければその種類では鳴らない。

画面を使わず `state\musics\place\playlist.json` を直接書いてもよい。

```json
{
  "playlists": {
    "inn":       {"宿.mp3": 100, "town/calm/Medieval Vol. 2 4 (Loop).mp3": 50},
    "guild":     {"guild/酒場.ogg": 100},
    "area:town": {"town/calm/The Streets of Baerlon.mp3": 100, "town/lively/Thought and Memory_44.1kHz_16Bit_4-4_T92_Loop.wav": 100}
  }
}
```

- 鍵は `musics\` からの相対パスをスラッシュ区切りで。`state\musics\place\宿.mp3` なら `宿.mp3`、`state\musics\place\guild\酒場.ogg` なら `guild/酒場.ogg`
- ファイルにあって曲が無い行は消さない（曲を一時的に外しても数字が残る）
- 起動時にファイルが無ければ、全種類が空の形で作られる

## 覚えた曲と `worlds\<世界>.json`

土地ごとに覚えた曲は `state\musics\place\worlds\<世界名>.json` に入る。

```json
{
  "areas": {
    "7": {"name": "陽光の砦", "chosen": {"level": "area:town", "track": "town/calm/The Streets of Baerlon.mp3"}}
  },
  "facilities": {}
}
```

ある土地の曲を選び直したいときは、画面の「覚えた曲を消す」（またはその土地の `chosen` を消す）で次に入ったとき選び直す。
`playlist.json` からその曲を外したときも選び直す（覚えた曲が候補に無くなるため）。
同じファイルの `playlist` が「ワールド個別設定」の中身で、その土地・その施設だけの曲になる。
施設の鍵は `土地id/施設id`（施設 id は土地の中でしか一意でない。GAME.md §2.7）。
世界名を変えると控えが行方不明になる（`311_` と同じ制約）。

## `104_balance_area_bgm` との関係

`104_` は新しく作られた土地の `bgm` をセーブに書き換えて偏りを均す。
この MOD は鳴らす瞬間に選ぶので、セーブには書かない。
両方入れても衝突しない（`104_` が均した曲は、この MOD で何も指定していない場所の「素の曲」として鳴る）。

この MOD だけで同じ「偏らない土地の曲」を作るには:

1. 設定画面の「町」で、フォルダを `town/calm` … と順に絞って「全て使う」（村・都市・ダンジョンも同様）
2. 「土地の曲は一度決めたら覚える」は入のまま

土地に最初に入ったときにその種類の全曲から選ばれ、以後その土地の曲になる。
`104_` と違って**既に知っている土地の曲も一度だけ変わる**点と、
選び方が「使用回数の最少優先」ではなく重みの抽選である点が残る差
（詳細と `104_` を将来終えるための条件は VERIFICATION.md §3.48）。

## 困ったとき

ログは `out\place_bgm.log` の `[PLACEBGM]` の行。
曲を決めるたびに1行で、鳴らした曲・決めた段・決め方（`picked` / `remembered` / `kept`）・
そのときの土地と施設・きっかけ（`by game` / `by move_phase` / `by poll`）が並ぶ。

| 症状 | やること |
|---|---|
| 曲が変わらない | `[PLACEBGM]` の行が出ているか。出ていなければ `out\modloader.log` の `applied` にこの MOD があるか（無効化していないか） |
| `no candidate` と出る | その場所の段に「使う」に入れた曲が無い。行の `area`/`fac` の種類と、画面で入れた種類を見比べる |
| `FAILED` と出る | ファイルは在るが鳴らせなかった。`out\modloader.log` の直前の ERROR に例外がある。形式が対応外 |
| 施設に入っても曲が変わらない | 行が `by move_phase` で出ているか。出ていて `fac ?` なら実行時に施設が引けていない。行そのものが無ければ `move_phase` に当たっていない |
| 通りを歩くたびに曲が頭から鳴る | 行の段と場所が毎回変わっている。`area ?` なら実行時に土地 id が引けていない |
| 土地に入るたびに違う曲になる | 「土地の曲は一度決めたら覚える」が切れているか、`worlds\<世界>.json` に書けていない（`modloader.log` に `控えを書けなかった`） |
| `playlist.json の … にある曲が見つからない` | 曲を消したか名前を変えた。行を消すか名前を直す |
| 曲を足したのに一覧に出ない | 拡張子が対応外か、`battle\` の下に置いている。画面なら「再走査」 |
| ワールド個別設定に世界が並ばない | セーブの置き場が見つかっていない。画面の下の行に探した場所が出る。別の場所にあるなら環境変数 `IML_INSTANTALE_DATA` で指す |
| ワールド個別設定で決めたのに効かない | 行の段が `world:facility:…` / `world:area:…` になっているか。なっていなければ世界名が違う（`worlds\` のファイル名とログの世界名を見比べる）か、その場所の指定に候補が無い |
| 「設定…」を押しても画面が開かない | 設定画面の下の状態行を見る。`tool.py` が無いか、Python が tkinter を持っていない |
